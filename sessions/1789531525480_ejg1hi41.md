#### fugleramme

E-ink bird frame for Raspberry Pi - real-time bird detection by audio, fully local AI, rendered as real, hand-cut 1800s bird illustrations.

The frame on a kitchen windowsill showing six birds heard in the garden, a window feeder on the glass behind it  
*Sorry about the dirty window - squirrels have been stealing the bird food.*

Live on **[fugleramme.arnegiacomo.dev](https://fugleramme.arnegiacomo.dev)** running from my kitchen window and displaying the actual birds currently heard in my garden (Bergen, Norway).

Hardware, install and operations docs: **[arnegiacomo.dev/fugleramme](https://arnegiacomo.dev/fugleramme/)**

[BirdNET-Go](https://github.com/tphakala/birdnet-go) listens on a mic and handles the classifier. Fugleramme polls its api, matches each species to an illustration, then packs them onto a page, and redraws only when the birds change - on an [Inky Impression](https://shop.pimoroni.com/products/inky-impression) e-ink panel, and as a web kiosk serving the same view. There's an admin page that lets you configure what to show, and automatic updates and such.

If you already run BirdNET-Go, point the frame at it instead - on the same machine or anywhere else reachable from your network.

#### Hardware

A Raspberry Pi 5, an [Inky Impression 13.3"](https://shop.pimoroni.com/products/inky-impression) (Spectra 6), a mic and an A4 frame. Full parts list, recommendations and alternatives: **Hardware**.

#### Art

Half the point of this project is showing off some amazing public-domain natural-history illustrations. Over 800 cut-outs covering more than 400 species, every one taken from a real plate and hand-curated for this project (no art is AI-generated, though some has been retouched with AI).

Each detected species is matched to its illustration, background-removed, and packed onto a textured paper page with the larger birds toward the centre, sized by body mass. An empty window shows a bare perch.

The plates are Scandinavian, British and central European, so the Nordics, the British Isles and Germany are best covered. Elsewhere not so much (yet). Broader European and North American coverage is in the works!

See Adding artwork for manual cutout steps.

From the pi (assuming you have the hardware up and running):

```
curl -fsSL https://raw.githubusercontent.com/arnegiacomo/fugleramme/main/install.sh | bash
```

Asks where BirdNET-Go should live and which ports to use, clones the repo, installs the required deps, and starts the frame as a systemd service. **NB!** Will probably require a reboot on a fresh system.

From a blank SD card, see the full install guide.

```
docker run -d -p 8080:8080 -v fugleramme:/data \
  -e FUGLERAMME_DETECTOR_URL=http://birdnet.local:8080 \
  ghcr.io/arnegiacomo/fugleramme
```

Or build the image from a checkout:

```
docker build -t fugleramme .
docker run --rm -p 8080:8080 -v fugleramme:/data \
  -e FUGLERAMME_DETECTOR_URL=http://birdnet.local:8080 fugleramme
```

Kiosk on `:8080`, admin on `:8080/admin`, everything it persists in `/data`.

On a Linux box with a USB mic, this brings up BirdNET-Go alongside it:

```
curl -fsSL https://raw.githubusercontent.com/arnegiacomo/fugleramme/main/examples/docker-compose.yml -o docker-compose.yml
docker compose up -d
```

See **Container** for more info.

#### Fugleramme：用本地 AI“听见”鸟类的电子墨水画框

Fugleramme 是一款面向树莓派的开源鸟类展示系统：它通过麦克风实时识别周围鸟鸣，再把对应鸟种以19世纪自然史插画呈现在电子墨水屏上。识别和展示可完全在本地运行，也能通过网页查看和管理。

##### 工作原理：从鸟鸣到插画

系统由 BirdNET-Go 和 Fugleramme 两部分配合：

1. **BirdNET-Go** 监听麦克风，用 AI 根据鸟鸣识别鸟种。
2. **Fugleramme** 定期读取其 API，将鸟种匹配到对应插画。
3. 系统自动去除插画背景，并将多只鸟排版到带纸张纹理的页面上：
   - 体型较大的鸟更靠近画面中央；
   - 插画大小依据鸟类体重调整；
   - 鸟种发生变化时才刷新电子墨水屏；
   - 没有识别结果时，画面只显示空栖木。

同一画面还能作为网页看板展示，并提供管理页面，用于配置显示内容和自动更新等功能。如果用户已有 BirdNET-Go，可直接连接同一设备或局域网中的现有实例。

##### 插画特色：真实古籍素材，而非 AI 生成

项目收录了 **800 多张手工抠图，覆盖超过 400 个鸟种**。所有图像均来自真实的公共领域自然史图版，由项目人工筛选和整理；插画本身不是 AI 生成，但部分素材使用 AI 做过修复。

目前素材主要来自斯堪的纳维亚、英国和中欧图鉴，因此对以下地区覆盖较好：

- 北欧
- 不列颠群岛
- 德国

其他地区覆盖相对不足，项目正在扩展欧洲其他地区及北美鸟种。

##### 硬件与展示方式

作者使用的主要硬件包括：

- Raspberry Pi 5
- Inky Impression 13.3 英寸 Spectra 6 彩色电子墨水屏
- 麦克风
- A4 相框

电子墨水屏适合长期静态展示，且系统只在检测到的鸟类发生变化时重绘。项目还提供网页看板；作者的在线实例展示的是其挪威卑尔根住所附近实时听到的鸟类。

##### 安装与运行

项目支持多种部署方式：

- **树莓派安装脚本**：自动询问 BirdNET-Go 的位置和端口，下载项目、安装依赖，并注册为 `systemd` 服务；全新系统可能需要重启。
- **Docker**：可直接运行官方容器，并通过环境变量指定 BirdNET-Go 地址；网页看板默认位于 `:8080`，管理页面位于 `:8080/admin`。
- **Docker Compose**：在带 USB 麦克风的 Linux 主机上，可同时启动 Fugleramme 和 BirdNET-Go。
- **开发环境**：项目提供模拟检测器，无须树莓派或真实 BirdNET-Go 也能开发和测试。

##### 灵感与项目定位

作者希望把墙上的传统鸟类海报变成一幅“只展示花园里当前真实鸟类”的动态画框。其视觉风格受到 Axel Thorenfeldt 的 WWF 自然海报启发，实时画框概念参考了 AvianVisitors，识别能力则来自 BirdNET-Go。

仓库还列出了若干相似项目，但明确说明 Fugleramme 未与它们共享代码或美术资源。

##### 开源贡献与许可

项目欢迎提交错误修复、文档改进和新鸟类插画：

- Bug 可提交问题报告；
- 使用疑问、创意或成品展示可在阅读 FAQ 后进入 Discussions；
- 修复、文档和插画可直接提交 PR。

主要许可并不完全一致：

- Fugleramme 代码：**MIT**
- BirdNET-Go 检测部分：**CC BY-NC-SA 4.0，仅限非商业用途**
- 鸟类插画：各素材目录分别标注来源和许可
- 字体、鸟类体重和分类学别名数据：分别采用对应的开放许可

因此，虽然主体代码较宽松，但实际部署或再发布时仍需同时遵守鸟鸣识别模型、插画和数据集各自的授权条件。

## 口播总结（1）

### 2026-09-17 00:10:54

Fugleramme 是一个把鸟鸣识别、电子墨水屏和十九世纪自然史插画结合起来的开源项目。它不会用摄像头追踪鸟，而是通过麦克风倾听周围的声音，在本地识别鸟类，再把刚刚听到的鸟，绘制成一幅不断变化的复古鸟类画册。

整个系统分成几个环节。首先，麦克风采集环境声音。一个名为 BirdNET-Go 的鸟鸣识别工具负责分析音频，并判断可能出现了哪些鸟。这个分类过程可以完全在本地运行，音频不必上传到云端。

接下来，Fugleramme 会定期读取 BirdNET-Go 的识别结果，为每一种鸟寻找对应的插画。然后，它把这些鸟排版到一张带有纸张纹理的画面上，再显示到电子墨水屏，或者同步展示在网页看板中。

这里有一个重要区别：画面展示的是系统最近“听到”的鸟，不一定是摄像头真正“看到”的鸟。因此，它更像一扇声音驱动的自然观察窗口。

项目的视觉设计，是它最有特色的部分。目前素材库收录了八百多张鸟类剪影，覆盖四百多个物种。所有鸟图都来自真实的公共领域自然史图版，并由人工挑选和抠图。图像本身不是人工智能生成的，不过其中一部分经过了人工智能辅助修整。

排版也不是简单地把鸟图堆在一起。系统会参考不同鸟类的体重，调整它们在画面中的尺寸。较大的鸟通常更靠近中央，从而让整张画既有视觉重心，也能大致体现物种之间的体型差异。当花园里只听到几种鸟时，画面会比较疏朗；鸟类增多后，画面就会像一本内容丰富的自然观察图鉴。如果暂时没有识别到鸟，屏幕上只留下一根空荡荡的栖木。

电子墨水屏不会持续播放动态画面。只有当检测到的鸟类发生变化时，Fugleramme 才会重新排版和刷新。这样一来，画框保持了纸质插画的静态质感，同时又能反映花园里正在发生的变化。

作者实际运行的版本放在挪威卑尔根的厨房窗边，展示花园里当下能够听到的鸟。这个创意来自作者墙上的一张世界自然基金会鸟类海报。他希望那张固定不变的海报，能够变成一幅只展示自家花园真实访客的“活画框”。

不过，插画素材的覆盖范围并不均衡。现有图版主要来自斯堪的纳维亚、英国和中欧，因此北欧、英伦群岛和德国的鸟类覆盖最好。其他地区的物种可能无法匹配到合适插画。项目正在扩充更广泛的欧洲和北美鸟类素材。

硬件方面，作者使用的是树莓派五代、一块十三点三英寸的 Inky Impression 彩色电子墨水屏、一个麦克风，以及一个四开大小的相框。BirdNET-Go 负责鸟鸣分类，Fugleramme 则负责读取结果、匹配插画、完成排版和控制显示。两者可以运行在同一台设备上，也可以分开部署。已经安装 BirdNET-Go 的用户，只要让画框连接到网络中可访问的识别服务即可。

除了实体电子墨水屏，系统还会提供相同画面的网页版本。管理页面可以配置要显示的内容，并处理自动更新等操作。因此，即使暂时没有树莓派或电子墨水屏，也可以先在普通电脑或服务器上运行网页看板。项目提供自动安装脚本，也支持通过 Docker 容器部署。

在授权方面，需要把不同部分分开看。Fugleramme 自身的代码采用宽松的 MIT 许可证。但单独安装的 BirdNET-Go，以及它所使用的鸟鸣识别模型，有非商业使用限制。鸟类插画、字体、体重数据和物种别名资料，也分别保留各自的来源与授权条款。如果要制作商业产品，不能只看主程序的开源许可证，还必须逐项核对检测模型和艺术素材的使用条件。

这个项目最值得记住的，不只是“用人工智能识别鸟”。它真正有趣的地方，是把本地声音识别、历史自然史插画和实体画框连成了一个完整体验。你听不到机器分析的过程，只会看到一幅安静的复古画面，随着花园里的鸟鸣悄悄改变。

## 深度解读（1）

### 2026-09-17 00:43:12

#### Fugleramme：AI 最自然的形态，可能不是聊天框，而是一幅会变化的画

Fugleramme 的技术并不新奇：树莓派与麦克风收集环境声音，BirdNET-Go 在本地识别鸟类，程序调用结果并匹配插画。但它真正值得关注的地方，是把一条常见的 AI 能力链，做成了一个**无需主动使用、却能持续改变人对环境感知的日常物件**。

##### 它展示的不是识别结果，而是“此刻的花园”

项目没有采用监控面板、物种列表或置信度曲线，而是把当前听到的鸟排成一幅十九世纪自然史图鉴：超过 800 张手工处理的公共领域插画，覆盖 400 多个物种；鸟的大小参考真实体重，较大的鸟靠近画面中央；没有检测结果时，只留下空栖木。电子墨水屏也只在物种变化时刷新。

这些设计把“模型输出”转换成了一个可被直觉理解的场景。用户看到的不是“系统以 87% 概率识别到某物种”，而是“今天谁来过花园”。**AI 在这里不是交互主体，而是维持作品与现实同步的后台能力。**

这也是一种比“给产品加 AI 入口”更有迁移价值的思路：先找到现实中缓慢变化、值得被长期感知的状态，再选择适合它的表达媒介。空气质量、潮汐、社区声景、家庭能耗，都可能适合类似的环境式界面；但前提是信息变化频率低、长期观看有意义，否则电子墨水与被动展示只会削弱即时性。

##### 决定体验的重投入，不在模型而在编辑

项目复用了 BirdNET-Go，检测器与展示层通过 API 解耦，甚至可以运行在不同机器上。代码层面的核心并不是训练新模型，而是物种别名、图像匹配、背景移除、版面编排、尺寸数据和素材溯源。

尤其值得注意的是，作者为 400 多个物种人工筛选和处理插画，并为素材记录原始图版与授权条款。当前素材集中在斯堪的纳维亚、英国和中欧，因此这些地区体验最好，其他区域覆盖较弱。这个限制揭示了生成式 AI 热潮中容易被忽略的一点：**当产品需要稳定风格、可信来源和准确对应关系时，策展与数据治理仍可能比模型调用更稀缺。**不用 AI 生成插画并非技术保守，而是在维护作品的历史质感、可追溯性和一致性。

##### 它是优秀原型，但还不是已验证的商业机会

项目已经降低了部署门槛：支持一键安装、Docker、远程检测器、网页 kiosk 和管理后台，作者也接受成品框架咨询。不过，仓库没有提供长期使用率、识别准确度或付费需求证据；新鲜感是否能转化为持续价值，仍需验证。硬件安装、麦克风环境、误识别和地域素材覆盖也都会影响体验。

更现实的边界来自授权：代码采用 MIT，但 BirdNET-Go 及相关检测组件包含非商业许可，插画素材又有各自条款。要把它发展成规模化商品，首先需要解决的可能不是供应链，而是模型与内容的商业授权。

Fugleramme 最有分量的启发因此不是“鸟类识别可以做成相框”，而是：**成熟的 AI 产品未必要求用户与模型对话；它也可以安静地把现实中原本难以察觉的变化，转化成一个值得长期共处的物件。**真正需要验证的，是哪些环境信号拥有这种长期观看价值。
