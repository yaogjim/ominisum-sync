**nash\_su - e/acc**

llm\_wiki 重磅更新 v0.6 🎉🎉🎉

大量重构，chat 引入 agent 能力，加入 skills 支持

\- 重构 Chat Agent 底座：将聊天 Agent 的核心逻辑从 TS 迁移到 Rust，包括上下文、工具调度、会话、取消、权限、事件流和 LLM 调用。  
\- 新增 Agent 工具与 Skill 能力：支持 Wiki/Source/Graph/Web/AnyTXT 检索、workspace 文件生成、shell 执行、用户交互表单，以及 Skill 扫描、启用、选择和按需读取。  
\- 改进搜索与渲染能力：将搜索 Provider 逐步迁移到 Rust，新增 Mermaid 代码块渲染和错误展示优化。
