## 分析要点

- **核心高价值点**：将同一任务分发给多个智能体，并用相互隔离的Git worktree保存结果，再统一比较和合并最佳实现。
- **留存建议**：作为多智能体并行开发工具的选型资料存档，需要时再测试（与AI编程和Agent工作流高度相关，其隔离式并行执行、统一评审和远程控制能力具有明确参考价值。）

**知识要点**

- 独立Git worktree可以隔离多个编程智能体的并行修改，降低文件和分支冲突。
- Orca面向可在终端运行的CLI智能体，通过统一界面管理会话、终端、差异评审和任务上下文。
- 远程SSH worktree、移动端通知与CLI自动化可支持长时间运行和跨设备管理智能体任务。

**行动项**

- 选择一个真实开发任务，安装Orca并创建多个隔离worktree进行并行方案对比。
- 验证现有Claude Code、Codex或其他CLI智能体与Orca的兼容性及资源占用。
- 测试差异行评论、结果合并、远程重连和移动端通知是否能改善当前代码评审流程。

#### Orca 项目简介

Orca 是一款面向高效开发者的开源 AI 编排工具，可让 Claude Code、Codex、OpenCode 等多个 CLI 智能体在独立 Git Worktree 中并行工作，并在同一界面统一管理、比较和评审结果。它还整合了终端、代码编辑、浏览器交互、远程开发和移动端监控等能力。

##### 核心功能

###### 1. 多智能体并行开发

- 可将同一个提示同时发送给 **5 个智能体**。
- 每个智能体运行在隔离的 Git Worktree 中，互不干扰。
- 用户可以比较不同智能体的实现结果，再选择并合并最佳方案。
- 支持 Claude Code、OpenClaude、Codex、OpenCode 等，也兼容任何能在终端运行的 CLI 智能体。

###### 2. 移动端监控与指挥

- 可通过手机查看智能体的运行状态。
- 智能体完成任务时会发送通知。
- 用户可以随时从移动端发送后续指令。
- 支持 **iOS App Store** 和 **Android APK**，需与桌面应用配对使用。

###### 3. 集成终端与代码编辑

- 提供类似 Ghostty 的高性能终端，支持：
  - WebGL 渲染
  - 无限分屏
  - 应用重启后保留滚动历史
- 内置类似 VS Code 的编辑器，支持自动保存。
- 可直接把文件或图片拖入智能体提示中，方便提供上下文。

###### 4. 可视化设计与浏览器交互

- 在真实 Chromium 窗口中点击任意 UI 元素，即可将其：
  - HTML
  - CSS
  - 裁剪后的截图  
  直接加入智能体提示。
- 支持 **Computer Use**，让智能体操作桌面应用和可见 UI，适合需要真实交互的工作流。

###### 5. GitHub 工作流与代码评审

- 可在 Orca 内浏览 PR、Issue 和项目看板。
- 能从任意任务直接打开对应 Worktree，减少工具和上下文切换。
- 可在 Diff 的任意代码行添加评论并发回智能体。
- 从评审、修改到提交，整个流程都可以在 Orca 内完成。

###### 6. SSH 远程开发

- 支持在高性能远程机器上运行智能体。
- 远程环境中仍可使用文件编辑、Git 和终端。
- 提供自动重连与端口转发功能。

###### 7. Orca CLI 与自动化

智能体也可以通过 Orca CLI 控制 Orca，将工作流脚本化。主要命令包括：

```bash
orca worktree create
orca snapshot
orca click
orca fill
```

这些命令可用于创建 Worktree、生成快照以及执行点击、输入等自动化操作。

##### 其他实用能力

- **快速打开**：跨 Worktree、文件、智能体、命令和仓库上下文搜索。
- **账号切换与用量追踪**：查看 Claude、Codex 的使用量和限额重置时间，并可免重新登录切换账号。
- **仓库内容预览**：直接预览 Markdown、图片、PDF 和项目文档。
- **通知与未读状态**：及时获知智能体完成任务或需要处理的情况，也可将会话标记为未读。
- 项目保持高频更新，完整的新功能应以官方**更新日志**为准。

#### Orca：把多个编程智能体整合进同一套开发工作流

Orca 是一款面向高效率开发者的开源 AI 编排器。它并非新的编程模型，而是统一管理 Claude Code、Codex、OpenCode 等 CLI 智能体，让多个智能体并行执行任务，并把开发、评审和远程控制集中在一个界面中。

##### 用隔离环境并行探索多个方案

同一个提示可同时分发给最多五个智能体，每个智能体运行在独立的 Git worktree 中，避免文件相互干扰。开发者可以比较不同结果、选择最佳实现并合并代码。这种模式把 AI 编程从“单次对话”扩展为多方案并行试验。

##### 覆盖从编码到评审的完整链路

Orca 将多种开发工具整合到桌面应用中：

- 支持终端分屏、持久化滚动记录和 VS Code 编辑器；
- 可直接浏览 PR、Issue 和项目看板，并在任意 diff 行评论后反馈给智能体；
- “设计模式”能从真实 Chromium 页面提取元素的 HTML、CSS 和截图；
- 支持远程 SSH worktree、自动重连及端口转发；
- 可让智能体操作桌面 UI，并通过 CLI 将创建 worktree、截图、点击等流程脚本化。

##### 手机端让智能体任务变为异步协作

配套 iOS 与 Android 应用可监控任务状态，在智能体完成或需要处理时发送通知，并允许用户远程追加指令。这意味着长时间运行的 AI 任务不再要求开发者持续守在电脑前。

##### 核心价值是兼容和工作流整合

Orca 宣称适配任何能在终端运行的 CLI 智能体，并提供账号切换、Claude/Codex 用量追踪、文件拖拽和仓库内容预览。它已支持 macOS、Windows、Linux，采用 MIT 许可证开源。其产品意义在于降低多智能体协作的管理成本，而非绑定某个模型或重新构建开发工具链。
