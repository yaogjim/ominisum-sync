## 正文

**Xiaoyin Qu**

我看好 OpenAI 1 万亿美元的估值（不是 Anthropic），尽管有免费的中国模型。原因如下：  
OpenAI 拥有 Codex（依我之见是更好的产品）和 OpenClaw，并且更支持开源。允许人们在 openClaw/Hermes 上使用 Codex 订阅。Codex 还支持其他开源模型。  
2\. OpenAI 仍然在消费端占据优势，这非常重要。随着模型趋近免费，个人代理将具有商业意义。目前，普通大众更可能使用 OpenAI 或 Gemini，而非 Claude。  
3\. 我对模型 API 业务不看好（一如既往），但作为一家公司，他们的业务更多元化，涵盖消费者/Codex 订阅服务、广告、咨询、机器人技术等。  
4\. 他们拥有更多的算力，并且这很重要。  
5\. 我对他们的广告业务持乐观态度。人们会信任代理商来做出购买决策。是的，聊天中的类似 Meta 的广告令人不安，并且损害信任，但他们会想出新的商业模式（代理钱包？联盟营销？）。随着今年代币价格下降，消费者将很快成为收入中心。

总体而言，我认为 OpenAI 在应用场景中更胜一筹，并采取模型无关的方法。它仍然比 Gemini 和 Meta 快得多，是最有可能在大规模采用中胜出的。依我之见，OpenAI 和 Anthropic 的风险状况截然不同。Anthropic 的风险要大得多。

## 解读（1）

### 2026-07-02 09:42:06

#### 深度总结

作者看好 **OpenAI 达到 1 万亿美元估值**，但不看好 Anthropic，核心判断是：

> **未来模型会越来越便宜，甚至免费；真正值钱的不是“模型本身”，而是应用入口、用户关系、算力、生态和商业化能力。**

主要理由：

1. **OpenAI 不只卖模型**
   - 有 ChatGPT 消费端入口；
   - 有 Codex 等开发者工具；
   - 可能扩展到广告、咨询、机器人、代理钱包等业务。
   - 相比单纯 API 公司，收入结构更丰富。

2. **消费端优势很关键**
   - 普通用户更可能使用 ChatGPT / Gemini，而不是 Claude。
   - 当 AI Agent 普及后，谁掌握用户入口，谁更容易变现。

3. **模型 API 业务不性感**
   - 模型能力会被开源和中国模型快速追平；
   - API 价格会持续下降；
   - 单靠模型调用收费，很难支撑超高估值。

4. **算力仍是护城河**
   - OpenAI 拥有更强算力资源；
   - 在大规模训练、推理、产品迭代上仍有优势。

5. **广告或代理商业化有潜力**
   - 未来用户可能让 AI 代理帮自己购物、订票、做决策；
   - OpenAI 可以在“代理决策链条”中探索广告、联盟佣金、钱包支付等模式。

6. **开源模型会赢，但 OpenAI 也会赢**
   - 作者认为开源模型会成为主流；
   - 但 OpenAI 胜出不是因为模型最强，而是因为它掌握应用层和用户层。

---

#### 深入浅出解读

这篇观点的本质是：

> **AI 竞争会从“谁的模型更强”，转向“谁离用户更近”。**

可以类比互联网时代：

- 搜索引擎不是因为网页最多才赚钱，而是因为它掌握了用户入口；
- 苹果不是因为所有硬件都最强，而是因为它掌握了生态；
- 微信不是因为技术最先进，而是因为用户每天都离不开。

所以作者认为：

| 竞争维度 | Anthropic | OpenAI |
|---|---|---|
| 模型能力 | 很强 | 很强 |
| 消费者入口 | 较弱 | 很强 |
| 开发者工具 | 强 | 强且更开放 |
| 商业化路径 | 偏 API / 企业 | 消费者、工具、广告、代理、机器人等 |
| 风险 | 更集中 | 更分散 |

简单说：

> Anthropic 更像“高质量模型公司”；  
> OpenAI 更像“AI 时代的平台公司”。

如果未来模型变成水电煤一样的基础能力，那么单纯卖模型会越来越难赚钱；但掌握用户、工作流、支付和分发渠道的平台，可能更有价值。

---

#### 辩证思考

##### 作者观点有道理的地方

###### 1. “模型不等于公司价值”
模型能力会快速扩散。开源、中国模型、巨头模型都会压低价格。  
长期看，**模型本身可能变成低毛利基础设施**。

###### 2. OpenAI 的入口优势真实存在
ChatGPT 已经成为大众心中的 AI 代名词。  
这种品牌心智和用户习惯很难复制。

###### 3. 应用层更容易产生利润
真正高价值的地方可能在：

- AI 编程；
- 企业工作流；
- 个人助理；
- 支付决策；
- 自动采购；
- 机器人执行。

这些都比单纯 API 调用更接近用户价值。

---

##### 但也有明显风险

###### 1. 1 万亿美元估值要求极高
即使 OpenAI 很强，也必须证明它能产生巨额利润。  
用户多不等于利润高，收入高也不等于净利润高。

###### 2. 广告逻辑未必成立
如果 AI 代理替用户做理性决策，它可能更看重：

- 价格；
- 质量；
- 时间；
- 用户偏好；

而不是广告影响。

这会削弱传统广告模式。  
未来更可能是“交易佣金 / 采购 API / 支付抽成”，而不是信息流广告。

###### 3. 开源可能削弱 OpenAI 护城河
如果开源模型足够好，企业可能选择自建或使用便宜方案。  
OpenAI 的 API 价格和利润率会持续承压。

###### 4. 巨头竞争不可忽视
Gemini 背后是 Google，Meta 有开源生态，苹果掌握设备入口。  
OpenAI 虽快，但未必能长期独占入口。

---

#### 我的判断

我认同作者的核心逻辑：

> **OpenAI 的最大价值不是模型，而是成为 AI 时代的超级入口。**

但我会更谨慎看待它的估值。

OpenAI 值钱的前提是它能完成三件事：

1. 把 ChatGPT 从工具变成日常入口；
2. 把 Agent 从聊天助手变成真实交易和执行系统；
3. 找到不破坏用户信任的商业化方式。

如果做到，它可能成为 AI 时代的 Google + Apple + Salesforce 的混合体。  
如果做不到，它可能只是最知名、但利润被算力和竞争吞噬的模型公司。

**一句话总结：**

> 看好 OpenAI，不是因为它模型永远领先；  
> 而是因为它最有机会把 AI 从“技术能力”变成“商业入口”。

## 结构化（1）

### 2026-07-23 10:14:36

#### 核心主旨

作者看好 **OpenAI 达到 1 万亿美元估值**，即使免费中国模型和开源模型持续崛起。其核心判断是：**OpenAI 的优势不只在模型本身，而在消费端入口、应用生态、算力和商业化能力；相比之下，Anthropic 的风险更高。**

##### 1. Codex 与开放生态形成应用优势

- 作者认为 **Codex 是更优秀的产品**，OpenAI 还拥有 OpenClaw 等应用与工具。
- OpenAI 对开源生态相对友好：
  - 用户可在 **OpenClaw/Hermes** 上使用 Codex 订阅；
  - Codex 也支持其他开源模型。
- 因此，即使未来开源模型胜出，OpenAI 仍可能凭借工具、产品和生态获胜，而不一定依靠自有模型领先。

##### 2. 消费端优势将变得更加重要

- 随着模型成本下降、能力趋同，模型本身可能越来越接近免费。
- 届时，能够为个人用户执行任务的 **AI 代理**将产生更大的商业价值。
- 在大众市场中，普通用户目前更可能选择 **OpenAI 或 Gemini**，而不是 Claude。
- 作者因此认为，OpenAI 的消费者认知、用户入口和分发能力是一项关键优势。

##### 3. 业务结构比单纯卖 API 更多元

作者一直不看好单一的模型 API 生意，但认为 OpenAI 已经拥有较多元的收入方向，包括：

- 消费者订阅；
- Codex 订阅；
- 广告；
- 咨询服务；
- 机器人技术。

这意味着，即使 API 价格因竞争而持续下降，OpenAI 仍可从应用和服务层寻找增长空间。

##### 4. 算力是重要的竞争壁垒

- OpenAI 掌握了更多算力资源。
- 在训练模型、支持大规模推理和服务海量用户方面，算力仍然非常重要。
- 因此，算力规模可帮助 OpenAI 保持产品迭代速度和大规模服务能力。

##### 5. 广告与代理经济可能成为收入来源

- 作者看好 OpenAI 的广告业务，因为未来用户可能会信任 AI 代理帮助自己做购买决策。
- 但传统的聊天广告，例如类似 Meta 的信息流广告，可能令人不适，并损害用户对代理的信任。
- OpenAI 可能需要探索新的商业模式，例如：
  - **代理钱包**：由 AI 代理管理和执行支付；
  - **联盟营销**：代理促成交易后获得佣金；
  - 其他围绕购买决策和交易的服务。
- 随着今年 token 价格下降，作者预计消费者业务很快会成为更重要的收入中心。

##### 总体判断

- OpenAI 在应用场景、消费端和产品落地方面更占优势，并采取相对**模型无关**的策略，可接入或支持不同模型。
- 作者认为，OpenAI 的行动速度仍快于 Gemini 和 Meta，因此最有可能赢得大规模用户采用。
- OpenAI 与 Anthropic 的风险结构并不相同：**作者明确认为 Anthropic 的风险更高**。
- 一句话概括作者的观点：**未来可能是开源模型胜出，但 OpenAI 可以依靠应用、入口和商业生态胜出。**

##### 热门回复中的主要争议

1. **作者进一步强调**  
   > “开源模型将会胜出。OpenAI 将会胜出不是因为它的模型。”  
   该回复获得 **17 个赞、3 条评论**，进一步说明其看好的是 OpenAI 的应用与商业能力，而非纯模型壁垒。

2. **对 Anthropic 竞争力的不同判断**  
   有回复认为 Anthropic 似乎已经占据领先位置，并询问作者是否掌握了外界看不到的信息。

3. **Codex 面临开源竞争**  
   有观点认可 OpenAI 的防御能力，但认为 Codex 最终仍难以战胜开源工具。

4. **Claude Code 仍有忠实用户**  
   有用户表示自己是 Claude Code 的忠实粉丝，说明 Anthropic 在编程工具领域仍有较强产品口碑。

5. **广告模式受到质疑**  
   反对者认为，在自主 AI 代理时代，代理会根据价格和限制条件直接预订航班或购买商品，人类不再需要被广告说服。届时更可能出现的是：
   - **采购 API**；
   - **代理钱包与支付层**；
   - 低于传统注意力广告价值的交易费用。  
   
   该观点认为，广告会损害代理的中立性和用户信任，因此“钱包层”可能成立，但传统“广告层”未必成立。
