## 正文

**sitin**

Lightpanda：一个用 Zig 从零写的无头浏览器。不是 Chromium fork，不是 WebKit patch，是全新实现。

为什么值得关注？看数据：  
• 内存占用是 Chrome 的 1/9  
• 执行速度是 Chrome 的 11 倍  
• 瞬时启动

兼容 Playwright、Puppeteer、chromedp（通过 CDP 协议），可以直接替换现有工具链。

这意味着：同样一台机器，跑 AI Agent 抓取任务可以开 9 倍并发。对于大规模爬虫、LLM 训练数据采集、自动化测试，成本直接砍一个数量级。

安装一行命令：

curl -L -o lightpanda [https://github.com/lightpanda-io/browser/releases/download/nightly/lightpanda-aarch64-macos…](https://github.com/lightpanda-io/browser/releases/download/nightly/lightpanda-aarch64-macos) &amp;&amp; chmod a+x ./lightpanda  
卷曲 -L -o lightpanda [https://github.com/lightpanda-io/browser/releases/download/nightly/lightpanda-aarch64-macos…](https://github.com/lightpanda-io/browser/releases/download/nightly/lightpanda-aarch64-macos) &amp;&amp; chmod a+x ./lightpanda

也有 Docker 镜像，一行起 CDP server。

目前 Web API 支持还在进行中（partial WIP），Playwright 兼容也有注意事项——新增 API 可能触发不同执行路径。但作为 AI Agent 的基础设施，够用了。

Zig 写浏览器这条路线越来越有意思。

## 要点提取（1）

### 2026-03-20 06:09:29

• Lightpanda 是一个用 Zig 从零实现的无头浏览器，不是 Chromium 或 WebKit 的分支/补丁版本。  
• 它主打高性能与低资源占用：内存约为 Chrome 的 1/9，执行速度可达 Chrome 的 11 倍，并且支持瞬时启动。  
• 由于兼容 Playwright、Puppeteer 和 chromedp（通过 CDP 协议），它可以较容易接入并替换现有自动化工具链。  
• 对 AI Agent 抓取、大规模爬虫、LLM 训练数据采集、自动化测试等场景来说，这意味着在同样硬件上可显著提升并发能力并降低成本。  
• 项目提供简单安装方式，可直接下载可执行文件，也提供 Docker 镜像来一键启动 CDP server。  
• 当前项目仍在持续完善中，Web API 支持尚未完整，Playwright 兼容性也有一些注意事项，但作为 AI Agent 基础设施已经具备实用价值。  
• 文章最后认为，用 Zig 来构建浏览器这条技术路线很值得持续关注。
