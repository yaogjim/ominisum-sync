## 分析要点

- **核心高价值点**：评估AI商业价值时，不应只看Token或工作负载增长，而应比较单位任务成本与其创造的增量收入和利润。
- **留存建议**：保留其关于模型路由、单位任务成本和AI价值链利润迁移的分析框架（核心判断可用于AI产品架构、成本优化和投资分析，但文中关键数据及案例缺少可核实来源。）

**知识要点**

- 企业可按任务难度和质量要求，将少量高价值任务交给前沿模型，将分类、检索、总结等任务路由至低成本模型。
- Token使用量与模型厂商收入可能脱钩，因为模型降价、开放权重模型替代和智能路由会持续压低单位Token收益。
- AI价值链的利润可能从算力和模型提供商，部分转移至最能以低成本创造增量收入的应用企业。

**行动项**

- 为AI产品建立按任务类型、质量要求和成本约束划分的模型路由方案。
- 持续跟踪每类任务的完成成本、成功率和人工替代价值，而非只统计Token消耗量。
- 评估AI项目时计算AI成本对应的增量收入或利润，并据此决定模型选择与功能扩展。

## 正文

**Alpha哥AI投资日记**

Harvey 是现在最成功的 Legal AI 公司之一，ARR 已经大约 3.5 亿美元。今年 1 月到 6 月，它的平台每月 Token 消耗从 1T 暴涨到 14.5T，半年涨了 14 倍。

按现在市场最流行的 AI Bull 逻辑，这应该超级利好 OpenAI、Anthropic：企业 Token 越烧越多，模型公司的收入自然也跟着爆。

结果 Harvey 最近干了什么？

它开始大量引入更便宜的 open-weight models，包括 GLM、Kimi，还自己做了一个法律模型 Tenet，底层就是基于 Moonshot 的 Kimi K3

原因其实很简单：Frontier intelligence 很好，但没必要每个任务都用最贵的模型。一个律所可能最难的 10% 任务继续扔给 Opus、GPT，剩下大量分类、检索、总结、初步审阅，完全可以 Routing 到便宜几倍甚至几十倍的模型。

于是未来完全可能出现一种很反直觉的情况：

Harvey 的 Token 使用量涨 14 倍，但 OpenAI / Anthropic 从 Harvey 身上赚的钱远远涨不到 14 倍，甚至某些 workload 的收入还会被开源模型吃掉。

前几天 Canva 其实也出现了类似的问题。Canva 今年大推 AI 之后，用户需求远超预期，结果推理成本也跟着爆了，公司一度不得不放慢 AI 功能向更多用户 rollout。后来 Canva 花了很大力气优化模型和基础设施，据说已经把完成一次 AI 任务的成本压低了大约 90%。

这两个案例放在一起，我觉得非常重要。

以前 SaaS 的逻辑是，用户一旦把 Salesforce、ServiceNow 接进整个 workflow，第二天老板觉得贵，也很难说换就换。

LLM API 没有这么强的 retention(留存), 今天 Claude 效果最好就用 Claude，明天 OpenAI 降价就切 OpenAI，下个月 Kimi、GLM 性价比更高，Smart Router 自动把 80% 的任务切过去。企业最终一定会越来越认真地优化 cost per task。

所以 AI 的总使用量我一点都不怀疑。

我真正开始担心的是：

Token 可能继续 10x、20x 地增长，但 Frontier Model 厂商每个 Token 能赚的钱下降得更快。

这也是为什么 Anthropic 最近 ARR 增速下降值得注意。Coding 这一波最好的场景已经跑出来了，接下来如果没有第二个 Claude Code，同时企业又越来越会 Routing、越来越会用便宜模型，OpenAI 和 Anthropic 的收入增长完全可能远远跑输整个 AI 使用量。

未来不仅要看AI workload 增长得有多快，以及每个 workload 实际需要多少 Compute。

未来很可能出现一个很奇怪的世界：

AI 无处不在，Token 天天创新高，但模型越来越便宜、企业越来越会优化token成本。

这个世界当然还是 AI 牛市，只是未必是现在市场想象中的那种 AI 牛市。

谁能用最低的 AI 成本，创造最高的增量 Revenue？未来 AI Trade 可能会从“谁卖 GPU、谁卖模型”，慢慢扩散到另一批公司：谁最会用 AI。如果一家公司的 AI 成本一年只有 1 亿美元，却能因此多创造 10 亿、20 亿甚至更多利润，这种公司的经济模型可能比单纯卖 Token 更性感。

## 解读（1）

### 2026-08-21 04:15:28

#### 核心结论

> **Token 用量暴增，不等于头部模型公司的收入、利润同步暴增。**  
> AI 的价值重心可能从 “谁提供最强模型”，逐渐转向 “谁能以最低成本把 AI 变成最高利润”。

##### 一、深度总结

Harvey 与 Canva 说明了同一趋势：

1. **企业的 AI 需求确实在爆发**  
   Harvey 半年 Token 用量增长约 14 倍，Canva 的 AI 使用也远超预期。

2. **但企业不会永远只用最贵模型**  
   高难度任务交给 GPT、Claude；分类、检索、总结等普通任务，则自动分流给 Kimi、GLM 或自研模型。

3. **企业优化的是 “每项任务成本”，不是 Token 数量**  
   Canva 据称将单次 AI 任务成本降低约 90%。因此，用量可以大涨，模型支出却未必同比增长。

4. **模型 API 的锁定效应弱于传统 SaaS**  
   企业可以通过智能路由随时切换模型，导致模型同质化、价格下降和供应商份额流失。

5. **AI 牛市可能改变受益者**  
   第一阶段看 GPU 和基础模型；下一阶段更应关注：  
   **谁能用少量 AI 成本，创造大量新增收入与利润。**

##### 二、深入浅出地解读

可以把模型看成不同档次的员工：

- 最难的案子，交给顶级专家；
- 日常整理、检索和初审，交给普通员工；
- 系统自动判断该找谁。

因此：

> 工作量增长 14 倍，不代表 “顶级专家” 的收入也增长 14 倍。

模型厂商收入大致取决于：

> **任务量 × 每项任务用量 × Token 单价 × 自身份额**

即使任务量暴涨，只要单价持续下降、任务被便宜模型分流，收入增速就可能明显落后；利润还要进一步扣除算力成本。

真正重要的指标由此从**Token 增长**转向：

- 每项任务成本；
- AI 带来的新增收入；
- AI 带来的新增利润；
- 模型切换成本与客户黏性。

##### 三、辩证思考

###### 文章判断成立的一面

- 模型正在商品化，单纯卖 Token 容易陷入价格战。
- 开源模型与智能路由会削弱头部厂商的定价权。
- 应用公司拥有场景、客户、数据和工作流，更可能沉淀长期价值。

###### 仍需保留判断的一面

- **便宜可能催生更大需求**：单价下降后，新增任务可能远超预期，模型厂商总收入仍可增长。
- **前沿能力仍有溢价**：高风险、高价值任务不会只追求便宜，而更看重准确率、可靠性和合规。
- **开源并非免费**：部署、运维、安全与推理基础设施同样有成本。
- **应用层也未必稳赢**：若产品缺少数据、渠道和工作流壁垒，同样容易被复制。

##### 最终判断

未来不是 “模型厂商失去价值”，而是价值衡量标准发生变化：

> **不能只看 AI 用了多少，而要看谁最终留住了利润。**

最值得关注的企业，不一定拥有最强模型，而是能把**模型、数据、流程和客户关系**组合起来，以最低 AI 成本创造最高可持续回报。

## 深度解读（1）

### 2026-09-18 10:19:30

#### Token 暴涨不等于模型收入暴涨：AI 的价值正在转向“任务经济性”

这篇内容最值得保留的，不是“开源模型将取代闭源模型”，而是一个更准确的收入拆解：**AI 使用量、算力消耗与基础模型厂商收入，并不会同比增长。**

按照文中数据，Harvey 半年内月度 Token 消耗从 1T 增至 14.5T，却开始把分类、检索、总结和初步审阅等任务转向更便宜的模型；Canva 面对激增的推理成本，也通过模型和基础设施优化，将单次 AI 任务成本压低约 90%。两者共同说明，企业一旦越过“先把 AI 用起来”的阶段，就会从追求模型能力转向优化 **cost per task——完成一个有效任务到底花多少钱**。

##### 模型调用正在从采购决策变成动态调度

传统 SaaS 的黏性主要来自数据、权限、流程和组织习惯，替换 Salesforce 往往意味着重做整套系统。模型 API 的切换成本相对低得多：企业可以保留同一个产品界面和工作流，只在后台根据任务难度、延迟、合规要求与价格动态选择模型。

因此，一家企业的模型支出更接近：

> 任务数量 × 单任务 Token × Token 单价 × 各模型承接比例

即使前两项高速增长，降价、缓存、蒸馏、短上下文设计和模型路由，也可能让后两项快速下降。**把 Token 增长直接外推为 OpenAI、Anthropic 的收入增长，遗漏了企业持续优化成本这一反馈机制。**

但“模型像水电一样可随时替换”也说得过早。法律等高风险场景需要稳定输出、审计、数据隔离和长期评测；更换模型并非改一个 API 地址。真正降低切换成本的是应用公司积累的评测集、路由系统和异常处理能力。换句话说，护城河未必消失，而可能从单一模型转移到掌握业务数据与工作流的应用层。

##### 下一阶段更该观察“每个任务创造多少价值”

文章对 Anthropic 增速的进一步推断证据还不充分。便宜模型会分流简单任务，但更强模型也可能创造过去不存在的复杂任务，例如长时间运行的编程代理、法律推演或科研工作流。前沿厂商能否增长，取决于高价值新任务扩张的速度，能否超过单位价格下降和份额流失。

对产品与商业判断而言，更有用的指标不再是调用量或 AI 功能渗透率，而是三件事：**任务成功率、单次有效任务成本，以及由此新增的收入或利润。** 企业模型路由与评测平台确有机会，但客户并不需要另一个“接很多模型”的中间层；它必须证明自己能在可靠性、合规和总成本之间做出优于人工配置的选择。

AI 牛市可能继续，但价值最大的公司未必是 Token 卖得最多的，而可能是那些把模型变成可替换成本项，同时把客户关系、数据闭环和业务收益留在自己手里的公司。

## 口播总结（1）

### 2026-09-20 00:19:29

人工智能的使用量暴涨，并不意味着 OpenAI、Anthropic 这类前沿模型公司能按同样速度赚钱。真正需要关注的，不只是企业用了多少 Token，而是每项任务最终用了什么模型，以及企业愿意为这项任务付多少钱。

法律人工智能公司 Harvey，就是一个很典型的案例。Harvey 的年度经常性收入，也就是 ARR，已经大约三点五亿美元。从今年一月到六月，它的平台每月 Token 消耗量，从一万亿增长到十四点五万亿，半年增长约十四倍。

Token 可以简单理解为模型处理文字时使用的基本计量单位。按照市场上常见的乐观逻辑，企业消耗的 Token 越多，调用大型模型越频繁，模型公司的收入就应该增长得越快。

但 Harvey 的实际做法，没有这么简单。

Harvey 正在大量引入价格更低的开放权重模型，包括智谱的 GLM 和月之暗面的 Kimi。它还开发了一款名为 Tenet 的法律模型，底层基于 Kimi K3。

原因在于，最先进的前沿模型虽然能力很强，却没有必要处理每一项任务。对一家律师事务所来说，最困难、最复杂的那百分之十任务，可以继续交给 Claude Opus 或 GPT。可是，分类、检索、总结和初步审阅等大量常规工作，完全可以交给便宜几倍，甚至几十倍的模型。

企业还可以使用智能路由系统，自动判断任务难度。复杂任务送给能力最强的模型，简单任务则转给更便宜的模型。这样一来，Harvey 的 Token 使用量即使增长十四倍，OpenAI 或 Anthropic 从 Harvey 获得的收入，也未必能增长十四倍。部分任务带来的收入，甚至可能直接被低价模型和开放权重模型分走。

Canva 的经历，也说明了同一个问题。

Canva 大规模推出人工智能功能以后，用户需求远超预期，但模型推理成本也随之激增。成本压力一度迫使 Canva 放慢向更多用户开放人工智能功能的速度。后来，Canva 花了很大力气优化模型选择和基础设施。据称，它已经把完成一次人工智能任务的成本降低了大约百分之九十。

这说明，人工智能需求越旺盛，企业越有动力压低每项任务的成本。因为对应用公司来说，目标不是消耗尽可能多的 Token，而是用尽可能低的成本，完成用户真正需要的工作。

这和传统的软件即服务，也就是 SaaS，存在一个重要区别。

过去，企业一旦把 Salesforce 或 ServiceNow 深度接入工作流程，迁移成本就会很高。即使管理层觉得价格太贵，也很难马上更换。因此，传统企业软件往往有较强的客户留存和定价能力。

大模型的应用程序接口，目前未必具有同样强的黏性。今天 Claude 效果最好，企业就使用 Claude。明天 OpenAI 降价，企业可以转向 OpenAI。再过一段时间，如果 Kimi 或 GLM 的性价比更高，智能路由系统就可能自动把百分之八十的常规任务切换过去。

随着技术成熟，企业会越来越认真地计算一项指标，也就是完成一次任务究竟要花多少钱。模型之间的切换和组合，也会变得更加灵活。

因此，真正值得警惕的情况是：人工智能的总使用量可能继续增长十倍、二十倍，但前沿模型公司从每个 Token 中赚到的钱，下降得更快。结果就是，模型公司的收入增速可能明显落后于整个行业的使用量增速。

作者认为，Anthropic 最近年度经常性收入增速放缓，就值得关注。编程是这一轮人工智能中最成功的应用场景之一，Claude Code 也已经证明了需求。但如果接下来没有出现第二个同等级的明星应用，同时企业又越来越擅长使用智能路由和低价模型，那么 OpenAI 和 Anthropic 的收入增长，就可能跑输人工智能工作量的增长。

这并不代表人工智能热潮会结束。相反，未来很可能出现一个看似矛盾的局面：人工智能无处不在，Token 使用量不断创新高，但模型越来越便宜，企业也越来越会控制成本。

在这种情况下，投资人工智能不能只看谁卖芯片、谁卖模型。更重要的问题可能变成：谁最会使用人工智能，谁能用最低的人工智能成本，创造最高的新增收入和利润。

如果一家公司每年投入一亿美元人工智能成本，却能因此增加十亿、二十亿美元，甚至更多利润，那么它的经济模型，可能比单纯出售 Token 更有吸引力。

最值得记住的是，使用量增长不等于收入同比例增长。智能路由和低价模型，会持续压低每项任务的成本。而下一阶段真正突出的公司，未必是卖出最多 Token 的公司，也可能是那些最擅长把廉价智能转化为高额利润的公司。
