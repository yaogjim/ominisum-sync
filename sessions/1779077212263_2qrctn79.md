Presidio *(Origin from Latin praesidium ‘protection, garrison’)* helps to ensure sensitive data is properly managed and governed. It provides fast ***identification*** and ***anonymization*** modules for private entities in text such as credit card numbers, names, locations, social security numbers, bitcoin wallets, US phone numbers, financial data and more.

##### Goals

- Allow organizations to preserve privacy in a simpler way by democratizing de-identification technologies and introducing transparency in decisions.
- Embrace extensibility and customizability to a specific business need.
- Facilitate both fully automated and semi-automated PII de-identification flows on multiple platforms.

##### Main features

1. **Predefined** or **custom PII recognizers** leveraging *Named Entity Recognition*, *regular expressions*, *rule based logic* and *checksum* with relevant context in multiple languages.
2. Options for connecting to external PII detection models.
3. Multiple usage options, **from Python or PySpark workloads through Docker to Kubernetes**.
4. **Customizability** in PII identification and de-identification.
5. Module for **redacting PII text in images** (standard image types and DICOM medical images).

⚠️ Presidio can help identify sensitive/PII data in un/structured text. However, because it is using automated detection mechanisms, there is no guarantee that Presidio will find all sensitive information. Consequently, additional systems and protections should be employed.

#### Microsoft Presidio：开源敏感数据识别与匿名化框架

##### 一句话总结

**Presidio 是微软开源的 PII（个人敏感信息）检测、脱敏、遮盖与匿名化框架**，可用于文本、图片和结构化数据，适合企业在 AI、数据分析、合规治理等场景中保护隐私数据。

##### 核心定位

Presidio 的目标是帮助组织更简单、透明、可定制地处理敏感数据，降低隐私泄露风险。

它可以识别并处理常见敏感信息，例如：

- 姓名
- 地址 / 地理位置
- 电话号码
- 信用卡号
- 社保号
- 金融数据
- 比特币钱包地址
- 医疗影像中的敏感信息等

##### 主要能力

###### 1. 敏感信息识别

Presidio Analyzer 支持多种识别方式：

- NLP 命名实体识别
- 正则表达式
- 规则逻辑
- 校验和判断
- 上下文感知识别
- 多语言支持
- 可接入外部 PII 检测模型

这意味着它既能识别规则明确的数据，也能处理较复杂的自然语言场景。

###### 2. 数据匿名化与脱敏

Presidio Anonymizer 可对识别出的敏感信息进行处理，例如：

- 删除
- 替换
- 掩码
- 加密或自定义匿名化策略

适合用于日志清洗、数据集发布、AI 训练数据预处理等场景。

###### 3. 图片敏感信息遮盖

Presidio Image Redactor 支持对图片中的敏感文本进行遮盖，包括：

- 常规图片
- DICOM 医疗影像

这对医疗、保险、政务等行业尤其有价值。

###### 4. 结构化数据处理

Presidio Structured 可处理表格、结构化数据中的敏感字段，适合数据仓库、BI、数据治理流程。

##### 产品与技术特点

###### 可插拔、可定制

Presidio 强调扩展性，企业可以根据业务需要：

- 自定义识别器
- 自定义脱敏规则
- 接入自有模型
- 构建特定行业的数据保护流程

###### 多种部署方式

支持：

- Python
- PySpark
- Docker
- Kubernetes
- 源码部署

适合从本地开发到生产级云原生部署。

##### 适用场景

Presidio 特别适合以下场景：

- AI 训练数据脱敏
- 日志与客服记录清洗
- 数据湖 / 数据仓库隐私治理
- 医疗影像去标识化
- 合规审计与数据共享
- SaaS 产品中的用户隐私保护

##### 重要提醒

Presidio 使用自动化检测机制，**不能保证识别出所有敏感信息**。

因此，在高风险或强合规场景下，应结合：

- 人工审核
- 权限控制
- 数据分类分级
- DLP 系统
- 加密与访问审计

形成完整的数据安全体系。

##### 商业与产品价值

Presidio 的价值不只是 “脱敏工具”，更像是企业隐私计算与数据治理链路中的基础组件。

对于 AI 产品和数据产品来说，它可以帮助企业在以下两者之间取得平衡：

- 数据可用性
- 隐私与合规安全

尤其在大模型应用、企业知识库、数据开放和跨团队数据协作中，Presidio 可以作为敏感数据进入系统前的 “安全网关”。

##### 总结

Presidio 是一个成熟、开放、可扩展的敏感数据保护框架，覆盖文本、图片和结构化数据。它适合技术团队快速构建 PII 检测、脱敏和匿名化能力，也适合作为企业数据安全与 AI 合规基础设施的一部分。
