## 正文

**Muratcan Koylan**

提高代理技能的最佳方法是将其执行历史视为训练数据。

技能是基于实际运行提炼的操作手册，经过整体整合，并将失败分析纳入循环。

比起许多相互冲突的微小文档，更倾向于一个强大的、去重的技能树。

较小的模型仍然可以有助于技能演进。

Trace2Skill（Qwen 团队）收集了包括代理成功和失败在内的一批代理轨迹，派遣并行的分析代理独立地从每条轨迹中提取经验，然后将所有内容合并为一份进化后的技能文档。

一个 35B 模型进化后的技能在 WikiTQ 上使一个 122B 模型的表现提升了高达 57.65 个百分点。在某一任务领域（电子表格）中进化出的技能转移到了完全不同的领域（维基百科问答）。

## 通俗精炼（1）

### 2026-03-31 03:41:38

#### 把 Agent 的“做事记录”变成能力升级器

##### 核心观点

提升 AI Agent 能力，一个非常有效的方法，不是反复堆提示词，也不一定是重新训练大模型，而是把它的**执行历史当作训练数据**来用。

也就是说：让 Agent 从自己做过的事情里复盘，提炼经验，沉淀成可复用的“技能”。

##### 文章讲了什么

###### 1. 技能不是写出来的，而是跑出来的

所谓“技能”，本质上是 Agent 在真实任务执行中总结出来的操作方法。

这些技能不是零散的提示片段，而应该是：
- 基于真实运行过程提炼
- 同时吸收成功经验和失败教训
- 经过整合、去重、结构化沉淀下来的知识

比起一堆互相冲突的小文档，更好的方式是构建一棵**统一、清晰、可演进的技能树**。

###### 2. Trace2Skill 的方法很关键

Qwen 团队提出的 `Trace2Skill`，核心流程是：

1. 收集 Agent 的执行轨迹，包括成功和失败案例  
2. 让多个分析 Agent 并行复盘这些轨迹  
3. 各自提炼出经验、策略和注意事项  
4. 再把这些内容合并成一份进化后的技能文档  

重点在于：**不改模型参数，也能靠“技能文档进化”提升能力**。

###### 3. 小模型也能帮助大模型变强

一个很有意思的结论是：**小模型可以参与技能提炼，再反过来提升大模型表现**。

文中提到：
- 由 `35B` 模型进化出的技能
- 能让 `122B` 模型在 `WikiTQ` 任务上提升最高 `57.65` 个百分点

这说明，能力提升不一定只靠更大的模型，也可以靠更好的“经验管理机制”。

##### 为什么这件事重要

###### 1. 让 Agent 真正具备“复盘能力”

很多 Agent 最大的问题，不是不会做，而是**做完不会总结，下次还犯同样的错**。

把执行历史变成技能，意味着 Agent 开始拥有类似人的复盘机制，能力可以持续积累，而不是每次从头再来。

###### 2. 技能可以跨任务迁移

文中还提到，在“电子表格”任务中进化出的技能，居然能够迁移到“维基百科问答”这类完全不同的任务中。

这说明高质量技能不是死记硬背，而是能抽象成更通用的方法论。

###### 3. 这比单纯堆文档更有效

很多团队会给 Agent 塞大量 SOP、规则和提示词，但这些内容往往：
- 重复
- 冲突
- 难维护
- 难迁移

相比之下，基于真实轨迹不断演进的技能体系，更像一个可持续优化的“组织经验库”。

##### 一句话总结

**Agent 能力提升的关键，不只是更大的模型，而是把“做过的事”系统化沉淀成技能，让它能够从成功与失败中持续进化。**
