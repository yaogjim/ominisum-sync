#### Why jev-seo?

Semrush 和 Ahrefs 每月费用高达 130 美元以上。OpenSEO 仍然需要付费的 DataForSEO 信用卡。大多数 SEO 套件都是臃肿的网页仪表板，充斥着虚荣图表。

- 零订阅（₹0）：直接抓取 DuckDuckGo HTML 并建议端点。无需信用卡，无需付费 API 密钥。
- TypeSafe Jev System One：语义意图分类、竞争差距检测和 AI 可见性（GEO）以确定性方式评分，无对话式 LLM 幻觉。
- 批量目录审计：在不到 1 秒内审计数百个 markdown/HTML 文件，检测标题冲突、规范链接不匹配和内容单薄页面。
- 2026 Schema.org 验证器：深入检查 JSON-LD 架构（ `SoftwareApplication` 、 `Article` 、 `Organization` 、 `Product` ），并标记已弃用的架构。
- Robots.txt 与 AI 爬虫雷达：评估 AI 机器人的权限（ `GPTBot` 、 `ClaudeBot` 、 `PerplexityBot` 、 `Google-Extended` 、 `Bytespider` ）。
- SERP 内容简报：将竞争对手的 SERP 摘要综合为可操作的内容蓝图，包含 H2 大纲和最优的 134-167 词 GEO 区块。
- Agent 原生（MCP）：原生 stdio JSON-RPC 2.0 MCP 服务器直接将 8 个 SEO 工具接入 Claude Code、Gemini CLI 和 Antigravity。
- 本地且私密：所有排名跟踪和审计历史记录都持久保存在单个本地 SQLite 数据库（ `.jev-seo.db` ）中。
- 低内存占用：快速的原生 Rust 二进制文件，在资源受限的机器上运行时内存占用低于 30MB。

#### Quickstart

```
# Install via Cargo (crates.io)
cargo install jev-seo

# Set your free TypeSafe key for semantic oracle scoring
export TYPESAFE_API_KEY=your_key_here

# Run a live SERP competitive radar check
jev-seo query "offline expense tracker android"

# Audit a single file or an entire documentation directory
jev-seo audit docs/

# Audit an XML sitemap for protocol security, URL limits, and hreflang
jev-seo sitemap https://example.com/sitemap.xml

# Validate JSON-LD Schema.org markup
jev-seo schema index.html

# Check AI crawler permissions on a live domain
jev-seo robots github.com

# Generate a SERP-driven content brief
jev-seo brief "agentic skills" --limit 5

# Track domain rankings over time (saved to local SQLite)
jev-seo rank --domain "crates.io" --query "rust grep"

# Start the Native Agent MCP Server
jev-seo mcp
```

#### Workflows

##### 1\. 批量目录与文件页面审计

```
jev-seo audit content/posts/
```

递归扫描所有 markdown 和 HTML 文件，识别标题冲突，检测内容单薄（少于 300 词），验证 canonical 链接，并标记图片 alt 缺失。

```
jev-seo schema content/guide.md
```

验证 `SoftwareApplication` 、 `Article` 、 `Organization` 和 `Product` 中的必需属性。标记已弃用的 schema 类型（例如 `HowTo` 富媒体搜索结果）。

```
jev-seo robots example.com
```

专门针对现代生成式 AI 索引器审计 `robots.txt` 指令：

- `GPTBot` (OpenAI model training)
- `ClaudeBot` &amp; `anthropic-ai` (Anthropic)
- `PerplexityBot` （Perplexity 引用引擎）
- `Google-Extended` (Gemini training)
- `Bytespider` (ByteDance)

```
jev-seo brief "fast local sqlite tui" --markdown
```

拉取实时 DuckDuckGo 竞争对手数据，计算最佳字数，并使用 Jev System One 扇出生成可操作的标题大纲，附带 150 字的 GEO 直接答案处方。

##### 5\. 生成式引擎优化（GEO）

```
jev-seo geo README.md --query "agentic skills framework for coding agents"
```

使用 Jev `Score` （1-10）和 `Noul` 计算 Perplexity、SearchGPT 和 Gemini Overviews 的引用概率。

```
jev-seo sitemap sitemap.xml
jev-seo sitemap https://example.com/sitemap.xml
```

依据 Google 网站管理员标准验证站点地图：强制使用规范的 HTTPS 协议、标记参数污染、验证 50,000 条 URL 限制，并审计国际 `hreflang` 代码（标记格式错误的代码，如 `en-UK` 与 `en-GB` ，并强制执行 `x-default` ）。

Integrated into `jev-seo audit`:

- 破折号密度扫描器：标记过度使用破折号的情况（每 500 词超过 2 个）。
- AI 词汇检测器：标记 17 个泛滥的 AI 模板化拐杖词（ `delve` 、 `leverage` 、 `testament` 、 `foster` 、 `seamless` 、 `crucial` 、 `robust` 、 `landscape` 等）。
- 标题层级审计器：标记非法的跳级情况（例如没有 `H2` 的 `H1 -> H3` ）。
- 内部链接图谱：精准定位跨目录中入站内部链接为 0 的孤立页面。
- 关键词蚕食雷达：识别针对相同关键词词干的竞争性文章。

##### 从关键词研究覆盖到 AI 搜索可见性

工具提供关键词联想、实时 SERP 竞品分析、排名跟踪和内容简报，也支持面向生成式搜索的 GEO 评分，评估内容被 Perplexity、SearchGPT、Gemini Overviews 引用的可能性。作者强调不生成文章，而用 TypeSafe Jev System One 做意图分类和规则化评估，以降低对话式 LLM 的幻觉风险。

##### 审计重点从页面扩展到站点与 AI 爬虫

它可批量扫描 Markdown/HTML，检查薄内容、标题冲突、canonical、图片 alt、标题跳级、孤立页面及关键词蚕食；还可验证 JSON-LD、站点地图的 HTTPS、5 万 URL 上限和 hreflang，并检查 GPTBot、ClaudeBot、PerplexityBot 等 AI 爬虫的 robots.txt 权限。项目声称数百文件审计可在 1 秒内完成，运行内存低于 30MB。

通过 stdio JSON-RPC 2.0，8 个工具可接入 Claude Code、Gemini CLI 等 Agent；历史数据保存在本地 SQLite。它代表 SEO 工具从云端仪表盘转向 “可编排能力模块” 的趋势。但 “替代 Semrush” 主要是作者定位：项目不提供云端看板，数据依赖 DuckDuckGo HTML，语义评分仍需免费的 TypeSafe Key，效果与稳定性尚缺少独立验证。

## 结构化（1）

### 2026-09-20 08:05:58

#### jev-seo：面向开发者与 AI 智能体的零成本 SEO/GEO 工具

`jev-seo`是一个用 Rust 编写的开源命令行工具，试图以 DuckDuckGo 数据、本地审计和确定性评分，替代 Semrush、Ahrefs 等付费 SEO 平台。它同时支持传统搜索优化（SEO）和生成式引擎优化（GEO，即提高内容被 Perplexity、SearchGPT、Gemini 等引用的可能性），并可通过 MCP 接入编码智能体。

##### 为什么开发这套工具

项目作者认为，现有 SEO 工具主要有三类问题：

- Semrush、Ahrefs 等订阅费可达每月 130 美元以上。
- 部分开源方案仍依赖 DataForSEO 等付费接口。
- 许多产品以笨重的网页仪表板和展示性图表为主，不适合开发者和自动化代理。

因此，`jev-seo`采用免费的 DuckDuckGo HTML 页面和搜索建议作为数据来源，不强制依赖付费 API，也不提供云端仪表板。部分语义意图与 GEO 评分需要配置免费的`TYPESAFE_API_KEY`。

##### 核心能力：从搜索研究到站内审计

工具覆盖了一套较完整的 SEO/GEO 工作流：

- **关键词与搜索结果分析**：获取关键词联想，分类搜索意图，并抓取实时 SERP（搜索结果页）中的标题、摘要和网址，寻找竞争内容缺口。
- **批量页面审计**：递归检查 Markdown 和 HTML 文件。作者称可在不到 1 秒内审计数百个文件，发现：
  - 标题冲突或层级跳跃，如从 H1 直接跳到 H3；
  - 少于 300 词的单薄内容；
  - canonical（规范链接）不匹配；
  - 图片缺少`alt`；
  - 没有任何内部链接指向的 “孤立页面”；
  - 多篇文章争夺相同关键词的 “关键词蚕食” 问题。
- **AI 模板化内容检查**：检测过多破折号，以及`delve`、`leverage`、`seamless`、`robust`等 17 个常见模板化词语。
- **Schema.org 验证**：检查 JSON-LD 结构化数据中`SoftwareApplication`、`Article`、`Organization`、`Product`等类型的必需属性，并提示已弃用或不再适用于富媒体搜索结果的类型。
- **站点地图检查**：验证 XML Sitemap 是否使用规范 HTTPS、是否存在参数污染、是否超过 5 万条 URL，并检查`hreflang`国际语言代码，例如识别`en-UK`应为`en-GB`，以及是否配置`x-default`。
- **AI 爬虫权限审计**：分析`robots.txt`对 GPTBot、ClaudeBot、PerplexityBot、Google-Extended、Bytespider 等机器人的允许或禁止规则。
- **排名跟踪**：持续记录域名在指定关键词下的排名变化，数据保存在本地 SQLite 文件`.jev-seo.db`中。

##### GEO：评估内容是否容易被 AI 引用

`geo`命令会针对指定查询，为页面给出 1—10 分的 AI 引用可能性评分，并检查页面是否包含适合直接回答用户问题的内容段落。

内容简报功能还会综合 DuckDuckGo 上的竞争页面，生成：

- 建议字数；
- H2 标题大纲；
- 内容缺口；
- 一个约 150 词的直接回答区块。项目认为约**134—167 词**的段落更适合作为 GEO 引用单元。

这些分析由 TypeSafe Jev System One 执行。按作者说明，Jev 在此只承担确定性的分类和评分，不负责生成式文本写作，以避免对话式大模型的幻觉。

##### 面向智能体：通过 MCP 暴露 8 个工具

运行`jev-seo mcp`后，程序会成为基于标准输入输出和 JSON-RPC 2.0 的 MCP 服务器，可直接接入 Claude Code、Gemini CLI 等智能体环境。

它提供 8 类工具：

1. 关键词发现与意图分类；
2. 实时搜索结果检查；
3. 本地页面与目录审计；
4. GEO 引用评分；
5. Schema 验证；
6. AI 爬虫权限检查；
7. 内容简报生成；
8. Sitemap 验证。

这使编码代理可以直接调用 SEO 能力，而不必操作网页仪表板。
