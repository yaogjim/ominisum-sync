#### Synara：类 Codex 的编程 GUI 工具

##### 核心概述

Synara 是一款编程 GUI 工具，界面和使用体验高度类似 Codex，因此上手门槛很低，适合已经熟悉 AI 编程工具的用户快速迁移使用。

##### 主要特点

- **界面类似 Codex**：操作逻辑接近，学习成本低。
- **支持多种 Coding Agent**：目前支持 8 个常见编程 Agent，例如 Pi、Claude Code、OpenCode 等。
- **可搭配 Deepseek 使用**：作者用 Pi + Deepseek 进行了测试，体验不错。
- **新增看板模式**：适合以任务流、项目管理方式组织 AI 编程工作。

##### v0.1.9 更新亮点

- 推出 **看板视图 Beta**
- 增加聊天专用工作区文件夹，用于存放生成文件
- 工作区编辑器支持仅搜索文件
- 新增 UI 密度设置，可调整侧边栏和输入区间距
- 设置页打开更快，流式渲染更少，体验更流畅

##### 产品判断

Synara 的定位更像是一个面向开发者的 AI 编程工作台，通过整合多个 Coding Agent 和熟悉的 Codex 式交互，降低用户切换成本。看板模式的加入，也让它不只是聊天式编程工具，而开始向“AI 编程项目管理平台”演进。
