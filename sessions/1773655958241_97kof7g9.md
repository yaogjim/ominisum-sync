## 正文

**Yanhua**

### 田渊栋：AI 护城河、记忆瓶颈与 Agent 的洪水

最近听了田渊栋在《硅谷坐标》的访谈，前 Meta 研究总监，强化学习和大模型推理方向的人。

聊的几个判断我觉得值得认真对待，整理出来分享给大家。

#### 护城河排序：数据 &gt; Infra &gt; 算力 &gt; 算法 ≈ 人才

这是他给出的排序，愿意为它背书。

数据排第一。垂直领域的数据稀缺、难复制、AI 很难直接生成。通用数据各大 lab 已经跑遍了，真正有价值的是业务里积累的、别人没有的东西。

Infra 排第二，但他加了注脚：这个护城河在变窄。

他自己对比了三个月前，AI 写代码让效率提高了至少 10 倍。如果这个趋势继续，以前需要强工程团队才能搭起来的东西，以后一个人加 AI 就够了。

算法的地位被高估了。

硅谷没有秘密。一个新方案出来，两三个月之后基本都传开了。DeepSeek 在残差连接上做了个魔改，很快有人发现简化版效果差不多。算法上的改进要么是微调，要么是颠覆性跳变：但跳变什么时候来，没人说得清。

现在所有人都在等那个跳变。

![Image](https://pbs.twimg.com/media/HDf03TTbkAA1ICP?format=jpg&name=large)

#### 大模型的两层记忆

很多人以为上下文窗口就是大模型的全部记忆。不是的。

短期：上下文记忆。 当前对话里的所有内容，快、灵活，但有上限。窗口满了就开始表现变差。他们 2023 年在 Meta 做的 Positional Interpolation，通过把长上下文的位置编码映射到短上下文上，用很小的训练代价实现了窗口扩展——从那篇文章开始，各家开始大幅拉长 context window。

长期：模型权重。 预训练写进去的，很难改变。预训练做得好，模型后续什么任务一点就通；预训练不够，你得把每一步都解释清楚，它才能跟上，举一反三想都别想。

记忆研究的核心矛盾：全部记住代价太高，选择性遗忘又可能漏掉关键信息。H2O 是他们后来做的一个方向，把"重要的记忆"捞回来，让模型在关键问题上还能答对。

这个 tradeoff 现在还没有银弹。

![Image](https://pbs.twimg.com/media/HDf0-PibYAAMFMZ?format=jpg&name=large)

#### 从背诵到顿悟：最难的那一跳

他观察女儿学数数时有个现象，让他一直在想。

教了很久，好像什么都没记住。然后有一天，突然之间，她不只是会数数了——开始对数字大小有感觉，能猜两位数的关系，能举一反三。没人再教什么新东西，但理解发生了质的变化。

大模型目前的记忆方式，跟这个差距很大。

现在的方法更像是：把每条知识存进去，需要的时候调出来。但那种内部重组、对世界理解的飞跃，还没发生。Google 的 Nested Learning 尝试把所有学习过程统一成 associative memory，逻辑有意思，但还是在记"点"，没有形成整体理解。

诸葛亮说"观其大概"：不看细节，但理解得足够深之后，结论自然出来。大模型现在还不会这个。

#### Scaling Law：大厂为什么停不下来

它是有效的，但代价在以指数级增长。

存储是瓶颈，电力是瓶颈，单卡内存不够就要切片、增加通信延迟，整个效率链条都在被拖慢。

那 OpenAI 和 Google 为什么还在这条路上跑？

路径依赖。大厂把所有 team 都建好了，已经形成了一台运转的机器。让它转向，去做一个不确定的新方向，非常困难。继续沿着 Scaling Law 走是最安全：不需要太多脑筋，见效快，只要投入就有产出。

等 Return 越来越少的时候，大厂才会开始想别的。现在还没到那个时候。

#### 强化学习的天花板，可能是预训练决定的

O1 出来之后大家都很兴奋，Test Time Scaling 好像打开了一条新路。

但后来有个让人不舒服的观察：强化学习推理的上界，可能被预训练锁死了。

强化学习能 work，是因为预训练给了模型大量的思维素材。强化学习在这些素材里搜索，找到那条对的路径并放大。如果预训练对这个问题的理解根本不够深，素材里就没有解题方法，用多少强化学习都找不到。

所以现在大家开始做 Continuous Learning：想在推理过程中同时更新模型权重，不只是搜索，而是让模型在做的过程中真正学到东西。

这个方向还在早期，但逻辑上是对的。

#### Agent 的洪水已经来了

他在年终总结里写了：洪水马上来了。

大部分人没感觉，因为不是 AI 从业者。日子还是岁月静好，直到某天突然发现自己被裁了：这次不是因为跟老板有矛盾，不是因为在这家公司做得不好是全行业的逻辑变了，技能在任何地方都没有用了。

Agent 颠覆的不只是工作方式。

你以前花两小时在亚马逊找东西、比价、下单。Agent 不会被闪烁的特价按钮吸引，不会因为广告 Banner 点进去，它只看最优解。整个电商逻辑、整个广告逻辑，都会变。

已经有人在用 Agent 帮自己买东西，说买得很开心：Agent 知道他所有的 preference，效率远高于自己浏览。

这不是五年后的事。

![Image](https://pbs.twimg.com/media/HDf1FZHaMAAMXb8?format=jpg&name=large)

#### 关于下一代教育，他只有一个答案

未来二十年会是什么样，他说真的不知道。

以前写科幻，一个想法可以慢慢写，因为五十年内不会发生。现在倒过来了：想法如果不写，明天就变成历史了，不是科幻。

能确定的只有一点：人的目的性，是机器替代不了的。这里不是说 AI 不能替代，本质上如果那部分被替代之后，这件事就失去意义了。

一部小说，一件艺术作品，它的价值在于：一个人有了某种冲动，把这个冲动变成了现实。这个冲动，不能外包。

所以教育下一代，核心只有一件事：让他找到自己的动力。有了动力，工具他自然会用，方向他自然会找。

![Image](https://pbs.twimg.com/media/HDf1Y9yaAAAg53u?format=jpg&name=large)

你觉得 Agent 来了之后，最先被颠覆的行业是哪个？

这篇文章的主旨是：田渊栋对 AI 发展的几个关键判断很值得重视，尤其是护���河、记忆瓶颈、强化学习上限，以及 Agent 即将带来的行业冲击。核心观点可以概括为：AI 还在快速进化，但真正难的不是“做大”，而是“理解”和“学习”的质变。

- 护城河：数据最重要，算法没那么重要
  - 他给出的护城河排序是：`数据 > Infra > 算力 > 算法 ≈ 人才`。
  - 数据排第一，因为真正有价值的是垂直领域、业务场景里长期积累的数据，这类数据稀缺、难复制，AI 也很难凭空生成。
  - Infra 排第二，但优势在缩小。原因是 AI 写代码让工程效率大幅提升，他举例说，相比三个月前，效率至少提高了 `10 倍`，未来很多原本需要强工程团队的事，可能“一个人 + AI”就能完成。
  - 算法的护城河被高估了。因为硅谷信息传播很快，一个新方法出来，`两三个月`后基本就公开化了。比如 DeepSeek 对残差连接做改动后，很快就有人发现简化版也能达到接近效果。

- 大模型的记忆：分短期和长期，但都有限制
  - 很多人以为上下文窗口就是模型全部记忆，其实不是。模型有两层记忆：
  - 短期记忆是上下文窗口，优点是灵活、响应快，但容量有限，窗口一长效果就会变差。
  - 长期记忆是模型权重，知识写在预训练里，后续很难改。预训练扎实，模型就更容易“举一反三”；预训练不足，很多步骤都得重新解释。
  - 他提到 Meta 在 `2023 年`做过 Positional Interpolation，用较小训练代价把长上下文映射到短上下文，从而实现窗口扩展；这之后各家模型都开始显著拉长 context window。
  - 记忆研究的难点在于：如果“全记住”，成本太高；如果“选择性遗忘”，又可能漏掉关键信息。H2O 这类工作，重点就是把重要记忆重新捞回来，但这个矛盾目前还没有“银弹”。

- 从记住知识到真正理解：AI 还没跨过最难的一步
  - 他用女儿学数数举例：前期教了很久似乎没效果，但某一天突然不仅会数数了，还能理解数字大小、推断两位数关系，这是一种“质变”。
  - 他认为大模型现在更像“存知识、调知识”，还没有发生这种内部重组后的真正理解飞跃。
  - Google 的 Nested Learning 虽然试图把学习过程统一成 associative memory，但本质上还是在记“点”，还没形成完整的世界理解。
  - 他说的大意是：现在模型还做不到“观其大概”——不是死扣细节，而是在深层理解后自然推出结论。

- Scaling Law：有效，但越来越贵
  - Scaling Law 仍然有效，所以大厂没有停下来的理由。
  - 但问题是代价在指数级上升：存储是瓶颈、电力是瓶颈、单卡内存不够就得切分模型，切分后通信延迟增加，整个系统效率都会被拖慢。
  - 那为什么 OpenAI、Google 还继续投入？因为路径依赖。团队、流程、资源都已经围绕这条路线搭好了，继续扩规模是最稳妥、最容易见效的办法。
  - 只有等投入产出比明显下降、回报越来越少时，大厂才更可能认真转向新路线；他认为现在还没到那个节点。

- 强化学习的上限：可能被预训练决定
  - O1 出来后，大家对 Test Time Scaling 很兴奋，觉得推理阶段还能继续“榨出”能力。
  - 但一个关键问题是：强化学习能达到多高，可能取决于预训练时模型脑子里有没有“素材”。
  - 简单说，强化学习更像是在已有知识里搜索更优路径；如果预训练根本没学到相关理解，那后面再怎么强化学习，也找不到正确解法。
  - 所以现在大家开始重视 Continuous Learning：希望模型在推理过程中不仅搜索答案，还能同步更新权重，真正学到新东西。这个方向还很早期，但逻辑上更合理。

- Agent：不是遥远未来，而是正在到来的“洪水”
  - 他判断 Agent 带来的冲击会非常快，只是大多数非 AI 从业者还没真正感受到。
  - 风险在于，很多人可能不是因为在原公司做得差而失业，而是整个行业逻辑变了，原有技能在任何公司都不再需要。
  - Agent 改变的不只是办公效率，还会改变商业模式。比如电商里，人类会被促销按钮、广告 Banner 吸引，但 Agent 只看“最优解”，这会直接冲击广告逻辑和平台导购逻辑。
  - 文中举了一个具体例子：已经有人用 Agent 帮自己购物，因为 Agent 了解他的全部偏好，买得更快、也更满意。作者强调，这不是 `5 年后`的事，而是很近的变化。

- 教育的重点：不是教技能，而是找到内在动力
  - 对未来 `20 年`会怎样，他承认很难预测，因为变化太快，很多今天的想法明天就可能变成现实。
  - 但他认为有一点相对确定：人的“目的性”很难被替代。
  - 比如小说、艺术作品的价值，不只是成品本身，而是“一个人为什么想做这件事，并把冲动变成现实”。这种内在驱动不能外包给机器。
  - 所以他对下一代教育的答案很简单：最重要的是帮助孩子找到自己的动力。只要有动力，工具会自己学，方向也会自己找。

如果再压缩成一句话，这篇文章最核心的提醒是：短期看，AI 的竞争关键在数据和落地；中期看，真正的瓶颈在记忆与理解；长期看，Agent 会重塑工作和商业，而人最需要守住的是“主动想做什么”。
