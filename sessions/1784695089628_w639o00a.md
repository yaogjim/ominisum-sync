#### 内容总结

这篇内容介绍了 Callstack 开源的移动端自动化 CLI 工具 **agent-device**。它的核心价值是让 Coding Agent 能够直接操作真实的 iOS/Android 应用，并完成探索、验证、记录和回放等任务。

##### 1. agent-device 的定位与核心能力

- **agent-device 是 Callstack 开源的移动端自动化 CLI**。
- 官方定位是：**“Mobile app verification for AI agents”（面向 AI Agent 的移动应用验证）**。
- 它并不是要完全取代传统测试框架，而是为 AI Agent 提供操作移动应用的能力。

AI Agent 可以通过它完成：

- 打开应用；
- 读取应用的 **Accessibility Snapshot**；
- 根据语义化的 `ref` 定位并点击控件；
- 输入文本；
- 截图与录屏；
- 采集应用日志；
- 抓取性能数据；
- 将探索过程保存为可重复执行的 `.ad` 脚本。

例如，Agent 可以打开一个购物 App，读取当前页面中的“搜索框”或“加入购物车”按钮，通过语义引用完成点击和输入，再将整个操作流程保存下来，之后重复回放。

##### 2. 支持的应用类型与运行环境

agent-device 不仅支持原生移动应用，还支持：

- 使用 **Expo** 构建的应用；
- 使用 **Flutter** 构建的应用；
- 在真实 iOS/Android 设备上运行的应用；
- 在 iOS/Android 模拟器上运行的应用。

这意味着开发者可以让 AI Agent 在接近真实用户使用环境的条件下，对移动应用进行操作和验证。

#### agent-device：让 AI Agent 操作并验证真实移动应用

Callstack 开源的 **agent-device** 是一款移动端自动化 CLI，核心能力是让 Coding Agent 像用户一样操作真实的 iOS、Android 应用，并完成验证、记录与复现。官方将其定位为“面向 AI Agent 的移动应用验证工具”，而非传统自动化测试框架的替代品。

##### 从界面理解到操作与诊断

agent-device 为 Agent 提供了一套完整的移动端工具能力：

- 打开应用，读取无障碍界面快照（accessibility snapshot）。
- 根据具有语义的元素引用执行点击和输入，而非只依赖屏幕坐标。
- 截图、录屏、采集日志，并抓取性能数据。
- 将探索和操作过程保存为可重复执行的 `.ad` 脚本。

这意味着 Agent 不仅能生成移动端代码，还能进入真实运行环境，自主检查界面、执行交互、收集问题证据，并复现操作路径，形成“开发—运行—验证”的闭环。

##### 支持多种技术栈与运行环境

该工具不仅支持原生 iOS、Android 应用，也可操作使用 **Expo** 和 **Flutter** 构建的应用；运行环境覆盖模拟器和真机，适用范围较广。

其产品意义在于：它把 AI 编程能力从代码层延伸到真实 App 的交互与验证层，可用于 Agent 驱动的功能验收、问题排查和探索式检查。但按照官方定位，它更适合作为 AI Agent 的验证工具，而不是直接取代成熟、确定性更强的传统测试体系。
