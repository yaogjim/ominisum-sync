Initial release: six6 cognitive loop for Claude Code

#### 🧠 six6

**Give Claude Code a thinking brain.**

*Memory · Meditation · Daydream · Autonomous thinking*

Quick Start · Features · Architecture · Configuration · Cloud Tasks

---

#### 😤 Problem

```
You: remember that API design we discussed last week?
AI:  I don't have access to previous conversations. Could you remind me?

You: ...we literally spent 2 hours on it
AI:  I apologize, but each conversation starts fresh. I don't retain memory.

You: *dies inside*
```

Claude Code is stateless. Every session starts from zero. No memory of past conversations, no reflection on what worked, no creative connections across contexts.

---

#### ✨ Solution

six6 gives Claude Code a cognitive loop:

Module What it does When

**Memory** Graphiti knowledge graph, persists across sessions Always on

**Meditation** Daily reflection, compresses experiences into insights 2:30 AM

**Daydream** Random memory sampling, sparks unexpected connections 5:00 PM

**Hooks** Auto memory recall on every prompt, zero manual work Every message

Your AI assistant becomes a **thinking partner** that grows with you.

---

```
# 1. Clone
git clone https://github.com/ythx-101/six6-claude-code.git
cd six6-claude-code

# 2. Start Graphiti (needs OpenAI key for embeddings)
export OPENAI_API_KEY="sk-..."
docker compose up -d

# 3. Install hooks
mkdir -p ~/.claude/hooks
cp hooks/*.py ~/.claude/hooks/
chmod +x ~/.claude/hooks/*.py

# 4. Add to ~/.claude.json
```

```
{
  "mcpServers": {
    "six6-memory": {
      "type": "http",
      "url": "http://localhost:8000/mcp"
    }
  }
}
```

```
# 5. Add hooks to ~/.claude/settings.json (see config/settings.example.json)

# Done. Start Claude Code.
```

See docs/memory-setup.md for remote deployment.

Mode Graphiti runs on Cloud /schedule Multi-device

#### 🎯 Features

##### Memory System

Every conversation gets indexed into a knowledge graph:

```
You: We decided to use PostgreSQL instead of MongoDB for the user service
     ↓ auto-saved to Graphiti
     ↓ recalled next time you mention "user service" or "database"
```

Memory groups:

- `raw` — daily conversations, observations
- `reflection` — meditation outputs, insights
- `topic_lab` — creative seeds from daydreams
- `soul` — core beliefs, principles (rarely changes)

Nightly reflection that:

1. Searches today's memories
2. Writes 300-500 word reflection
3. Identifies cognitive changes
4. Saves to `reflection` group

Runs on Claude's cloud even when Mac sleeps.

Creative exploration that:

1. Randomly samples 5-8 memories across groups
2. Finds unexpected connections
3. Generates idea seeds
4. Saves to `topic_lab` group

"What if the database migration pattern we discussed connects to that distributed systems paper?"

##### Hooks

Hook Trigger Action

`memory-recall.py` Every user message Search &amp; inject relevant memories

`stop-memory-check.py` Session end Remind to save important insights

`post-memory-add.py` Memory write Log to `~/.claude/memory-log.jsonl`

#### six6：给 Claude Code 装上 “持续思考的大脑”

##### 一、这是什么

`six6`是一个为 Claude Code 设计的 “认知循环系统”。  
它试图解决 AI 助手每次会话都 “失忆” 的问题，让助手不仅能记住过去，还能定期反思、联想，并在后续对话中自动调用相关记忆。

一句话说：**它把一次性聊天工具，升级成会不断积累认知的长期型助手。**

##### 二、核心问题

传统 Claude Code 的短板很明显：

- **没有长期记忆**：上次聊过的内容，下次就忘了
- **没有反思机制**：不会总结哪些思路有效、哪些决策值得保留
- **没有跨场景联想**：无法把不同话题中的经验连接起来

对重度用户来说，这意味着：  
**每次都要重新 “教育” 助手，协作成本很高。**

##### 三、它的解决方案

six6 通过 4 个模块构建一个认知闭环：

###### 1. 记忆（Memory）
把日常对话自动写入知识图谱，形成可持续积累的 “外部大脑”。

###### 2. 冥想（Meditation）
每天定时回顾当天记忆，提炼成更高层的洞察和反思。

###### 3. 白日梦（Daydream）
随机抽取不同记忆片段，生成意外连接，激发新想法。

###### 4. 自动钩子（Hooks）
在每次用户发消息时，自动检索并注入相关记忆，几乎不需要手动操作。

##### 四、产品价值

six6 的意义不只是 “记住内容”，而是让 AI 更像一个持续进化的协作伙伴：

- **从 “工具” 变成 “伙伴”**：不再每次从零开始
- **提高连续协作效率**：项目、决策、偏好都可延续
- **增强洞察能力**：通过反思与联想生成新认知
- **支持长期知识沉淀**：适合复杂产品、技术、研究型工作流

##### 五、系统怎么工作

整体架构可以理解为三层：

###### 1. 本地交互层
Claude Code + Hooks，负责日常对话时的记忆召回与保存。

###### 2. 记忆存储层
基于 Graphiti 和数据库，负责长期存储与检索知识图谱。

###### 3. 云端任务层
通过定时任务执行 “冥想” 和 “白日梦”，即使本地设备休眠也能运行。

这意味着它既支持**本地使用**，也支持**远程部署和多设备同步**。

##### 六、主要能力亮点

###### 1. 自动记忆沉淀
对话内容会被自动索引，例如你提到某个服务、数据库或决策，之后相关话题出现时可以被召回。

###### 2. 分层记忆管理
记忆被分成几类：

- `raw`：原始日常对话
- `reflection`：反思后的洞察
- `topic_lab`：创意和灵感种子
- `soul`：相对稳定的原则和信念

###### 3. 定时反思与创意生成
系统不仅存储信息，还会主动做总结和跨主题联想，形成更高价值的内容。

##### 七、部署与使用门槛

它并不是一个开箱即用的消费级产品，更像一个面向高级用户的增强框架。  
使用它通常需要：

- 配置 OpenAI Key
- 启动 Graphiti 服务
- 安装 Claude hooks
- 修改本地 Claude 配置
- 视情况部署云端定时任务

所以更适合：

- 深度使用 Claude Code 的开发者
- 希望构建长期 AI 工作流的人
- 对 “AI 记忆系统” 有强需求的产品 / 研究用户

##### 八、总结判断

six6 的本质，是在为 Claude Code 补齐 “长期记忆 + 反思 + 联想” 能力。  
它最有价值的地方，不是单纯记住聊天记录，而是让 AI 开始具备一种**持续积累认知、逐步形成上下文理解**的能力。

如果你把 AI 看作一次性问答工具，它可能有点重；  
但如果你希望 AI 成为长期协作伙伴，six6 代表的是一个很有前景的方向。
