## 分析要点

- **核心高价值点**：企业Agent不只有工具增强一种形态，还可按“代客户交付业务、重构自身经营、开放存量系统能力”划分为三种不同落地路线。
- **留存建议**：保留三类落地路线框架，作为企业Agent方案设计与模式选择的参考（提出了可复用的企业AI落地分类，能够辅助区分运营交付、内部经营改造和存量平台开放三种系统形态。）

**知识要点**

- 垂直运营交付模式由AI系统直接承接从业务受理到完成交付的完整流程。
- Agent重构主营业务需要同步调整数据、流程、岗位、评测和运营，而非仅增加对话入口。
- 存量平台可将数据、权限、业务逻辑和工作流封装为受控能力，供Agent调用并降低迁移成本。

**行动项**

- 将现有企业Agent项目归入三种路线之一，明确其价值来源和交付边界。
- 评估现有系统的数据、权限、规则和工作流是否能够以受控接口开放给Agent。
- 若采用经营重构路线，为转化率、NPS、服务容量和收入建立对应评测指标。

## 正文

**凡人小北**

最近在看 AI native 的系统构建，Salesforce 是其中一个经典的落地路线，还有其他两个形态：corgi 和 kavak。  
corgi 是一家保险理赔公司，kavak 是一家拉美的二手车运营平台。

具体三个路线：  
路线一：Corgi 式“垂直运营交付”，直接承接一宗理赔从报案到结案的运营服务。

路线二：Kavak 式“用 Agent 重做自身经营”，用 Agent 改变获客、转化、服务容量和客户体验，直接对应主营业务的转化、NPS、服务客户数和收入。落地需要数据、流程、岗位、评测和运营一起调整。

路线三就是这个 Salesforce in Claude 的“把存量平台开放给 Agent”  
Salesforce 的优势是已经拥有客户数据、权限、规则、工作流和分发入口。可以让 Agent 站在现有系统之上工作，迁移成本相对低。Salesforce 把这种能力称为 Headless 360：数据、工作流、业务逻辑和权限被开放成受控能力，供新的 AI 入口调用。这给了 Agent 一个现成的业务底座，这也是现在企业最好落地的一种形态。

## 通俗精炼（1）

#### AI 原生企业系统的三条落地路线

文章将 AI 原生系统归纳为三种形态：替客户完成垂直业务、用 Agent 重构自身经营，以及让 Agent 调用企业已有平台。作者认为，Salesforce 代表的第三条路线迁移成本较低，是目前企业较容易落地的形态。

##### Corgi：直接交付完整业务结果

保险理赔公司 Corgi 采用“垂直运营交付”模式，不只是提供软件，而是直接承接一宗理赔从报案到结案的全流程。AI 被嵌入实际运营，客户购买的是最终业务成果，而非单一工具。

##### Kavak：用 Agent 重做核心经营流程

拉美二手车平台 Kavak 将 Agent 用于改造自己的获客、转化和服务流程，目标直接对应转化率、NPS、服务客户数和收入。其难点不只是部署模型，还要同步调整数据、流程、岗位分工、效果评测与运营机制，本质上是组织和经营体系的重构。

##### Salesforce：把存量业务能力开放给 Agent

Salesforce 的路径不是推翻原有系统，而是让 Agent 在其上工作。其已有的客户数据、权限、规则、工作流和分发入口，可通过“Headless 360”以受控方式供 AI 调用，为 Agent 提供现成的业务底座。

目前测试版“Salesforce in Claude”提供 37 项预置销售技能，用户可在对话中准备客户通话、审查交易、创建销售管道仪表板或生成预测。其意义在于：企业能保留既有系统与治理机制，同时增加自然语言交互和自动执行能力，降低 AI 接入业务的迁移门槛。
