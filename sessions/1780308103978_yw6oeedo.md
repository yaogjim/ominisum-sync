**Y11**

最值得关注的开源项目（按影响力和信息差排序）

\---  
S 级：必须关注

1\. Pi (pi-mono) — 54K stars，MIT，Armin Ronacher 出品  
\- Flask/Jinja2 作者的新作，系统 prompt 不到 1000 token，靠"懒加载技能"运行  
\- 支持 fork 和二次开发，token 效率极高  
\- 信息差原因：中国社区对 Armin Ronacher 的认知还停留在 Flask，不知道他已经杀入 AI Agent 赛道

2\. Claw Code — 192K stars，MIT，Python/Rust 重写  
\- 2026 年 3 月 Claude Code 源码泄露后，社区 clean-room 重写  
\- GitHub 历史上最快达到 100K stars 的仓库  
\- 信息差原因：国内几乎没有报道这个项目，但它已经是 star 数最高的 AI 编程工具

3\. Hermes Agent — 167K stars，Nous Research 出品  
\- 自我改进的 CLI Agent，持久记忆 + 自动技能创建  
\- 支持 300+ 模型，跨平台（Telegram/Slack/Discord/WhatsApp）  
\- 信息差原因：Nous Research 在国内知名度远低于其实力

4\. Bernstein — Apache 2.0，Python 编排器  
\- 一个 LLM 调用做规划，后续调度/git worktree 隔离/质量门禁/审计链全确定性执行  
\- 支持 40+ CLI 编程 Agent（Claude Code、Codex、Gemini CLI、Cursor、Aider）  
\- 信息差原因：Agent 编排层的新范式，国内还没人讨论

\---  
A 级：高度推荐

5\. Omi (BasedHardware) — 开源 AI 项链，7756 commits  
\- BLE 芯片 + 麦克风，音频通过 OPUS 编码流式传输到手机  
\- 已合并 OpenGlass（眼镜配件），支持 Ollama 本地模型  
\- 免费层：完全开源，硬件 BOM 成本低  
\- 信息差原因：国内对可穿戴 AI 的关注集中在大厂产品，不知道开源方案已经这么成熟

6\. Mastra — 23K stars，Apache 2.0，TypeScript  
\- Gatsby.js 团队出品，Observational Memory 技术将 token 成本降低 4-10x  
\- 文本压缩 3-6x，工具输出压缩 5-40x  
\- 信息差原因：TypeScript 生态的 Agent 框架在国内几乎无人讨论

7\. Crush — 25K stars，Charm 出品，Go TUI  
\- Bubble Tea 团队的新作，终端美学极致  
\- 支持 MCP、LSP、中途切换模型  
\- 注意：FSL 许可证（2 年后转 MIT）

8\. Qwen Code — 25K stars，Apache 2.0，阿里出品  
\- Gemini CLI 的开源 fork，针对 Qwen-Coder 模型调优  
\- Gemini CLI 将于 2026 年 6 月 18 日退役，Qwen Code 成为事实上的开源继承者  
\- 信息差原因：Gemini CLI 退役的消息在国内几乎没报道

#### 总结

这篇内容列出 **8 个“值得关注”的开源 AI/Agent 项目**，按重要性分为：

   - 卖点：极简系统 prompt + 懒加载技能。

2. **Claw Code**
   - AI 编程工具，声称增长极快。
   - 卖点：类似 Claude Code 的开源重写。

3. **Hermes Agent**
   - Nous Research 出品的 CLI Agent。
   - 卖点：持久记忆、自我改进、支持多平台和多模型。

4. **Bernstein**
   - Agent 编排器。
   - 卖点：让 LLM 负责规划，后续执行尽量确定化，强调隔离、审计和质量控制。

##### A 级：高度推荐

5. **Omi**
   - 开源 AI 可穿戴设备。
   - 卖点：AI 项链、麦克风、BLE、可接本地模型。

6. **Mastra**
   - TypeScript Agent 框架。
   - 卖点：降低 token 成本，做记忆和压缩。

7. **Crush**
   - Go 写的终端 AI 工具。
   - 卖点：终端体验好，支持 MCP、LSP、模型切换。

8. **Qwen Code**
   - 阿里出品的 AI 编程工具。
   - 卖点：基于 Gemini CLI fork，适配 Qwen-Coder。

#### 解读

这篇文章的核心逻辑是：

> 不只是看 star 数，而是看“未来可能影响 AI Agent 生态的开源项目”。

它重点关注三类方向：

##### 1. AI 编程工具

例如：

- Claw Code
- Qwen Code
- Crush

这类项目想解决的是：

> 让 AI 像程序员助手一样，在终端里读代码、改代码、跑命令、修 bug。

通俗讲，就是开源版 Claude Code / Cursor / Devin 的不同变体。

---

##### 2. Agent 框架与编排层

例如：

- Pi
- Hermes Agent
- Bernstein
- Mastra

这类项目不只是“聊天”，而是让 AI 能：

- 规划任务
- 调用工具
- 记住历史
- 自动创建技能
- 多步骤执行
- 控制成本和质量

通俗讲，就是在做：

> 让 AI 从“会回答问题”变成“会干活”。

---

##### 3. AI 硬件与可穿戴设备

例如：

- Omi

它代表的是另一个趋势：

> AI 不只在电脑和手机里，也会进入眼镜、项链、耳机等随身设备。

如果成熟，未来可能变成“随身 AI 助理”。

---

#### 需要警惕的地方

这篇内容有明显“榜单文”特征：

- 语气很确定
- 强调“信息差”
- 大量使用 star 数背书
- 有些说法可能未经核实
- 评论区也有人指出存在错误

尤其需要注意：

##### 1. Star 数不等于项目质量

GitHub star 高，可能说明：

- 热度高
- 营销强
- 蹭热点成功

但不一定代表：

- 代码好
- 能长期维护
- 真能用于生产

---

##### 2. “信息差”可能是包装话术

文章多次说：

> 国内没人知道  
> 国内没人讨论  
> 国内没有报道

这种说法容易制造焦虑，但不一定准确。

真正要看的是：

- 是否持续更新
- 是否有真实用户
- 文档是否完善
- issue 是否活跃
- 是否有稳定 release
- 许可证是否友好

---

##### 3. 部分事实可能需要核实

评论区已经有人指出：

- Pi 作者信息可能有误
- Claw Code 的爆火来源可能并不单纯
- “信息差”判断可能不准确

所以不要直接把它当权威榜单。

---

#### 我的意见

这篇文章**有参考价值，但不能全信**。

我建议这样看：

##### 值得重点关注

###### 1. Bernstein

因为它关注的是 **Agent 编排层**。

未来 AI Agent 真正难的不是“让模型说话”，而是：

- 如何安全执行
- 如何复现结果
- 如何隔离环境
- 如何审计过程
- 如何控制失败风险

这个方向很重要。

---

###### 2. Mastra

TypeScript 生态的 Agent 框架值得关注。

原因很简单：

> 大量前端、全栈和 SaaS 项目都在 TS 生态里。

如果它能把记忆、工具调用、成本压缩做好，会有实际落地价值。

---

###### 3. Omi

开源 AI 硬件值得关注。

但它的难点不是模型，而是：

- 续航
- 隐私
- 佩戴体验
- 语音识别质量
- 场景是否刚需

方向有想象力，但落地难度也高。

---

##### 谨慎看待

###### Claw Code / Pi / Hermes Agent

这些项目听起来很强，但需要进一步确认：

- 作者背景是否属实
- star 是否自然增长
- 是否真有核心创新
- 是否只是 Claude Code / Cursor 热潮下的跟风项目

---

#### 最后结论

这篇榜单可以作为：

> “AI Agent 开源项目观察清单”

但不能作为：

> “投资、选型、技术决策依据”。

如果你真想跟进，建议优先看三件事：

1. **项目是否持续维护**
2. **是否有真实 demo 和用户案例**
3. **许可证是否适合商业使用**

一句话：

> 别被“信息差”带节奏，真正的信息差在于你亲自跑一遍、读一遍代码、看一遍 issue。
