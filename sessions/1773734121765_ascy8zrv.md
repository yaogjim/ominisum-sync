## 正文

**indigo**

Nvidia 宣布全力支持 OpenClaw 开源项目，将其定位为 Agent 电脑的操作系统 — 连接大语言模型、管理资源、访问工具和文件系统、调度任务、拆解提示为步骤、调用子 agent、支持任意模态输入输出。他直言：“我用了跟描述操作系统完全相同的语法。”

Windows 催生了个人电脑，OpenClaw 要催生个人 Agent。每家软件公司的 CEO 现在都需要回答一个问题：“你的 OpenClaw 策略是什么？” 正如当年每家公司都需要 Linux 策略、HTTP 策略、Kubernetes 策略。

目前最大挑战是企业安全！Agent 能在企业网络中访问敏感信息、执行代码、对外通信 — 这显然不能放任不管。NVIDIA 因此推出 NemoClaw 参考设计，整合 OpenShell 安全技术，网络护栏 + 隐私路由器，各 SaaS 公司可将自身策略引擎接入，由 OpenShell 统一执行管控。

这就是企业 IT 的文艺复兴✨

黄老板断定：每一家 SaaS 公司都将变成 AaaS（Agent as a Service）公司。企业 IT 产业将从 2 万亿美元规模向数万亿扩张 — 不再提供工具让人操作，而是提供特定领域的 Agent 供人租用。

未来每位工程师都会有年度 token 预算，金额大约是年薪的一半，用来将生产力放大 10 倍。“这已经是硅谷的招聘工具了——你的工作附带多少 token？”

逻辑闭环由此形成：未来每家软件公司都是 Agent 式的，既是 token 的消费者（赋能自己的工程师），也是 token 的生产者（服务所有客户）。
