#### Features

- **Visual Canvas** — Drag-and-drop components with live ANSI preview at configurable zoom levels
- **20+ TUI Components** — Screen, Box, Button, TextInput, Checkbox, Radio, Select, Toggle, Text, Spinner, ProgressBar, Table, List, Tree, Menu, Tabs, Breadcrumb, Modal, Popover, Tooltip, Spacer
- **Layout Engine** — Absolute, Flexbox, and Grid layout modes with full property control
- **Color Themes** — Dracula, Nord, Solarized Dark/Light, Monokai, Gruvbox, Tokyo Night, Nightfox, Sonokai — all updating the canvas in real-time
- **Dark / Light Mode** — Toggle between dark and light editor UI; persists across sessions
- **Layers Panel** — Hierarchical component tree with drag-to-reorder, visibility toggle, lock, and inline rename
- **Property Panel** — Edit layout, style, and component-specific props for the selected component
- **Undo / Redo** — Full history for all tree mutations
- **Save / Load** — `.tui` JSON format via native OS file picker (Chrome/Edge) or browser download (Firefox/Safari)
- **Multi-Framework Export** — Generate code for Ink, BubbleTea, Blessed, Textual, OpenTUI, Tview
- **Command Palette** — `Cmd/Ctrl+P` for quick component creation, theme switching, and dark/light mode toggle
- **Gradient Backgrounds** — Add linear gradients to any element background with angle control and N color stops; rendered as discrete character-cell bands matching real ANSI terminal output
- **Settings** — Accent color presets, dark/light mode toggle, and default download folder

## 结构化（1）

### 2026-03-16 09:08:44

这篇文章主要介绍了`tui-studio`这个项目：它是一个类似 Figma 的可视化编辑器，用来设计终端界面（TUI）应用。核心价值在于：用户可以通过拖拽和可视化配置来搭建 TUI，并一键导出到多个主流框架。

- **项目定位**
  - `tui-studio`是一个 “终端 UI 可视化设计工具”，目标是降低 TUI 应用的设计和开发门槛。
  - 它提供实时画布，用户像做界面设计一样搭建终端应用，而不是纯手写代码。

- **核心功能**
  - 支持可视化画布：组件可拖拽到画布中，并实时预览 ANSI 终端效果，还能调节缩放。
  - 内置`20+`种 TUI 组件，包括`Screen`、`Box`、`Button`、`TextInput`、`Table`、`Tabs`、`Modal`、`Tooltip`等。
  - 提供多种布局方式：`Absolute`、`Flexbox`、`Grid`，并可细调属性。
  - 支持分层管理：有图层面板，可拖动排序、切换显示 / 隐藏、锁定和重命名组件。
  - 提供属性面板，可直接编辑布局、样式和组件专属属性。
  - 支持完整的撤销 / 重做历史记录。

- **主题与界面体验**
  - 内置多套颜色主题，如`Dracula`、`Nord`、`Solarized Dark/Light`、`Monokai`、`Gruvbox`、`Tokyo Night`、`Nightfox`、`Sonokai`，且能实时刷新画布效果。
  - 编辑器本身支持深色 / 浅色模式切换，并且会跨会话保存。
  - 支持渐变背景，可设置线性渐变角度和多个颜色点，并以贴近真实 ANSI 终端输出的字符带形式渲染。

- **效率工具与操作方式**
  - 提供命令面板，可通过`Cmd/Ctrl+P`快速创建组件、切换主题和切换深浅模式。
  - 常用快捷键完整，例如：
    - 保存：`Cmd/Ctrl+S`
    - 打开：`Cmd/Ctrl+O`
    - 导出：`Cmd/Ctrl+E`
    - 撤销：`Cmd/Ctrl+Z`
    - 重做：`Cmd/Ctrl+Shift+Z`或`Cmd/Ctrl+Y`
  - 还支持组件快捷键，例如按`b`快速创建`Button`，按`t`创建`Tabs`，按`l`创建`List`。

- **保存、导出与兼容性**
  - 项目文件保存为`.tui`格式，本质是 JSON，包含版本、项目元数据、主题和组件树等信息。
  - 支持多框架导出，覆盖多种语言生态：
    - `Ink`：TypeScript / React
    - `BubbleTea`：Go
    - `Blessed`：JavaScript
    - `Textual`：Python
    - `OpenTUI`：TypeScript
    - `Tview`：Go
  - 保存 / 加载可通过原生系统文件选择器或浏览器下载方式完成，兼容不同浏览器。

- **快速开始与技术栈**
  - 启动方式很直接：`git clone`后执行`npm install`、`npm run dev`，再打开`http://localhost:5173`。
  - 技术栈包括：
    - `React 19`
    - `TypeScript 5.8`
    - `Vite 7`
    - `Zustand 5`
    - `Tailwind CSS`
    - `Lucide React`
  - 常用命令有`npm run dev`、`npm run build`、`npm run lint`、`npm run preview`。

- **项目现状**
  - 仓库显示共有`132`次提交。
  - 代码语言占比以`TypeScript 97.0%`为主，`JavaScript 2.5%`，其余`0.5%`。
  - 目前 “未发布正式 Release，也没有发布 Packages”。
  - 作者还特别说明：自己主要是设计师，代码大多由 Claude 辅助完成。

一个直观例子是：如果你想设计一个带`Tabs`、`List`、`Button`和`Modal`的终端工具界面，不需要从零写布局代码，可以先在画布里拖出来、调样式和主题，再导出成`BubbleTea`或`Ink`代码继续开发。
