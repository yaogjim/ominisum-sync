Unsloth Studio 让你运行和训练文本、 [音频](https://unsloth.ai/docs/basics/text-to-speech-tts-fine-tuning) 、 [嵌入](https://unsloth.ai/docs/new/embedding-finetuning) 、 [视觉](https://unsloth.ai/docs/basics/vision-fine-tuning) 以及更多类型的模型。适用于 Windows、Linux 和 macOS。

#### ⭐ Features

Unsloth 提供了几个适用于推理和训练的关键特性：

##### Inference

- **搜索 + 下载 + 运行模型** 包括 GGUF、LoRA 适配器、safetensors
- **导出模型** ： [保存或导出](https://unsloth.ai/docs/new/studio/export) 模型到 GGUF、16 位 safetensors 以及其他格式。
- **工具调用** ：支持 [自修复工具调用](https://unsloth.ai/docs/new/studio/chat#auto-healing-tool-calling) 以及网络搜索
- **[代码执行](https://unsloth.ai/docs/new/studio/chat#code-execution)**: 让 LLMs 运行代码、数据并验证结果，从而使答案更加准确。
- 自动调整推理参数和自定义聊天模板
- 上传图片、音频、PDF、代码、DOCX 以及更多文件类型用于聊天。

##### Training

- 训练 **500+ 模型** 最高可达 **2 倍更快** ，同时最高节省 **70% 更少的显存** ，且无精度损失。
- 支持全量微调、预训练、4 位、16 位以及 FP8 训练。
- **可观测性** ：实时监控训练，跟踪损失和 GPU 使用率并自定义图表。
- **数据配方** ： [自动创建数据集](https://unsloth.ai/docs/new/studio/data-recipe) from **PDF、CSV、DOCX** 等。在可视化节点工作流中编辑数据。
- **强化学习** ：最高效的 [RL](https://unsloth.ai/docs/get-started/reinforcement-learning-rl-guide) 库，使用 **80% 更少的 VRAM** 用于 GRPO、 [FP8](https://unsloth.ai/docs/get-started/reinforcement-learning-rl-guide/fp8-reinforcement-learning) 等。
- [多 GPU](https://unsloth.ai/docs/basics/multi-gpu-training-with-unsloth) 训练已支持，即将迎来重大改进。

#### ⚡ Quickstart

Unsloth 可以通过两种方式使用：通过 **[Unsloth Studio](https://unsloth.ai/docs/new/studio/)** （网页用户界面），或通过 **Unsloth Core** （基于代码的版本）。每种方式有不同的要求。

Unsloth Studio 适用于 **Windows, Linux, WSL** 和 **macOS** 。

- **CPU：** 仅支持聊天推理
- **NVIDIA GPUs：** 训练可在 RTX 30/40/50、Blackwell、DGX Spark、DGX Station 以及更多设备上进行
- **macOS：** 目前仅支持聊天； **MLX 训练** 即将推出
- **多 GPU：** 现已可用，即将推出重大升级

```
git clone https://github.com/unslothai/unsloth.git
cd unsloth
pip install -e .
unsloth studio setup
unsloth studio -H 0.0.0.0 -p 8888
```

使用我们的 [Docker 镜像](https://hub.docker.com/r/unsloth/unsloth) `unsloth/unsloth` 容器。阅读我们的 [Docker 指南](https://unsloth.ai/docs/get-started/install/docker) 。

```
pip install unsloth
```

在 Windows 上， `pip install unsloth` 只有在安装了 PyTorch 的情况下才能使用。请阅读我们的 [Windows 指南](https://unsloth.ai/docs/get-started/install/windows-installation) 。你可以使用与 Unsloth Studio 相同的 Docker 镜像。

###### AMD, Intel

For RTX 50x, B200, 6000 GPUs: `pip install unsloth`. 阅读我们的指南，了解以下内容： [Blackwell](https://unsloth.ai/docs/blog/fine-tuning-llms-with-blackwell-rtx-50-series-and-unsloth) 和 [DGX Spark](https://unsloth.ai/docs/blog/fine-tuning-llms-with-nvidia-dgx-spark-and-unsloth)  
要在 **AMD** 和 **Intel** GPUs 上安装 Unsloth，请遵循我们的 [AMD 指南](https://unsloth.ai/docs/get-started/install/amd) 和 [Intel 指南](https://unsloth.ai/docs/get-started/install/intel) 。
