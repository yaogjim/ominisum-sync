## 正文

**Sac**

### 当未来可以被模拟，我们离预知还有多远？

昨晚，我经历了一个新的「震撼时刻」，上次这种时刻还是「人生k线」的问世。

这个产品的名字是「MiroFish」(

[@mirofish\_ai](https://x.com/@mirofish_ai)) ，仅仅只是一个小小的demo 片段，却让我盯着屏幕沉思了2个小时。 它有多么不可思议，Github中对 MiroFish 的介绍是这样的：

> MiroFish 是一款基于多智能体技术的新一代 AI 预测引擎。通过提取现实世界的种子信息（如突发新闻、政策草案、金融信号），自动构建出高保真的平行数字世界。在此空间内，成千上万个具备独立人格、长期记忆与行为逻辑的智能体进行自由交互与社会演化。

简单来说，你上传材料，MiroFish会根据材料生成多个模拟现实人类的Agent，让它们相互作用，推演未来。想象一下，假如未来可以被AI模拟，我们离预知还有多远。

### 思考一：Mirofish改变的是人们的决策方式

以前，我们一般是怎么决策的：

> 层级一：经验与直觉。通过过去经历形成的认知，做出判断。 层级二：专家咨询。通过咨询专家或者咨询公司，辅助做出决策。（甚至玄学咨询） 层级三：数据分析。运用软件分析海量数据做出判断。

现在：通过AI (MiroFish) 模拟未来，做出判断。 想象一下：

> 如果西贝用 MiroFish 进行公关指导，贾国龙可能就不会宣布西贝大规模闭店。 如果锤子手机用 MiroFish 预测市场反应，罗永浩现在可能就不会在做播客了。

我认为 MiroFish 最伟大的创新点之一在于其一定会改变未来世界的决策模式，小到个人每日决策，大到国家政策，谁不想用一个沙盘进行模拟辅助判断。

### 思考二：Agent究极进化论：从回答过去到预演未来

AI agent 1.0：单兵作战。你给agent一个待解决的问题，agent独立思考、调用工具、完成任务。 AI agent 2.0：Agent Teams。相比于1.0时代， agent 学会了分工协作，学会了更高效的完成任务。 需要补充的是，Agent 1.0 和 Agent 2.0 时代有一个共识的问题，模型都会受困于过去的数据。它就像一个学生反复做往年的真题，也许能越做越快、越做越准，但它的解题思路永远来自历史的经验。当面对真正前所未有的、没有历史参照的全新挑战时，这套方法就触及了它的极限。

Agent 3.0 时代：以 MiroFish 为代表的群体智能，是一个由成千上万个具有独立人格和长期记忆的Agents构成的「数字社会」。这些Agent在一个类似于真实世界的平行世界中自由交互、碰撞、演化，并推理出未来的结果。当成千上万个Agent产生真实的社会交互时，它们本身就在创造新的、不存在于任何历史数据中的信息。

为了方便大家理解我的观点，我用作者发布的红楼梦Demo来举例。这个Demo导入了《红楼梦》原著前80回的故事，让AI自行推演后续剧情，再与现有的后40回进行对比。 MiroFish从前80回的故事中提取出贾宝玉、林黛玉等角色，生成一群具有独立人格的Agent。这些Agent在数字世界中按照各自的性格自由交互，推演出属于它们自己的结局。而这些结局，是不存在于任何历史数据中的全新内容。

![Image](https://pbs.twimg.com/media/HC867OHbAAE2mzb?format=jpg&name=large)

具体的预测结果建议大家直接观看作者发布的demo视频，看完你会和我一样震撼。（链接在最后）

### 思考三：超级个体时代已经到来

MiroFish 作者是大四的学生，项目是10天vibe coding出来的，并获得了盛大3000万的投资。 他当前vibe coding的工作流是： figma 设计草图 - google ai studio 快速复制一个前端demo - 把页面补进项目文档，再把任务拆成模块，交给AI IDE 分批开发。 与此同时，他也在文章分享了些经验，包括可以使用多agent 并行一个任务等等。（以上总结自作者小红书文章）

通过阅读作者整篇文章，我最大的感受是超级个体时代已经来临，因为市场正在疯狂寻找那些能把AI转化为生产力的人，并且这样的案例正在一个个出现。在这个时代，真正让一个人脱颖而出的，是敢于创造的精神、独特的审美和丰富的想象力。毕竟，AI 让一切皆有可能。 最后借用Mirofish创始人的一句话：

> Vibe coding 做产品、做开源，是一条切实可行、可复制的路径，而且现在还不拥挤。

AI时代已经到来！至于如何play this game, it depends on you!

## 结构化（1）

### 2026-03-13 00:27:03

**主旨概括：**  
文章围绕 AI 预测引擎 **MiroFish** 展开，认为它的突破不只是“分析过去”，而是通过构建一个由大量智能体组成的“数字社会”来**模拟未来**，从而可能改变人类的决策方式。作者也借此进一步指出：AI 时代的“超级个体”正在加速出现。

---

##### 1. MiroFish 是什么：把“模拟未来”变成可能
- MiroFish 被介绍为一种基于**多智能体技术**的 AI 预测引擎。  
- 它会从现实世界中提取“种子信息”，例如：
  - 突发新闻
  - 政策草案
  - 金融信号
- 然后自动构建一个**高保真的平行数字世界**，让成千上万个具有：
  - 独立人格
  - 长期记忆
  - 行为逻辑  
  的 Agent 在其中自由互动、演化，进而推演未来。

**通俗理解：**  
你上传材料，它不是只给你一个分析报告，而是“造出一群数字人”，让它们在模拟社会里互动，看看未来可能怎么发展。

---

##### 2. 它可能改变决策方式：从“靠经验”到“先预演未来”
作者认为，MiroFish 最大的意义之一，是会改变人类做决策的方式。

###### 原来的决策模式
- **层级一：经验与直觉**  
  根据过往经历和个人判断做决定。
- **层级二：专家咨询**  
  找专家、咨询公司，甚至玄学方式辅助决策。
- **层级三：数据分析**  
  用软件和数据模型做判断。

###### 新的决策模式
- **通过 AI 模拟未来，再做决策。**

###### 文中举的例子
- 如果**西贝**用 MiroFish 做公关推演，贾国龙也许不会宣布“大规模闭店”。
- 如果**锤子手机**用它预测市场反应，罗永浩可能不会走到今天做播客这一步。

**核心观点：**  
未来无论是个人选择、企业决策，还是国家政策，大家都会希望先在 AI 沙盘里“演一遍”，再决定现实中怎么做。

---

##### 3. Agent 的进化：从回答问题，到创造未来场景
文章把 Agent 的发展分成三个阶段：

###### Agent 1.0：单兵作战
- 一个 Agent 接到任务后，自己思考、调用工具、完成任务。  
- 本质上还是单点解决问题。

###### Agent 2.0：团队协作
- 多个 Agent 分工合作，提高任务完成效率。  
- 但仍有一个共同限制：**依赖历史数据**。

###### 共同瓶颈
- 无论 1.0 还是 2.0，本质上都在“基于过去做推理”。  
- 就像学生反复做往年真题，可能越来越熟练，但面对**没有历史参考的全新问题**时，会碰到极限。

###### Agent 3.0：群体智能与“数字社会”
- 以 MiroFish 为代表。  
- 它不是让一个或几个 Agent 回答问题，而是让**成千上万个 Agent 构成一个社会**。  
- 这些 Agent 在平行世界中不断互动、碰撞、演化。  
- 在这个过程中，它们会产生**历史中从未存在过的新信息**。

**关键突破：**  
不再只是“学习过去”，而是通过社会化模拟，去“预演未来”。

---

##### 4. 红楼梦 Demo：一个直观案例
为了说明自己的观点，作者引用了 MiroFish 的一个 Demo：

- 系统导入《**红楼梦**》前 **80 回**内容；
- 再让 AI 自主推演后续剧情；
- 最后把它推演的结果，与现有的后 **40 回**进行对比。

###### 这个 Demo 的做法
- 从前 80 回中提取出**贾宝玉、林黛玉**等角色；
- 把这些人物变成具有独立人格的 Agent；
- 让它们在数字世界中按照各自性格自由互动；
- 最终推演出属于它们自己的结局。

###### 这个案例说明什么
- 这些结果不是简单复述原著，也不是从已有资料里“抄答案”；  
- 而是在角色互动中，生成了**历史数据里本来不存在的新剧情**。

**通俗理解：**  
它像不是在“续写小说”，而是在“把人物真的放进一个世界里，看他们自己会活成什么样”。

---

##### 5. 超级个体时代：AI 正在放大个人创造力
作者还从 MiroFish 创始人的经历，谈到了“超级个体”趋势。

###### 创始人背景与项目情况
- 作者是**大四学生**；
- 项目用 **10 天**通过 vibe coding 做出；
- 获得了**盛大 3000 万投资**。

###### 文中提到的工作流
- **Figma** 设计草图  
- 用 **Google AI Studio** 快速复制前端 demo  
- 把页面补进项目文档  
- 再拆成模块，交给 **AI IDE** 分批开发  
- 还可以用**多 Agent 并行**完成任务

###### 作者的判断
- 市场正在疯狂寻找那些**能把 AI 变成生产力的人**；
- 未来真正让个人脱颖而出的，不只是技术本身，而是：
  - 创造力
  - 审美
  - 想象力
  - 敢于动手的精神

**文中引用的观点：**  
> “Vibe coding 做产品、做开源，是一条切实可行、可复制的路径，而且现在还不拥挤。”

---

##### 6. 总结：文章最终想表达什么
- MiroFish 让作者看到一种新的可能：**AI 不只是回答问题，而是可以模拟社会、推演未来。**
- 它可能重塑从个人到组织的决策方式。
- 同时，MiroFish 创始人的案例也说明：AI 时代里，个人借助工具快速创造产品、放大影响力，已经越来越现实。

**一句话总结：**  
这篇文章既是在感叹 MiroFish 对“未来预测”的想象力，也是在强调：**AI 正把“预测未来”和“放大个人能力”同时推到新阶段。**
