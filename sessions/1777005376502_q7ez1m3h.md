#### README.md

#### wechat-daily

微信聊天日报生成器 — Claude Code Skill

从微信 Mac 4.x 的本地加密数据库提取聊天记录，用 AI 生成每日精华摘要。

#### 功能

- 自动解密微信本地数据库（AES-256-CBC + SQLCipher 4）
- 可配置监控指定群聊和联系人
- AI 生成精炼日报，按主题分类（工具技巧、行业动态、观点碰撞等）
- 支持指定日期查询

#### 安装

```
npx skills add mcncarl/yichen-skills
```

安装后在 Claude Code 中手动启用 wechat-daily skill。

##### 方式二：手动安装

将本目录复制到 `~/.claude/skills/wechat-daily/`

#### 依赖

- macOS + 微信 Mac 4.x
- Python 3.9+
- pycryptodome（数据库解密）
- zstandard（消息解压）
- frida + frida-tools（仅首次密钥提取时需要）

安装 Python 依赖：

```
pip3 install pycryptodome zstandard
```

首次提取密钥时还需安装 frida：

```
pip3 install frida frida-tools
```

#### 使用

安装后在 Claude Code 中说 **"日报"** 即可触发。

##### 首次使用

1. 说"日报"，Skill 会自动进入配置引导
2. 运行密钥提取脚本（需要登录微信）
3. 选择要监控的群聊和联系人
4. 自动生成首份日报

##### 日常使用

- **"日报"** — 生成昨天 08:00 到今天 08:00 的日报
- **"4月16日的日报"** — 生成指定日期的日报
- **"微信日报 2026-04-16"** — 同上

#### 配置文件

##### \~/.config/wechat-daily.json（用户配置）

```
{
  "wxid": "wxid_xxx",
  "db_base_path": "~/Library/Containers/com.tencent.xinWeChat/Data/Documents/xwechat_files/wxid_xxx/db_storage",
  "monitor_groups": ["群名1", "群名2"],
  "monitor_contacts": [],
  "report_dir": "~/Documents/wechat-daily",
  "time_mode": "8am_to_8am"
}
```

##### \~/.config/wechat-keys.json（密钥，自动生成）

```
{
  "message_0": "hex_key",
  "contact": "hex_key",
  "session": "hex_key"
}
```

#### 安全与隐私说明

- **所有数据仅在本地处理** ，不上传任何服务器
- 密钥存储在本地 `~/.config/` 目录，不包含在本项目中
- frida 仅在首次提取密钥时使用，提取后不再需要
- 本项目不收集、不存储、不上传任何用户聊天数据
- 建议定期更换密钥（重新运行 extract\_keys.py）

#### 法律合规声明

本项目仅供个人学习和研究使用。使用者需注意：

1. **仅限处理自己的聊天数据** ：解密和读取的数据库必须属于使用者本人
2. **不得用于侵犯他人隐私** ：未经他人同意，不得提取、传播他人的聊天记录
3. **遵守当地法律法规** ：使用 frida 等工具需遵守相关法律，不得用于非法目的
4. **微信用户协议** ：本工具涉及的操作可能违反微信用户协议，使用者需自行承担相关风险
5. **数据安全** ：生成的日报可能包含敏感信息，请妥善保管，不要公开发布包含他人隐私的内容

本项目在以下开源项目的基础上开发，感谢原作者的贡献：

#### 技术原理

微信 Mac 4.x 使用 SQLCipher 4 加密本地数据库：

- AES-256-CBC 分页加密（page\_size=4096, reserve=80）
- PBKDF2 密钥派生（256000 轮）
- 通过 frida hook `CCKeyDerivationPBKDF` 在运行时捕获密钥
- 部分消息内容使用 ZSTD 压缩

#### 微信聊天日报生成器：一文看懂

##### 这是什么
这是一个基于 Claude Code 的小工具，能从微信 Mac 4.x 的本地加密数据库中提取聊天记录，并自动生成“微信聊天日报”。  
它的核心价值是：把分散、冗长的聊天内容，整理成按主题分类的精华摘要，方便快速回顾重要信息。

##### 它能做什么
这个工具主要提供三类能力：

1. **读取聊天数据**：自动解密微信本地数据库，提取聊天记录。  
2. **生成日报**：利用 AI 对聊天内容进行提炼，总结成简洁日报。  
3. **按需配置**：可以指定监控哪些群聊、联系人，也支持按日期查询某一天的日报。

简单说，它解决的是“微信群消息太多、信息太散、每天没法高效复盘”的问题。

##### 怎么使用
安装后，在 Claude Code 中输入“日报”即可触发。  
首次使用时，工具会引导完成配置，包括提取密钥、选择监控对象，并生成第一份日报。

日常常见用法包括：
- `日报`：生成默认时间范围内的日报
- `4月16日的日报`
- `微信日报 2026-04-16`

这意味着它既适合每天固定查看，也适合事后补查某天的信息。

##### 技术原理
它的底层逻辑并不简单，主要包括：

- 微信 Mac 4.x 的数据库是加密的，使用 **SQLCipher 4 + AES-256-CBC**
- 工具通过 **Frida** 在首次使用时动态提取数据库密钥
- 解密后再读取聊天内容
- 部分消息还需要进行 **ZSTD 解压**
- 最终由 AI 生成结构化日报

换句话说，这不是“调用微信接口”，而是直接处理本地数据库。

##### 安全与隐私
项目强调：**所有数据都只在本地处理，不上传服务器**。  
密钥也只保存在本地配置目录中，Frida 仅在首次提取密钥时需要使用。

不过，它仍然涉及聊天数据和本地密钥，因此用户需要注意：
- 妥善保管生成的日报
- 不要泄露他人隐私信息
- 定期更换密钥以降低风险

##### 风险与合规
这是一个很有用但也很敏感的工具。  
项目明确说明，它仅适用于**个人学习和研究**，且只能处理**自己的聊天数据**。

需要特别注意几点：
- 不能未经同意读取或传播他人聊天记录
- 使用 Frida 等技术手段需符合当地法律法规
- 某些操作可能违反微信用户协议，相关风险需要用户自行承担

##### 一句话总结
这是一个面向高频微信用户的“本地聊天信息压缩工具”：  
**它把微信聊天记录从“海量噪音”变成“可快速复盘的日报”，实用性很强，但也伴随隐私、合规和平台规则风险。**
