## 正文

Scriptable CAD with Lua. Write parametric 2D and 3D models in Lua and export them to 3MF, STL, OBJ, PLY, OFF, AMF, or SCAD, or render them straight to a PNG.

**[Try it in the playground](https://luacad.ad-si.com/playground/index.html)** — the engine runs in the browser as WebAssembly, so there is nothing to install and nothing gets uploaded.

LuaCAD embeds Lua 5.4 in a Rust engine that evaluates CSG operations directly (via [Manifold](https://github.com/elalish/manifold)) or generates [OpenSCAD](https://www.openscad.org/) code for external rendering.

![LuaCAD Studio previewing the MuSHR racecar model, a 43-part assembly of 490,802 triangles, beside the Lua script that builds it](https://luacad.ad-si.com/images/luacad-studio-screenshot.png)

#### Why Lua?

- Similar syntax as the OpenSCAD language, but better:
  - More powerful
  - More consistent
  - Faster
  - Easily embeddable
- Operator overloading for natural CSG syntax (`a + b`, `a - b`, `a * b`)
- Already used in other CAD software like [LibreCAD](https://github.com/LibreCAD/LibreCAD_3) and [Autodesk Netfabb](https://help.autodesk.com/view/NETF/2025/ENU/?guid=GUID-93C06838-2623-4573-9BFB-B1EF4628AC4A)

#### Example

###### LuaCAD:

```
my_cube = cube { size = { 1, 2, 3 } }

function my_sphere(radius)
  return sphere({ r = radius }):translate(5, 0, 0)
end

model = my_cube + my_sphere(2)

render(model)
```

###### Equivalent OpenSCAD:

```
module my_cube() {
  cube(size=[1,2,3]);
}

module my_sphere(radius) {
  translate([5,0,0]) sphere(r = radius);
}

union() {
  my_cube();
  my_sphere(2);
}
```

#### Getting Started

```
cargo install luacad         # CLI for running and converting LuaCAD scripts
cargo install luacad-studio  # GUI desktop app with live 3D preview
```

Or from source, which requires [Rust](https://www.rust-lang.org/tools/install):

```
git clone https://github.com/ad-si/LuaCAD.git
cd LuaCAD
make install
```

Both crates vendor their C/C++ dependencies, so no system libraries need to be installed — but a C++ compiler and CMake must be available to build them. `luacad` builds Manifold and Clipper2; `luacad-studio` additionally builds [OpenCSG](http://www.opencsg.org/), which needs OpenGL development headers (on Debian/Ubuntu: `libgl1-mesa-dev`, `libx11-dev`, `libxcb1-dev`, `libxkbcommon-dev`, `libxrandr-dev`, `libwayland-dev`).

##### CLI Usage

```
luacad convert model.lua output.3mf   # Convert to 3MF
luacad convert model.lua output.stl   # Convert to STL
luacad convert model.lua output.scad  # Export as OpenSCAD
luacad watch model.lua output.3mf     # Rebuild on file changes
luacad render model.lua preview.png   # Render to a PNG image
luacad info model.lua                 # Print triangle counts and bounding box
luacad lint model.lua                 # Lint with selene (also takes directories)
luacad run model.lua                  # Execute (side-effects only)
```

`convert` and `watch` infer the format from the output extension; `--format <fmt>` overrides it, and `--via-openscad` hands the export to an installed OpenSCAD binary instead of building the mesh with Manifold.

#### BOSL2

LuaCAD has full support for the [Belfry OpenSCAD Library v2](https://github.com/BelfrySCAD/BOSL2/wiki), reimplemented in LuaCAD itself, so it renders, previews and exports to a mesh without OpenSCAD or BOSL2 installed:

```
bosl.cuboid { {40, 40, 40}, rounding = 2 }
bosl.regular_prism { 5, r = 10, h = 25 }
bosl.spur_gear { circ_pitch = 5, teeth = 20, thickness = 5 }
```

Exporting to `.scad` still writes the BOSL2 call itself, which keeps the exported file as short as the script that produced it.

#### Text and Imports

`text()` outlines a system font into a sketch and `text3d()` extrudes it in one step, so text becomes real geometry rather than SCAD output:

```
render(text("LuaCAD", { size = 12, halign = "center" }):linear_extrude(2))
```

`import()` reads every mesh format LuaCAD writes and returns a solid you can transform and combine like any primitive; SVG and DXF return a 2D sketch instead, ready to extrude.

#### Supported Export Formats

- **[SCAD](https://en.wikipedia.org/wiki/OpenSCAD)** - OpenSCAD format
- **[3MF](https://en.wikipedia.org/wiki/3D_Manufacturing_Format)** - 3D Manufacturing Format
- **[STL](https://en.wikipedia.org/wiki/STL_%28file_format%29)** - Standard Triangle Language for 3D printing
- **[OBJ](https://en.wikipedia.org/wiki/Wavefront_.obj_file)** - Wavefront 3D object format
- **[PLY](https://en.wikipedia.org/wiki/PLY_%28file_format%29)** - Polygon File Format
- **[OFF](https://en.wikipedia.org/wiki/OFF_%28file_format%29)** - Object File Format
- **[AMF](https://en.wikipedia.org/wiki/Additive_manufacturing_file_format)** - Additive Manufacturing File Format

Every value your script returns becomes its own 3MF object, so slicers load them as individually movable parts. Label them with `:name(…)` to control how they appear in the object list. The other formats cannot express separate objects, so they flatten everything into a single mesh.

## 结构化（1）

#### LuaCAD 内容精炼总结

LuaCAD 是一款以 **Lua 脚本编写参数化 2D/3D 模型**的 CAD 工具，可直接渲染 PNG，也可导出为 3MF、STL、OBJ、SCAD 等多种格式。它既能在浏览器中通过 WebAssembly 运行，也提供命令行和桌面应用，适合程序化建模及 3D 打印工作流。

##### 1. 核心功能与技术架构

- 使用 **Lua 5.4** 编写参数化模型，支持 2D 草图、3D 实体及 CSG（构造实体几何）运算。
- 可在在线 Playground 中直接运行：
  - 引擎以 **WebAssembly** 方式在浏览器本地执行；
  - 无需安装软件；
  - 模型数据不会上传。
- 底层采用 **Rust 引擎**，有两种处理方式：
  1. 通过 **Manifold** 直接计算 CSG 并生成网格；
  2. 生成 OpenSCAD 代码，再交给外部 OpenSCAD 渲染。
- 支持直接渲染成 PNG，或导出为多种 CAD、网格和 3D 打印格式。

##### 2. 为什么选择 Lua

LuaCAD 认为 Lua 与 OpenSCAD 语法相近，但具有以下优势：

- 表达能力更强，语言规则更一致；
- 执行速度更快；
- 容易嵌入其他软件；
- 支持运算符重载，可自然地表达 CSG 运算：
  - `a + b`：合并；
  - `a - b`：差集；
  - `a * b`：交集。
- Lua 已被 LibreCAD、Autodesk Netfabb 等 CAD 软件采用。

例如，创建一个尺寸为 `1 × 2 × 3` 的立方体，再与半径为 `2`、沿 X 轴移动 `5` 个单位的球体合并：

```lua
my_cube = cube { size = { 1, 2, 3 } }

function my_sphere(radius)
  return sphere({ r = radius }):translate(5, 0, 0)
end

model = my_cube + my_sphere(2)
render(model)
```

相比等价的 OpenSCAD 写法，LuaCAD 可以直接使用函数、变量及 `+` 运算符，代码更接近普通编程语言。

##### 3. 安装与构建

可通过 Cargo 安装：

```bash
cargo install luacad         # 命令行工具
cargo install luacad-studio  # 带实时 3D 预览的桌面 GUI
```

也可以从源码安装：

```bash
git clone https://github.com/ad-si/LuaCAD.git
cd LuaCAD
make install
```

构建要求如下：

- 需要安装 Rust、C++ 编译器和 CMake。
- 项目已内置所需的 C/C++ 依赖，通常不必额外安装系统库。
- `luacad` 会构建 **Manifold** 和 **Clipper2**。
- `luacad-studio` 还会构建 **OpenCSG**，因此需要 OpenGL 开发头文件。
- Debian/Ubuntu 上可能需要：

```bash
libgl1-mesa-dev libx11-dev libxcb1-dev libxkbcommon-dev
libxrandr-dev libwayland-dev
```

##### 4. 命令行用法

LuaCAD CLI 支持转换、监听、渲染、检查和执行脚本：

```bash
luacad convert model.lua output.3mf   # 转换为 3MF
luacad convert model.lua output.stl   # 转换为 STL
luacad convert model.lua output.scad  # 导出为 OpenSCAD
luacad watch model.lua output.3mf     # 文件变化时自动重新构建
luacad render model.lua preview.png   # 渲染为 PNG
luacad info model.lua                 # 查看三角面数量和包围盒
luacad lint model.lua                 # 使用 selene 检查代码
luacad run model.lua                  # 执行脚本，仅处理副作用
```

补充规则：

- `convert` 和 `watch` 会根据输出文件扩展名自动判断格式。
- 可通过 `--format &lt;fmt>` 手动指定格式。
- 使用 `--via-openscad` 时，会调用已安装的 OpenSCAD 导出，而不是由 Manifold 直接生成网格。

##### 5. BOSL2 支持

LuaCAD 完整支持 **Belfry OpenSCAD Library v2（BOSL2）**，并在自身内部重新实现，因此：

- 无需安装 OpenSCAD；
- 无需单独安装 BOSL2；
- 可以直接预览、渲染并导出网格。

示例：

```lua
bosl.cuboid { {40, 40, 40}, rounding = 2 }
bosl.regular_prism { 5, r = 10, h = 25 }
bosl.spur_gear { circ_pitch = 5, teeth = 20, thickness = 5 }
```

以上代码分别可创建：

- 尺寸为 `40 × 40 × 40`、圆角半径为 `2` 的立方体；
- 半径 `10`、高度 `25` 的五棱柱；
- 圆周节距 `5`、齿数 `20`、厚度 `5` 的直齿轮。

导出为 `.scad` 时，LuaCAD 会保留原始 BOSL2 调用，而不是展开为大量底层几何代码，因此导出文件仍然简短。

##### 6. 文本与外部文件导入

###### 文本建模

- `text()`：将系统字体轮廓转换为 2D 草图。
- `text3d()`：一步生成拉伸后的 3D 文本。
- 文本会成为真实几何体，而不只是 OpenSCAD 输出指令。

示例：

```lua
render(
  text("LuaCAD", {
    size = 12,
    halign = "center"
  }):linear_extrude(2)
)
```

该示例生成字号为 `12`、水平居中的“LuaCAD”文字，并拉伸 `2` 个单位形成实体。

###### 文件导入

- `import()` 可读取 LuaCAD 支持写出的各种网格格式。
- 导入后的模型会作为实体，可继续移动、缩放、旋转或参与布尔运算。
- SVG 和 DXF 文件会被导入为 **2D 草图**，之后可进行拉伸生成 3D 模型。

##### 7. 支持的导出格式

LuaCAD 支持以下格式：

| 格式 | 用途 |
|---|---|
| SCAD | OpenSCAD 脚本格式 |
| 3MF | 3D Manufacturing Format，适合现代 3D 打印 |
| STL | 常见的三角网格及 3D 打印格式 |
| OBJ | Wavefront 3D 对象格式 |
| PLY | Polygon File Format |
| OFF | Object File Format |
| AMF | Additive Manufacturing File Format |
| PNG | 模型预览图像 |

其中，**3MF 对多对象支持最好**：

- Lua 脚本返回的每个值都会成为独立的 3MF 对象；
- 切片软件加载后，可分别移动这些部件；
- 可使用 `:name(…)` 为对象命名，控制其在对象列表中的显示名称。

其他导出格式无法表达多个独立对象，因此会将所有内容合并、展平为一个网格。

#### LuaCAD：用 Lua 编写可参数化、可本地运行的 2D/3D CAD 模型

LuaCAD 是一套脚本化 CAD 工具：用户用 Lua 描述参数化模型，通过布尔运算组合几何体，并直接预览或导出制造、打印所需文件。其突出特点是同时支持浏览器、本地 CLI 和桌面应用，且浏览器版基于 WebAssembly 运行，模型无需上传。

##### Lua 负责建模，Rust 引擎完成几何计算

LuaCAD 在 Rust 引擎中嵌入 Lua 5.4，支持用 `a + b`、`a - b`、`a * b` 等运算符自然表达几何体的合并、相减和相交。模型既可通过 Manifold 直接执行 CSG（构造实体几何）运算，也可生成 OpenSCAD 代码交由外部渲染。

项目认为，Lua 与 OpenSCAD 语法接近，但表达能力、一致性、速度和可嵌入性更好；Lua 也已用于 LibreCAD、Autodesk Netfabb 等 CAD 软件。

##### 覆盖从编写、预览到导出的完整流程

LuaCAD 提供 CLI 与带实时 3D 预览的桌面 Studio，可监听文件变化自动重建、渲染 PNG、检查模型、输出三角面数量和包围盒。它支持：

- 导出 3MF、STL、OBJ、PLY、OFF、AMF 和 SCAD；
- 导入上述网格格式，以及可继续拉伸的 SVG、DXF 草图；
- 将系统字体转为真实几何体；
- 原生重实现 BOSL2，可生成圆角方块、棱柱、齿轮等复杂模型，无需安装 OpenSCAD 或 BOSL2。

##### 3MF 更适合保留零件结构

脚本返回的每个值都会成为独立的 3MF 对象，可命名并在切片软件中分别移动；其他格式无法表达多对象结构，只会合并为单一网格。这使 LuaCAD 不只是代码生成器，也可作为面向参数化设计和 3D 打印的轻量、可嵌入建模引擎。
