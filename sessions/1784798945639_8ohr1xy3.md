### 梁文锋投资者交流会（完整版全文）

梁文锋

欢迎各位投资人。我们一开始来做这个公司，初衷是没有想到说我最后要赚多少钱，要到资本市场上去，要上市，要怎么样的，所以我们是没有这个初衷的。最开始的几十个人完全没有这么想过。如果他这么想，他就不会来。

所以总体讲，我们是怀着一个对这个世界非常大的善意来做这个事情，然后我们觉得这是对人类有用的，这是一个金钱以外的事情。当然，到了后面，这个事情发现利益非常大之后，又有其他的诱惑，这个是另外的事情。但是我们出发的初衷、我们的愿景，以及我们保持到现在的这个愿景，不是按照一个商业利益最大化的方式来做的。

我觉得这点比较关键。大概二十年前，在管理上我最崇拜的是杰克·韦尔奇，就是 GE 的前 CEO。现在回来看，他说的大部分东西可能都已经不对了，但是他最重要的一点说对了：一个公司最重要的是它的愿景。管理一个大公司，靠的不是你的规章制度，靠的是愿景。愿景是什么呢？

愿景不是挂在墙上的标语，愿景是你怎么做，不是怎么说，就是你怎么实际运行。反正杰克·韦尔奇说的原话我忘了，大概是这个意思。所以，我们是怎么管理这么多人、怎么组织起来的？其实我们没有组织，就是愿景驱动的，靠一个愿景来组织。我们是没有组织的。这个有好处，也有坏处。

未来我们会想办法扬长避短，但这是我们的特色。我们并不是以一个“我要实现什么 KPI、没有考核”的方式来做，只有愿景。这个愿景甚至也不是成文的，并不是写出来的，没有写出来过任何东西。这个愿景是在我们做事情的方法、我们对待这个世界的态度里。

可能我们公司每个人对这个愿景的理解也不一样，可能每一个人的愿景也是有差别的，但是在一个大的方向上是一致的。

我觉得还是怀着对这个世界非常大的善意，然后想做一点事情。我们是用这个来组织起来的。接下来我先讲，讲完之后大家再提问。我可能会围绕着这个愿景来讲后面的事情。这个愿景是真的，不是编出来的，我们是真的这么想，真的这么做的。否则你没法解释我们的很多事情。为什么我们这么坚持开源？

因为这个愿景本身就要求开源。你没有这个愿景，你没法把人组织起来。比如说，\*\*也开源，但是\*\*的开源跟我们的开源不一样。\*\*的开源有一种被迫的感觉，他们觉得这不是本意，但是对我们来讲，这就是我们的本意。然后在开源这个事情上面，我们一开始就想得非常清楚。

首先，第一个就是愿景；第二个，我们认为要把 AI 这个事情在商业上做成，开源是有好处的。这听起来有点矛盾，有点违反直觉，因为在历史上，开源跟商业化都是有冲突的。但我觉得 AI 跟以前不一样。

因为在历史上，一个软件公司，它的市场一年可能就几十亿美金，离开源了，它就没有了，可能就只剩下几千万或几亿美金了。但是 AI 这个事情足够大，最终它可能得占掉人类社会 GDP 的百分之十，比如说。那么它其实是一个非常大的数字。

一个人独占这个事情，你不可能独占这个事情，你一定得跟别人分享，否则你肯定活不下来。这跟之前开源做一个软件可能是不一样的，因为那个软件的市场就没那么大。但是 AI 这个事情实在太大了。如果说我们想独占这个利益，那么一定是要被历史抛弃的。我觉得最主要这是一个客观的规律，这是一个历史观。

并不是说我不开源，我就能够独占这个市场，这在理论上就不符合客观事实。你一定会遇到很多阻力，一定会有其他的方法阻止你实现这个目标。在这种情况下，我觉得不一定要按照传统的商业思维。你需要有一套机制来确保你自己能够获得的利益是有限的，那么你才有可能做成。需要克制，我觉得是需要克制。

如果说我们想在我们手上把 AI 这个事情做成，首先第一个，我觉得是需要克制的。不能够想着人类 GDP 的百分之多少都归我了，或者说中国 GDP 百分之多少都归我了。你越这么想，越做不成。

所以我们从一开始就觉得需要克制。你越克制，你越有可能能够做成这层事。这是一个商业上的考量，当然这是一个宏观的考虑。我觉得这是符合直觉的，至少是符合我的直觉，或者说至少我是真的这么想的。我们并没有非常多的其他优势，我们没有什么本事，我们并没有比别人有钱，也没有说我们人员比其他公司更好，其实没有的。

你想，我们两年前成立这个公司的时候，我们又没有很多钱，又没有很多卡，又没有什么知名度，又没有什么号召力，我们就是一群非常平凡的人。

我们真的就是一群平凡的人。如果说喜欢的一个叙事是一群平凡的人做出了不平凡的事情，而不是一群天才做出了不平凡的事情，这个跟我们的克制是很有关系的，跟我们的克制、跟我们的愿景是一脉相承的。那么，开源跟商业化会不会有冲突？我觉得在 AI 这个事情上面，你不克制，你就不起。

开源是属于克制的一部分，那么我们的克制不仅表现在开源上面，我们还表现在很多方面上。但总体上来讲，我们是不用考虑开源这个事，不用考虑克制这个事情。你越克制，可能就越容易做成，或者说至少到目前为止是印证的，到目前为止是能解释得通的。

否则没有办法能够解释为什么我们能够做成：我们并没有什么武器，起点又非常低，资源又非常少，我们的人其实也就是随机的一群平凡的人。我自己也就是一个大学毕业的学生，也不是最顶级的那个学校毕业的。这个克制也是我们愿景里的一部分。AI 这个事情太大了，利益太大了。

我们非常克制，只要能够做成，最后利益都会非常大。你随便分一点，利益就非常大，所以现在根本不用考虑拿这里面的哪一部分利益、怎么拿，我觉得根本不用考虑这件事情，因为这个利益足够大了。你只要分一点点，就已经很足够了。所以我们之前说，我们只赚取一个合理的利润，只看你的意愿，而不是利润之大，这个是不一样的。

这不是我们的 API 定价。我们 API 定价觉得一个合理的利润，大概是我们到市场上买一批设备回来，十个月收回成本，我觉得这是一个合理的利润。

在当前的情况下，考虑到你有风险、还有前期的投入等等，如果一个服务器我们在财务上按照三年或者五年的摊销，但在商业上，我们觉得大概十个月收回成本，我们觉得够了，OK，我们觉得够了。所以这个是我们现在 API 定价的逻辑。我们的 V3.2 Flash 跟其他的，都是十个月收回设备的成本。

这就是我们的标准。它其实不是利润最大化的，如果利润最大化，应该把价格设得更高。因为在这个价格区间，用户的需求是没有弹性的，就是我价格再翻一半，或者说我价格再抬高一倍，token 的消耗量区别不大的。如果我价格再贵一倍，我的总收入接近一倍。稍等一下，我对一下。哎呀，太好了。

我跟你们讲个故事，就是我们的一款模型。一开始我们担心需求太多，所以一开始把价格定得比较高，团队里大家不是很高兴。后来我把价格又降下来了，降到四分之一，大家就很开心。我觉得这个才是我们真实的想法。

就是我前面说的愿景，我们还是让这个东西对人是有用的，而不是我们赚最多的钱，而是我们在能够赚到合理利润的情况下，大家都用得起。我觉得这次我们公司其他人的想法，就是我们那时候降价的时候，公司群里面很多人是欢呼的，大家都觉得很开心。因为这是我们花了这么多精力，这么用心把这个模型做好的目的。

目的就是能够非常便宜、效果非常好，能够让大家都能够充分地用。我们就觉得这很开心，这是我们的动力，这是我们的愿景，这是我们公司能够凝聚到一起去做这个事情的共识吧，这是我们公司内部的共识。这点应该是比较特殊的，因为降价这样对于我们其他的竞争对手来讲，肯定不是个好事，他们一定不是欢呼的。

因为你的收入、你的 ARR，那个你降一半，ARR 就掉一半。对，这是一个我们不一样的地方。我们觉得这就够了。从我们公司内部来讲，我十个月收回成本，这个商业上我已经非常满意了。对于公司外部来讲，我们也觉得这个价格是大家比较开心、比较乐意看到的，大家是双赢的，公司跟社会、跟所有人都双赢的。

我觉得，OK，刚刚有人在屏幕上留言说，十个月回本这个利润太高了。确实是还有降价的空间，确实还有降价空间。在模型的优化上也还有空间，所以整体降价空间还是比较大的。但是这个成本，十个月回本，我们自己能做到，其他家做不到。像可能阿里或者腾讯，他不是我们的优化，他的成本应该是要比这个高好几倍的。

这里还是有很多优化的工作。刚刚说我们为什么不继续降价，是因为它没有弹性。就是我再降价，需求不会更多了，或者我再降价，需求增加得很少了。因为这个价格所有人都用得起了，大家都觉得这个价格是满意的，不会因为这个价格贵而不用了。

所以降价首先公司不会有更多的收入，对社会来讲也没有更多的价值，因为这个价格大家都满意了。你价格再低，对这个社会的幸福感也没有增加很多。对，OK，不过刚刚这个问题上，就是我们在定价这个事情上面，我们肯定不是以

公司收入最高或者利润最高，不是最出发点的。这是我们克制的一部分，因为从短期来讲，你价格高一点，你可能收入多一点；但从长期来讲，还真不好说。因为我觉得克制是一种策略。对我来讲，克制是一种战略。就在于有时候你可以舍弃一些，来换更多其他的东西。

开源这个事，其实也是一样的，也可以认为是我们的压力，也可以认为是我们的让利。首先，这个让利对于我们公司内部来讲，我们很高兴，大家都很开心，员工觉得很有成就感，我们会因此有凝聚力。以及这个让利对社会是有好处的，社会也很高兴，其他同行或者说普通人都会很高兴。

所以这种克制，我理解是这种克制从长远上来讲，能够增加我们做成 AGI 的概率。在考虑一件事的时候，我是毫不怀疑 AGI 会有非常大的商业价值。那么在这个基础上，我优先考虑的不是我怎么多加一点份额，我怎么多拿一些份额，我优先考虑的是我怎么增加我能够做成的概率。这个克制可能还体现在很多其他的方面。

比如说，我们去年春节用户突然很多，但是我们并没有去追求我要留这些用户，或者说拿这些用户来变现，或者说我要去抢这些商业利益，在用户上面兑现。我们没有去抢用户，没有去赚钱，但我们很努力想办法把用户服务好。

我们并不会有这样的想法，说我要做成下一个超级 App，然后我要去跟谁竞争，我要做成下一个字节、做成下一个腾讯，完全没有这样的想法。我们是可以这么做，但是我们没有这么做。我的理解是，这也是克制的一部分。你不要想什么都要赚了，你好像有了用户之后，好像就能够做成下一个字节了，然后你就把那个吃了。

我觉得这个在商业上是行得通的，是有可能的。如果去年时候我们用了大笔钱，就跟字节去抢用户，也是一种打法。但是我们选择是一种非常克制的做法，就是我不跟你去争这个东西，因为后面还有西瓜，前面的可能都是芝麻。

或者说，我们公司大部分人不认为这是一个非常重要的事情，不认为这是一个跟 AGI 比较起来同等重要的问题。开源那个可以多说一下，因为之前有很多问题问的都是开源。首先，我觉得我们是会开源的，然后我们最强的模型可能也是会开源的。因为我看不到闭源什么好处，看不到必然的好处。

字节它的模型是闭源的，它有什么好处？我看不到有什么好处。哪怕是模型开源，你把所有东西都告诉别人，这个门槛也非常高。别人要用起来，这个门槛也非常高。他要用起来，就很难；其次，他要用起来，还要成本做得很低，也很难很难，没有那么容易。

## 结构化（1）

### 2026-07-23 09:29:05

梁文锋认为，公司应以**实现 AGI（通用人工智能）**为长期目标，用愿景而非 KPI 凝聚团队，并通过开源、低价和商业克制提高成功概率。短期的 C 端用户、B 端收入和 API 商业化只是 AGI 研发过程中的副产品，真正的核心风险是团队稳定性，最大现实瓶颈则是算力资源。

> **说明：**以下总结仅基于所提供的交流会文本；原文末尾在 “把 AGI 往前……” 处中断。部分公司名称被隐去，个别数字和利润口径按原文保留。

##### 1. 创业初衷：愿景优先，不以商业利益最大化为目标

- 公司最初的几十个人，并不是为了上市、进入资本市场或赚最多的钱而来，而是希望做一件对人类有用的事。
- 梁文锋强调，真正的愿景不是墙上的口号，而是公司实际如何做事、如何对待世界。
- 公司主要依靠共同愿景组织团队，而不是严密的组织结构、KPI 或考核制度。
- 他曾推崇 GE 前 CEO 杰克・韦尔奇的管理思想，并认同其中一点：**管理大公司最重要的不是规章制度，而是愿景。**
- 团队成员对愿景的理解可能不同，但大方向一致：对世界保持善意，努力做有价值的事情。

##### 2. 为什么坚持开源：既是价值观，也是商业策略

- 开源首先来自公司的愿景：AI 应该让更多人受益，而不是被一家公司独占。
- 梁文锋判断，AI 未来可能占到人类社会 GDP 的**10%**，市场规模远超传统软件，因此任何公司都不可能长期独占全部利益。
- 如果一家公司试图把巨大收益全部留给自己，反而会遭遇更大阻力，最终更难做成。
- 因此，公司需要 “克制”：
  - 不追求垄断市场；
  - 不要求获取过高利润；
  - 主动分享技术和利益；
  - 优先提高实现 AGI 的概率。
- 他认为，公司两年前成立时没有很多资金、算力、知名度和号召力，团队也并非 “天才集合”，更像是 “一群平凡的人做出不平凡的事”。克制和愿景，是公司能够凝聚起来的重要原因。

##### 3. API 定价：以约十个月回收设备成本为标准

- 公司当前 API 定价不是利润最大化，而是希望获得 “合理利润”。
- 具体标准是：购买一批设备后，商业上大约**10 个月收回设备成本**。
  - 财务上服务器可能按**3 年或 5 年**摊销；
  - 但商业定价以约 10 个月回本为目标。
- **V3.2 Flash**等模型都遵循这一标准。
- 梁文锋称，在当前价格区间，用户需求已经缺乏明显弹性：
  - 即使价格提高**50% 甚至翻倍**，Token 使用量也不会明显下降；
  - 因而如果追求利润最大化，完全可以定得更贵。
- 但公司不以收入和利润最高为出发点，而是希望模型 “效果好、价格低、大家都用得起”。

###### 降价案例

- 某款模型最初因担心需求过大而定价较高，团队成员对此并不高兴。
- 后来价格降到原来的**四分之一**，公司群里很多人欢呼。
- 这体现了内部共识：研发模型的目的，是让更多人低成本使用，而不是赚最多的钱。
- 梁文锋也承认，当前价格仍有下降空间，但继续降价不会显著增加需求，也未必创造更多社会价值。

> 原文后续将 “10 个月回本” 表述为大约对应 “**六倍利润**”。这一利润口径没有进一步解释，宜按讲话原意理解，不宜直接套用常见财务利润率概念。

##### 4. “克制” 是一种长期战略

- 梁文锋认为，克制不是单纯让利，而是用短期舍弃换取长期成功概率。
- 开源和降价的好处包括：
  - 员工更有成就感，团队凝聚力更强；
  - 社会和行业能够更广泛地使用技术；
  - 降低外部阻力；
  - 提高公司最终做成 AGI 的可能性。
- 他相信 AGI 会带来巨大商业价值，因此优先考虑的不是 “多拿一点份额”，而是 “增加做成的概率”。

##### 5. 不争夺所有商业机会：C 端和 B 端只是 “沿路捡芝麻”

- 去年春节用户量突然增长时，公司没有急于抢用户、变现或打造下一个超级 App，也没有试图成为下一个字节或腾讯。
- 公司虽然努力维持服务，但没有投入巨额资金争夺 C 端市场。
- 梁文锋把短期用户和收入比作 “芝麻”，把未来 AGI 机会比作 “西瓜”：
  - 芝麻可以顺手捡；
  - 但不能为了芝麻停下通往 AGI 的脚步。
- C 端用户目前仍是一项成本支出，但未来可能有价值，因此公司会以较低成本维持。
- API 和企业端业务也可能形成可观收入：
  - ARR 有机会达到**数亿美元**；
  - 如果 AI 相关收入做到**10 亿美元**，公司现金流可能转正，并覆盖研发及全部运营费用。
- 不过这些业务不是公司最高优先级，而是 AGI 研发过程中的中间产物。

##### 6. 开源不会破坏商业模式

- 梁文锋表示，公司会继续开源，甚至最强模型也可能开源，因为他看不到闭源的必然好处。
- 即使模型代码和方法公开，第三方仍面临较高门槛：
  - 模型部署困难；
  - 很难做到同样低的成本；
  - 需要大量工程优化和组织能力。
- 创业公司在这方面可能处于 “甜蜜点”：
  - 太小，资源和力量不足；
  - 太大，组织成本和内部阻力过高；
  - 当前公司规模反而更适合持续优化。
- 如果公司只获取合理利润，并以 10 个月回本的价格提供服务，第三方由于成本更高，可能很难靠独立部署盈利。
- 按原文说法：
  - 在 “六倍利润” 条件下，开源不会影响商业模式；
  - 如果追求 “100 倍利润”，开源才可能让第三方以更低价格参与竞争。
- 公司不仅不担心其他人部署模型，还愿意帮助开源社区和竞争对手复现、优化部署。
- 开源模型与公司自部署模型是一样的，不会故意开源较差版本。
- 去年 C 端实践也未显示开源与自有用户服务存在明显冲突。

##### 7. AGI 技术路线：从语言模型走向持续学习

梁文锋认为，当前 AI 在获得完整上下文和清晰指令时，部分能力已经超过人类，但它仍无法自然替代员工，关键缺陷是缺少长期上下文和持续学习能力。

###### 当前 AI 的局限

- 一名员工进入公司后，可以用两个月熟悉环境、人物和工作流程。
- 之后听到 “叫小王过来”，就知道小王是谁、在哪里、应该如何联系。
- AI 没有此前两个月的学习过程，必须被明确告知全部背景信息，因此无法像员工一样自然工作。

###### 他判断的技术阶梯

1. **语言模型**：形成基础能力。
2. **CoT（思维链）**：通过内部思考提高智能上限；在奥数、编程等任务上可超过顶尖人类。
3. **Agent（智能体）**：扩大可完成任务的范围，是当前正在推进的阶段。
4. **持续学习**：让模型像人一样长期学习，而不是每次依赖完整指令和上下文。
5. **自我迭代阶段**：模型能够研究并开发自己的下一版本。
6. **具身智能**：进入现实世界，做家务、养老等实际工作。

- 每一级都建立在前一级之上，不存在 “白走” 的技术路线。
- Agent 达到上限后仍不能完全替代员工，因此下一个明确瓶颈是持续学习。
- 当 AI 能持续学习后，可能进入所谓 “奇点”，即具备自我研究和自我迭代能力。
- 但梁文锋认为，这种 “奇点” 未必是突然发生的，更可能是一个较长、连续的渐进过程。
- 公司偏好先解决持续学习和自我迭代，再做具身智能，因为前面的智能能力可以帮助完成后续研发，整体路径更轻松。

##### 8. AGI 研发对商业业务形成 “降维优势”

- 公司真正关心的是 AGI 技术突破，而不是单独为 C 端或 B 端开发模型。
- C 端产品、企业服务和 API，都是通往 AGI 过程中自然形成的副产品：
  - 不需要庞大的销售团队；
  - 只需少数人维护 API；
  - 甚至可以没有专门客服，用户会主动使用。
- 梁文锋认为，站在更高的 AGI 技术目标上做应用，可能形成 “降维打击”：
  - 去年公司没有大力争夺 C 端用户，但用户依然留下；
  - 今年 B 端收入增长也较为乐观。
- 这种优势不一定来自个人更聪明，而来自组织方式：愿景能够让优秀人才持续合作，并保持投入和激情。
- 与以产品或流量为目标的公司相比：
  - 对方可能在产品、流量和服务上更有优势；
  - 公司的优势则主要在模型技术、人才组织和长期凝聚力。

##### 9. 唯一不可退让的核心利益：团队稳定

- 梁文锋认为，公司最大的、甚至唯一的核心利益是**保持团队稳定性**。
- 他的判断是：
  - 只要团队核心成员不离开，公司最终就能做成 AGI；
  - 挫折最多导致进度晚半年或一年，不会改变最终结果；
  - 资金和其他资源都相对容易获得。
- 近期融资在一定程度上降低了人才流失风险：
  - 重要和资深员工获得了较多期权；
  - 只要核心员工稳定，其他成员通常也不容易离开。
- 团队成员并非完全为钱而来，更看重能否在一个有机会实现 AGI 的环境里工作。
- 公司历史上的人才流动率相对同行较低，但团队稳定仍被视为最大风险。

##### 10. 对外合作：不把互联网大厂或同行当作敌人

- 除团队稳定外，公司愿意在其他利益上保持克制，不希望与任何大厂或创业公司成为敌人。
- 公司愿意帮助阿里、智谱、月之暗面等同行做得更好，包括协助复现开源模型。
- 对合作伙伴可以提供更多帮助，但即便面对竞争者，在技术开源的根本利益上也没有明显冲突。
- 梁文锋认为，善意和开源并未损害公司商业利益：
  - C 端用户仍较多且稳定；
  - B 端业务也较为乐观；
  - 长期看甚至可能带来额外加分。

##### 11. 研发边界：只做与 “智能主线” 直接相关的技术

- 公司集中做 AGI 主线，包括语言模型、CoT、Agent、训练方法和持续学习。
- 暂时不会重点投入：
  - 3D；
  - 视频生成；
  - 当前形态的世界模型；
  - 其他与智能上限关系不大的方向。
- 梁文锋认为，视频生成可能是好生意，但不是提升智能上限的关键技术。
  - Sora 出现后，很多大公司和小公司都投入视频生成；
  - 后来不少小公司又砍掉该方向。
- 公司不会仅因为某项技术商业前景好就去做，而要判断它是否位于 AGI 路线图上。
- 多模态最终仍要做，但在当前阶段，最重要的是先把 AI 训练和持续学习做好。

##### 12. 与美国的主要差距：不是人才，而是算力

- 梁文锋判断，中美 AI 的核心差距主要是资源，尤其是算力，而不是人才质量。
- 公司目前约有**2 万张 H 系列等效算力**，其中大部分是最近一两个月刚到，仍有机器尚未交付。
- 接下来几个月还会继续大规模采购，基本以英伟达设备为主。
- 采购策略是：
  - 在价格合理的前提下，能买多少就买多少；
  - 如果能在半年内把融资资金全部换成显卡，反而是理想情况；
  - 公司愿意支付一定溢价，但不会接受明显不合理的价格。
- 梁文锋称，如果一年能花掉**200 亿元**采购算力，就说明采购部门成绩非常好。
- 他认为，显卡比资金放在银行里更有价值，因为显卡既能支持研发，也能通过 API 服务产生现金流。

###### 大模型规模差距

- 美国最先进模型的激活参数规模，按原文说法约为**800B（8000 亿）**。
- 国内模型目前大多只有**几十 B 激活参数**，相差约一个数量级。
- 若要训练同等规模模型，梁文锋估算需要：
  - 约**5 万张 GB300**；或
  - 约**20 万张华为 950**。
- 这还只是正式训练，不包括前期研究和大量实验。
- 即使把**500 亿元**全部投入算力，也很难充分支撑这种规模的模型研究。
- 公司现阶段及未来几个月的资源，只足以在**十 B 至几十 B 激活参数**规模上做更多实验。
- 因此当前策略是：
  1. 先把能够训练和部署的几十 B 模型做好；
  2. 资源增加后，再推进到约**150B、156B 或 250B**激活参数；
  3. 暂不在 800B 规模上与美国正面竞争。
- 算力不足还会影响人才成长，因为研究人员能做的实验更少。因此表面上的人才、模型和应用差距，本质上都可能源于算力差距。

##### 13. 大模型竞争的终局：成本、时间和体验

梁文锋认为，长期看，各家模型能力可能不会有特别大的本质差异，最终竞争主要体现在三方面：

1. **成本**
   - 在提供相同质量服务时，谁能把成本做到更低。
   - 低成本需要长期的工程优化和组织能力，是最重要的壁垒。

2. **时间**
   - 同样的能力，早几个月做出来与晚几个月做出来，商业结果可能完全不同。
   - 研发速度是核心竞争力。

3. **用户体验**
   - 产品体验会形成一定用户黏性和壁垒；
   - 但相较成本和时间，它可能不是最本质的差异。

##### 结论

- 梁文锋的整体思路可以概括为：**用愿景组织团队，用克制降低阻力，用开源扩大社会价值，用低成本建立商业能力，最终集中资源推进 AGI。**
- 在这一框架下，API、C 端和 B 端收入都不是终点，而是支撑长期研发的中间成果；团队稳定决定公司能否持续前进，算力则决定前进速度和模型上限。

#### 从 “愿景驱动” 到 AGI：梁文锋谈开源、克制、团队与算力

投资者交流会一开始，梁文锋没有先谈收入、估值或上市，而是回到公司成立时最初的几十个人：他们为什么聚在一起，又为什么愿意把开源、低价和 AGI 放在短期商业利益之前。沿着这条线索，他进一步讲到 API 定价、C 端与 B 端业务、技术路线、团队稳定性，以及中国与美国之间最现实的算力差距。

##### 最初的几十个人，不是为了上市和利润而来

梁文锋欢迎投资人之后，先解释了公司成立时的初衷。最早做这家公司时，他们没有预设最后要赚多少钱，也没有把进入资本市场、上市当成目标。最开始加入的几十个人同样没有这样想；在他看来，如果一个人首先考虑的是这些，他当初可能就不会来。

把这些人组织起来的，是一种对世界的善意。他们认为正在做的事情对人类有用，意义不只在金钱。后来，随着 AI 显现出巨大的利益，当然也会出现其他诱惑，但公司的出发点和延续至今的愿景，并不是按照商业利益最大化来设计的。

大约二十年前，梁文锋在管理上最崇拜的是通用电气前 CEO 杰克・韦尔奇。现在回头看，他认为韦尔奇讲的大部分东西可能已经不对了，但有一点仍然成立：一家大公司最重要的是愿景，管理不能只靠规章制度。这里的愿景不是挂在墙上的标语，而是公司实际怎样运行、遇到选择时怎样做。

这也解释了公司的组织方式。梁文锋甚至说，他们 “没有组织”，而是靠愿景把人聚在一起。公司不是以 KPI 和考核为主要驱动力，愿景也从来没有被正式写成一份文件。它存在于做事的方法和对待世界的态度里。每个人对它的理解可能不同，个人愿景也会有差别，但大的方向是一致的：怀着善意，做一点真正有用的事情。

这种组织方式有好处，也有坏处，未来仍要设法扬长避短。但梁文锋强调，这个愿景并不是后来为了对外解释而编出来的，而是真实地影响着公司的决策。否则，就无法解释公司为什么长期坚持开源，也无法解释员工面对模型降价时为什么会欢呼。

##### AI 的利益足够大，因此更需要开源和克制

梁文锋认为，开源首先是愿景的自然要求。其他公司的开源有时带着被迫的意味，并非原本意愿；对他们来说，开源从一开始就是本意。不过，开源也不只是价值选择，它还有商业上的理由。

传统软件公司的市场规模可能一年只有几十亿美元。一旦开源，原本的收入空间可能从几十亿美元缩到几千万或几亿美元，因此开源与商业化经常发生冲突。但 AI 不同。梁文锋举了一个宏观尺度的估计：AI 最终可能占到人类社会 GDP 的 10%。如果这个判断成立，它对应的利益会大到任何一家公司都不可能独占。

正因为如此，试图独吞这个市场并不符合客观规律。一个公司越想把人类或中国 GDP 中的某个巨大比例全部据为己有，越会遇到阻力，也越难把事情做成。要真正推动 AI，需要建立一种机制，主动限制自己能够获取的利益。梁文锋反复使用的词是 “克制”。

这种克制并非单纯让利，而是一种战略：主动舍弃一部分短期利益，换取更高的成功概率。他确信 AGI 会产生巨大的商业价值，因此首先考虑的不是怎样多占一点份额，而是怎样增加公司最终做成 AGI 的概率。既然总利益足够大，公司最后只需要分到其中很小一部分，就已经足够，不必在现阶段急着决定究竟拿哪一块、拿多少。

梁文锋也用公司的起点来说明这种选择。公司成立时既没有很多钱，也没有很多算力卡，没有知名度和号召力，成员只是 “一群非常平凡的人”。他本人也只是大学毕业，并非来自最顶级的学校。他更认同的叙事是：一群平凡的人做出了不平凡的事情，而不是一群天才完成了奇迹。公司能够走到现在，愿景和克制比所谓天才优势更能解释这个过程。

##### 模型降到原价四分之一，员工在公司群里欢呼

克制最具体的表现之一，是 API 定价。梁文锋给出的标准不是利润最大化，而是购买一批设备后，大约十个月收回设备成本。财务上，一台服务器可能按照三年或五年摊销；但商业定价时，公司认为十个月回本已经足够，能够覆盖风险和前期投入。V3.2 Flash 等模型，都按照这个逻辑定价。

这种价格并不是市场所能承受的最高价格。梁文锋判断，在当前价格区间，用户需求缺乏弹性：即使价格提高一半甚至翻倍，token 消耗量也不会明显减少，公司收入却可能接近翻倍。如果目标只是利润最大化，完全应该把价格定得更高。

他接着讲了一款模型的定价过程。模型上线之初，团队担心需求过多，因此先把价格定得比较高，团队成员对此并不高兴。后来梁文锋把价格降到原来的四分之一，大家反而很开心。降价时，公司群里有很多人欢呼，因为他们投入大量精力把模型做好，目的就是让模型既便宜又有效，使更多人能够充分使用，而不是尽可能多赚钱。

在其他公司，降价通常意味着 ARR 同比例下滑，员工很难为此欢呼。但在梁文锋所在的公司，十个月收回成本已经是商业上可以接受的结果；与此同时，外部用户也能以满意的价格使用模型，公司与社会形成双赢。

交流过程中，有人在屏幕上留言，认为十个月回本的利润仍然太高。梁文锋承认，价格确实还有下降空间，模型优化也还有空间。不过，他解释了为什么公司没有立即继续降价：当前价格已经让所有人都用得起，再降价并不会带来明显新增需求，公司的收入不会因此增加，社会获得的额外价值和幸福感也有限。

更重要的是，这个十个月回本的成本水平，并不是所有公司都能做到。梁文锋判断，阿里或腾讯如果没有同样的优化，其成本可能比他们高好几倍。这里仍包含大量模型部署和成本控制工作。后来谈到开源商业模式时，他又把十个月回本换算为大约六倍利润，并认为在这个利润水平上，开源与收费服务并不冲突；未来利润倍数可能下降到四倍、三倍，但仍有足够的商业空间。

##### 不抢春节流量，C 端和 B 端只是通往 AGI 的副产品

克制也体现在用户和市场争夺上。去年春节期间，用户突然大量涌入，公司没有趁机抢占商业利益，也没有急着把这些用户变现。他们没有设想把产品做成下一个超级 App，更没有把成为下一个字节或腾讯当成目标，但仍然努力把突然到来的用户服务好。

梁文锋承认，如果当时投入大笔资金与字节争抢用户，在商业上并非行不通。但公司选择不这样做，因为后面还有 “西瓜”，眼前的机会可能只是 “芝麻”。即使这个芝麻并不小，与后面的 AGI 相比，也没有大到值得公司停下来，把主要资源转过去。

现在回头看，他认为去年没有在 C 端集中发力可能是正确的。公司仍然用较低成本维持着这些用户。现阶段，这些用户可能只是纯成本支出，也还不知道以后具体有什么用；但既然可以顺手保留下来，公司就不会主动丢掉。

今年，API 和其他 AI 服务也可能形成可观收入。如果需求继续增长，而且公司能够买到更多显卡，ARR 做到几亿美元是有可能的。如果 AI 相关收入能够达到十亿美元，公司现金流可能基本回正，足以覆盖研发费用和其他全部支出。公司会做这件事，也会把服务做好，但不会把它当成第一优先级。去年的 C 端、今年的 B 端，都不是与 AGI 同等重要的目标。

梁文锋把这些业务称为通往 AGI 路上的中间产出。公司本来就要训练模型、提高智能、跨过技术台阶，把已有能力通过 API 提供给用户，并不需要额外构建一套庞大组织。按他的说法，只要几个人维护 API，甚至不需要客服和销售，用户就会自己来。

去年 C 端的情况也印证了这一点。公司没有投入太多精力，一度甚至不想继续维护这些用户，但用户 “赶都赶不走”，最后仍然留下来。今年 B 端收入的增长也比较乐观，而公司同样没有为此投入很大的额外精力。梁文锋把这种现象理解为一种技术上的降维：站在 AGI 的技术目标上，顺手处理低一级的应用和商业化问题，所需精力会更少。

这也是公司与一般商业公司的区别。其他公司可能为了服务 C 端或 B 端用户而开发模型；他们则是为了 AGI 开发模型，恰好产生了可以商业化的能力。AGI 这个更大的愿景，还能凝聚和组织更多优秀人才。人才优势并不意味着公司的人天生更聪明，而是这些人能够被组织起来、相互合作，并持续朝同一个目标前进。

##### 最强模型也会开源，真正的门槛留在部署与成本里

谈到开源，梁文锋明确表示，公司会继续开源，最强的模型也可能开源，因为他看不到闭源必然带来的好处。即使把模型和相关信息公开，第三方真正把它用起来仍然有很高门槛；要进一步把部署成本降到足够低，更是困难。

这些工作的原理可能大家都懂，但不是每家公司都有意愿和能力组织人力，把每一个细节做到目标水平。大公司会受到管理和物理条件的制约，太小的创业公司又可能没有足够力量。梁文锋认为，他们目前所处的公司规模恰好位于一个 “甜区”：再小会力量不足，再大则可能出现新的组织问题。

按照十个月回本的价格提供 API，第三方即使拿到开源模型，也很难靠独立部署赚到钱，因为第三方通常做不到同样的成本。如果公司追求一百倍利润，开源当然会影响收入 —— 第三方即使以二十倍成本部署，也能提供更便宜的服务；但当公司只获取大约六倍利润时，第三方没有足够空间与之竞争。

因此，公司不担心别人部署自己的模型，反而希望更多人部署起来，并愿意为开源社区提供协助。梁文锋担心的不是别人抢走生意，而是第三方某些细节没有做对，使模型效果变差，或者成本过高。

公司提供的开源模型，与自己线上部署的模型也是一样的。他们不会开源一个较差版本，同时把更好的版本留给自己。去年一整年，公司的 C 端服务基本建立在开源基础上，实际并没有出现开源与自有 C 端用户相冲突的情况。即使腾讯拥有更大的流量，能够部署同一款开源模型，也没有因此把公司的全部 C 端用户接走。

梁文锋认为，这种做法反而使公司更从容。外部看起来，他们选择了研究和开源这种更难的模式；但因为主动舍弃了许多商业负担，公司内部并没有同时背负争流量、做销售、守高利润等多重目标。他甚至用 “根本都不用加班” 来形容这条路线的轻松：真正让其他公司感到困难的，往往是同时想要的东西太多。

##### 从思维链到 Agent，下一道明确障碍是持续学习

当讨论转向长期目标时，梁文锋把目标明确为 AGI。不同人对 AGI 的定义可以不同，但不妨碍公司把它作为共同方向。在他看来，从现有技术出发，通往 AGI 的路线已经相对清楚。

当前这一代 AI，如果一个问题被描述得足够清楚，并且获得完整的上下文和指令，在很多任务上已经能够超过人类。但 “完整上下文” 本身几乎无法满足。比如这场会议，参与者各自携带着几十年形成的上下文，而 AI 并不具备这些积累。

在有限上下文里，AI 可以做得比人更好，却仍无法直接替代一名员工。公司招聘一名员工后，他可能需要两个月熟悉环境和工作，之后便能理解很多依赖共同背景的话。有人说 “叫那个小王来”，员工知道小王是谁；AI 如果没有经历此前两个月的学习，就必须被告知小王的身份、职务、所在位置、如何联系，以及联系时需要注意什么。理论上，只要提供全部信息，AI 可以完成任务，但现实中不可能每次都补齐所有上下文。

因此，梁文锋认为 AI 还缺少持续学习能力。如果 AI 也能像新员工一样，在公司里学习两个月并保留这些经验，它才可能进一步替代大量人类工作。

他把智能发展描述为一段段向上的阶梯。去年的阶梯是 CoT，也就是思维链。通过让模型自己思考，智能上限被推到更高水平，AI 能够解决更多问题。CoT 发展到上限后，模型在奥数题和编程等任务上已经超过最顶尖的人类，但仍停留在这一技术边界，并没有因此直接到达 AGI。

今年的阶梯是 Agent。Agent 建立在 CoT 之上，CoT 又建立在语言模型之上，所以此前的每一步都没有白走。Agent 能够扩大模型可以完成的任务范围，也会提高智能上限，但它同样会走到尽头：当这一框架下可以解决的问题被逐渐解决后，AI 依然不能像长期员工那样理解环境。

站在 Agent 这个台阶上，梁文锋看到的下一个明确瓶颈就是持续学习。模型不应每次都依赖一次强训练，而应像人一样进行较长时间的连续学习。完成任务、从任务中吸收经验等问题也与此相关。这个障碍必须跨过去，他相信一定有方法，只是需要时间。

持续学习之后，模型可能进入通常所说的 “奇点”：它能够完成人类能做的所有事情，也能够研究和开发自己的下一个版本，推动更先进的人工智能模型出现。不过，梁文锋并不认为这会是瞬间发生的突变。所谓奇点更可能是一段持续时间较长的渐变过程，只是早期预言习惯把它称为奇点。

在这个阶段之后，才是具身智能。模型进入现实世界，能够做家务、提供养老服务。梁文锋认为，最理想也最轻松的顺序，是先解决持续学习，再到能够自我迭代的阶段，最后进入具身智能。这样，每一步都能利用此前的技术帮助开发后面的技术；如果在自我迭代之后再做具身智能，很多工作甚至可以由模型自己完成。反过来，如果一开始就把具身智能放在前面，人类团队需要承担大量艰苦工作。

这条路线也决定了公司不是什么热门方向都做。他们只做 GPT、CoT、Agent、持续学习等智能主线。3D、视频生成等方向，在梁文锋看来与当前智能上限关系不大，因此不会因为它们商业前景好就投入。

Sora 出现后，视频生成一度成为热点，大公司和小公司都在做，仿佛不做就不能算 AI 公司；但后来许多小公司又把这条业务砍掉。梁文锋认为，视频生成可以是好生意，却不等于它处在智能路线图上。世界模型的含义更复杂，很多技术都可以被归入其中，但按公司的判断，它同样不是当前阶段最重要的问题。现阶段最重要的仍是把 AI 训练做好，之后解决持续学习。多模态最终要做，但暂时缩小训练范围、不做多模态，只会使一部分任务无法完成，并不妨碍核心算法成立。

##### 唯一不能退让的是团队稳定，最大的外部差距则是算力

在可以克制的诸多利益之外，梁文锋提出了公司唯一不能退让的核心利益：保持团队稳定。他认为，只要团队成员不走，大家能够继续做下去，公司就一定能做成 AGI。即使遭遇挫折，也只是继续尝试；钱、资源和其他要素最终都相对容易获得。

因此，团队稳定既是公司的最大核心利益，也是最大的风险。近期融资在很大程度上缓解了这一风险，因为员工获得的期权数量和金额都比较大。只要最重要、最早加入的一批员工保持稳定，其他人也不太容易离开。即使部分人的期权或收入少一些，他们也并非完全为钱而来，更看重能否在一个有机会做成 AGI 的环境里工作。

从历史情况看，公司的人才流动一直比同行少。但梁文锋仍把它视为唯一真正的挑战。其他问题最多导致进度晚半年或一年，不至于使目标无法完成。公司现在做的许多事情，最终都服务于团队稳定；除此之外，其他利益都可以让步。

这也影响了公司与外部同行相处的方式。梁文锋不愿意与任何互联网大厂或创业公司成为对手，更愿意赋能和协助其他人。即使面对阿里、智谱、月之暗面等被视为竞争对手的公司，他们也愿意帮助对方把开源模型复现出来：如果对方复现不了，可以说明问题，公司可以告诉其怎样复现。对合作伙伴，公司会做得更多，但在大的利益上不存在冲突。

在梁文锋看来，这种善意并没有损害公司的商业利益。去年 C 端用户仍然很多且相对稳固，今年 B 端进展也比较乐观。开源、帮助同行和不争夺所有机会，没有让公司少拿到什么，反而可能带来额外收益。

但从另一个维度看，公司真正缺少的东西非常明确：算力资源。梁文锋说，公司当时大约拥有两万张 H 系列等效算力，其中大部分是最近一两个月才到，仍有不少机器尚未交付。去年总体算力较少，今年正在非常激进地扩充，接下来几个月还会采购大批机器，基本上都是英伟达产品。

采购策略是，只要价格合理，能够买到多少卡就买多少。如果融资资金能在半年内全部变成显卡，他认为反而是最理想的结果。钱放在银行只能获得大约两个点的收益，而显卡按照此前的商业逻辑，大约十个月可以收回成本。真正的困难不是是否愿意花钱，而是市场上没有足够多的卡，价格也不能高到完全不合理。

他甚至说，如果公司一年能够花掉两百亿元，说明采购部门的业绩 “超级好”。即使支付一定溢价，公司也愿意把资金变成卡，因为有了卡，后续总能通过提供服务形成现金流，不需要在账上长期存放大量现金。

梁文锋判断，中国与美国在 AI 上最主要的差距就是资源，而不是人。中美使用的在很大程度上是同一批人才，只是有人留在国内，有人去了国外，这种流动并不是所有最聪明的人都去了美国。国内仍有大量优秀人才，而且每年都有庞大的人才补充。

人才能力上的差距，本质上也来自算力。因为卡少，国内研究人员能够进行的实验更少，长期积累后就会显出差距。模型能力和应用层面的差异，也可以追溯到算力投入的差异。即使美国公司为个别人才开出一亿美元薪水，人才工资在总投入中的占比仍然很小，大头依旧是算力。

在最大模型规模上，差距更加直接。当时美国最大的模型激活参数大约为 800B，而国内最大模型可能仍在几十 B 激活规模，相差约一个数量级。如果要训练同等级模型，梁文锋估计需要五万张 GB300，或者二十万张华为 950；这还只是正式训练，没有算上前期研究和大量实验。即使把五百亿元全部投入，也未必真正承担得起。

公司现有和近期即将获得的资源，主要只能支持在十 B 激活量级做更多实验，而几十 B 激活规模内仍有许多问题需要研究清楚。等资源增加后，才可能逐步走到 150B、156B 或 250B 激活规模。硬把大量卡堆起来训练一个超大模型并非完全不可能，真正的问题是训练前无法进行充分研究，失败和调整的成本过高。

华为卡的产量同样有限。如果训练 800B 激活模型需要二十万张最新华为卡，那么短期内便很难通过国产供给弥补这个缺口。因此，公司当前不会直接在最大模型规模上与美国竞争，而是先在自己能够训练、也能够承担推理成本的几十 B 激活范围内，把模型和训练方法做到最好。

##### 大模型走到终局，差距会落在成本、时间和体验上

最后谈到大模型竞争的终局时，梁文锋判断，不同模型最终在能力上可能不会有特别大的差距。真正能够拉开距离的，主要是成本、时间和用户体验。

成本排在第一位。面对同样的服务和同样的质量，一家公司能以多低的成本提供，构成了实质壁垒。他以比亚迪电池作类比：即使其他企业掌握相近技术，也未必能按同样价格生产出来。模型公开并不等于成本能力也被复制，部署、工程优化和组织效率仍会形成差异。

第二个差异是时间。相同能力早几个月做出来，和晚几个月做出来，商业处境并不一样。模型达到同一目标时，是快一点还是慢一点，也会影响竞争结果。

第三个差异是用户体验。用户之间仍会形成一定粘性和壁垒，但梁文锋认为，这种差异可能不如前两项本质。长期来看，最关键的仍是成本，以及谁能更早到达下一阶段。

至于产品线扩大之后怎样继续定价、怎样设计长期商业化路径，梁文锋仍把答案落回最初的主线上：现阶段最值得投入精力的事情，依然是继续把 AGI 向前推进。C 端用户、B 端收入和 API 服务都可以做，也应当做好，但它们只是沿途自然产生的商业机会，而不是公司最初聚集起来的原因。

## 口播总结（1）

### 2026-08-03 01:15:41

#### 梁文锋投资者交流会：口播总结

这场交流会主要讲了这家公司为什么坚持开源、为什么不把利润最大化放在第一位，以及它对 AGI，也就是通用人工智能，技术路线和商业竞争的判断。听完之后，你可以了解这家公司的管理方式、定价逻辑、长期目标，以及它目前真正面临的优势和瓶颈。

##### 一、公司的起点：不是为了赚钱，而是为了做一件对人类有用的事

首先，梁文锋强调，这家公司最初成立时，并没有把赚钱、上市或者进入资本市场作为目标。

最开始加入的几十个人，想的都是做一件对这个世界有用的事情。公司后来发现人工智能背后的利益很大，确实会遇到各种诱惑，但最初的愿景并没有改变。这里所说的愿景，不是写在墙上的口号，而是体现在公司每天怎么做事、怎么面对世界，以及怎么作出取舍。

他认为，大公司真正依靠的，不只是规章制度和考核指标，更重要的是一个共同愿景。这家公司并不是主要靠严格的组织层级、关键绩效指标，也就是 KPI，来把人组织起来，而是靠一个比较松散、甚至没有完全写成文字的共同方向。

每个人对这个愿景的理解可能不完全一样，但大方向是一致的：怀着善意，做一点有用的事情。

这套方式有优点，也有缺点。优点是能够把一群普通人凝聚起来，去完成一件不普通的事。缺点是，愿景不够明确时，组织管理可能会比较松散。公司未来会想办法保留优点、减少缺点，但这种由愿景驱动，而不是由商业利益最大化驱动的方式，已经成为它的特色。

也正因为如此，后面很多看似反常的做法，比如坚持开源、主动降价、不抢所有用户，都可以从这个愿景中得到解释。

##### 二、为什么坚持开源：人工智能的市场太大，没人能够独占

接下来，重点是开源。

开源，简单说，就是把模型的代码、结构或者使用方法公开出来，让其他人可以研究、部署和改进。梁文锋认为，这家公司坚持开源，首先是因为愿景本身就要求这样做。对他们来说，开源不是一种迫不得已的商业策略，而是从一开始就认可的方向。

第二个原因，是人工智能的市场规模可能远远超过过去的软件市场。

过去，一个软件公司的市场可能只有几十亿美元。如果把软件开源，商业收入可能就从几十亿美元下降到几千万或者几亿美元，所以开源和商业化经常会发生冲突。

但人工智能不同。梁文锋提出一种判断：未来人工智能可能占到人类国内生产总值，也就是 GDP 的百分之十左右。这个市场如果真的这么大，就不是一家公司可以独占的。你如果试图把所有利益都拿走，反而可能因为受到社会、行业和竞争者的阻力，最终什么也做不成。

所以，他把“克制”看成一种商业战略。越是想把人工智能做成，就越不能一开始就想着占有全部市场。必须接受让利，接受分享，甚至让其他公司也参与进来。

换句话说，开源不一定是在削弱自己，也可能是在提高这家公司最终做成 AGI 的概率。

##### 三、克制的核心：只拿合理利润，而不是尽可能多赚钱

更重要的是，这种克制不只体现在开源上，也体现在定价和用户策略上。

梁文锋说，公司的 API，也就是让其他开发者通过接口调用模型服务，定价标准不是追求最高收入，而是让设备成本在大约十个月内收回。

服务器在财务上可能按照三年或五年来折旧，但在商业上，公司希望一台设备大约十个月就能收回成本。这个标准已经包含了前期投入和经营风险，因此公司认为这样的回报足够合理。

他还提到，这种十个月回本的模式，大致相当于六倍左右的利润。看起来数字不低，但如果把价格再提高一倍，用户使用量可能不会明显下降。也就是说，当前需求对价格并不敏感，涨价可能直接带来更多收入。

但公司没有因此把价格抬高。原因是，价格高一点，短期收入可能更多；可长期来看，低价能让更多人使用模型，也能让员工感到自己做的技术真正产生了社会价值。

梁文锋举了一个很典型的例子：公司一开始担心需求太大，所以把一款模型的价格定得比较高。后来价格降到了原来的四分之一，团队成员反而非常高兴，内部群里甚至出现了欢呼。

这说明，公司内部对成功的理解，不是“模型卖得越贵越好”，而是“在赚到合理利润的同时，让更多人用得起，而且效果足够好”。

当然，他也承认，十个月回本仍然存在继续降价的空间。只是目前再降价，用户需求增加得很少。因为这个价格已经让大多数人觉得可以接受，继续降价，既不会明显增加公司收入，也不会明显增加社会价值。

因此，当前定价的出发点不是收入最高，而是合理利润、广泛使用和长期发展之间的平衡。

##### 四、为什么不抢所有用户：眼前的“芝麻”，可能不如未来的“大西瓜”

这种克制，也体现在用户和业务选择上。

去年春节前后，公司的消费者端，也就是 C 端业务，突然迎来大量用户。很多公司可能会趁机投入大量资金，抢用户、做流量、提高变现，甚至把目标定成下一个大型互联网平台。

但这家公司没有这样做。它没有把大量精力用来抢用户，也没有急着把用户变成收入，而是尽量用较低成本把服务维持好。

梁文锋把这种选择比作“不要为了抢前面的芝麻，错过后面的大西瓜”。在他的判断里，去年 C 端用户的增长、今年企业端，也就是 B 端的收入机会，当然值得做，也应该把服务做好，但和 AGI 相比，它们并不是同等重要的目标。

公司认为，真正更大的机会在人工智能能力本身。如果去年投入很多钱去和大型互联网公司争夺消费者用户，可能看起来规模很大，但未必能得到真正重要的东西。

所以，公司会顺手把能够低成本获得的用户和收入机会接住，但不会为了这些短期机会，改变 AGI 的主线。

他也提到，如果 API 和人工智能服务的需求继续扩大，并且公司能够买到更多显卡，那么年度经常性收入，也就是 ARR，做到几亿美元是有可能的。如果人工智能业务达到十亿美元规模，公司的现金流可能就能够覆盖研发和其他全部支出。

但这些都不是公司的第一优先级。它们更像是做 AGI 过程中顺带产生的商业收入。

##### 五、开源为什么不一定损害商业利益

关于开源和商业化是否冲突，梁文锋给出了更具体的解释。

即使把模型开源，其他公司也不能轻易复制同样的效果。因为真正把模型部署起来，需要大量工程工作，还要把成本控制到足够低。模型原理公开，并不等于任何公司都能用同样的成本和效率运行它。

他认为，这正是这家公司目前所处的一个有利规模。

公司太小，可能没有足够的人力和资源把开源模型真正做好；公司太大，又可能因为管理复杂、部门之间协调困难，很难迅速组织力量完成部署优化。处在中等规模时，既有一定技术和人力，又保留创业公司的灵活性，反而比较适合做这件事。

在定价方面，如果公司只追求大约六倍的利润，也就是十个月左右收回设备成本，那么独立部署模型的第三方就很难获得利润。因为第三方的成本通常更高，很难做到同样的价格。

但如果公司追求一百倍利润，情况就不同了。第三方即使成本比公司高很多，也可能通过独立部署来提供更便宜的服务，从而抢走部分市场。

所以，开源是否影响收入，取决于公司想要赚多少。只赚合理利润时，开源和商业化可以并存；如果想赚极高的垄断利润，开源当然会限制这种空间。

公司还表示，开源的模型和自己部署的模型是同一个模型，不会故意开源一个较弱的版本，自己使用更强的版本。过去一年里，开源模型与公司自有的消费者服务之间，也没有明显冲突。

甚至相反，公司希望其他人能够把模型部署起来。它真正担心的不是别人来竞争，而是别人部署失败，或者因为细节没有处理好，导致模型效果差、使用成本高，从而影响整个开源生态。

##### 六、公司的长期目标：沿着一条清晰的路线走向 AGI

下面进入公司最核心的长期目标，那就是 AGI。

AGI，也就是通用人工智能，指的是能够像人一样，在很多不同任务中理解、学习和解决问题的人工智能。每个人对 AGI 的具体定义可能不同，但公司把它作为长期目标。

梁文锋认为，现在这一代人工智能在一些限定条件下已经超过人类。只要人类能够给模型完整的背景信息、清楚的指令，它在某些任务上可能比人做得更好。

问题在于，现实世界里，人通常不需要把所有背景都重新解释一遍。

比如，一个新员工进入公司，工作两个月后，就会熟悉公司环境。他知道“小王”是谁，也知道去哪找小王。可是人工智能如果没有持续积累上下文，你对它说“把小王叫过来”，就必须额外解释小王是谁、在哪个部门、应该去哪里找，以及需要注意什么。

因此，当前人工智能的主要限制，不只是完成任务的能力，而是缺少像人一样长期学习和持续积累经验的能力。

梁文锋把人工智能的发展理解成一层一层的台阶。

第一层是语言模型，也就是通过大量数据学习语言和知识的模型。

接下来是 CoT，也就是“思维链”。它让模型能够把问题拆开，进行多步思考。通过思维链，模型在数学、编程等任务上的能力上限明显提高，甚至可以超过顶尖人类，但它仍然无法真正达到 AGI。

再往后是 Agent，也就是智能代理。智能代理不只是回答问题，还可以根据目标调用工具、拆解任务、连续执行多个步骤。这样，人工智能能够处理的任务范围更广。

但 Agent 也会遇到上限。它可以解决越来越多的问题，却仍然不能像一个真正的员工一样，在现实环境中持续学习、积累经验。

因此，下一道关键关卡是持续学习。也就是模型不需要每次都重新训练，而是能够像人一样，在工作过程中不断学习新的知识和方法。

如果持续学习解决了，模型就可能进一步具备自我改进能力。它可以研究自己的不足，开发新的模型版本，推动人工智能不断迭代。

外界常把这一步称为“奇点”，好像会突然发生巨大的变化。但梁文锋认为，它更可能是一个渐进过程，而不是某一天突然发生的突变。

再往后，才是具身智能。具身智能就是让人工智能进入现实世界，拥有身体或者机器人形态，能够做家务、照顾老人，以及完成各种物理世界中的工作。

所以，公司判断的一条较理想路线是：先提升模型训练能力，再解决持续学习，然后逐步走向自我迭代，最后发展到具身智能。

这条路线的好处是，后面的技术可以借助前面的人工智能来开发。比如，等模型具备更强的自我迭代能力后，它可能自己帮助开发具身智能，而不需要完全依靠人类来完成。

##### 七、为什么把 C 端和 B 端看成副产品

回到现实商业层面，梁文锋认为，消费者业务和企业业务都不是公司的终极目标。

其他公司可能是为了服务消费者，或者为了获得企业收入，才去训练和优化模型。而这家公司首先做的是 AGI。C 端和 B 端服务，是在做 AGI 的过程中自然产生的中间成果。

比如，公司为了研究更强的模型，本来就需要把模型通过 API 提供出去。既然模型已经做出来了，就可以顺便服务企业和开发者。这并不需要额外投入太多销售力量，也不需要把大量人力放在流量竞争上。

这种做法带来了一种他所说的“降维打击”。意思是，公司站在更高的技术目标上，再去做相对低一级的应用和服务，因此不需要投入同样多的精力，也可能获得不错的结果。

去年消费者端突然出现大量用户，就是一个例子。公司没有刻意争抢，却意外获得了很多关注。梁文锋认为，这并不代表公司的人比别人更聪明，而是因为 AGI 这个愿景能够吸引和组织一批优秀的人。

聪明的人聚在一起，并不会自动形成高效合作。真正困难的是让他们愿意长期合作，有激情地朝着同一个目标努力。愿景在这里发挥了组织和激励作用。

##### 八、公司真正的核心利益：保持团队稳定

梁文锋随后谈到，公司最不能放弃的核心利益，只有一个，那就是团队稳定。

他的判断是，只要核心团队不离开，公司就一定有机会做成 AGI。过程中即使遇到挫折，最多晚半年或晚一年，但不会因此彻底失败。

钱、资源和其他条件，在他看来都可以逐步获得。真正无法轻易替代的，是已经形成默契的团队，以及团队长期合作的状态。

最近一次融资，在一定程度上缓解了团队稳定的风险。因为重要员工和老员工获得了较多期权，长期利益和公司发展绑定得更紧。

公司与同行相比，人才流动一直比较少。但梁文锋仍然认为，人员稳定是最大的挑战，也是公司唯一不能退让的利益。

因此，公司的很多决定，包括克制利润、坚持开源、不过度扩张，最终都与保持团队稳定有关。只要团队能稳定下来，其他方面都可以做取舍。

##### 九、只做 AGI 主线，不追逐所有热门方向

在技术方向上，公司强调只做与 AGI 主线直接相关的事情。

目前公司认为，语言模型、思维链、智能代理、持续学习，以及模型如何自己提出问题，是更接近智能上限的关键问题。

相反，三维内容、视频生成和世界模型等方向，虽然可能是很好的商业机会，但在公司当前的判断中，并不一定是提高智能上限的核心路径。

以视频生成为例，Sora 出现之后，很多大公司和小公司都投入其中。后来一些小公司又把这条业务砍掉了。梁文锋认为，视频生成可以是好生意，但它和人工智能智能水平的主线不一定直接相关。

世界模型的含义更加宽泛。公司当前的判断是，现阶段最重要的仍然是把模型训练做好，再解决持续学习，而不是优先投入世界模型。

这里强调的是“当前阶段”的判断，而不是说这些方向永远不重要。其他公司愿意做，公司也不反对，甚至愿意提供帮助。因为这些业务和公司自己的 AGI 主线并不存在根本利益冲突。

##### 十、和美国的主要差距：不是人才，而是算力资源

接下来是资源问题。

梁文锋认为，公司与美国人工智能公司的主要差距，不在人才，而在算力。算力，简单说，就是训练和运行人工智能模型所需要的计算资源，主要来自大量高性能显卡。

目前公司大约拥有两万张按 H 系列显卡折算的等效算力，其中很大一部分是在最近一两个月才到位的。接下来几个月，公司还会继续大量采购英伟达等公司的显卡。

公司的策略是，只要价格合理，能买多少就买多少。融资拿到的钱，如果能在半年内全部变成显卡，梁文锋认为反而是理想情况。因为显卡能够直接用于训练模型、提供服务，放在银行里只能获得较低利息。

但现实困难是，显卡并不是有钱就能立刻买到，而且价格不能高得不合理。所以公司真正担心的，是买不到足够多的卡。

算力不足还会进一步影响人才培养。因为算力少，研究人员能做的实验就少，积累经验的机会也少。因此，表面上看是人才差距，背后仍然可能是算力差距。

在最大规模模型方面，差距更加明显。美国一些顶级模型的激活参数规模大约达到八百 B。这里的“激活参数”，可以理解为模型每次处理任务时真正参与计算的参数数量。国内目前大多还处在几十 B 的规模。

如果要训练与八百 B 激活规模相当的模型，梁文锋估计，可能需要五万张 GB300，或者二十万张华为最新型号的显卡，而且这还只是训练，不包括前期研究和反复实验。

这意味着，公司目前不会直接去和美国竞争最大的模型规模，而是先把自己能够训练和使用的几十 B 规模做好。等将来资源更多，再逐步扩展到一百五十 B、两百五十 B 等更大规模。

所以，他的判断是：目前真正限制国内人工智能发展的，不是缺少聪明人，而是算力和资本投入不足。模型能力、应用能力以及人才训练机会，都受到这个因素影响。

##### 十一、大模型最终比什么：成本、速度和体验

最后，梁文锋谈到，大模型竞争最终会拉开什么样的差距。

他的判断是，模型能力本身可能不会长期保持巨大差距。真正重要的区别，主要有三个。

第一是成本。也就是提供同样质量的服务，谁能用更低的成本完成。成本越低，价格就越有竞争力，也越容易大规模使用。梁文锋认为，成本可能是最重要、最难被复制的壁垒。

第二是时间。谁能更早把同样的能力做出来，谁就能更早进入市场。早几个月和晚几个月，可能会带来完全不同的结果。

第三是用户体验。不同模型在响应速度、稳定性、使用方式和具体效果上，仍然会有差别。这些差别可能形成一定的用户黏性，但从长期看，用户体验的重要性可能排在成本和时间之后。

因此，公司现在最值得投入精力的事情，仍然是沿着 AGI 的主线继续突破，而不是单纯追求短期收入或产品数量。

##### 最后，记住四个结论

第一，这家公司最核心的驱动力不是利润最大化，而是做出对人类有用的 AGI。愿景不是口号，而是具体的经营和管理方式。

第二，开源和商业化不一定冲突。只要公司满足于合理利润，而不是追求极高的垄断利润，就可以通过低成本、强工程能力和服务效率保持竞争力。

第三，C 端用户和 B 端收入更像是做 AGI 过程中的副产品。公司愿意做，但不会为了短期市场机会，放弃长期技术主线。

第四，公司真正不能失去的是稳定的核心团队；而与美国相比，当前最大的外部瓶颈不是人才，而是算力资源。

第五，大模型长期竞争最终可能集中在三个方面：谁的成本更低，谁能更早做出来，以及谁能提供更好的用户体验。

#### 真正的壁垒未必是模型所有权，而是组织、成本与持续学习

##### 开源不等于放弃商业化，前提是把壁垒移到部署成本

文中对开源经济学的判断比泛泛谈生态更具体：模型权重即使公开，第三方仍要解决推理优化、集群利用率、稳定性和运维问题；如果官方 API 已足够便宜，自建与转售就很难形成成本优势。于是，**开源模型可以成为标准和获客渠道，商业护城河则从“别人拿不到模型”转向“别人无法以同样成本可靠运行”。**

这也解释了为什么低价可能是一种进攻策略：它压缩第三方利润空间，同时扩大模型的事实标准地位。不过，“十个月回收设备成本”等说法不能直接等同于利润，电力、闲置率、研发投入、设备贬值和供需波动都会改变计算。该模式还要求公司持续保持推理效率领先，并获得足够算力；一旦云厂商补贴价格，或企业因隐私、主权与定制需求坚持私有部署，结论就会变化。

更值得产品经理留意的是其需求弹性判断：当 token 价格低到不再阻碍使用，继续降价并不会明显增加需求。届时真正的瓶颈会转向**工作流接入、数据权限、结果可信度和组织改造**，而不是模型调用费。

##### Agent 之后，难题可能是“获得并更新上下文”

文本对 AGI 路线最有启发的观察是：当前模型在上下文完整、任务描述清楚时已经很强，但真实工作恰恰依赖长期积累的隐性信息。员工知道“小王是谁”、哪些规则只是纸面制度、某个客户为何特殊；AI 每次都需要重新被告知。Agent 扩展了行动范围，却未必解决长期适应问题。

因此，“持续学习”可以被理解为下一阶段瓶颈。但这里需要区分两件事：模型权重持续更新，和通过记忆、检索、反馈获得连续上下文。后者可能更早产生产品价值，也更可控。具体机会不是再做一个通用 Agent，而是构建**带权限的组织记忆、事件记录、反馈学习、评估与回滚系统**，替代今天的文档、RAG 和人工交接。待验证的核心假设是：长期记忆能否显著提高任务完成率，同时不引入隐私泄露、错误累积和权限越界。

整篇最值得保留的判断是：**当模型能力逐渐扩散，竞争不会简单终结于“谁拥有最强模型”，而会转向谁更早到达、谁运行得更便宜，以及谁能让 AI 真正融入长期而混乱的现实工作。**
