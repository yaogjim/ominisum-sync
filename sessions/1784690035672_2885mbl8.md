## 分析要点

- **核心高价值点**：将ESP32、ESP-NOW长距离通信、AES-GCM加密与透明串口转发结合，提供了低成本无人机遥测链路的可落地实现路径。
- **留存建议**：选择性浏览并保留，适合作为无人机低速遥测链路的工程参考（包含通信模式、加密方式、硬件连接、网络端口和配置流程等可复用的工程信息。）

**知识要点**

- ESP32可通过UART连接飞控，并以WiFi或ESP-NOW向地面站转发MAVLink等遥测协议。
- 项目支持透明传输模式，也支持对MAVLink、MSP和LTM进行解析，以增强遥测可靠性和状态展示。
- 文档明确了典型接入方式，包括网页配置、UDP 14550、TCP 5760以及地面站端点注册要求。

**行动项**

- 使用官方支持的ESP32板卡，按文档将飞控3.3V UART连接到合适的ESP32引脚。
- 刷写固件后连接DroneBridge WiFi，通过dronebridge.local或192.168.2.1完成网页配置。
- 使用QGroundControl或其他地面站测试UDP 14550或TCP 5760链路，并验证遥测收发。

DroneBridge logo

A firmware for the popular ESP32 modules from Espressif Systems. Probably the cheapest way to communicate with your drone, UAV, UAS, ground-based vehicle or whatever you may call them.

It also allows for a fully transparent serial to WiFi pass-through link with variable packet size (As of release v2.0 no continuous stream of data is required anymore in MAVLink and transparent mode).

DroneBridge for ESP32 is a telemetry/low data rate-only solution. There is no support for cameras connected to the ESP32 since it does not support video encoding.

DroneBridge for ESP32 concept

#### Features

- Bidirectional: serial-to-WiFi, serial-to-WiFi Long-Range (LR), serial-to-ESP-NOW link, Bluetooth LE
- Support for **MAVLink**, **MSP**, **LTM** or **any other payload** using transparent option
- Affordable: \~7€
- Up to **150m range** using standard WiFi
- Up to **1km of range** using ESP-NOW or Wi-Fi LR Mode - sender &amp; receiver must be ESP32 with LR-Mode enabled
- **Fully encrypted** in all modes including ESP-NOW broadcasts secured using AES-GCM 256 bit!
- Weight: &lt;8 g
- Supported by: QGroundControl, Mission Planner, mwptools, impload etc.
- Easy to set up: Power connection + UART connection to flight controller
- Fully configurable through an easy-to-use web interface
- Parsing of LTM &amp; MSPv2 for more reliable connection and less packet loss
- Parsing of MAVLink with the injection of Radio Status packets for the display of RSSI in the GCS
- Fully transparent telemetry down-link option
- Reliable, low latency

DroneBridge with connectionless ESP-NOW protocol support for increased range of 1km or more.

DroneBridge for ESP32 can be used to control drone swarms at a low cost.

DroneBridge for ESP32 supports ESP-NOW LR, enabling ranges of more than 1km with external receiving antennas.  
The number of drones is only limited by the channel capacity and the ESP32s processing power. All data is encrypted using AES256-GCM.

#### Wiring

1. Connect the UART of the ESP32 to a 3.3V UART of your flight controller. It is not recommended to use the ESP32s pins that are marked with TX &amp; RX since they often are connected to the internal serial ouput. Go for any other pin instead!
2. Set the flight controller port to the desired protocol.

**Check out the manufacturer datasheet! Only some modules can take more than 3.3V. Follow the recommendations by the ESP32 board manufacturer for powering the device**  
**[For further info please check the wiki!](https://dronebridge.gitbook.io/docs/dronebridge-for-esp32/hardware-and-wiring)**

#### Configuration

1. Connect to the WiFi `DroneBridge ESP32` with password `dronebridge`
2. In your browser type: `dronebridge.local` (Chrome: `http://dronebridge.local`) or `192.168.2.1` into the address bar.**You might need to disable the cellular connection to force the browser to use the WiFi connection**
3. Configure as you please and hit `save`

DroneBridge for ESP32 web interface

**[For further info please check the wiki!](https://dronebridge.gitbook.io/docs/dronebridge-for-esp32/configuration)**

- The ESP will auto-send data to all connected devices via UDP to port 14550. QGroundControl should auto-connect using UDP
- Connect via **TCP on port 5760** or **UDP on port 14550** to the ESP32 to send &amp; receive data with a GCS of your choice.
- **In case of a UDP connection the GCS must send at least one packet (e.g. MAVLink heart beat etc.) to the UDP port of the ESP32 to register as an endpoint. Add ESP32 as an UDP target in the GCS**
- Manually add a UDP target using the web interface

#### DroneBridge for ESP32 内容总结

DroneBridge for ESP32 是一款开源固件，可将低成本 ESP32 模块变成安全、双向的无人机遥测通信设备，支持 Wi‑Fi、Wi‑Fi LR、ESP‑NOW 和 BLE。它适用于飞行器、地面车辆及无人机集群，但仅面向遥测和低速数据传输，不支持视频编码或摄像头传输。

##### 1. 项目定位与通信能力

- 可在飞控串口与无线网络之间建立双向通信链路，包括：
  - 串口 ↔ 标准 Wi‑Fi
  - 串口 ↔ Wi‑Fi Long Range（LR）
  - 串口 ↔ ESP‑NOW
  - Bluetooth LE（BLE）
- 支持 **MAVLink、MSP、LTM**，也可通过透明传输模式承载其他协议。
- 从 **v2.0** 起，MAVLink 和透明模式不再要求持续产生数据，并支持可变长度数据包。
- 仅适用于遥测和低数据速率场景；ESP32 本身无法进行视频编码，因此不支持相机视频传输。

##### 2. 主要特点

- **成本低**：设备成本约 **7 欧元**。
- **体积轻**：重量低于 **8 克**。
- **通信距离**：
  - 标准 Wi‑Fi 最远约 **150 米**。
  - ESP‑NOW 或 Wi‑Fi LR 模式可达到约 **1 公里以上**；发送端和接收端都必须是支持并启用 LR 模式的 ESP32。
- **安全性高**：所有模式均加密，包括 ESP‑NOW 广播，采用 **AES‑GCM 256 位加密**。
- **可靠且低延迟**：
  - 可解析 LTM 和 MSPv2，以减少丢包、提高连接可靠性。
  - 可解析 MAVLink，并注入 Radio Status 数据包，让地面站显示 RSSI 信号强度。
  - 也提供完全透明的遥测下行模式。
- **配置简单**：只需连接电源和飞控 UART，即可通过网页界面完成设置。
- 兼容 **QGroundControl、Mission Planner、mwptools、imploAD** 等地面站或工具。

##### 3. 无人机集群与表演应用

DroneBridge 可低成本控制无人机集群：

- 借助 ESP‑NOW LR 和外置接收天线，通信距离可超过 **1 公里**。
- 可管理的无人机数量主要受无线信道容量和 ESP32 处理能力限制。
- 集群通信数据同样采用 **AES-256-GCM** 加密。

项目还提供针对 **Skybrush 无人机灯光秀**优化的特别版本，支持：

- 远程电源管理，如休眠与唤醒。
- 更多安全性和可靠性检查。
- 用于批量烧录、管理和维护无人机的开源商业支持套件。
- 基于 **DLSE API** 编写自定义管理工具。
- ESP32 的 OTA 无线更新。
- 在受支持芯片上使用 Wi‑Fi 6（OFDMA）和 5GHz，涉及 **ESP32‑C3、ESP32‑C5、ESP32‑C6** 等型号。

##### 4. 硬件选择与固件安装

- 官方建议优先使用经过测试和支持的开发板，这些板卡价格低、体积小，并集成了无人机应用所需功能。
- 用户也可以利用项目提供的 **KiCad PCB 工程及生产文件**自行制作电路板，支持个人和商业用途，并提供更易焊接的版本。
- 推荐使用官方在线烧录工具安装固件；其他烧录方法可参考项目 Wiki。
- 当前仓库信息显示项目已更新至基于 **ESP-IDF 5.4.4 的 v2.2.1**。

##### 5. 接线注意事项

- 将 ESP32 的 UART 连接到飞控的 **3.3V UART**，并将飞控对应端口设置为所需协议。
- 不建议使用 ESP32 板上标有 **TX/RX** 的引脚，因为这些引脚通常连接内部串口输出；建议选择其他可映射的 GPIO。
- 供电前必须查看具体模块或开发板的数据手册：
  - 并非所有 ESP32 模块都能承受高于 **3.3V** 的电压。
  - 应严格遵循板卡厂商的供电建议。

##### 6. 网页配置流程

1. 连接名为 **DroneBridge ESP32** 的 Wi‑Fi。
2. 默认密码为 `dronebridge`。
3. 在浏览器中访问：
   - `dronebridge.local`
   - Chrome 可使用 `http://dronebridge.local`
   - 或直接访问 `192.168.2.1`
4. 按需求调整参数并保存。
5. 如果页面无法打开，可能需要关闭手机蜂窝数据，强制浏览器通过 ESP32 的 Wi‑Fi 访问设备。

##### 7. 与地面站连接

- ESP32 会通过 UDP 将数据发送给所有已连接设备，默认端口为 **14550**。
- **QGroundControl** 通常可以通过 UDP 自动连接。
- 其他地面站可使用：
  - TCP：端口 **5760**
  - UDP：端口 **14550**
- 使用 UDP 时，地面站至少需要先向 ESP32 发送一个数据包，例如 MAVLink 心跳包，以注册为通信端点。
- 也可以：
  - 在地面站中将 ESP32 添加为 UDP 目标。
  - 通过 DroneBridge 网页界面手动添加 UDP 目标。

##### 8. 项目支持

项目提供 Wiki、Discord 社区和官方网站，供用户获取最新版本、硬件说明、烧录及配置文档。该项目接受 PayPal 捐赠，以支持后续开发与维护。

#### DroneBridge：用 ESP32 搭建低成本、加密的无人机遥测链路

DroneBridge 是一套开源 ESP32 固件，可在飞控串口与地面站之间建立双向无线连接。它主打约 7 欧元、低于 8 克的低成本方案，适用于无人机、地面车辆及集群控制，但仅面向遥测和低速数据，不支持视频传输。

##### 多种无线方式与协议，最长可达公里级

固件支持标准 Wi‑Fi、Wi‑Fi 长距离模式、ESP‑NOW 和蓝牙 LE：

- 标准 Wi‑Fi 距离约 150 米；
- ESP‑NOW 或 Wi‑Fi LR 可超过 1 公里，但收发两端都需使用开启 LR 模式的 ESP32；
- 支持 MAVLink、MSP、LTM，也可通过透明模式承载其他串口协议；
- 项目称所有模式均采用 AES‑256‑GCM 加密，包括 ESP‑NOW 广播。

它还能解析 MAVLink、MSPv2 和 LTM，以降低丢包，并向地面站注入无线状态数据，从而显示 RSSI 信号强度。

##### 部署门槛低，但需注意硬件与网络配置

ESP32 通过 3.3V UART 接入飞控，用户连接其热点后即可在网页中配置。数据默认通过 UDP 14550 或 TCP 5760 与 QGroundControl、Mission Planner 等地面站通信，并支持 OTA 升级。部分 ESP32‑C3、C5、C6 芯片还支持 Wi‑Fi 6 或 5GHz。

##### 价值在于廉价扩展，而非替代专业数传

该方案可用于低成本无人机集群，规模受无线信道容量和 ESP32 算力限制；项目还提供面向 Skybrush 无人机表演的版本，支持远程休眠、唤醒和集中维护。其优势是开放、轻量、协议兼容性强，但距离指标依赖天线和环境，也不能承担高清视频等高带宽任务。
