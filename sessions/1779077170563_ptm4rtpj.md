```
import spacy

# Load English tokenizer, tagger, parser and NER
nlp = spacy.load("en_core_web_sm")

# Process whole documents
text = ("When Sebastian Thrun started working on self-driving cars at "
        "Google in 2007, few people outside of the company took him "
        "seriously. “I can tell you very senior CEOs of major American "
        "car companies would shake my hand and turn away because I wasn’t "
        "worth talking to,” said Thrun, in an interview with Recode earlier "
        "this week.")
doc = nlp(text)

# Analyze syntax
print("Noun phrases:", [chunk.text for chunk in doc.noun_chunks])
print("Verbs:", [token.lemma_ for token in doc if token.pos_ == "VERB"])

# Find named entities, phrases and concepts
for entity in doc.ents:
    print(entity.text, entity.label_)
```

#### spaCy：面向生产级应用的 Python NLP 工具库

##### 1. 核心定位

spaCy 是一个工业级自然语言处理（NLP）框架，主打**高性能、可扩展、可部署**。  
它适合将文本处理能力集成到真实业务系统中，而不仅是做学术实验或 Demo。

典型能力包括：

- 分词
- 词性标注
- 依存句法分析
- 命名实体识别
- 文本分类
- 词形还原
- 实体链接
- 句子切分
- 自定义 NLP Pipeline

---

##### 2. 主要能力与特性

###### 多语言与预训练模型

spaCy 支持**75+ 种语言**，并提供**25 种语言的 84 个训练管线**。  
它也支持预训练词向量，以及基于 BERT 等 Transformer 的多任务学习模型。

###### 生产级性能

spaCy 强调速度和稳定性，适合部署到真实业务环境。  
它提供：

- 高性能推理
- 可复现实验配置
- 模型打包与部署
- 工作流管理
- 准确率评估
- CPU / GPU 适配能力

###### 可扩展架构

开发者可以轻松加入自定义组件、属性和模型。  
同时支持 PyTorch、TensorFlow 等框架中的自定义模型接入。

---

##### 3. 与大语言模型的结合

spaCy 推出了`spacy-llm`，用于把大语言模型接入结构化 NLP Pipeline。

它的价值在于：

- 快速构建 Prompt 原型
- 将 LLM 的非结构化输出转成稳定结果
- 支持多种 NLP 任务
- 在部分场景下无需训练数据

这让 spaCy 不只是传统 NLP 工具，也能成为 LLM 应用中的结构化处理层。

---

##### 4. 数据标注与模型训练

###### Prodigy 标注工具

Prodigy 是 spaCy 生态中的高效数据标注工具，强调 “机器教学”。  
它让数据科学家可以自己完成标注，从而加快模型迭代。

适用场景包括：

- 实体识别
- 意图识别
- 图像分类
- 模型训练与评估

###### 可复现训练系统

spaCy v3 引入了完整的训练配置系统。  
训练过程中的参数都写入配置文件，没有隐藏默认值，便于：

- 实验复现
- 参数追踪
- 团队协作
- 自动化训练

---

##### 5. 从原型到生产的工作流

spaCy 提供项目系统，帮助团队管理从数据处理、预处理、训练到部署的完整流程。

它支持：

- 数据资源下载
- 命令执行
- 校验和验证
- 缓存
- 项目模板
- 自动化工作流

这对于企业级 NLP 项目非常重要，可以降低交付和维护成本。

---

##### 6. 定制化商业服务

spaCy 官方还提供 Tailored Pipelines 服务，即由核心团队为客户定制 NLP Pipeline。

其卖点包括：

- 官方团队交付，专业性强
- 项目可直接部署
- 价格与交付范围明确
- 提供代码、数据、测试和文档
- 方便后续维护、再训练和扩展

这体现出 spaCy 不只是开源框架，也在构建面向企业客户的商业化服务。

---

##### 7. 学习资源与性能表现

spaCy 提供免费的高级 NLP 在线课程，包含视频、课件、选择题和浏览器内编码练习。

在性能方面，spaCy v3 的 Transformer Pipeline 已接近当前先进水平。  
同时，它也提供更轻量的 CPU 优化模型，适合在成本敏感的场景中使用。

---

##### 8. 产品视角总结

spaCy 的核心价值是：  
**把复杂的 NLP 能力产品化、工程化、可部署化。**

它不是单纯追求模型效果，而是围绕真实业务落地构建完整体系：

- 底层 NLP 能力
- 训练配置
- 数据标注
- 工作流管理
- LLM 集成
- 模型部署
- 企业定制服务

对于需要在产品中集成文本理解能力的团队来说，spaCy 更像是一个**NLP 工程平台**，而不仅是一个 Python 库。
