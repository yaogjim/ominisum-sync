聊聊 Agent-Native 开发框架应该怎么设计👇

在谈 Agent-Native 之前，我们应该很熟悉 Cloud-Native 、AI-Native 这些概念，或者是 Native Speaker 这种表达

Native 就是原生的意思，强调的是事物最开始就是这个样子的，而不是后来改成这样的。

1\. English Native Speaker 指的是一出生就在英语环境，母语是英语的人

2\. Cloud-Native 强调的是业务一开始就在云上跑，而不是通过去 IOE 化把原来的系统迁移上云

3\. AI-Native 强调的是产品设计之初，功能和流程都是基于 AI 的能力来设计的，离开 AI 跑不起来或者跑不出好的效果

Agent-Native，讲的是产品功能和工作流程都是基于 Agent 的特性和能力来设计的，离开 Agent 就不 work

回到 ShipAny 框架的设计。在 ShipAny One、ShipAny Two 里，我们已经积累了一堆常用的业务功能：登录、注册、支付、 存储、多语言、SEO、管理后台等。

在新版本的 ShipAny 里，这些能力全部模块化了，按需启用，可插拔。关键是设计了几个核心的 Skills，把 ShipAny 内置的功能模块、开发流程都描述清楚，包括模块说明、数据表结构、API 参数等。Agent 读到这些 Skills 后，能快速搞懂整个框架的架构设计，然后按流程开发。

Agent-Native 开发框架的设计，首先要保证集成的功能足够多，功能模块化、低耦合。其次要梳理通用的开发流程，包括初始化项目、创建新模块、设计新页面、设计图片等。然后把每个流程文档化，不同的流程可组合，沉淀成 Agent 能理解的 Skills。

ShipAny 内置的核心 Skills 包括：

1\. quick-start：快速初始化新项目，完成 MVP 版本开发

2\. clone-website：复刻指定网址的项目

3\. new-module：开发新的功能模块

4\. new-page：开发新的页面

5\. deploy-cloudflare：一键发布到 Cloudflare

还有 generate-image（生成图片）、sync-upstream（同步上游更新）、security-scan（安全扫描）、launch-audit（发布前审计）等，基本覆盖了一个项目的完整开发周期。

#### Agent-Native 开发框架应该如何设计

##### 核心概念：什么是 Agent-Native

Agent-Native 指的是：产品功能与工作流程从一开始就围绕 Agent 的能力来设计，而不是传统软件后来接入 Agent。

类比来看：

- **Cloud-Native**：业务一开始就跑在云上
- **AI-Native**：产品流程从设计之初就依赖 AI
- **Agent-Native**：产品开发、功能执行、工作流推进都依赖 Agent，离开 Agent 就难以正常运转

##### 设计原则：让 Agent 真正能开发

作者认为，一个 Agent-Native 开发框架需要满足几个关键条件：

###### 1. 功能足够完整

框架应内置常见业务能力，例如：

- 登录 / 注册
- 支付
- 存储
- 多语言
- SEO
- 管理后台

这些能力需要覆盖从 MVP 到上线的基础需求。

###### 2. 模块化、低耦合

所有功能都应模块化，可按需启用、可插拔，避免 Agent 在复杂耦合系统中难以理解和修改。

###### 3. 流程文档化

不仅要有代码模块，还要把开发流程清晰描述出来，包括：

- 初始化项目
- 创建新模块
- 设计新页面
- 生成图片
- 部署上线
- 安全扫描
- 发布前审计

这些流程需要沉淀成 Agent 能理解和执行的 **Skills**。

##### ShipAny 的实践：用 Skills 驱动开发

ShipAny 新版本将内置功能和开发流程整理成一系列 Skills，让 Agent 读取后快速理解框架结构，并按标准流程完成开发。

核心 Skills 包括：

- **quick-start**：快速初始化项目，完成 MVP
- **clone-website**：复刻指定网站
- **new-module**：开发新功能模块
- **new-page**：开发新页面
- **deploy-cloudflare**：一键部署到 Cloudflare
- **generate-image**：生成图片
- **sync-upstream**：同步上游更新
- **security-scan**：安全扫描
- **launch-audit**：发布前审计

这些 Skills 基本覆盖了一个产品从开发到上线的完整生命周期。

##### 商业信号：AI 产品开发正在工具化

ShipAny 新版本发布不到 2 天已售出 200 单，且老用户复购比例较高。

作者认为，这说明市场正在认可一种新定位：  
**ShipAny 是 AI 出海产品的“金刚铲”，帮助用户把产品开发交给 Agent，一小时上线 AI 产品。**

##### 一句话总结

Agent-Native 开发框架的关键，不只是接入 Agent，而是把功能模块、开发流程和项目知识全部结构化为 Agent 可理解、可执行的 Skills，让 Agent 成为产品开发的核心执行者。
