## 解读（1）

### 2026-07-02 09:42:06

#### Rainier：机票票价到底怎么来的？

##### 一、深度总结

机票价格不是简单“查一下官网”就能得到，背后有两类核心来源：

###### 1. 标准公开运价：ATPCO 体系

主流机票价格来自 **ATPCO** 发布的运价与规则数据。  
平台需要购买这些数据，并实时解析：

- 票价基础价
- 舱位规则
- 改退签规则
- 税费
- 航线限制
- 销售区域限制
- 日期限制

然后通过计算，生成用户看到的机票价格。

能真正解析全球 ATPCO 数据并稳定报价的公司很少，全球可能不到 10 家。

典型玩家：

- Amadeus
- Sabre
- Travelport
- 携程
- 去哪儿
- 中航信等

其中 **Amadeus API** 是较成熟的商业方案，小规模使用可能免费，商用可谈价，很多平台底层都依赖类似系统。

---

###### 2. 私有运价：航司或 OTA 自己的价格

除了公开运价，还有一类是：

- 航司私有运价
- OTA 私有折扣
- 渠道专属价格
- 包销/协议价

这些价格不一定进入 ATPCO，也不一定能通过 Amadeus 查到。

所以一些平台会用：

- 爬虫
- Meta Search
- 多渠道比价
- OTA 聚合

来获取更低价或特殊价。

这也是为什么不同平台看到的价格可能不同。

---

###### 3. 查票方案取决于数据来源

如果只想覆盖大多数场景，可以基于 Amadeus 这类 API 做一层封装，甚至做成 MCP 工具。

但如果想拿到所有低价、私有价、特殊渠道价，就必须接入更多来源，甚至做爬取和聚合。

---

###### 4. 里程票是另一个复杂系统

Rainier 特别强调：  
**里程票和现金票不是一回事。**

原因是：

- 各航空联盟里程并不完全互通
- 各航司兑换规则不同
- 旺季放票少
- 航司并不总希望用户用里程兑换热门航班
- 航司更愿意用户用里程兑换商品、酒店、低价值权益

所以“接入各大航空公司里程来规划查票”比普通查现金票更难。

---

##### 二、深入浅出解读

可以把机票价格理解成三层：

###### 第一层：官方价

类似超市标价。  
这些价格来自 ATPCO，规则标准化，专业系统可以解析。

###### 第二层：渠道价

类似不同电商平台的优惠价。  
航司可能给某些 OTA 特价，OTA 也可能自己补贴。

所以你在携程、飞猪、去哪儿、航司官网看到的价格可能不一样。

###### 第三层：里程票

类似积分兑换。  
但不是你有积分就一定能换到想要的票。

尤其是热门航线、节假日、商务舱，航司会严格控制放票。

---

##### 三、关键洞察

###### 1. 查票不是“搜索”，而是“计算”

机票价格不是数据库里直接摆着一个固定数字。  
它通常是由运价、规则、库存、税费、舱位共同计算出来的。

---

###### 2. 价格不只取决于票价，还取决于库存

热门回复里提到一个重要点：  
相比 fare，真正核心的是 **availability，即舱位库存**。

也就是说：

> 有这个价格，不代表你能买到。  
> 有这个舱位，才可能成交。

航司还会用收益管理系统，根据：

- 出发日期
- 购票时间
- 航线热度
- 中转组合
- O&D 逻辑
- 历史销售数据

动态控制放哪些舱位、放多少票。

---

###### 3. MCP 可以做，但边界要清楚

做一个“机票查询 MCP”并不难。  
比如基于 Amadeus API 封装：

- 查询航班
- 比价
- 过滤航司
- 过滤时间
- 推荐路线

但要做到：

- 覆盖所有 OTA 私有价
- 精准查询里程票
- 判断真实可兑换性
- 获取实时库存

难度会大很多。

---

##### 四、我的辩证思考

###### 1. 技术上可行，商业上困难

用 API 做查票工具并不难。  
难的是数据授权、实时性、库存准确性和商业合作。

机票行业不是纯技术问题，而是强渠道、强规则、强利益分配的行业。

---

###### 2. “全网最低价”本质上很难保证

因为价格来源太多：

- ATPCO 公共运价
- 航司官网价
- OTA 私有价
- 会员价
- 企业协议价
- 补贴价
- 里程兑换价

所以任何平台说“绝对最低”，都很难严谨成立。

更准确的说法应该是：

> 在我接入的数据源范围内，为你找到较优价格。

---

###### 3. AI 适合做规划，不一定适合做出票

AI/MCP 很适合做：

- 航线组合推荐
- 日期灵活比价
- 多机场方案比较
- 现金票 vs 里程票权衡
- 中转风险提示
- 行李规则总结

但真正出票仍依赖稳定的交易系统、支付系统、航司接口和售后能力。

---

###### 4. 里程票的价值在于策略，不在于接口

里程票查询难点不只是“有没有 API”，而是：

- 哪个联盟更划算
- 哪个航司税费低
- 哪些航线容易放票
- 什么时间查更容易有票
- 是否值得转点
- 是否有隐藏兑换甜点

所以未来 AI 在里程票领域最大的价值，可能不是单纯查票，而是做“兑换策略顾问”。

---

##### 五、一句话总结

机票价格来自公共运价、私有渠道价和库存管理的复杂组合；普通查票可以靠 Amadeus 等 API 实现，但要覆盖私有低价和里程票，需要更深的数据、渠道和策略能力。

## 结构化（1）

### 2026-07-23 10:14:13

#### 文章总结

机票查询与规划的核心，是先弄清票价的数据来源：主流公开运价通常来自 **ATPCO**，航司和 OTA 还拥有各自的私有运价，两者需要不同的询价方式。普通机票查询可以基于 Amadeus 等 API 实现 MCP，但里程票因联盟不互通、航司限制和仓位动态管理，复杂度更高。

##### 1. 机票价格的两类来源

- **ATPCO 公布的主流运价**
  - 通过运价数据与适用规则计算出具体票价。
  - 服务商需要购买 ATPCO 数据，并进行实时解析。
  - 这是目前行业内最主流、最标准化的票价来源。

- **航司或 OTA 的私有运价**
  - 由航空公司或在线旅游平台自行掌握，不一定会进入公开分销体系。
  - 通常可通过爬虫或聚合搜索获取，这类方式被称为 **Meta Search（元搜索）**。
  - 数据来源不同，对应的询价和技术方案也不同。

##### 2. 主流查票方案：Amadeus API

- 普通机票查询可以使用 **Amadeus API**：
  - 小规模调用通常免费；
  - 商业使用价格可协商；
  - 专业度较高，许多平台底层都采用其服务。
- Amadeus 无法覆盖所有 OTA 的私有运价，但作者认为，它足以满足约 **99%** 的常规查票需求。
- 其他较小的服务商包括 **Duffel、Skyscanner**，也可以采用多种数据源混合的方案。

##### 3. 全球票价解析市场门槛较高

- 全球范围内，能直接解析 ATPCO 数据并生成票价的服务商，作者估计 **不超过 10 家**。
- 中国市场中的主要参与者包括：
  - **携程**
  - **去哪儿**
  - **中航信**（作者认为只能算“半个”，并对其技术来源作出负面评价，但未提供具体证据）
- 因此，若只是构建一个机票查询 MCP，较容易的路径是：**基于 Amadeus API 再封装一层接口**。

##### 4. 里程票是另一套更复杂的问题

- 各航空联盟及航司之间的里程通常**不能完全互通**，难以用统一接口直接查询和规划。
- 航司也未必希望用户兑换里程票，尤其是在旺季：
  - 更倾向于把座位卖给现金购票旅客；
  - 相比兑换机票，航司可能更欢迎用户用里程兑换商品。
- 因此，“接入各大航司里程并自动规划查票”的 MCP，比普通现金票查询更难实现。

##### 5. 补充观点：真正难点还包括可用仓位

相关从业者补充指出：

- 即使接入 Amadeus，也不一定能获得航司或渠道的私有运价。
- 相比票面价格（Fare），更关键的是**仓位可用性（Availability）**。
- 现代航司系统普遍加入：
  - 收益管理（Revenue Management）；
  - O&D，即始发地—目的地控制逻辑。
- 这些机制会动态调整不同航线、行程组合和渠道可售的座位，因此外部系统很难持续获得准确的仓位信息。
