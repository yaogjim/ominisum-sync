#### 文章主旨

这篇文章总结了作者在使用 Claude Code 半年多后，最希望早点知道的 10 个实用技巧。核心目的只有一个：**减少操作负担，提升人机协作效率，让你更专注在编程和写作本身。**

##### 一、先从 “启动方式” 优化使用习惯

###### 1. 最基础的启动方式：直接命令行启动
- 最简单的方式就是在终端输入`claude`。
- 对不喜欢命令行的人，也可以通过`Claude Desktop`使用可视化界面。
- 作者认为：
  - 普通用户更适合可视化界面；
  - 程序员通常更偏好命令行方式，因为更快、更灵活。

###### 2. 利用历史会话启动，减少重复解释上下文
作者提到，重启 Claude Code 后，很多人会这样做：
```bash
claude
/resume
```

但更高效的方式是直接用官方参数：

```bash
claude -c              # 直接启动最近会话
claude -n "page"       # 给会话命名
claude -r "page"       # 启动指定会话
claude "你好"          # 启动时直接带提示词
```

- 作者高频使用的是`claude -c`。
- 这个命令的价值在于：**省去重复恢复上下文的步骤**，尤其适合频繁中断、重开的场景。

###### 3. 使用`-p`进行自动化、无界面调用
```bash
claude -p "分析 input.cvs..." --output-format json
```

- `-p`可以让 Claude Code 以**无 UI、自动化**方式运行。
- 特别适合：
  - 自动化任务；
  - 需要结构化输出（如 JSON）的流程；
  - 调用本地订阅 Token 的场景。
- 作者还提到，一些工具（如 Obsidian + Claude Code 方案）就是基于这种方式封装出来的。

##### 二、运行过程中，3 个小技巧最实用

###### 1. 不要用`Ctrl+C`乱中断，用`Esc`更安全
- 很多新手会用`Ctrl+C`结束任务，但这往往会**直接退出 Claude**。
- 更合理的做法：
  - 按一次`Esc`：立刻打断当前任务；
  - 按两次`Esc`：调出检查点列表，可回退到之前状态。
- 这个技巧的意义是：**避免 Claude 把代码改乱后无法快速撤回**。

###### 2. 在 Claude 内直接执行命令，不用切换终端
可以直接在 Claude 中输入：
```bash
!npm run lint
```

- 这样就能在当前会话里执行命令，不需要再开一个终端窗口。
- 作者还提到可通过快捷键将命令 “后置”。
- 这个小技巧的价值是：**减少上下文切换**，哪怕每次只省 30 秒，长期也很可观。

###### 3. 管理上下文，避免对话越聊越慢
随着聊天记录变长，会出现两个问题：
- token 消耗变多；
- Claude 运行速度变慢。

解决方法有两个：

```bash
/clear
/compact
```

- `/clear`：清空无用上下文，适合重新开始。
- `/compact`：压缩上下文，适合不想完全丢掉历史内容时使用。
- 作者用很形象的比喻：
  - `/clear`像一下子关掉 20 个 Chrome 标签页；
  - `/compact`像让 Claude “喝杯红牛”，让它更清醒。

作者认为，单靠记命令还不够，因为 Claude Code 本质仍是命令行工具，学习成本和心智负担都存在。社区里出现的一些配套工具，主要在解决 3 个痛点：
