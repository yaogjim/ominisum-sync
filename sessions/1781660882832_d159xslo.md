### Hermes 分析师 10 倍更好

Hermes Analyst 刚刚变得 10 倍更好 — UI/UX 大幅改进 + 配置代理从未如此简单 + 由于嵌套编排器功能，研究能力得到了提升

在过去两周中，

[@NousResearch](https://x.com/@NousResearch) 团队发布了很多很棒的东西

- 赫尔墨斯 Windows
- Hermes 桌面
- 代理资料
- 异步子代理
- 嵌套编排器
- 原生代理型商业集成与
  [@stripe](https://x.com/@stripe)
- Telegram 上的富文本/输出

还有可能有很多我漏掉的。

在本文中，我将快速介绍我最感兴趣的变化以及我在最近一轮补丁更新后使用 Hermes 的体验

> tl;dr -&gt; 10 倍更流畅，感谢 Nous 团队

我一直在 Windows 的 WSL2 上使用 Hermes，这并不理想——在 Linux 上访问文件很复杂，有时代理会把文件放在难以访问的位置，有时它会在 Linux 上执行一些在 Windows 上不会出现的操作。

于是 Hermes Windows + Hermes 桌面来得正是时候，而且迁移过程很简单

- Ubuntu 上的 Hermes 备份
- 通过在 Nous 网站下载.exe 客户端来安装 Hermes Desktop
- 然后 “hermes import”

所有内容都已迁移过来（agentcash x402 钱包和 Hindsight 数据除外，这两项我必须手动迁移），但总体来说迁移过程非常无缝顺畅。

---

#### Hermes 桌面 - 为所有人设计

Hermes Desktop 是一个桌面用户界面，旨在作为使用 Hermes 的中枢。它提供类似 ChatGPT/Claude 的界面，具备丰富的视觉效果、思维链、表格，并且现在所有输出都以分页方式显示（与仅显示简单文本相比）。

这使得查看输出结果比以前容易得多。

通过 Hermes Desktop 检查和配置技能、消息应用、定时任务、模型以及不同的代理配置文件也更简单，而不必手动前往.env 或 config.yaml 文件进行调整。

考虑到最近对 Fable 5 的禁令 + OpenRouter Fusion（一种通过结合开源模型可实现 Fable 5 级智能的技术），现在调整 Hermes 时的 R/R 有了很大改善。

更多更高质量的工作流程，这些工作流程能够借助更好的工具/工具包及模型驱动，从而分担你的任务。

---

#### Hermes 研究能力刚刚提升了 10 倍

如果你一直关注我的 Hermes Analyst 系列，你可能还记得深度研究流程（Deep Research Pipeline），这是我为 Hermes 创建的一项技能，以便更好地进行结构化的深度研究。

当时的挑战是，代理会逐步完成整个研究过程，等待一件事完成后再开始另一件。这本身没问题，但当流程扩展且集成了许多工具后，代理很难坚持使用所有工具。结果呢？Hermes 跳过了一些工具，导致输出质量下降。

“ 技能捆绑 ” (即让子代理批量处理技能并并行执行它们) 确实有助于确保代理不会跳过工具。但是……有一种方法可以做得更好，并且能产生更好的研究成果。

Nous Research 刚刚发布了一个名为“Nested Orchestrator”“

这是一个 Hermes 生成的功能

- 1 编排器子代理（或更多）
- 编排器随后生成3个工作节点（叶代理）来执行复杂任务

根据任务的复杂程度，更多的编排器可以并发运行，管理更多的叶代理。

结果 = orchestrator 交叉整合来自叶代理的源数据，综合洞察和 delta，从而产生更优的输出。

## 解读（1）

### 2026-06-17 02:12:11

#### Hermes Analyst「10 倍更好」：深度总结与解读

##### 一、深度总结

这篇文章核心讲的是：**Hermes 从“能用的 AI Agent”升级成了“更易用、更可控、更适合复杂研究的 Agent 工作台”。**

主要变化有三类：

###### 1. 使用门槛大幅降低

过去作者在 Windows 上通过 WSL2 使用 Hermes，存在文件路径混乱、环境割裂、操作不顺等问题。

现在：

- 有了 **Hermes Windows**
- 有了 **Hermes Desktop**
- 可通过 `hermes import` 迁移旧数据
- 配置不再主要依赖 `.env`、`config.yaml`

结果是：  
**Hermes 从偏工程师工具，开始变成普通用户也能顺畅使用的桌面应用。**

---

###### 2. UI/UX 明显增强

Hermes Desktop 提供了类似 ChatGPT / Claude 的交互界面，支持：

- 富文本输出
- 表格展示
- 分页查看
- 可视化配置技能、模型、任务、消息应用、代理配置文件

这意味着用户不再只是“调用一个命令行代理”，而是在使用一个完整的 **AI Agent 控制台**。

---

###### 3. 研究能力通过“嵌套编排器”增强

文章最重要的升级是：**Nested Orchestrators，嵌套编排器。**

过去 Hermes 做深度研究时，流程是线性的：

> 一个任务做完，再做下一个。

问题是：

- 流程一复杂，Agent 容易漏用工具
- 工具越多，稳定性越差
- 输出质量不稳定

后来通过“技能捆绑”改善，让子代理并行处理部分任务。

现在进一步升级为：

> 编排器 Agent 负责拆解任务，多个叶子 Agent 并行执行，最后由编排器交叉整合结果。

也就是：

```text
用户任务
  ↓
编排器 Agent
  ↓
多个子 Agent 并行研究
  ↓
编排器汇总、对比、提炼
  ↓
更高质量输出
```

作者认为，这让 Hermes 的研究能力提升了一个量级。

---

##### 二、深入浅出解读

可以把 Hermes 想象成一个“研究团队”。

###### 过去的 Hermes

像一个很聪明的实习生。

你给它一个复杂任务，比如：

> 帮我分析宏观经济、地缘政治、美股和加密市场之间的关系。

它会自己一步步做，但问题是：

- 容易忘步骤
- 忙不过来
- 有些资料没查
- 有些工具没用
- 最后报告可能不够完整

---

###### 现在的 Hermes

更像一个小型咨询团队。

它内部有分工：

- 一个“项目经理”负责拆任务
- 几个“研究员”分别查资料
- 有人看宏观
- 有人看股票
- 有人看加密
- 有人看地缘政治
- 最后项目经理统一整合

所以它不是单个 Agent 在硬扛，而是多个 Agent 协作。

这就是所谓的 **嵌套编排器**。

本质上，它解决的是 AI Agent 的一个关键问题：

> 单个智能体容易在长流程中失控，多智能体分工可以提升复杂任务完成度。

---

##### 三、这篇文章真正重要的地方

表面上看，文章是在介绍 Hermes 新功能。

但深层看，它反映了 AI Agent 发展的三个趋势：

###### 1. Agent 正在从“聊天机器人”走向“工作系统”

ChatGPT 更像一个对话入口。  
Hermes 这类工具更像一个可配置、可执行、可协作的工作系统。

未来用户可能不是问一句话，而是配置一套流程，让 AI 持续完成任务。

---

###### 2. AI 的关键不只是模型，而是编排

文章提到 OpenRouter Fusion、开源模型组合等，说明模型能力很重要。

但真正让 Hermes 变强的，不只是“换了更聪明的大脑”，而是：

- 如何拆任务
- 如何调用工具
- 如何并行执行
- 如何整合结果
- 如何避免漏步骤

也就是说：

> 未来 AI 应用的竞争，不只是模型竞争，更是工作流和编排能力的竞争。

---

###### 3. 多 Agent 协作是复杂任务的重要方向

复杂研究任务很难靠单个 Agent 完成。

因为单个 Agent 容易：

- 注意力漂移
- 工具调用不完整
- 执行链过长
- 上下文变乱
- 结果缺少交叉验证

多 Agent 协作则可以通过分工降低复杂度。

这类似人类组织：

> 复杂问题不是靠一个天才解决，而是靠一个结构化团队解决。

---

##### 四、辩证思考

###### 积极面

Hermes 的升级很有价值。

它把 AI Agent 从“玩具感”推向“生产力工具”：

- 桌面端降低门槛
- UI 改善提升可用性
- 配置可视化减少工程负担
- 嵌套编排增强复杂任务能力
- 多 Agent 让研究更全面、更稳定

尤其对投资研究、行业分析、技术调研、市场追踪这类任务，很有潜力。

---

###### 但也不能过度乐观

“10 倍更好”更多是体验和工作流层面的提升，不代表结果一定 10 倍准确。

多 Agent 系统也有新问题：

1. **更多 Agent 不等于更正确**  
   如果底层信息源有误，多个 Agent 可能只是更快地产生错误结论。

2. **并行研究可能带来噪音**  
   子代理越多，信息越杂，整合质量反而更依赖编排器能力。

3. **复杂系统更难调试**  
   单个 Agent 出错还容易定位，多 Agent 出错可能很难知道是哪一层出了问题。

4. **输出更丰富，不等于洞察更深**  
   内容变长、结构更完整，并不必然代表判断更准确。

5. **自动化研究仍需要人类把关**  
   尤其在金融、宏观、地缘政治等高风险领域，AI 可以辅助，但不能替代最终判断。

---

##### 五、我的结论

Hermes 这次升级的意义，不只是“功能变多”，而是它更接近一个真正的 **AI 研究操作系统**。

最关键的进步是：

> 从单 Agent 执行，走向多 Agent 编排；  
> 从命令行工具，走向普通用户可用的桌面工作台；  
> 从简单问答，走向复杂研究流程自动化。

但它的价值不在于完全替代分析师，而在于放大分析师能力。

更准确地说：

> Hermes 不一定让普通人立刻变成顶级分析师，  
> 但它可能让会提问、会设计流程、会判断结果的人，效率大幅提升。
