#### json-render

**The Generative UI framework.**

从提示生成动态、个性化的用户界面，同时不牺牲可靠性。预定义的组件和操作确保安全、可预测的输出。

```
# for React
npm install @json-render/core @json-render/react
# for React with pre-built shadcn/ui components
npm install @json-render/shadcn
# or for React Native
npm install @json-render/core @json-render/react-native
# or for video
npm install @json-render/core @json-render/remotion
# or for PDF documents
npm install @json-render/core @json-render/react-pdf
# or for HTML email
npm install @json-render/core @json-render/react-email @react-email/components @react-email/render
# or for Vue
npm install @json-render/core @json-render/vue
# or for Svelte
npm install @json-render/core @json-render/svelte
# or for SolidJS
npm install @json-render/core @json-render/solid
# or for terminal UIs
npm install @json-render/core @json-render/ink ink react
# or for 3D scenes
npm install @json-render/core @json-render/react-three-fiber @react-three/fiber @react-three/drei three
```

#### Why json-render?

json-render 是一个 **生成式 UI** 框架：AI 从自然语言提示生成界面，受限于你定义的组件。你设置护栏，AI 在其中生成：

- **Guardrailed** - AI can only use components in your catalog  
  **受护栏约束的** - AI 只能使用您目录中的组件
- **可预测的** - JSON 输出每次都与你的 JSON 模式匹配
- **快速** - 流式传输并随着模型响应逐步渲染
- **跨平台** - React、Vue、Svelte、Solid（web）、React Native（mobile）来自同一个目录
- **一应俱全** - 36 个预构建的 shadcn/ui 组件，即开即用

#### Quick Start

```
import { defineCatalog } from "@json-render/core";
import { schema } from "@json-render/react/schema";
import { z } from "zod";

const catalog = defineCatalog(schema, {
  components: {
    Card: {
      props: z.object({ title: z.string() }),
      description: "A card container",
    },
    Metric: {
      props: z.object({
        label: z.string(),
        value: z.string(),
        format: z.enum(["currency", "percent", "number"]).nullable(),
      }),
      description: "Display a metric value",
    },
    Button: {
      props: z.object({
        label: z.string(),
        action: z.string(),
      }),
      description: "Clickable button",
    },
  },
  actions: {
    export_report: { description: "Export dashboard to PDF" },
    refresh_data: { description: "Refresh all metrics" },
  },
});
```

```
import { defineRegistry, Renderer } from "@json-render/react";

const { registry } = defineRegistry(catalog, {
  components: {
    Card: ({ props, children }) => (
      <div className="card">
        <h3>{props.title}</h3>
        {children}
      </div>
    ),
    Metric: ({ props }) => (
      <div className="metric">
        <span>{props.label}</span>
        <span>{format(props.value, props.format)}</span>
      </div>
    ),
    Button: ({ props, emit }) => (
      <button onClick={() => emit("press")}>{props.label}</button>
    ),
  },
});
```

```
function Dashboard({ spec }) {
  return <Renderer spec={spec} registry={registry} />;
}
```

**就是这样。** AI 生成 JSON，你安全地渲染它。

##### Dynamic Props

任何属性值都可以通过表达式实现数据驱动：

```
{
  "type": "Icon",
  "props": {
    "name": {
      "$cond": { "$state": "/activeTab", "eq": "home" },
      "$then": "home",
      "$else": "home-outline"
    },
    "color": {
      "$cond": { "$state": "/activeTab", "eq": "home" },
      "$then": "#007AFF",
      "$else": "#8E8E93"
    }
  }
}
```

Expression forms:

- **`{ "$state": "/state/key" }`** - reads a value from the state model  
  **`{ "$state": "/state/key" }`** - 从状态模型中读取一个值
- **`{ "$cond": <condition>, "$then": <value>, "$else": <value> }`** - 评估一个条件并选择一个分支
- **`{ "$template": "Hello, ${/user/name}!" }`** - interpolates state values into strings  
  **`{ "$template": "Hello, ${/user/name}!" }`** - 将状态值插值到字符串中
- **`{ "$computed": "fn", "args": { ... } }`** - calls a registered function with resolved args  
  **`{ "$computed": "fn", "args": { ... } }`** - 调用已注册的函数并使用已解析的参数

##### Actions

组件可以触发操作，包括内置的 `setState` 操作：

```
{
  "type": "Pressable",
  "props": {
    "action": "setState",
    "actionParams": { "statePath": "/activeTab", "value": "home" }
  },
  "children": ["home-icon"]
}
```

The `setState` action updates the state model directly, which re-evaluates visibility conditions and dynamic prop expressions.

##### State Watchers

响应状态变化通过触发操作：

```
{
  "type": "Select",
  "props": {
    "value": { "$bindState": "/form/country" },
    "options": ["US", "Canada", "UK"]
  },
  "watch": {
    "/form/country": {
      "action": "loadCities",
      "params": { "country": { "$state": "/form/country" } }
    }
  }
}
```

`watch` is a top-level field on elements (sibling of `type` / `props` / `children`). Watchers fire when the watched value changes, not on initial render.  
`watch` 是元素上的顶级字段（与 `type` / `props` / `children` 同级）。监听器在被监听的值发生变化时触发，而非在初始渲染时。

```
flowchart LR
    A[User Prompt] --> B[AI + Catalog]
    B --> C[JSON Spec]
    C --> D[Renderer]

    B -.- E([guardrailed])
    C -.- F([predictable])
    D -.- G([streamed])
```

1. **Define the guardrails** - what components, actions, and data bindings AI can use  
   **定义护栏** - AI 可以使用的组件、操作和数据绑定
2. **Prompt** - describe what you want in natural language  
   **提示词** - 用自然语言描述你想要的内容
3. **AI generates JSON** - output is always predictable, constrained to your catalog  
   **AI 生成 JSON** - 输出始终可预测，受限于你的目录
4. **Render fast** - stream and render progressively as the model responds  
   **快速渲染** - 流式传输并在模型响应时逐步渲染

> 不让 AI 随便写前端代码，而是让 AI 在你规定好的组件清单里输出 JSON。

大致流程是：

1. 你先定义组件和动作  
   比如 `Card`、`Button`、`Metric`，以及 `refresh_data`、`export_report`。

2. 框架自动生成一份“系统提示词”  
   告诉 AI：你能用哪些组件、每个组件有哪些参数、能触发哪些动作。

3. AI 根据用户需求输出 JSON Spec  
   例如生成一个仪表盘、表单、卡片页面。

4. 渲染器把 JSON Spec 变成真实 UI  
   在 React / Vue / React Native / PDF 等环境中展示。

所以它不是“AI 直接写页面”，而是：

**自然语言 -> JSON 规范 -> 渲染器 -> 页面**

- 你想要 AI 的创造力
- 但你又需要工程上的稳定性

`json-render` 相当于在两者之间找平衡：

- 给 AI 发挥空间
- 但不给 AI 失控空间

这比“让大模型直接吐 React 代码”更适合正式应用。

这对聊天式 UI、AI Agent 操作界面很有价值，用户体验会更自然。

比较适合：
