## 正文

**Geek Lite**

提供一个多 Agent 编排的看板与开发环境，让人类在审查变更的同时并行调度多个 AI Agent 执行任务。

[https://github.com/kdlbs/kandev](https://github.com/kdlbs/kandev)

Kandev 是一个跑在服务器上的 AI Agent 编排工具，Claude Code、Codex、Copilot、Gemini 等 7 个 Agent 通过 ACP 协议接入，流水线里每一步可以指定不同 Agent。任务在看板和流水线里管理，可以并行跑，子任务从父任务派生。工作区内置终端、编辑器、git 面板和浏览器预览，用 git worktree 隔离各 Agent 的代码。执行方式支持本地进程、Docker 和远程 sprites .dev。

## 通俗精炼（1）

### 2026-05-03 01:51:06

#### Geek Lite：多 Agent 编排看板与开发环境

##### 一句话总结

**Kandev 是一个运行在服务器上的 AI Agent 编排开发工具**，可以让人类在审查代码变更的同时，并行调度多个 AI Agent 执行不同任务，提升 AI 辅助开发的效率与可控性。

##### 核心功能

###### 1. 多 Agent 接入与编排

Kandev 支持通过 **ACP 协议**接入多个 AI Agent，包括：

- Claude Code
- Codex
- Copilot
- Gemini
- 以及其他共 7 类 Agent

在开发流水线中，每一步都可以指定不同的 Agent 执行，实现类似“AI 团队分工协作”的效果。

###### 2. 看板与流水线管理任务

任务可以通过：

- 看板管理
- 流水线编排
- 并行执行
- 父子任务拆分

这意味着复杂需求可以被拆成多个子任务，由不同 Agent 同时处理。

###### 3. 内置完整开发工作区

Kandev 提供一套集成式开发环境，包括：

- 终端
- 编辑器
- Git 面板
- 浏览器预览

人类可以直接在同一个工作区内查看、审查、修改和合并 Agent 的产出。

###### 4. 代码隔离与执行环境

为了避免多个 Agent 互相干扰，Kandev 使用 **git worktree** 隔离不同 Agent 的代码变更。

执行方式支持：

- 本地进程
- Docker
- 远程 sprites.dev 环境

##### 产品价值

###### 对开发团队

Kandev 更像是一个“AI 开发团队调度平台”，而不是单一 AI 编程助手。它适合处理多任务、多分支、多 Agent 协作的开发场景。

###### 对产品和工程管理者

它的价值在于把 AI 编程从“单点对话”升级为“流程化协作”：

- 人负责审查和决策
- Agent 负责并行执行
- 看板负责组织任务
- Git 负责隔离与追踪变更

##### 总结判断

Kandev 代表了一类新的 AI 开发工具方向：**从单 Agent 辅助编程，走向多 Agent 协作式软件生产**。

它的关键不只是让 AI 写代码，而是提供了任务编排、环境隔离、代码审查和流程管理能力，让 AI 更接近一个可调度、可管理的工程团队。

##### 主旨概括

Geek Lite 介绍了一个名为 **Kandev** 的开源工具：它是运行在服务器上的 **多 AI Agent 编排看板与开发环境**，可以让人类一边审查代码变更，一边并行调度多个 AI Agent 执行开发任务。

---

##### 1. Kandev 的核心定位

- **Kandev** 是一个面向开发场景的 AI Agent 编排工具。
- 它支持把多个 AI 编程助手接入同一个工作流中，统一管理任务、流水线和代码变更。
- 适合需要同时运行多个 AI Agent、并行处理开发任务的团队或个人。

项目地址：  
[https://github.com/kdlbs/kandev](https://github.com/kdlbs/kandev)

---

##### 2. 支持多个主流 AI Agent

Kandev 通过 **ACP 协议**接入多个 AI Agent，目前支持包括：

- Claude Code
- Codex
- Copilot
- Gemini
- 以及其他共 **7 个 Agent**

关键点是：  
- 不同任务步骤可以指定不同 Agent 执行。
- 例如：一个 Agent 负责写代码，另一个 Agent 负责测试或审查。

---

##### 3. 任务管理方式：看板 + 流水线

Kandev 提供类似项目管理工具的任务组织方式：

- 任务可以放在 **看板** 中管理。
- 也可以通过 **流水线** 分步骤执行。
- 任务支持 **并行运行**。
- 子任务可以从父任务中派生出来。

通俗理解：  
> 一个大需求可以拆成多个子任务，同时交给不同 AI Agent 处理，提高开发效率。

---

##### 4. 内置开发工作区

Kandev 不只是任务调度工具，还内置了一套开发环境，包括：

- 终端
- 编辑器
- Git 面板
- 浏览器预览

这意味着用户可以在一个界面里完成：

- 分配任务
- 查看 AI 修改的代码
- 运行命令
- 预览效果
- 审查 Git 变更

---

##### 5. 使用 Git Worktree 隔离代码

为了避免多个 Agent 同时改代码导致冲突，Kandev 使用 **git worktree** 隔离不同 Agent 的工作区。

简单来说：

- 每个 Agent 可以在独立代码副本中工作。
- 人类开发者可以分别审查它们的修改。
- 避免多个 AI 同时修改同一份代码造成混乱。

---

##### 6. 支持多种执行方式

Kandev 的任务执行方式比较灵活，支持：

- 本地进程
- Docker
- 远程 sprites.dev

这让它既可以在本地开发环境中使用，也可以部署到更隔离或远程的运行环境中。
