### 我用 2 刀复现了Karpathy 的 autoresearch

Andrej Karpathy 最近开源了一个叫 autoresearch 的项目：

给 AI agent 一个真实的 LLM 训练环境，让它自己改代码 → 训练 5 分钟 → 看结果有没有变好 → 保留或丢弃 → 无限循环。

[https://github.com/karpathy/autoresearch](https://github.com/karpathy/autoresearch)

整个 repo 只有三个核心文件：

- train.py：完整的 GPT 模型 + 训练循环，agent 改这个文件
- prepare.py：数据准备脚本（别动）
- program.md：给 agent 的研究指令，你来改这个文件

每轮训练固定 5 分钟（wall clock），用 val\_bpb（验证集 bits per byte，越低越好）作为指标

agent 可以自由修改模型架构、超参数、optimizer、batch size——几乎所有东西都能动

![Image](https://pbs.twimg.com/media/HEoWU8IbAAA2BpG?format=jpg&name=large)

核心是 1. GPU 机器 + 2. 聪明的 Agent + 3. 好用的 harness

##### autoresearch 是什么

`autoresearch` 的核心思路是：

- 人先定义研究目标和边界
- AI agent 自己改代码、做实验、看指标
- 不断循环，持续尝试优化模型

它的本质不是“自动写代码”，而是让 AI 在一个真实训练环境里，执行完整的“小型科研流程”。

##### 项目怎么运作

整个项目只有 3 个关键文件：

- `train.py`：模型和训练逻辑，agent 主要修改这里
- `prepare.py`：数据准备脚本，一般不动
- `program.md`：给 agent 的研究指令，定义方向和规则

每一轮固定训练 **5 分钟**，用 `val_bpb` 作为指标，数值越低越好。  
agent 可以调整模型结构、学习率、优化器、batch size 等几乎所有训练相关参数。

##### 为什么说复现成本很低

作者这次复现的成本大致是：

- GPU 实例：约 **1.6 美元**

- 总成本：**不到 2 美元**

大概可以跑 **20～25 轮实验**。  
也就是说，普通开发者和 AI 爱好者也能低门槛体验一套接近前沿研究的自动化流程。

要跑起来，核心需要 3 样东西：

- 一台 GPU 机器

作者使用的是：

##### 这件事真正重要的地方

这不只是一个 demo，更像是一种新的科研工作方式：

##### 核心结论

`autoresearch` 展示的不是单次模型优化，而是 **AI 自动做实验** 的雏形。  
它最有价值的地方在于：把过去昂贵、复杂、需要大量人工介入的研究流程，压缩成了一套普通人也能低成本体验的自动化 pipeline。
