## 正文

**宝玉**

Claude Code 新增 Routines 功能，把 AI 编程助手从“你问它答”升级成了“自动干活”。

简单说，Routines 就是一个预设好的 Claude Code 任务模板，你告诉它干什么、给它接上代码仓库和外部工具，然后设定触发条件，它就能在 Anthropic 的云端自己跑起来，不需要你盯着电脑。

触发方式有三种。第一种是定时任务，比如每天早上九点自动整理 Issue 列表。第二种是 GitHub 事件触发，比如有人提了 PR 就自动跑一遍代码审查。第三种是 API 调用，你的监控系统报警了，直接把报警内容甩给它，它自己去查日志、定位问题、开修复 PR。

Anthropic 内部已经在用了。Claude Code 产品经理 Noah Zweben 说，他们团队用 GitHub 事件触发来做文档同步，每次代码合并到发布分支，Routines 自动生成对应的文档更新。

对开发者来说，这个功能的价值在于把那些重复性的工程杂活自动化了。以前你可能需要写 CI 脚本、配 GitHub Actions、再接个 Slack Bot，现在一个 Routine 就能串起来，而且它能调用你在 Claude 上连接的所有 MCP 服务，Slack、Linear、Google Drive 都行。

使用门槛不高，Pro、Max、Team、Enterprise 用户都能用。Routines 数量不限，但每天的运行次数有上限，超出后需要开启额外用量计费。

一个值得关注的细节：Routines 目前还在研究预览阶段（Research Preview），API 接口格式和限制随时可能调整。另外，Routine 执行的所有操作都以你的身份进行，提交代码用的是你的 GitHub 账号，发 Slack 消息用的也是你的账号，所以权限配置需要上点心。

对于已经在用 Claude Code 做日常开发的人，Routines 可能是目前最接近给自己配一个 AI 初级工程师的体验。你在写代码、开会、睡觉的时候，它在帮你做 Code Review、整理 Backlog、同步文档。

## 通俗精炼（1）

### 2026-04-20 00:36:46

#### Claude Code Routines：让 AI 从“回答问题”变成“自动干活”

##### 核心结论
Claude Code 新增的 `Routines`，本质上是一个可预设、可触发、可自动执行的 AI 任务模板。它不再只是等你下指令，而是能在云端按规则自己运行，替你处理重复性的开发事务。

##### 它能做什么
Routines 适合把一类固定流程交给 AI 持续执行，比如：
- 定时整理 Issue、Backlog
- 有人提交 PR 时自动做代码审查
- 监控系统报警后，自动查日志、定位问题并发起修复 PR
- 代码合并后，自动同步更新文档

一句话：它更像“AI 初级工程师”或“自动化代理”，而不只是聊天式助手。

##### 触发方式
Routines 目前支持 3 种触发方式：
- **定时触发**：按固定时间自动执行
- **GitHub 事件触发**：如 PR、代码合并等事件触发
- **API 触发**：外部系统可直接调用，让 AI 接手处理任务

这意味着，它可以真正接入企业现有的研发和监控流程。

##### 对开发者的价值
它的最大价值，是把过去需要自己搭建的自动化流程大幅简化。  
以前可能要写 CI 脚本、配 GitHub Actions、再连 Slack Bot；现在一个 Routine 就能串起来，而且还能调用 Claude 已连接的 MCP 服务，如 Slack、Linear、Google Drive 等。

本质上，它降低了自动化门槛，也拓展了 AI 在工程流程中的实际可用性。

##### 使用门槛与限制
目前 `Pro`、`Max`、`Team`、`Enterprise` 用户都可使用。  
Routines 数量不限，但**每日运行次数有限制**，超出后需要额外付费。

另外，它还处于 **Research Preview（研究预览）** 阶段，接口格式和能力边界未来都可能调整。

##### 需要特别注意的风险
一个关键点是：Routine 执行操作时，**默认使用的是你的身份和权限**。  
比如：
- 提交代码，用的是你的 GitHub 账号
- 发送消息，用的是你的 Slack 账号

所以，权限配置和操作边界必须谨慎，否则自动化效率提升的同时，也可能放大误操作风险。

##### 总结
`Routines` 的意义，不只是新增了一个功能，而是把 AI 编程助手从“被动响应”推进到“主动执行”。  
对于已经在用 Claude Code 的开发者来说，它可能是目前最接近“给自己配一个 AI 助理工程师”的产品形态。

#### 主旨概括

Claude Code 新增的 `Routines`，本质上是把 AI 编程助手从“被动回答问题”升级成“按规则自动执行任务”的工具。  
它的核心价值是：把开发中重复、琐碎、可流程化的工作交给 AI 在云端持续完成，减少人工盯守。

##### 1. Routines 是什么

- `Routines` 可以理解为一个预设好的 Claude Code 任务模板。
- 用户只需要告诉它要做什么、连接代码仓库和外部工具，再设置触发条件，它就能自动在 Anthropic 云端运行。
- 这意味着不再需要开发者一直守在电脑前，AI 可以自己完成一整套流程化任务。

**通俗理解：**  
以前像是“你发一句，它做一步”；现在更像是“你提前把工作流程交代好，它自己按条件开工”。

##### 2. 三种触发方式

原文提到，`Routines` 目前有 3 种主要触发方式：

- **定时触发**：按固定时间执行任务。  
  - 例子：**每天早上 9 点自动整理 Issue 列表**。
- **GitHub 事件触发**：当代码仓库里发生特定事件时自动执行。  
  - 例子：**有人提交 PR 后，自动进行一轮代码审查**。
- **API 调用触发**：由外部系统主动把信息推给它。  
  - 例子：**监控系统报警后，把报警内容发给 Routine，它会自己查日志、定位问题，甚至直接开修复 PR**。

这说明它不只是“定时器”，而是可以接入开发流程和运维流程的自动化入口。

##### 3. Anthropic 内部已经在使用

- Anthropic 内部已经开始使用这个功能。
- Claude Code 产品经理 **Noah Zweben** 提到，他们团队用 **GitHub 事件触发** 来做文档同步。
- 具体做法是：**每次代码合并到发布分支，Routines 就自动生成相应的文档更新**。

这个案例说明，Routines 并不只是概念展示，而是已经应用在真实团队协作中，尤其适合文档同步、待办维护这类规则明确的工作。

- 最大价值是**自动化重复性工程杂活**。

  - 写 `CI` 脚本
  - 配 `GitHub Actions`
  - 再接一个 `Slack Bot`

- 它还可以调用你在 Claude 上连接的所有 `MCP` 服务，包括：
  - `Slack`
  - `Linear`
  - `Google Drive`

也就是说，它不只是“会写代码”，而是能把代码仓库、协作工具、通知工具连成一个自动工作链条。

##### 5. 使用门槛和限制

- 可用用户范围包括：
  - `Pro`
  - `Max`
  - `Team`
  - `Enterprise`
- **Routines 数量不限**。
- 但**每天运行次数有限制**。
- 如果超出限制，需要开启**额外用量计费**。

这意味着它的试用门槛不算高，但如果高频使用，成本需要提前评估。

##### 6. 当前阶段与风险点

原文特别提醒了两个重要注意事项：

所以，虽然自动化能力很强，但**权限配置必须谨慎**。  
否则它“帮你干活”的同时，也是在用你的身份做事，带来一定安全和误操作风险。

这些讨论说明：虽然 `Routines` 很有潜力，但在“大任务长时间连续执行”这件事上，行业体验可能还没有完全成熟。
