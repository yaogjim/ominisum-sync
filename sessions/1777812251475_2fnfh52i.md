## 通俗精炼（1）

### 2026-05-03 12:43:34

#### Tweetskill：把你的推特人格“蒸馏”成 AI 写作风格

##### 核心问题

作者认为，AI 帮人写推文时，经常会出现两个问题：

- 语气不像本人
- 内容有明显“AI 味”

即使内容正确，也很容易让人一眼看出不是自己写的。

##### 解决思路

作者开源了一个工具 **tweetskill**，目标是把一个人的历史推文进行分析，并“蒸馏”成 AI Agent 可读取的 **skill 文件**。

这个 skill 文件会总结用户的写作习惯，例如：

- 常用表达方式
- 哪类推文更容易获得传播
- 常用/不用的格式
- 个人语言风格和内容偏好

之后 AI 再写推文时，就可以参考这个文件，更接近原本账号的人格和语气。

##### 使用方式

安装命令：

```bash
npx skills add DbgKinggg/tweetskill
```

安装时可选择对应的 AI Agent，例如：

- Hermes
- OpenClaw
- Claude Code

之后在 AI Agent 中输入类似命令：

```text
analyze @elonmusk
```

工具默认使用 X 官方 API 获取推文，并需要用户提供 X Bearer Token。

##### 输出结果

分析完成后，会生成类似：

```text
elonmusk-skill.md
```

这个文件就是账号风格的“人格说明书”。

之后可以让 AI 读取该文件，例如：

```text
读 elonmusk-skill.md，帮我写一条关于 grok 新版本的推文
```

也可以把 skill 文件直接放进 AI Agent 的配置里长期使用。

##### 产品价值

tweetskill 本质上是在解决 **AI 个性化表达** 的问题。

它不是简单让 AI 写内容，而是先理解一个人的历史表达，再生成更贴近本人风格的内容。配合其他 skill，例如去 AI 味、调研增强、交易/信息分析等能力，作者称之为一种“赛博永生”的内容代理方式。

##### 一句话总结

**tweetskill 是一个把推特历史内容分析成 AI 可复用人格文件的开源工具，用来让 AI 写出更像本人语气、少一些 AI 味的推文。**

## 结构化（1）

### 2026-05-03 12:56:42

##### 主旨概括

作者认为，AI 直接代写推文常常“不像本人”、充满“AI 味”。为了解决这个问题，他开源了 **tweetskill**：通过分析一个人的历史推文，把其表达风格“蒸馏”成 AI Agent 可读取的 skill 文件，让 AI 更像本人地写内容。

##### 1. 问题：AI 写推文不像本人

- 作者长期遇到一个痛点：让 AI 帮忙写推文时，生成内容很容易被看出不是自己的语气。
- 常见问题包括：
  - 表达方式不符合本人习惯；
  - 语气生硬、有明显“AI 味”；
  - 不懂用户平时发推的格式、节奏和偏好。

##### 2. 解决思路：把推特人格“蒸馏”成 Skill

- 作者认为，既然同事的工作方式可以被“蒸馏”成 skill，那么推特上的人格和表达风格也可以。
- 因此他开源了 **tweetskill**。
- tweetskill 的核心作用是：
  - 分析用户的历史推文；
  - 提炼出用户的语言风格、内容偏好和常用表达；
  - 生成一个 AI Agent 可以直接读取的 `skill.md` 文件。

##### 3. tweetskill 的作用：让 AI 写得更像本人

- tweetskill 会先把一个账号的推文历史分析清楚。
- 分析完成后，会生成类似 `elonmusk-skill.md` 这样的文件。
- 文件中会包含：
  - 用户惯用的表达方式；
  - 哪类推文更容易获得高互动；
  - 用户从来不用或很少用的格式；
  - 整体内容风格和写作习惯。

例如，分析 `@elonmusk` 后，可以让 AI 读取 `elonmusk-skill.md`，再写一条关于 Grok 新版本的推文，从而更贴近马斯克的发推风格。

##### 4. 使用方法：安装并在 AI Agent 中调用

- 安装命令：

```bash
npx skills add DbgKinggg/tweetskill
```

- 安装时可以选择把 skill 安装到哪个 AI Agent 中，例如：
  - Hermes
  - OpenClaw
  - Claude Code 等

- 在 AI Agent 中可以直接输入类似命令：

```text
analyze @elonmusk
```

- tweetskill 默认使用 **X 官方 API** 获取推文，因此会要求用户提供 **X Bearer Token**。

##### 5. 生成 Skill 后的用法

- 跑完分析后，会得到一个对应账号的 skill 文件，例如：

```text
elonmusk-skill.md
```

- 之后可以这样使用：

```text
读 elonmusk-skill.md，帮我写一条关于 grok 新版本的推文
```

- 也可以直接把生成的 skill 文件放进 AI Agent 的配置里，让 AI 长期按照该风格写作。

##### 6. 可与其他 Skill 组合，增强效果

- 作者还提到，tweetskill 可以搭配其他 skill 使用，例如：
  - “去 AI 味”的 skill；
  - surf skills 等调研增强工具；
  - okx skill 等特定领域能力工具。

- 通过组合不同 skill，AI 不仅能更像本人说话，还能具备更强的信息检索和内容调研能力。

##### 7. 项目信息

- 项目名称：**tweetskill**
- 开源地址：

```text
https://github.com/DbgKinggg/tweetskill
```
