## 正文

**kanlanc** opened this issue on 3/8/2026

I been trying to get the fast models working with factory droid and factory just keeps breaking if I try to do this with extra\_args

Has anyone figured this out?

**ephraimduncan** commented on 3/12/2026

When using `provider: "openai"`, Factory sends requests via the [OpenAI Responses API](https://platform.openai.com/docs/api-reference/responses/create). The `extraArgs` object maps directly to top-level body parameters of `POST /responses` and must use **snake\_case**.

##### Example

```
{
  "customModels": [
    {
      "model": "gpt-5.4",
      "displayName": "GPT-5.4 (Fast)",
      "baseUrl": "http://localhost:8317/v1",
      "apiKey": "dummy-not-used",
      "provider": "openai",
      "extraArgs": {
        "service_tier": "priority",
        "store": false
      }
    }
  ]
}
```
