##### 二、深入浅出解读

###### 1. 这不是一个普通提示词

它不是简单问：

> “帮我讲讲 Pi Agent。”

而是明确要求 Codex 做三件事：

```text
先理解源码和文档
再设计教学路径
最后生成完整教程项目
```

这类提示词的价值在于：  
**它把 AI 当成“技术导师 + 项目架构师 + 文档工程师”来用。**

---

###### 2. 教程重点不是“看懂源码”

很多源码教程的问题是：

- 一上来贴代码
- 直接分析文件
- 缺少背景
- 初学者不知道为什么这么设计

而这个提示词强调：

> 不是源码解读，而是渐进式教学。

也就是说，它更像这样：

```text
先讲 Agent 是什么
再讲 Pi Agent 解决什么问题
然后拆成小模块
每个模块做一个 Demo
最后拼成完整项目
```

学习体验会更接近“手把手做项目”。

---

###### 3. 为什么用 VitePress？

VitePress 适合做技术教程网站，因为它支持：

- Markdown 文档
- 代码示例
- Mermaid 图表
- 项目目录展示
- 流程图、架构图
- 部署到 Vercel / GitHub Pages

简单说：

> VitePress 很适合把一个复杂技术项目，整理成结构清晰的在线课程。

---

###### 4. Pi Agent 学习价值在哪里？

Pi Agent 属于 AI Agent 方向。

AI Agent 可以简单理解为：

> 一个不只是聊天，而是能理解任务、调用工具、执行步骤、返回结果的 AI 系统。

一个 Agent 通常包含：

| 模块 | 作用 |
|---|---|
| LLM | 负责理解和推理 |
| Tools | 负责执行具体能力 |
| Memory | 保存上下文或历史信息 |
| Planner | 拆解任务 |
| Executor | 执行步骤 |
| Runtime | 管理运行流程 |

所以学习 Pi Agent，不只是学一个项目，而是在学：

> AI Agent 的基本工程实现方式。
