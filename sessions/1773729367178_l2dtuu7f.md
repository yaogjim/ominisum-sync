### 国内订阅Claude最简单的方式，只需一张国内Visa卡，0手续费，5分钟搞定

刚找到了一个订阅Claude会员的途径，0手续费，没有复杂的流程，超简单，只要有一张Visa卡就行，国内的也可以，一共分5步：

1. npm install -g agent-cards
2. agent-cards signup
3. agent-cards cards create --amount 20（充值$20，注册用英文名，支持大陆Visa卡充值）
4. agent-cards cards details \[ID\]（查看卡片信息，ID填上面命令返回的ID）
5. Claude订阅页面填入银行卡信息，账单地址填卡片地址，姓名填注册时到英文名。

这个方法实际上就是创建一张虚拟预付 Visa 卡订阅，虚拟卡提供商是

[https://agentcard.sh](https://agentcard.sh/)，agent-cards这个代码库我也用Claude扫描过，没有恶意代码。

先做个免责声明，这不是推广，按照以上步骤操作，我订阅成功了。但是这个卡的退款流程我还没测试完整，我知道的是每次订阅都要充一次值创建一张卡，订阅之后卡就会关闭，没使用的卡7天后也会自动关卡，卡里没用完的余额会退回支付渠道。所以花多少就充多少，没有必要多充。

至于Claude封号退款的问题，问了AI客服说不知道，到时候可能要和人工客服掰扯。

另外这卡现在公测期间0手续费，限量1000张，我前几天申请的时候卡发完了，昨天才申请到。

我有稳定的Claude订阅老号，这次为了测试订阅流程用的是纯新号，刚注册完就订阅，VPN是8.8一个月万人骑的机场，IP美国，也是为了测试封号到底是不是跟机场有关。

因为IP不够纯净，会跳短信验证码，我用的英国giffgaff卡收手机验证码，这个卡大家也可以去办一个，实体卡，一年保号费用才5块钱左右，专收验证码。

如果卡号发完了也别着急，我再继续去帮大家找渠道。
