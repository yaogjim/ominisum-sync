## 正文

Last year, we saw [Morse Micro introduce the MM8108](https://www.cnx-software.com/2025/01/14/morse-micro-mm8108-wifi-halow-soc-supports-up-to-43-33-mbps-transfer-rate-improves-range-and-power-efficiency/) Wi-Fi HaLow (802.11ah) SoC with up to 43.33 Mbps throughput, along with an MM8108-RD09 USB dongle reference design, for which we had virtually no details at the time.

Morse Micro has now released **USB-A and USB-C Wi-Fi HaLow adapters** based on that reference design. The adapters let PCs and routers connect to 802.11ah networks through USB without a dedicated expansion card and feature an external SMA antenna delivering up to 26 dBm transmit power.

[![Morse Micro’s Wi Fi HaLow USB Network Adapters in USB A and USB C form factors](https://www.cnx-software.com/wp-content/uploads/2026/09/Morse-Micros-Wi-Fi-HaLow-USB-Network-Adapters-in-USB-A-and-USB-C-form-factors-720x504.jpg)](https://www.cnx-software.com/wp-content/uploads/2026/09/Morse-Micros-Wi-Fi-HaLow-USB-Network-Adapters-in-USB-A-and-USB-C-form-factors.jpg)

Wi-Fi HaLow USB network adapter specifications:

- SoC – Morse Micro MM8108 32-bit RISC-V Host Applications Processor (HAP)
  - Standard – IEEE802.11ah Wi-Fi HaLow
  - Frequency band – 850-950 MHz (Worldwide sub-1 GHz license-exempt range)
  - Operating Modes – Access Point (AP) and Station (STA).
  - Channel Width – 1/2/4/8 MHz
  - Modulation – BPSK, QPSK, 16QAM, 64QAM, 256QAM.
  - Data rate – Up to 43.3 Mbps using 256-QAM modulation at an 8 MHz bandwidth
  - Transmit power – Up to 26 dBm
- Antenna – SMA connector on the back of the dongle (includes an external Wi-Fi HaLow antenna in the box)
- USB – USB-A or USB-C port
- Security
  - AES
  - SHA-256 / SHA-384 / SHA-512
  - WPA3
  - OWE (Opportunistic Wireless Encryption)
- Power – 5V via USB Type-A or Type-C port
- Dimensions – TBD
- Operating Temperature – -40°C to +85°C (silicon/chip — not the enclosed stick)
- Supported Regions – USA, Canada, Australia, UK, Europe, and Japan

Wi Fi HaLow extends coverage up to 10 times farther than traditional Wi Fi, supporting large sites and multi-building connectivity.

Morse Micro also released [the hardware design and manufacturing files](https://www.morsemicro.com/download/rd09-reference-design-package/) for the MM8108-RD09 reference design. The company says the USB adapters support Windows, Linux, and macOS. However, I was unable to find the “pre-written driver” for Windows. Linux users need to compile the driver against a patched kernel with S1G (802.11ah) support or use Morse Micro’s OpenWrt fork. The morse\_driver and firmware are available on [GitHub](https://github.com/MorseMicro/), along with documentation and resources. More information, including software releases, datasheets, design guides, application notes, and user guides, can be found on the [Morse Micro documentation portal](https://docs.morsemicro.com/).

[![RD09 WiFi Halow reference design](https://www.cnx-software.com/wp-content/uploads/2026/09/RD09-WiFi-Halow-reference-design-720x451.webp)](https://www.cnx-software.com/wp-content/uploads/2026/09/RD09-WiFi-Halow-reference-design.webp)

Internal drawings for the RD09 reference design

The MM8108 chipset has already been used in modules such as the [Morse Micro MM8108-M20](https://www.cnx-software.com/2026/06/03/morse-micro-mm8108-m20-high-power-wi-fi-halow-module-delivers-up-to-28-5-dbm-tx-output-power/) and [Quectel FGH200M](https://www.cnx-software.com/2026/03/04/upgraded-fgh200m-wi-fi-halow-module-features-morse-micro-mm8108-soc-handles-up-to-8191-iot-devices/). This year, the company also released the [HaLowLink 2](https://www.cnx-software.com/2026/01/13/halowlink-2-wi-fi-halow-access-point-and-extender-offers-up-to-1-km-range-supports-up-to-1000-iot-end-devices/) Wi-Fi HaLow access point based on that same MM8108 HaLow chipset.

The Morse Micro Wi-Fi HaLow USB network adapters are currently [sold on Mouser for $58.00](https://au.mouser.com/en/c/?q=MM-u0&m=Morse%20Micro) in both the USB Type-A and Type-C configurations, with AU variants also available. Additional information is available on the [product page](https://www.morsemicro.com/products/development-resources/wi-fi-halow-usb-network-adapters).
