#### 主旨概括

作者回顾一条 **6 月发布的未来三年预测**，认为其中“软件形态变化”和“物理 AI”暂时还没有明显动态，但自己正在实践另外三点。其核心认识是：**培养个人 Agent，本质上不是固定某个工具，而是长期维护一份高质量、专属于自己的上下文。**

##### 1. 回顾未来三年的五点思考

原推文提出了五个方向，本次重点回顾如下：

1. **软件形态将发生变化**
   - 现在的软件像“盒子”，有固定的界面、功能和入口。
   - 未来的软件可能更像“水”：Agent 会根据当前任务，实时生成所需的界面和功能，用完后再变化、重组。

2. **物理 AI 的潜力被长期低估**
   - AI 不会只存在于聊天框中。
   - 汽车、手机、电脑和机器人等设备，都可能成为 AI 的“身体”，让智能进入现实世界。
   - 作者表示，目前尚未看到这两个方向出现特别明显的动态或新闻。

3. **学习 Agent 开发**

4. **继续偏向使用云端 Agent**

5. **持续使用并培养一只属于自己的 Agent**

其中后三点，作者已经在实际践行。

##### 2. “培养个人 Agent”的两项重点

作者认为，培养 Agent 主要包含两个方面：

- **固定并优化工作流**：让 Agent 更熟悉个人常用的任务流程，提高协作效率。
- **积累独家专属上下文**：持续记录自己的工作、经历、习惯和思考，使 Agent 更了解自己。

相比之下，工作流可能随着工具和需求不断变化，但个人上下文具有更长期的价值。

##### 3. 养 Agent 的本质：维护个人上下文

作者将“养 Agent”总结为：

> **长期维护一份清晰、高质量、专属于自己的上下文。**

这些经过整理和清洗的数据，未来可以帮助更高智能的 AI 快速理解用户。例如，个人的工作记录、项目经历、决策方式和表达偏好，都可能成为 Agent 提供个性化服务的重要基础。

因此，真正值得长期积累的，不只是某个 Agent 产品或固定流程，而是**可迁移、可复用的个人知识与经历数据**。

##### 4. AI 行业变化速度极快

作者感慨，虽然实际上只过去了 **一个月**，但 AI 圈的变化密度让人产生了仿佛已经过去 **半年**的感觉，反映出当前 AI 技术和产品迭代速度非常快。

#### 养 Agent 的本质，是持续积累个人专属上下文

##### 个人 Agent 的长期资产是上下文，而非工作流

作者已在实践另外三点：学习 Agent 开发、偏向使用云端 Agent，以及持续培养个人 Agent。其中，“培养”并非单纯选择某个模型，而是维护一份高质量、可复用的个人上下文，包括工作经历、项目记录、偏好和思考方式。

工作流会随着工具和模型快速变化，但经过整理、清洗的个人数据更持久，也更有助于未来更强的 AI 理解用户。由此看，个人 Agent 的真正壁垒不是固定配置，而是长期沉淀的专属上下文。AI 领域变化之快，也让作者产生“一个月像半年”的感受。
