## 正文

**宝玉**

FxEmbed 是一个开源项目，解决的是 Twitter/X 和 Bluesky 链接在 Discord、Telegram 等平台上嵌入预览效果差的问题。

用法很简单：在 https://x.com 前加 fx，在 http://x.com/ 前加 fixup，在 [http://bsky.app](http://bsky.app) 前加 fx，链接就能正常展示视频、GIF、投票结果、引用推文、多图等内容。

要获取原始 API JSON 数据，可以把 X 链接（包括长文）前面域名换成 [http://api.fxtwitter.com](http://api.fxtwitter.com)  
例如：  
[https://api.fxtwitter.com/dotey/status/2029969547927658673…](https://api.fxtwitter.com/dotey/status/2029969547927658673)

几个亮点功能：支持帖子翻译（链接末尾加 /en 等语言代码）、直接获取媒体文件链接、多图拼接mosaic模式、纯图/纯文字模式、Telegram 的 Instant View 线程展开，还会自动去除追踪参数。

技术上用 TypeScript 写的 Cloudflare Worker，边缘计算架构，免费额度每天 10 万次请求。隐私方面也做得不错，没有日志、没有数据库、没有广告和追踪，Worker 本身跑完就释放内存，不留痕迹。

MIT 协议开源，可以自己部署。

> **@xDinoDeer**

## 结构化（1）

### 2026-03-17 06:41:13

这篇文章主要介绍了开源项目 FxEmbed：它能改善 Twitter/X 和 Bluesky 链接在 Discord、Telegram 等平台上的预览效果。核心价值是“改一下链接就能更完整地展示内容”，同时还提供 API、翻译、媒体提取等实用功能。

- 背景与作用
  - FxEmbed 解决的是社交平台链接“预览太差”的问题，尤其是 X（原 Twitter）和 Bluesky 的内容在 Discord、Telegram 中经常显示不完整。
  - 它可以让链接正常展示更多内容，比如视频、GIF、投票结果、引用推文和多图。

- 使用方式
  - 用法很简单：
    - 在 `x.com` 前加 `fx`
    - 在 `http://x.com/` 前加 `fixup`
    - 在 `http://bsky.app` 前加 `fx`
  - 这样处理后，链接预览会更完整、更适合在聊天工具里传播。

- API 与数据获取
  - 如果想拿到原始 API JSON 数据，可以把 X 链接的域名改成 `api.fxtwitter.com`。
  - 它不仅支持普通帖子，也支持长文内容。
  - 文中给了例子：
    - `https://api.fxtwitter.com/dotey/status/2029969547927658673`
    - 引用案例还提到，可通过这个接口抓取推特长文：
      - `https://api.fxtwitter.com/levie/status/2030714592238956960`

- 亮点功能
  - 支持帖子翻译：在链接末尾加 `/en` 等语言代码即可。
  - 支持直接获取媒体文件链接，方便下载或二次处理。
  - 支持多图拼接的 `mosaic` 模式。
  - 提供纯图模式、纯文字模式。
  - 对 Telegram 还支持 `Instant View` 线程展开。
  - 会自动去除追踪参数，链接更干净。

- 技术实现
  - 项目使用 TypeScript 编写，运行在 Cloudflare Worker 上，属于边缘计算架构。
  - 免费额度为每天 `10 万次请求`，说明它在成本和可用性之间做了较好平衡。

- 隐私与开源
  - 隐私设计是一个重点：`没有日志、没有数据库、没有广告和追踪`。
  - Worker 执行完成后会释放内存，尽量做到“不留痕迹”。
  - 项目采用 `MIT` 协议开源，用户也可以自己部署。  

一句话看，FxEmbed 不只是“优化链接预览”的小工具，更像是一个兼顾展示效果、数据访问、隐私和可自部署能力的轻量基础设施。
