### 短视频工作室要失业了？这个 Agent 操盘手能拆竞品、写脚本、盯数据！强到不像话！

> 内容很干，也很长。但很值！如何拆脚本，做选题，找热点，做内容日历等全都做了详细的说明！妈妈再也不用担心我做短视频了！ 本文涉及的 Agent 加入“钱来有道”社群获取，或订阅我，在订阅区分享，广告完毕，我们开始！

因为这个 Agent 非常复杂，我调试了大概4\~5天，今天终于可以跟大家见面了。

做短视频人们都知道一件事，写文案从来都不是最难的，难的是不知道该怎么写，写什么，写完之后好不好。

很多朋友最焦虑的从来不是坐在电脑面前写不出字，而是每天打开手机刷两个小时同行的视频，再看到别人又爆了一条，心里面只剩下：我怎么办？我应该发什么？

越看的越多，大脑越是一片空白。

知道别人火了，却说不出来个所以然，更不知道我能不能用这个思路。

这个焦虑不是个例，我身边几乎所有做抖音跟视频号的朋友们，都被这四件事卡的死死的。

第一件事就是选题焦虑，不是没想法，而是没有一个稳定的把外部信息转化为自己选题的方法。每天都是凭灵感，灵感来了报一条，灵感断了憋三天。

第二个是不会拆解，都要说看竞品，可看完之后呢，要么诊断搬运，平台一判降权全完了，要么完全不知道怎么借鉴，只能干瞪眼。能说出这条火了，但说不出它为什么火，火在哪个结构点上面？

第三个是产出太慢了，选题定了，从选题到成稿还是磨，开头钩子想半天，反复调，口播稿改了十几遍，一个视频两个小时是常态，每周要发三条，根本不可持续。

第四是不知道明天发啥。 今天发完了，明天呢？后天呢？没有系统规划，每天临时抱佛脚。更要命的是，发了的内容数据有没有可能爆？完全没底。

AI 工具就是用来提效的，我们要掌握这个创作的核心逻辑，运用系统性的工具去解决它。

解决没人帮你想题目，没人帮你看数据，没人陪你建立长期的内容策略，所以我做了这个 Agent 短视频内容超级操盘手，帮你省下千的报课费用，一切尽在你自己的掌握之中！

#### 主旨概括

这篇文章介绍了一个面向短视频创作者的 Agent 工具，核心目标是把 “选题焦虑、拆解无门、产出太慢、不会看数据” 这些常见难题，变成一套可执行、可复用的内容生产流程。  
作者强调，这个 Agent 不是单纯帮你 “写文案”，而是从人设定位、竞品拆解、脚本生成、内容排期到数据复盘，提供一整套 “短视频操盘” 方案。

##### 1. 为什么要做这个 Agent：短视频创作者最常见的 4 个痛点

- 作者调试这个 Agent 花了大约**4~5 天**，因为它要解决的不是单点问题，而是整条内容生产链路的问题。
- 文章指出，做短视频最难的往往不是 “不会写”，而是：
  - **不知道写什么**：每天靠灵感，缺少稳定的选题方法。
  - **不会拆竞品**：知道别人火了，但说不清为什么火，也不会借鉴。
  - **产出太慢**：一个视频从选题到成稿经常要**2 个小时**，一周发**3 条**都很难持续。
  - **没有长期规划**：今天发完了，不知道明天发什么，也不知道内容有没有爆的可能。
- 作者认为，AI 工具真正的价值是 “提效 + 系统化”，不是简单代写。

##### 2. Agent 的核心方法论：拆框架、换变量、批量出

- 整个 Agent 围绕三个动作展开：
  - **拆框架**：把爆款内容的结构和逻辑拆清楚。
  - **换变量**：保留有效结构，替换成自己的赛道、案例和表达。
  - **批量出**：把经验沉淀成选题库、公式库、脚本库和内容日历。
- 文章想传达的核心是：做短视频不能只靠临场发挥，而要靠 “可复用的方法”。

##### 3. 使用前准备：先安装，再让 Agent 认识你是谁

- 使用前要先解压项目目录，例如：
  - Mac：`~/Documents/douyin-content-master/`
  - Windows：`D:\ 工作 \douyin-content-master\`
- 正确目录结构应包含：
  - `CLAUDE.md`
  - `README.md`
  - `agent/`
  - `config/`
  - `content/`
  - `logs/`
- 启动 Claude Code 后，Agent 会读取`CLAUDE.md`自动启动；如果没反应，可手动输入：`请读取 CLAUDE.md 并按其中的指令执行！`

###### 画像定位是最关键的前置步骤

- Agent 首先会进行 “画像采集”，了解你的：
  - 账号定位
  - 赛道
  - 风格
  - 受众
  - 禁区内容

- 最终会生成类似结果：
  - 创作者昵称、赛道、风格

  - 纯内容骨架约**1400 字**

- 它会继续分析：
  - **选题公式**：例如 “反常识观点 + 焦虑→释然”
  - **结构骨架**：钩子、铺垫、核心层、收束层
  - **情绪曲线**：每个阶段如何推动观众情绪变化
  - **可迁移度评估**：哪些能直接借鉴，哪些要调整
  - **原创化建议**：如何改写成适合自己账号的内容

###### 文章保留的关键案例

- 原文钩子示例：
  - “**找自己擅长的事，是赚钱最大的弯路**”
- Agent 给出的分析结论包括：
  - 钩子类型：**反常识 + 冲突**
  - 吸引力评分：**5/5**
  - 情绪密度：**高密度，约每 30 秒一个情绪转折**
  - 可迁移度评分：**5/5**
- Agent 还给出适配 “AI 赚钱赛道” 的改写示例：
  - “**你收藏了 200 个 AI 赚钱教程，一个没做对吧？因为你在找那个‘最适合你的’。别找了，不存在。**”
- 这些拆解结果会保存到：
  - `content/decode/2026-04-10_01_天赋论观点拆解.md`
  - `config/formula-library.json`
  - `config/hooks-library.json`

##### 5. 脚本生成功能：不仅写文案，还带拍摄和发布建议

- 使用`~script`可以直接生成短视频脚本。
- 默认会输出**3 条不同角度**的脚本，每条包括：
  - 脚本正文
  - 拍摄备注
  - 情绪指导
  - BGM 建议
  - 字幕重点
  - 评论区引导语
  - 发布建议
- 默认字数范围是**280-380 字**，适合一般口播视频。

###### 支持不同时长和不同模式

- 例子：
  - `~script AI 工具订阅最常踩的坑 --duration 30 --count 2`
- 这代表生成**2 条 30 秒脚本**，字数大致应控制在**150-220 字**。
- 还有 “观点直出模式”：
  - 如果用户直接粘贴一段**超过 50 字**的完整观点，Agent 会保留核心主张，只做表达包装。
- 商业化表达也可控制：
  - `--cta hook`：在结尾加入自然植入
  - `--cta off`：完全关闭商业化引导

##### 6. 脚本诊断功能：判断有没有 “爆款潜力” 和 “AI 味”

- 通过`~review`，Agent 会对脚本进行质量诊断。
- 文章提到的评估方式是**五维度评分**，如果是变现账号，第五维会重点看 “**转化路径清晰度**”。
- 它还能专门检测 “AI 味” 表达，比如：
  - “首先”
  - “其次”
  - “最后”
  - “值得一提的是”
  - “综上所述”
- 如果文案出现这些套路化表达，Agent 会：
  - 降低人格化评分
  - 标出问题词
  - 给出改写建议

##### 7. 不会记命令也能用：自然语言也能触发对应功能

- 作者专门强调：即使你记不住`~`命令，也可以直接用大白话交流。
- 比如说：

- Agent 会自动识别这是脚本需求，并转到相应模式。
- 如果用户说 “我不知道明天发什么”，Agent 会自动识别为选题需求，触发`~topics`或`~daily`。
- 即使输错命令，Agent 也会做容错提示，例如：
  - 输入`~ 写脚本`，会提示你是不是想用`~script`
  - 输入`~ 分析数据`，会提示你用`~analyze`或`~data`

##### 8. 数据分析功能：从 “感觉” 变成 “科学复盘”

- 当账号有一定作品积累后，可以通过`~data`导入抖音创作者中心导出的作品数据。
- 数据来源路径是：
  - 抖音创作者中心
  - 作品分析
  - 投稿列表
  - 按时间导出数据
- Agent 可识别**12 个维度**，并提示 “已导入 N 条数据”。

###### 单条诊断和趋势分析

- 单条分析示例：`~analyze 4 月 3 日`
- 文中给出的 “差视频” 诊断链案例：
  - 封面点击率**2.8%** → 偏低 → 封面或标题有问题
  - **5 秒完播率 45%** → 偏低 → 钩子有问题
  - **2 秒跳出率 32%** → 过高 → 内容匹配度有问题
  - **完播率 18%** → 偏低 → 内容质量不够
- 趋势分析命令：`~analyze --trend`
- 如果数据少于**10 条**，Agent 会提示准确度有限，但仍可做基础分析。
- 作者建议积累到**20~30 条数据**后再分析，结果会更稳定。

##### 9. 选题与热点功能：从自身积累、竞品和热点中持续找方向

###### 三种主要选题模式

- `~topics --mine`
  - 从你已有的拆解报告、脚本中挖掘新选题。
  - 一般会推荐**7 个左右**选题。
  - 每个选题会附带：
    - 选题描述
    - 来源标注
    - **3 个切入角度**
    - 难度评级、预估互动、时效性、竞争度、适合形式、建议时长
- `~topics --rival`
  - 从竞品拆解报告中延展选题。
  - 本质是 “保留有效框架，换成你的角度”。
- `~topics --hot`
  - 联网搜索全网热点，再通过四道关卡筛选：
    - 赛道关联度
    - 独特角度
    - 时效性
    - 风险评估

###### 热点和突发事件响应

- 对于突发事件，可用`~flash`
- 示例：
  - `~flash Claude Code 源码官方泄露事件！`
- Agent 会在**1~3 分钟**内完成：
  - 搜索信息
  - 判断赛道关联
  - 做**六项风险检查**
  - 找独特角度
  - 生成**30-60 秒**应急脚本

##### 10. 内容日历和一键操盘：把选题、脚本、排期连起来

- 如果某条脚本不错，可以用`~calendar`放进内容日历。
- 月度规划可用：`~calendar --month`
- 最强的全流程功能是：`~daily`

###### `~daily`会怎么工作

- Agent 会按流程执行：
  - 读取画像和当天排期
  - 询问是否有新的竞品素材
  - 生成**5-7 个**今日选题
  - 等你确认后，再批量生成脚本
  - 生成后做快速质量诊断
  - 最后输出 “今日内容包”
- 这意味着它不只是 “写一条文案”，而是在模仿一个真正的内容操盘手工作方式。

##### 11. 其他补充功能：风格模仿、钩子库、帮助系统

- `~mimic`
  - 上传某个博主**5-8 条**口播文案后，学习其风格。
  - 后续可结合`~script --style mimic: 博主名`使用。
- `~hooks`
  - 查看按**七大类型**分类的钩子库。
  - `~hooks --match 选题`可推荐最匹配的**3-5 条**钩子。
- `~help`
  - 用来查看所有命令说明。

##### 12. 实际使用中可能出现的问题与解决方案

文章最后列出了一些常见问题，说明这个 Agent 虽然强，但依然依赖模型能力和规则执行效果：

- **问题 1：不按规则文件执行**
  - 解决：手动提醒先读取对应规则文件，如`persona-rules.md`
- **问题 2：脚本字数不准**
  - 解决：重新强调字数范围，如 “严格控制在 280-380 字”
- **问题 3：`~daily`没有在关键节点暂停**
  - 解决：明确要求必须在两个人工确认节点暂停
- **问题 4：商业化植入太硬**
  - 解决：要求 “植入自然，语气和正文一致”
- **问题 5：数据维度识别错误**
  - 解决：导入前明确字段定义，例如 CTR 是封面点击率
- **问题 6：意图识别出错**
  - 解决：记录容易误判的表达，为后续优化意图映射表提供依据

这篇文章本质上是在介绍一个 “短视频内容操盘系统”，而不是单独的写稿工具。它试图把短视频创作拆成 “画像定位 — 竞品拆解 — 批量出题 — 脚本生成 — 排期发布 — 数据复盘 — 策略优化” 的闭环，让创作者从 “每天临时想内容” 转向 “按系统做内容”。

如果用一个简单例子概括：以前你可能只是让 AI “帮我写一条口播稿”，现在这个 Agent 更像一个会陪你一起做账号的操盘手 —— 不仅告诉你写什么，还告诉你为什么这么写、什么时候发、发完怎么看数据、下一步怎么调。

##### 1. 它厉害的点，不是 “会写”，而是 “会操盘”

- 先了解你是谁、做什么、卖什么

- 然后生成适合你的选题和脚本
- 最后结合数据，反过来优化下一波内容

> **把短视频从 “靠灵感” 变成 “靠方法”**

这对新手尤其有吸引力，因为很多人不是不会努力，而是不知道努力方向对不对。

##### 2. 它最核心的价值，是帮你 “看懂爆款”

文章里反复强调一个问题：  
很多人知道别人火了，但**不知道为什么火**。

这个 Agent 的价值就在于，它会把一条爆款内容拆成几个关键层：

- 开头钩子为什么吸引人
- 中间怎么铺垫
- 核心观点怎么推进
- 结尾怎么收束和引导互动
- 情绪是怎么一步步拉起来的

这其实很重要。因为真正能复制的，从来不是句子本身，而是：

> **结构、节奏、情绪、论证方式**

这比单纯 “洗稿” 高级得多，也更安全。

##### 3. 它适合的人，不只是小白

表面上看，这工具很适合不会写脚本的新手。  
但其实对已经在做号的人，价值更大。

因为做过内容的人最痛的往往不是 “写不出一条”，而是：

- 每天都要想下一条
- 写了很多，却不知道哪种更容易爆
- 数据越来越多，但不会复盘
- 内容发久了，风格容易乱

而这个 Agent 把这些问题都往 “系统化运营” 上推了一步。  
也就是说，它不是只帮你出稿，而是想帮你形成：

- 内容库
- 公式库
- 钩子库
- 日历排期
- 数据复盘机制

这套东西一旦跑起来，创作效率会比单条写稿高很多。

##### 4. 它也不是万能的

文章虽然写得很强，但其实也透露出几个现实问题：

- **对模型能力有要求**：不同模型表现不稳定
- **指令多，学习成本高**：新手一开始容易懵
- **结果仍依赖输入质量**：你的定位、素材、表达越清晰，效果越好
- **不能代替人的判断**：热点要不要追、内容适不适合自己，还是得自己拍板

所以它更像 “副驾驶”，不是 “全自动驾驶”。

如果你本身没有内容感，没有行业理解，只想靠它一键出爆款，那大概率会失望。
