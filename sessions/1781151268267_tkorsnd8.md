**Jesse Lau 遁一子**

Thariq分享了如何一个prompt搞定Fable的launch video

我把prompt导出来了：

英文：

&gt; I'm processing the recording of a bunch of videos in @Fable  
\-Full-Recording/  
the script for them is in @Fable  
\-Full-Recording/fable5script.md. I want you to  
run the eleven labs transcription service on them. Then stitch together the best shots, into one final clip. A few notes: there are multiple takes per scene, the  
best takes are usually the ones at the end with the fewest ums, but that can change. I also re-shot the first scene at the end. They should all be organized  
by timeline. For a few of them I start the video saying "Hey \[name\]" as a way of starting the sentence warm, we should cut that out. Create a JSON file for the  
video that shows per scene, each clip we're using and the time ranges from them.  
Then, create a final scene using ffmpeg. Orchestrate this all using workflows.  
/goal dont stop until you have a final video

中文：

我正在处理 @Fable  
\-Full-Recording/ 目录中的一批视频录制文件。

这些视频对应的脚本位于：  
@Fable  
\-Full-Recording/fable5script.md

我希望你先对这些视频运行 ElevenLabs 的转录服务（transcription service），然后从中挑选最佳镜头，并将它们剪辑成一个最终视频。

补充说明：

\- 每个场景都有多个拍摄版本（multiple takes）。  
\- 通常最好的版本是最后几个录制的版本，因为其中的“嗯”“啊”等口头停顿最少，但也不一定总是如此。  
\- 我在最后又重新拍摄了一遍第一幕（first scene）。  
\- 所有素材都应该按照时间线顺序进行整理。  
\- 有些视频开头我会说一句“Hey \[name\]”，只是为了热启动语气，我们应该把这部分剪掉。

请创建一个 JSON 文件，用于说明：  
\- 每个场景使用了哪些片段（clips）  
\- 每个片段采用了哪些时间范围（time ranges）

然后使用 ffmpeg 生成最终的视频。

使用工作流（workflows）来编排整个过程。

/goal 在得到最终视频之前不要停止。

## 解读（1）

### 2026-06-11 04:14:28

#### 一句话总结

这条内容展示了：**用一个高质量 Prompt，让 AI 自动完成从视频转录、选片、剪辑、生成 JSON 剪辑方案，到用 ffmpeg 输出最终发布视频的完整流程。**

---

#### 深度总结

核心不是 “一个 Prompt 很神奇”，而是它把视频制作拆成了可执行工作流：

1. **输入素材**
   - 一批原始视频录制文件
   - 一份对应脚本文档

2. **理解内容**
   - 调用 ElevenLabs 做语音转录
   - 对照脚本识别不同场景、不同 take

3. **选择最佳片段**
   - 优先选择后面录制的版本
   - 去掉 “um / 啊 / 嗯” 等口头停顿
   - 剪掉开头暖场句，如 “Hey [name]”

4. **结构化剪辑方案**
   - 输出 JSON
   - 标明每个场景用哪个视频片段、起止时间

5. **自动生成成片**
   - 用 ffmpeg 拼接
   - 通过 workflow 编排
   - 直到生成最终视频才停止

本质上，这是把传统视频剪辑中的 “人工判断 + 工具操作”，改造成了**AI 理解内容 + 自动调用工具 + 程序化生成结果**。

---

#### 深入浅出解读

以前剪视频像这样：

> 人看一堆素材 → 找好片段 → 手动裁剪 → 拼起来 → 调色 → 导出。

这个 Prompt 做的是：

> 让 AI 先 “看懂” 素材，再像剪辑师一样做决定，最后像工程师一样调用工具自动生成视频。

它厉害的地方不在于文字很长，而在于指令非常清楚：

- **告诉 AI 素材在哪里**
- **告诉 AI 脚本在哪里**
- **告诉 AI 判断标准**
- **告诉 AI 要删什么**
- **告诉 AI 输出什么格式**
- **告诉 AI 用什么工具完成**
- **告诉 AI 不完成不要停**

这就是一个好 Prompt 的关键：  
**不是许愿，而是定义任务、规则、工具、结果。**

---

#### 这个 Prompt 的真正价值

它体现了未来 AI 工作流的方向：

##### 从 “帮我想想” 到 “帮我做完”

普通 Prompt：

> 帮我剪一个视频。

高级 Prompt：

> 读取这些素材，转录音频，对照脚本，选择最佳 take，去除废话，生成剪辑 JSON，用 ffmpeg 输出最终视频，完成前不要停止。

区别在于：

| 普通 Prompt | 高级 Prompt |
|---|---|
| 模糊愿望 | 明确流程 |
| 依赖 AI 猜 | 给 AI 判断标准 |
| 只要建议 | 要最终交付物 |
| 单次对话 | 工具编排 |

---

#### 可复用 Prompt 结构

可以抽象成这个模板：

```text
我有一批素材在 [路径]，
对应说明 / 脚本在 [路径]。

请先做 [分析 / 转录 / 识别]，
然后根据 [判断标准] 选择最佳内容。

注意：
- 删除 [不需要的部分]
- 优先保留 [高质量内容]
- 按照 [顺序 / 结构] 组织

请输出：
1. 结构化方案，如 JSON
2. 最终成品文件

使用 [工具] 完成整个流程。
/goal 在得到最终结果之前不要停止。
```

---

#### 辩证思考

##### 积极面

AI 正在把复杂创作流程 “自动化”：

- 创作者不必亲自打开剪辑软件
- 小团队也能完成专业级制作
- 内容生产速度大幅提升
- Prompt 变成新的 “导演脚本 + 执行说明书”

未来很多工作不是人亲手做，而是人设计流程，让 AI 执行。

---

##### 局限面

但它还不能完全替代人类剪辑师。

因为视频剪辑不只是 “选最顺的一条”：

- 哪个表情更有感染力？
- 哪个停顿更有戏剧效果？
- 哪个镜头更符合品牌气质？
- 节奏是快一点还是慢一点？
- 哪些 “不完美” 反而更真实？

这些仍然需要审美、经验和判断。

AI 擅长执行明确规则，  
但高级创作常常依赖模糊感觉。

---

##### 我的判断

这个案例的启发不是：

> 以后剪辑师没用了。

而是：

> 低价值重复剪辑会被自动化，高价值创意判断会更重要。

未来会分化成两类人：

1. **只会操作软件的人**  
   容易被工具替代。

2. **能定义审美、流程和结果的人**  
   会借助 AI 放大产能。

真正的能力不再是 “我会点哪个按钮”，  
而是：

> 我知道要做成什么样，并能让 AI 做出来。
