**临床级 \* 用于 Apple Health 导出的健康数据分析**

将原始的 Apple Health XML 数据转换为全面的健康评估报告——21 种统计方法、30 项疾病风险筛查、35+个 SVG 可视化图表，引用 59 篇同行评审论文。支持 Claude Code、Cursor、Copilot、Codex、Gemini CLI 以及 8+个其他 AI 代理。

> \* **"临床级"指的是使用同行评审的统计方法和已发表的临床参考范围——而非监管批准或诊断有效性。本工具仅用于信息和教育目的。它不是医疗设备，不提供医疗建议，也未在临床试验中得到验证，也未获得任何监管机构（FDA、CE 等）的批准。所有疾病风险筛查均为初步估算，需要持牌医疗从业者确认。请勿仅凭本工具的输出做出医疗决策。**

#### Install

```
npx skills add labrinyang/apple-health-analysis -y -g
```

##### Clinical Rigor

- **数据质量评估** ：11 个数据流已评估（可靠性等级：高 / 中 / 低 / 不足）
- **证据分级** ：A（强）/ B（中）/ C（提示性）/ D（不足）每项发现
- **缺失数据协议** ：从不崩溃，从不伪造。数据不足的部分会被跳过并附带说明
- **多语言** : `--lang en` / `--lang zh` 用于报告界面; AI 叙事以用户语言编写

## 结构化（1）

### 2026-04-02 07:41:49

#### 主旨概括

这是一个面向 Apple Health 导出数据的 “临床级” 分析工具仓库，核心价值是：把原始 XML 健康数据，转换成一份基于同行评审方法、带疾病风险筛查和大量可视化的综合健康报告。  
它强调 “临床级” 是指采用了公开发表的统计方法和临床参考范围，而不是医疗认证产品，不能替代医生诊断。

##### 1. 项目定位与适用范围

- 该工具用于分析 Apple Health 导出的个人健康数据，生成全面评估报告。
- 覆盖内容非常广：`21 种统计方法`、`30 项疾病风险筛查`、`35+ 个 SVG 可视化图表`，并引用了`59 篇同行评审论文`。
- 兼容多个 AI 代理和开发环境，包括 Claude Code、Cursor、Copilot、Codex、Gemini CLI 等`8+`个工具。
- 适合做个人健康趋势观察、教育用途、数据探索，但不适合直接作为医疗决策依据。

##### 2. 免责声明：为什么叫 “临床级”，但不是医疗设备

- 文中明确说明，“临床级” 仅表示方法参考了同行评审研究和已发表的临床阈值。
- 它不是医疗设备，也没有经过临床试验验证。
- 未获得 FDA、CE 等监管批准。
- 所有疾病筛查结果都只是 “初步估算”，必须由持牌医疗专业人员进一步确认。
- 换句话说，它更像 “高质量健康分析助手”，不是 “自动诊断系统”。

##### 3. 安装与使用方式

- 最推荐的安装命令是：
  ```bash
  npx skills add labrinyang/apple-health-analysis -y -g
  ```
- 安装后，可直接让 AI 代理执行类似 “分析我的 Apple Health 数据” 的任务。
- 也支持 Claude 插件安装：
  ```bash
  claude plugins marketplace add labrinyang/apple-health-analysis
  claude plugins install apple-health-analysis
  ```

  ```bash

  ```

##### 4. 核心分析能力：统计方法很强，偏研究型

###### 4.1 因果与复杂系统分析

- 项目不仅做简单趋势统计，还加入了更高级的方法：
  - 格兰杰因果关系（Granger Causality）
  - 转移熵（Transfer Entropy）
  - 收敛交叉映射（CCM）
- 对应参考文献包括：
  - Granger（1969）
  - Schreiber（2000）
  - Sugihara（2012）
- 这类方法适合研究 “某项指标变化是否可能领先另一项指标”，例如：
  - 步数变化是否先于静息心率改善
  - 作息变化是否影响血糖波动

###### 4.2 非线性与节律分析

- 支持样本熵、DFA、庞加莱图、多尺度熵等方法，用于分析 HRV、心率等复杂生理信号。
- 支持 Cosinor、日际稳定性（IS）、日内变异性（IV）等昼夜节律分析方法。
- 这些方法常用于判断：
  - 生理节律是否规律
  - 自主神经系统是否稳定
  - 睡眠 / 活动节律是否紊乱

###### 4.3 趋势、变化点与统计严谨性

- 支持 Mann-Kendall 趋势检验、贝叶斯变化点检测、CUSUM 等方法。
- 同时加入 Bootstrap 置信区间、Cohen’s d / Hedges’ g、置换检验等统计严谨性工具。
- 也就是说，它不仅告诉你 “有变化”，还尽量判断 “变化是否有统计意义”。

###### 4.4 综合模型

- 项目还能计算：
  - 生物年龄
  - 健身年龄
  - 稳态负荷指数（Allostatic Load）
- 对应参考包括 Levine（2013）、Nes（2013）、McEwen（1998）。
- 这类结果更适合做整体健康状态的 “综合画像”。

##### 5. 疾病风险筛查：覆盖 8 大类、30 项条件

###### 5.1 筛查范围

项目将疾病风险筛查扩展到`8 个类别`，共`30 项`，包括：

- 内分泌：2 型糖尿病、甲减、甲亢、胰岛素抵抗
- 心血管：心血管疾病、高血压、冠心病、房颤、心衰、体位性心动过速综合征
- 呼吸：阻塞性睡眠呼吸暂停、COPD
- 神经：早期帕金森、认知衰退、癫痫发作风险
- 肌肉骨骼：肌少症、跌倒风险
- 睡眠障碍：失眠、REM 睡眠行为障碍、昼夜节律障碍
- 精神心理：抑郁 / 昼夜节律紊乱、焦虑、慢性疲劳
- 其他：贫血、听力损失、感染 / 发热、代谢综合征、维生素 D 替代指标、脱水

###### 5.2 筛查依据

- 每项筛查都使用论文中的生物标志物阈值。
- 输出不仅有风险分数，还会给出影响因素和临床建议。
- 关键参考研究包括：
  - FINDRISC（Lindstrom 2003）用于糖尿病风险
  - Framingham（D’Agostino 2008）用于心血管风险
  - STOP-BANG（Chung 2008）用于睡眠呼吸暂停筛查
  - CHARGE-AF（Alonso 2013）用于房颤风险

###### 5.3 可以怎么理解

- 例如，如果一个人的夜间血氧下降、呼吸频率异常、睡眠结构紊乱，系统可能提示阻塞性睡眠呼吸暂停风险升高。
- 如果步速下降、步态不稳、楼梯上升速度下降，可能提示肌少症或跌倒风险。
- 这类结果更适合作为 “早筛提醒”。

##### 6. 可视化报告：不只是数据表，而是可读性很强的 HTML 报告

- 生成的是一个独立 HTML 文件，大小约`160KB`。

  - `8 个维度 + 总体评分`的环形仪表盘

  - 心率区间环图
  - 血糖 TIR 堆叠条形图
  - 睡眠结构 donut 图

##### 8. 支持分析的数据类型很多，远超 “步数 + 睡眠”

###### 8.1 主要数据种类

项目可处理的数据包括：
