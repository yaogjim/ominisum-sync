#### 4. 工具本身：`fieldtheory` 的工作原理与特点

作者在回复里给出了这个工具的基本信息。

##### 4.1 工具信息

- 工具名：`fieldtheory`
- 价格：**免费**
- 支持系统：**Mac / Linux**

##### 4.2 核心原理

- 它通过读取 **Chrome 浏览器中的会话 Cookie**
- 去调用 **X 的内部 GraphQL API**
- 因此**不需要 X 官方 API Key**

这点很重要，因为很多人卡在“没有 API 权限”这一步，而这个工具绕开了这个门槛。

##### 4.3 安装要求

安装命令：

```bash
npm install -g fieldtheory
```

需要的环境：

- **Node.js 20+**
- **Google Chrome**

#### 5. Mac 上的配置和使用方式

作者还给出了 Mac 的配置步骤，整体流程非常直接。

##### 5.1 前置条件

- 确保 **Chrome 已登录 X**

##### 5.2 首次运行时会做什么

- 第一次运行时，工具会自动从 Chrome 读取会话 Cookie
- 然后同步你的 X 书签到本地

##### 5.3 常用命令

增量同步：

```bash
ft sync
```

- 作用：**只拉取新的书签内容**

全量重新抓取：

```bash
ft sync --full
```

- 作用：**把所有书签重新完整抓取一遍**
