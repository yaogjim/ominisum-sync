## 正文

**宝玉**

NVIDIA GEAR 实验室发布了 ENPIRE，一套让 AI 编程 agent 自主操控真实机器人做实验的系统。是在真实物理世界里跑，让 AI 自己重置场景、跑实验、判断成败、查论文、改代码、再来一轮，人类只需要早上起来看报告就行。

ENPIRE 的全称是 Agentic Robot Policy Self-Improvement in the Real World，由 NVIDIA GEAR 实验室联合 CMU、UC Berkeley 共同开发。Jim Fan 是 GEAR 实验室的联合负责人，他把这个方向叫 AutoResearch，意思是让 AI 来做科研。之前这个概念只在纯数字环境里跑通过，ENPIRE 是第一次把它搬到了物理世界。

系统的运作方式是这样的：给一组 AI 编程 agent 分配一队机器人、一批 GPU 和足够的 token 预算，然后设定一个目标，比如“尽快完成这个任务，让机器人保持忙碌但别出事”。接下来人就可以走了。

agent 会自动做四件事：

1\. 搭建环境：包括自动重置场景和自动判断成败  
2\. 改进操控策略：从启发式学习到行为克隆到强化学习都会尝试  
3\. 在真实机器人上跑实验收集数据  
4\. 分析失败原因并迭代改进代码

整个循环完全自主，不需要人参与。

ENPIRE 测试了几个相当刁钻的操作任务：把细小的 pin 脚精确插入盒子、穿扎带、用剪刀剪扎带、把 GPU 插到主板上。这些都是需要高精度灵巧操作的任务，不是简单的抓取搬运。最终 agent 自主训练出的策略达到了 99% 的成功率（pass@8 标准）。

项目同时测试了三款编程 agent：  
1\. OpenAI 的 Codex（搭配 GPT-5.5）  
2\. Anthropic 的 Claude Code（搭配 Opus 4.7）  
3\. 月之暗面的 Kimi Code（搭配 Kimi K2.6）。

三家的 agent 都能跑通整个流程，但在不同任务上的研究进展速度有差异。

一个比较有意思的发现是他们所谓的“物理 scaling law”：8 台机器人并行探索，比 1 台或 4 台的研究推进速度快得多。

更多机器人意味着更多并行实验，agent 之间还能互相参考对方的成功策略，类似于多个研究者同时攻关同一个问题。不过扩大规模也有代价，token 消耗会显著增加，而且 agent 花在总结同伴进展上的时间会变多，机器人的实际利用率反而下降。

所有代码会开源，让你在家也能搭一个自运行的机器人实验室，但你至少得有一队机器人臂和一批 GPU。开源本身的意义在于，其他机器人实验室可以直接复用这套 agent 驱动的实验框架，省掉大量人工盯实验的时间。

#### ENPIRE 深度总结、通俗解读与辩证思考

##### 一、深度总结

ENPIRE 是 NVIDIA GEAR 实验室联合 CMU、UC Berkeley 推出的一个 **AI 自主机器人科研系统**。

它的核心意义是：  
> 让 AI 编程 Agent 不只在电脑里写代码、跑仿真，而是直接操控真实机器人，在物理世界里自己做实验、失败、分析、改进、再实验。

过去所谓 AutoResearch 多发生在数字环境中，比如代码、数学、仿真任务。ENPIRE 的突破在于把这一套搬进了真实世界。

系统流程大致是：

1. **人类设定目标**
   - 比如让机器人完成某个高精度操作任务。

2. **AI Agent 自主规划实验**
   - 设置环境；
   - 判断成功或失败；
   - 查资料；
   - 写代码；
   - 选择学习方法。

3. **机器人真实执行**
   - 在真实机械臂上反复试错。

4. **AI 分析失败并迭代**
   - 找原因；
   - 改策略；
   - 继续实验。

5. **人类只看最终报告**
   - 不再需要全程盯着机器人。

实验任务包括：

- 插入细小 pin 脚；
- 穿扎带；
- 用剪刀剪扎带；
- 把 GPU 插到主板上。

这些任务都属于高精度、灵巧操作，难度远高于普通抓取搬运。

最终，AI Agent 自主训练出的机器人策略达到了 **99% 成功率，按 pass@8 计算**。

项目还比较了三类编程 Agent：

- OpenAI Codex + GPT-5.5；
- Anthropic Claude Code + Opus 4.7；
- Moonshot Kimi Code + Kimi K2.6。

三者都能跑完整流程，但效率和进展速度存在差异。

另一个重要发现是所谓 **物理 scaling law**：

> 机器人越多，并行实验越多，AI 研究推进越快。

例如 8 台机器人明显快于 1 台或 4 台。  
但规模扩大也带来成本：

- token 消耗增加；
- Agent 之间同步和总结时间变长；
- 机器人实际利用率可能下降。

项目计划开源，让其他实验室复用这套“AI 驱动机器人实验室”框架。

---

##### 二、深入浅出解读

可以把 ENPIRE 理解成：

> 给 AI 配上一批机器人，让它像研究生一样自己做实验。

传统机器人研发像这样：

```text
人类设计方法 → 写代码 → 跑机器人 → 看失败 → 改代码 → 再跑
```

ENPIRE 想改成：

```text
人类给目标 → AI 自己写代码 → 机器人自己实验 → AI 自己总结 → AI 自己改进
```

也就是说，人类从“实验员”变成“老板”：

- 不再亲自盯每一次试错；
- 只负责给方向、看结果、管安全边界。

它的重要性在于，机器人学习长期受限于一个问题：

> 真实世界实验太慢、太贵、太需要人盯。

仿真可以跑很多次，但仿真和现实有差距。  
真实机器人数据最有价值，但采集成本极高。

ENPIRE 的价值就是降低真实世界试错成本：

- AI 自动重置场景；
- AI 自动判断成败；
- AI 自动改代码；
- 多台机器人并行跑；
- 数据和经验持续累积。

如果这条路走通，机器人研发可能从“手工作坊”进入“自动化实验工厂”。

---

##### 三、核心看点

###### 1. AI 开始进入真实科研闭环

它不只是回答问题，而是能：

- 提出尝试；
- 执行实验；
- 观察结果；
- 修改方案；
- 再次验证。

这更接近真正的科研过程。

---

###### 2. 机器人研发可能被大幅加速

过去一个策略可能需要研究人员调几天。  
现在可能变成多个 Agent 和多台机器人通宵并行试错。

这类似软件开发里的 CI/CD，只不过对象从代码变成了机器人行为。

---

###### 3. “物理世界 scaling” 很关键

大模型有 scaling law：模型越大、数据越多，能力越强。  
ENPIRE 提出类似思路：

> 机器人数量、实验次数、Agent 协作规模，也可能带来机器人能力的跃迁。

这意味着未来机器人公司的竞争，可能不仅是算法竞争，也是：

- 机器人集群规模；
- 实验自动化能力；
- 真实世界数据闭环能力的竞争。

---

##### 四、辩证思考

###### 积极面

ENPIRE 代表了一个重要趋势：

> AI 不再只是工具，而开始成为自动化科研流程的一部分。

它可能带来三类变化：

1. **提高研发效率**
   - 少人值守；
   - 自动试错；
   - 快速迭代。

2. **积累高质量真实数据**
   - 真实机器人数据比纯仿真更接近实际应用。

3. **推动通用机器人能力**
   - 高精度装配、维修、制造等场景可能受益。

---

###### 局限面

但也不能过度神化。

第一，ENPIRE 目前仍依赖昂贵基础设施：

- 多台机械臂；
- GPU；
- 大量 token；
- 安全环境；
- 专业工程系统。

它不是普通人马上能在家复现的东西。

第二，成功率指标需要谨慎理解。

99% pass@8 很亮眼，但要看：

- 任务环境是否受控；
- 物体种类是否有限；
- 是否能泛化到陌生场景；
- 单次成功率和多次尝试成功率是否有差别。

第三，真实世界安全问题更复杂。

AI 自动控制机器人，一旦策略出错，可能导致：

- 损坏设备；
- 伤害人员；
- 误操作高价值物体。

所以“自主”必须配套强安全边界。

第四，它更像“自动化实验系统”，还不等于“真正科学家”。

AI 能迭代策略，但是否能提出本质性新理论、发现深层机制，目前仍有限。

---

##### 五、一句话结论

ENPIRE 的意义不只是让机器人学会几个任务，而是展示了一种新范式：

> 未来机器人研发可能由 AI Agent 自动驱动，在真实世界中持续实验、持续学习、持续进化。

它很重要，但还处在早期。  
短期看，是机器人实验室效率工具；  
长期看，可能是“自动化科研工厂”的雏形。

## 结构化（1）

### 2026-06-18 11:52:25

##### 主旨概括

NVIDIA GEAR 实验室联合 CMU、UC Berkeley 发布了 **ENPIRE**，一套让 AI 编程 agent 在真实物理世界中自主操控机器人做实验、改代码、迭代策略的系统。它的意义在于：AI 不再只是在虚拟环境里“做科研”，而是开始能在真实机器人实验室里自主完成研究循环。

##### 1. ENPIRE 是什么：把 AutoResearch 搬到真实世界

ENPIRE 全称是 **Agentic Robot Policy Self-Improvement in the Real World**，由 NVIDIA GEAR 实验室、CMU 和 UC Berkeley 共同开发。

GEAR 实验室联合负责人 Jim Fan 将这一方向称为 **AutoResearch**，也就是“让 AI 来做科研”。此前类似概念主要在纯数字环境中验证，而 ENPIRE 的突破在于：  
- AI agent 直接操作真实机器人；  
- 在真实物理环境中跑实验；  
- 自动判断实验成败；  
- 自动查资料、改代码、继续迭代；  
- 人类只需要最后查看报告。

通俗来说，它像是一个“自动运行的机器人实验室”。

##### 2. 系统如何运作：AI agent 自主完成实验闭环

ENPIRE 的使用方式是：给一组 AI 编程 agent 分配机器人、GPU 和足够的 token 预算，再设定目标，例如“尽快完成任务，同时让机器人保持忙碌但不要出事故”。

之后，人类可以离开，系统会自主完成四类工作：

1. **搭建和维护实验环境**  
   - 自动重置场景；  
   - 自动判断任务是否成功。

2. **改进机器人操控策略**  
   - 尝试启发式方法；  
   - 使用行为克隆；  
   - 使用强化学习等方式优化策略。

3. **在真实机器人上跑实验**  
   - 通过真实操作收集数据，而不是只依赖仿真。

4. **分析失败并迭代代码**  
   - 找出失败原因；  
   - 修改代码；  
   - 再次实验。

整个过程不需要人类持续盯着实验。

##### 3. 测试任务：都是高精度机器人操作

ENPIRE 测试的任务并不是简单的抓取和搬运，而是更接近真实工业场景中的高精度操作，包括：

- 把细小的 **pin 脚** 精确插入盒子；
- 穿扎带；
- 用剪刀剪扎带；
- 把 **GPU 插到主板上**。

这些任务都要求机器人具备较强的灵巧操作能力。最终，AI agent 自主训练出的策略在 **pass@8 标准下达到 99% 成功率**。

##### 4. 测试了三款编程 agent

项目中测试了三家公司的编程 agent：

1. **OpenAI Codex**，搭配 GPT-5.5；  
2. **Anthropic Claude Code**，搭配 Opus 4.7；  
3. **月之暗面 Kimi Code**，搭配 Kimi K2.6。

结果显示，三种 agent 都能跑通 ENPIRE 的完整流程，但在不同任务上的研究推进速度有所不同。

##### 5. “物理 scaling law”：机器人越多，研究越快，但成本也更高

文章提到一个重要发现：所谓 **物理 scaling law**。

实验显示，**8 台机器人并行探索**，比 1 台或 4 台机器人的研究推进速度快得多。原因是：

- 更多机器人可以同时跑更多实验；
- 多个 agent 可以互相参考成功经验；
- 类似多个研究者同时攻关同一个问题。

但规模扩大也有明显代价：

- token 消耗显著增加；
- agent 需要花更多时间总结同伴进展；
- 机器人实际利用率可能反而下降。

也就是说，并不是机器人越多越划算，还要考虑算力、token 和调度成本。

##### 6. 开源意义：降低机器人实验室的人力成本

ENPIRE 的代码将会开源。理论上，其他人也可以搭建类似的自运行机器人实验室，但前提是需要：

- 一队机器人臂；
- 一批 GPU；
- 足够的 token 预算。

对普通个人来说门槛很高，但对机器人实验室而言，这套框架的价值在于：  
可以复用 agent 驱动的实验流程，减少人工盯实验、调代码、反复测试的时间成本。

##### 7. 网友关注点：兴奋与成本担忧并存

热门回复中，很多人感叹“早上起来直接看报告”很像科研自动驾驶，认为 AI 正在学会自己做科研。

也有人指出现实问题：  
- 8 个 Codex agent 加 GPU 和大量 token，成本会很高；  
- “物理 scaling law”虽然能提升速度，但必须先算账；  
- 对普通人来说，长期运行这样的系统可能负担不起。

整体来看，ENPIRE 展示了 AI 自动科研在真实机器人领域的潜力，但距离普通人低成本使用还有不小距离。
