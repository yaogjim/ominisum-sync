#### LinearUncle：在 Claude Code 里调用 Codex 生图

##### 核心观点

Claude Code 本身不能生成图片，而 Codex 可以。作者认为这是 Claude Code 的一个遗憾，但现在可以通过社区做的 **image-gen skill** 或相关插件，在 Claude Code 中直接调用 Codex 生成图片。

##### 解决方案

用户可以把 `image-gen skill` 安装到 Claude Code 中，让 Claude Code 在背后调用 Codex 完成图片生成。

这样就不需要：

- 打开 Codex
- 单独生成图片
- 再复制回 Claude Code

尤其在手机上工作时，可以减少工具切换，保持工作流连续。

##### 插件方式

除了手动安装 skill，也可以使用评论区提到的 `codex-plugin-cc` 插件。该插件已经集成了这个生图能力，使用起来更方便。

##### 延伸讨论

作者还提到一个 vibe coding 技巧：

> 让 LLM 优先使用成熟库或框架，而不是从零开始写代码。

原因是成熟工具更稳定，能显著提升效率和成功率。比如让 Codex 自己绘制复杂思维导图时，节点一多就容易布局混乱；如果使用成熟库，效果会更可靠。

##### 一句话总结

通过 image-gen skill 或 codex-plugin-cc，可以让 Claude Code 间接调用 Codex 生图，减少工具切换，提升 AI 编程与创作的连续性。
