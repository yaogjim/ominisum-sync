## 正文

**前端哥Liam**

### claude 被封号，不用怕，我们有个更快更适合的模型

如何在 Claude Code 中快速体验，蚂蚁即将开源的万亿参数旗舰 MoE 模型 Ling-2.6-1T。

Ling-2.6-1T 是蚂蚁 InclusionAI 在 2026 年 4 月 23 日发布的万亿参数旗舰 MoE 模型，是 Ling 2.6 系列的“满血”版本。它采用 MLA + 混合线性注意力架构，1T 总参数，63B 激活参数，主打 Fast-Thinking 范式——把推理内化进模型，不输出冗长思维链，所以 token 成本只有同级思考模型的约四分之一。

![Image](https://pbs.twimg.com/media/HHEysNHWQAAx_UA?format=jpg&name=large)

我看好多人都在用 cc-switch 那个开源的 Claude code 配置切换器，但是我的场景它不满足，我要同时开多个终端会话，可能一个使用官方的订阅账号，另外一个会话使用 Ling-2.6-1T，相互不干扰。cc-switch是针对全局设置的，改了之后，会影响所有的会话。

核心思路

Claude Code 的模型提供方完全由环境变量控制，而每个终端会话的环境变量是独立的——所以你只需要让两个会话各自加载不同的环境变量即可，根本不需要切换配置文件。

#### 🛠️ 第一步：获取 Ling-2.6-1T 的 API Key

Ling-2.6-1T 即将开源，根据官方发布的信息，它目前已经在 OpenRouter 上线。

1. 前往 OpenRouter 官网并注册/登录账号。
2. 在后台找到 Keys 页面，点击生成一个新的 API Key。
3. 复制并保存好这串 API Key，我们接下来的步骤会用到它。

#### 📥 第二步：在 shell 配置里加个函数

把下面这段加到 \~/.zshrc 或 \~/.bashrc (zsh 示例, bash 几乎一样):

```bash
export OPENROUTER_API_KEY="sk-or-v1-你的key"

# 会话: OpenRouter + inclusionai/ling-2.6-1t
claude-ling() {
  ANTHROPIC_BASE_URL="https://openrouter.ai/api" \
  ANTHROPIC_AUTH_TOKEN="$OPENROUTER_API_KEY" \
  ANTHROPIC_API_KEY="" \
  ANTHROPIC_MODEL="inclusionai/ling-2.6-1t:free" \
  ANTHROPIC_SMALL_FAST_MODEL="inclusionai/ling-2.6-1t:free" \
  CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1 \
  claude "$@"
}
```

#### 🚀 第三步：在 Claude Code 中起飞！

开两个终端窗口/tab:

- 窗口 1: 输入 claude 回车, 直接跑官方订阅
- 窗口 2: 输入 claude-ling 回车, 跑 Ling-2.6-1T。

两个会话互不干扰，因为环境变量只在函数调用的子进程里生效。

进入 Claude Code 后，在窗口 2 里输 /status ，应该能看到 base URL 是 openrouter，模型是 inclusionai/ling-2.6-1t:free

![Image](https://pbs.twimg.com/media/HHEz1G-W8AAR3gl?format=jpg&name=large)

#### 📥 第四步：使用 Ling-2.6-1T 帮我生成一个图书馆的网页

![Image](https://pbs.twimg.com/media/HHEz67OWoAAWVs-?format=jpg&name=large)

最后生成的网页效果如下：

---

##### Ling-2.6-1T 是什么

**Ling-2.6-1T** 是蚂蚁 InclusionAI 发布的旗舰 MoE 模型：

- 总参数规模：**1T**
- 激活参数：**63B**
- 架构：**MLA + 混合线性注意力**
- 特点：主打 **Fast-Thinking**
- 优势：将推理能力内化进模型，不输出冗长思维链，因此 token 成本更低，约为同级思考模型的四分之一

目前该模型已在 **OpenRouter** 上线，可通过 API 使用。

---

##### 为什么不用 cc-switch

很多人用 **cc-switch** 切换 Claude Code 配置，但它更适合全局切换。

作者的需求是：

- 同时打开多个终端会话
- 一个使用 Claude 官方账号
- 一个使用 Ling-2.6-1T
- 两边互不干扰

而 cc-switch 修改的是全局配置，会影响所有会话，因此不适合这个场景。

---

##### 核心思路

Claude Code 的模型提供方由环境变量控制。

而不同终端会话的环境变量是独立的，所以只需要：

> 给不同终端加载不同环境变量，就可以让 Claude Code 使用不同模型。

不需要频繁切换配置文件。

---

##### 操作流程

###### 1. 获取 OpenRouter API Key

先到 OpenRouter 注册账号，并生成 API Key。

Ling-2.6-1T 当前可通过 OpenRouter 调用。

---

###### 2. 在 Shell 配置中添加函数

在 `~/.zshrc` 或 `~/.bashrc` 中添加一个 `claude-ling` 函数。

该函数会临时设置：

- OpenRouter API 地址
- OpenRouter API Key
- Ling-2.6-1T 模型名
- 禁用 Claude Code 非必要流量

这样运行 `claude-ling` 时，就会启动一个使用 Ling-2.6-1T 的 Claude Code 会话。

---

###### 3. 多终端并行使用

打开两个终端：

- 终端 1：输入 `claude`  
  使用 Claude 官方订阅

- 终端 2：输入 `claude-ling`  
  使用 Ling-2.6-1T

由于环境变量只在当前函数启动的子进程里生效，所以两个会话不会互相影响。

这篇文章的价值在于提供了一个实用技巧：
