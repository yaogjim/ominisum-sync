## 结构化（1）

### 2026-07-09 03:30:56

##### 主旨概括

作者分享了一个把 **Codex 订阅接入 Claude Code** 的方法：让 **Fable 5 负责规划与审查**，让 **Codex/GPT 5.5 负责重代码执行**，从而降低 Fable 5 的代币消耗、提升开发效率。作者称这种方式至少可节省 **60% 的 Fable 5 代币消耗**。

---

##### 1. 核心思路：Fable 5 做“指挥官”，Codex 做“执行员”

- 在 Claude Code 中安装 OpenAI Codex 插件后，可以让 Fable 5 调用 Codex。
- 工作分工是：
  - **Fable 5**：负责规划、理解代码仓库、架构决策、任务拆解、最终审查。
  - **Codex / GPT 5.5**：负责具体编码、调试、测试修复、重构、多文件修改等繁重执行任务。
- 作者称，这样可以让 Fable 5 调用 **GPT 5.5 + 最多 10 个子代理协同工作**，显著提升效率。

---

##### 2. 设置步骤：在 Claude Code 中安装 Codex 插件

###### 步骤 1：安装 Codex 插件

在 Claude Code 中执行以下命令：

```bash
/plugin marketplace 添加 openai/codex-plugin-cc
/plugin 安装 codex@openai-codex
/reload-plugins
```

作用是把官方 OpenAI Codex 插件加入 Claude Code 环境。

---

###### 步骤 2：让 Fable 5 完成配置

作者建议粘贴一段提示词，让 Fable 5 自动检查和配置 Codex：

- 运行 `/codex:setup`
- 如果缺少 Codex CLI，就安装它
- 如果 Codex 未认证，就引导用户用 ChatGPT 账户认证
- 验证 Codex 是否能在 Claude Code 中正常运行
- 确认 `codex:codex-rescue` 子代理可用
- 设置过程中不要修改项目代码

核心目的：**一次性完成 Codex 在 Claude Code 中的可用性配置**。

---

###### 步骤 3：完成 ChatGPT/Codex 账户认证

- Fable 5 会触发 Codex 安装流程。
- 用户只需要用自己的 **ChatGPT / Codex 账户认证一次**。
- 认证后，Codex 就可以在 Claude Code 内部运行，并使用用户自己的 Codex 订阅额度。

---

##### 3. 使用方式：明确告诉 Fable 5 如何委派任务

作者建议给 Fable 5 一段固定工作流提示词，核心规则是：

- Fable 5 是“编排者”。
- 遇到复杂实现、调试、测试修复、重构、多文件编辑时，调用 Codex。
- 委派 Codex 时使用：

```bash
/codex:rescue
```

- 优先选择 **GPT 5.5（xtra high）** 作为 Codex 模型。
- 给 Codex 的任务要保持具体、聚焦。
- Codex 完成后，Fable 5 必须再次检查结果。
- 不要盲目信任 Codex 输出。

简单理解：  
**Fable 5 负责想清楚怎么做，Codex 负责把代码写出来，最后 Fable 5 再验收。**

---

##### 4. 作者的进阶建议

作者给出几个实用技巧：

1. **把这套流程做成一个 Skill**
   - 作者将其命名为 `Fable-GPT`。
   - 每次新会话开始时调用这个 Skill，提高复用效率。

2. **用 Skill + Goal 处理长期任务**
   - 对于复杂、耗时的开发任务，Goal 更适合长期执行。

3. **Codex 20x Pro 计划可使用多个子代理**
   - 作者表示自己同时使用 **5–7 个代理**。
   - 并且从未触发 **5 小时限制**。

4. **注意上下文衰减**
   - 长对话经过多次压缩后，上下文质量会下降。
   - 作者建议在 **4 次压缩后清空对话**。
   - 使用 `/handoff` 指令保留上下文，再开启新会话继续工作。

这篇内容本质上是在介绍一种 AI 编程协作流：**Claude Code 中用 Fable 5 做高层规划与审查，用 Codex/GPT 5.5 做具体代码执行**。它的优势是节省 Fable 代币、提高并行处理能力，但需要注意任务拆分、结果复查和上下文管理。

## 通俗精炼（1）

### 2026-09-18 10:58:32

#### 在 Claude Code 中接入 Codex：让 Fable 5 规划、GPT 5.5 执行

作者提出一种多模型协作方式：在 Claude Code 中安装 OpenAI Codex 插件，并使用 ChatGPT/Codex 订阅完成高消耗的编码任务；Fable 5 则负责规划、架构判断和验收。其核心是把昂贵模型当“编排器”，把 Codex 当“执行器”，以降低 Fable 5 的代币消耗。

##### 一次配置即可调用 Codex

安装 `openai/codex-plugin-cc` 后，运行 `/codex:setup`，按提示安装 Codex CLI，并用 ChatGPT 账户认证。验证 `codex:codex-rescue` 子代理可用后，Claude Code 就能通过 `/codex:rescue` 委派任务；设置期间无需修改项目代码。

##### 按任务类型分工，而非盲目切换模型

推荐工作流是：

- Fable 5：理解代码库、制订计划、拆解任务、做架构决策和最终审查。
- Codex：承担实现、调试、测试修复、重构和多文件编辑等重活。
- 委派任务应具体、聚焦；Codex 完成后仍由 Fable 5 检查，不能直接采信结果。

作者建议将流程封装成技能，在会话开始时调用；长期任务可结合多个子代理并行执行。

##### 收益来自订阅额度复用，但效果仅属作者经验

作者声称该方法可节省至少 60% 的 Fable 5 代币，并称自己同时使用 5—7 个代理仍未触及 5 小时限制；另一次任务中，以约一半 Fable 配额和三成 Codex 周额度完成了约三倍工作量。这些数字是个人实践记录，并非通用测评。

主要问题是长会话中的上下文衰减与交接不顺。作者建议约四次上下文压缩后清空会话，并用自定义 `/handoff` 保存必要信息，在新会话继续工作。
