## 分析要点

- **核心高价值点**：后训练的核心障碍可能不只是技术差距，而是目标难定义、效果难验证、成果难展示与资源不足共同构成的负向循环。
- **留存建议**：选择性存档，作为模型研发资源配置与组织问题的观察样本（提出了后训练因目标模糊、评估困难和资源不足而形成负向循环的可复用解释框架。）
- **不足**：主要依据匿名从业者交流和个人推断，缺少数据、具体案例及可核实来源。

**知识要点**

- 预训练可围绕损失、训练时间和成本形成较清晰反馈，而后训练的下游目标更难定义，并存在针对指标进行优化而非真实能力提升的风险。
- 训练数据清洗和具体训练配方通常不公开，使后训练创新更难被外部识别，也更难获得论文、宣传和资源回报。
- 在高不确定性研发中，组织能否持续为长期失败但潜在重要的方向配置人才、算力和时间，可能与技术判断同样关键。

**行动项**

- 评审后训练项目时，明确下游目标、评价指标、指标投机风险及独立验证方式。
- 选择一项模型基础设施优化任务，让Agent按明确吞吐目标检查内核与链路，并由工程师复核结果。
- 在长期研究项目中预先设定续投条件、时间预算和阶段性证据要求。

**axisxy**

继续发一则和国内 model researcher 交流的 memo。今天和某模型厂的一位 post-train researcher 聊了聊。Ta 对「国内在 Pre-training 上更有优势、Post-training 相对落后」这件事，补充了一个视角：

国内基本已经「会做」Pre-training 了，但 Post-training 可能还处在一个比较混沌的阶段。

一个核心原因是，两者的 reward 清晰程度很不一样。

Pre-training 的反馈很明确，比如可能就是在单位时间内，把 Next Token Loss 降得越低越好，同时尽可能降低训练成本。

Post-training 要解决的，则是怎么让模型在下游应用中表现得更好。但怎么定义和评估这个「更好」，以及怎么确认模型是真的变强了、而不是在 hacking 某个指标，都非常 tricky。

此外，Pre-training 的创新也更容易被外界看到。

模型架构没有那么强的机密性，一开源大家就能看到，也可以写成 Paper、拿去做 PR。但一家模型公司的数据是怎么清洗的、具体用了什么训练 Recipe，通常不会拿出来讲。

再加上众所周知的缺卡问题，而模型的绝对能力又是模型厂的生死线，大家自然会把更多资源投入反馈更明确、也更容易获得声量的 Pre-training。

Post-training 因此陷入了一个有点尴尬的循环：因为混沌，所以拿不到足够多的资源；又因为资源不够，这种混沌迟迟无法被解决。

除了这个话题，我们还聊到了几个挺有意思的点：

1/ 「大厂最终一定会赢」是一种偷懒的推论。

模型竞争不是比身价。拥有更多钱、卡和人，不等于一定能训出最好的模型。

在这位 researcher 看来，真正起决定性作用的，可能是组织里到底有多少人发自内心想把模型训好，以及组织摩擦会不会消耗掉这些人的热情。（没有说加入创业公司的人会更有梦想的意思。）

2/ Agent 确实已经在替代 AI Lab 里的一部分工作。（所以我们最近和一些 researchers 交流，感觉有些人确实已经有失业焦虑了。）

拿 Infra 举例，现在可以直接告诉 Agent：「每秒只能输出 50 个 Token，请优化到 60 个」，然后让它自己检查 Kernel 和整条链路。

所以一些 Infra 工程师开始自己给自己找事干，比如跑去研究算法、理解训练需求。

（从这里再往外延伸一步：如果说 AI Coding 模糊了产品、研发和设计之间的边界，那么 AI for AI / RSI 似乎也在逐渐模糊数据、算法和 Infra 之间的边界。

3/ Model Research 本身，可能就是最 Science 的 AI for Science。

我们还探讨了两个没有答案的问题，也列在这里吧，欢迎有想法的朋友分享你的见解～

Q2/ OpenAI 是怎么持续相信 RL 这个方向，并最终把 o1 做出来的？

我们好奇的不是具体的 Recipe，而是背后的组织问题。

想起之前请清华大学叉院的助理教授 @jxwuyi  
录过一期播客（[https://xiaoyuzhoufm.com/episode/67efcaf5f9578163d601286a…](https://xiaoyuzhoufm.com/episode/67efcaf5f9578163d601286a)），他在节目里提到，OpenAI 很早就在做 RL，但之前做了很久都没有得到结果。

那么，在一个方向连续失败很多年以后，他们的团队为什么还能继续相信它，招到人、说服老板、拿到资源，然后真的把事情做出来呢🤔

这个问题可能需要更了解 OpenAI 的朋友来回答了。

最后，其实跟很多 researchers 交流，尤其是问他们觉得哪家模型更有希望时，大家最后都会强调组织文化。

在一个快速变化、资源永远不够的行业里，怎么把人和算力分给那些还没有答案的创新，以及愿意等这些创新多久，可能和技术判断本身一样重要吧。

## 通俗精炼（1）

### 2026-09-18 10:30:37

#### 模型竞争的难点正从预训练转向后训练与组织能力

文章记录了一位国内模型厂后训练研究员的观察：国内团队已较熟练地掌握预训练，但后训练仍处于目标模糊、评价困难的阶段。模型能否继续突破，不只取决于算力和算法，也取决于组织是否愿意为高风险、长期无结果的方向持续投入。

##### 后训练缺少清晰反馈，形成资源困境

预训练可用单位时间内的下一词元损失和训练成本衡量，目标相对明确；后训练则要判断模型在真实应用中是否“更好”，还需排除模型针对评测指标取巧，验证难度更高。

同时，架构创新容易通过开源、论文获得声量，数据清洗和训练配方却通常保密。叠加国内算力紧张，资源更容易流向回报明确的预训练，导致后训练因混沌而缺资源、又因缺资源而长期混沌。

##### 决胜因素可能是组织文化，而非资源总量

“大厂一定赢”被认为是过度简化：钱、卡和人才数量并不自动转化为最好模型。关键还在于有多少人真正想把模型做好，以及组织摩擦是否会耗尽其热情。OpenAI 长期投入强化学习、最终做出 o1，也引出一个组织问题：方向多年不见成果时，团队如何持续招人、争取资源并保持信念。

##### Agent 正在重塑 AI 研发分工

Agent 已能承担部分实验室基础设施工作，例如自动检查 Kernel 和整条推理链路，把输出速度从每秒 50 Token 优化到 60。这迫使 Infra 工程师向算法和训练需求延伸，也让数据、算法与基础设施的边界逐渐模糊。

文章还留下一个开放问题：如何让模型真正理解时间和成本，避免因“永远不必交卷”而无限思考。以上主要来自单次交流，并非行业共识；评论中也有人以国内模型后训练的明显提升提出质疑。
