### 提问 · 2026-03-30 07:51:16

当你在一个中型项目中启动 Claude Code 并发送 'hello' 时，大约会消耗多少 token 以及会发起多少个 API 请求？

### 回答 · 2026-03-30 07:51:16

大致可以按这个量级理解：

- `token 消耗`：通常在几万 token 级别，常见可估算为`2 万～8 万 token`
- `API 请求数`：通常不是 1 次，常见在`3 ~ 10 次请求`左右

如果是 “中型项目” 且 Claude Code 启动时会自动读取目录结构、规则文件、部分代码上下文，那么哪怕你只发一个`hello`，实际消耗也往往主要来自 “加载上下文”，而不是这句问候本身。

更具体一点：
- 轻一点的中型项目：`约 2 万～4 万 token`，`3 ~ 6 次请求`
- 上下文收集更积极时：`约 5 万～8 万 + token`，`6 ~ 10 次请求`
- 如果还读取了`README`、`CLAUDE.md`、若干关键源码、工具调用结果，可能会更高

原因主要是：
- Claude Code 会先收集项目上下文
- 可能分多轮进行工具调用、目录扫描、文件摘要
- 最终才把整理后的上下文和你的`hello`一起送入模型
