## 正文

**躺在废墟里 Lieflat**

一个 skill，让你做出顶级审美的图表。

我开源的 Lieflat Charts 已经在 GitHub 2k star 啦～它是一套数据可视化与报告生成 skill，可供 Moxt、Claude Code、Codex 等 AI agent 使用。

它由统一的字体、留白、线条和动效建立视觉语法，有60多种图型，覆盖柱、线、面积、直方图等基础图型，还有热力图、小提琴图、环形关系图、桑基图等复杂图型，部分还支持交互。

色彩上，以黑白灰单色为基础，也支持青瓷蓝、椰林绿、编辑红三种色系，后续还会尝试更多丰富配色～

这个skill 的原理是用 html 来做图表，好处很明显，有很丰富的动效，可以无缝衔接到 html 做的 PPT 中。如果需要 PPT 格式，也可以让 agent 转成动图贴进 PPT 里。

使用非常简单，装好后把你的数据或者想要可视化的主题告诉agent，agent 会选择合适的图表类型，自动出图。如果你需要出报告，目前也有报告模式，可以一键产出数据可视化报告。

#### Lieflat Charts：让 AI Agent 自动生成统一风格的可视化图表

Lieflat Charts 是一套开源的数据可视化与报告生成 Skill，可接入 Moxt、Claude Code、Codex 等 AI Agent。用户只需提供数据或主题，Agent 就能选择图表类型并生成成品；作者称项目目前已在 GitHub 获得约 2,000 个 Star。

##### 用统一视觉语法覆盖 60 多种图表

该项目通过一致的字体、留白、线条和动效控制整体风格，包含柱状图、折线图、面积图、直方图等基础图表，也支持热力图、小提琴图、环形关系图、桑基图等复杂形式，部分图表可交互。

配色以黑、白、灰为基础，另提供青瓷蓝、椰林绿和编辑红三套色系，强调克制、统一的视觉表达。

##### 基于 HTML，方便动效展示与报告制作

Lieflat Charts 使用 HTML 生成图表，因此更容易实现丰富动效，也能直接嵌入 HTML 制作的演示文稿。若需要传统 PPT，可让 Agent 将动态图转换后插入；报告模式还可一键生成带数据可视化的完整报告。

##### 价值在于降低“选图与排版”门槛

它把图表选择、视觉规范和报告输出封装成 Agent 可调用的能力，适合快速制作汇报与分析材料。其核心卖点不是新的分析方法，而是提高可视化生产效率并保持风格一致；“顶级审美”属于作者定位，原文未提供与其他图表工具的系统比较。
