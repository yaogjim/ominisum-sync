## 结构化（1）

### 2026-03-20 11:14:44

#### 文章主旨

这篇内容主要在介绍**Hermes Agent 与 Pinokio 的联动能力**：用户可以通过一键安装快速部署 Hermes，并让它自动调用本机已安装的应用来完成任务。重点突出的是它的**易用性、跨平台支持，以及 “代理自动操作软件” 的实际演示效果**。

##### 1. Hermes Agent 的定位与核心卖点

- Hermes Agent 被描述为一个**开源代理（open source agent）**，特点是会 “随着用户一起成长”。
- 它具备**多级记忆系统（multi-level memory）**，可以记住学到的内容，并随着时间推移变得更强。
- 同时，它支持**持续的专用机器访问能力**，意思是它不只是一次性对话工具，而是能长期在设备环境中工作。

**通俗理解：**
- 普通聊天助手更像 “问一次答一次”；
- Hermes 更像一个 “能记住上下文、还能长期帮你操作电脑” 的智能代理。

##### 2. 一键安装与部署体验

- 文中重点宣传了**Hermes Agent 1-Click Launcher（一键启动器）**。
- 这个启动器可以完成：
  - 安装 Hermes Agent
  - 启动 Hermes Agent
  - 管理整个**Hermes agent/gateway stack（代理 / 网关栈）**
- 配套展示了一个**52 秒视频**，内容覆盖：
  - 安装
  - 设置
  - 第一次与 Hermes 聊天

**重要信息：**
- 支持**所有操作系统**
- **无需 WSL**
- 可以直接运行在**原生 Windows**上

**这意味着：**
它降低了使用门槛，尤其对 Windows 用户更友好，不需要再额外配置 Linux 子系统。

##### 3. Hermes 与 Pinokio 的联动能力

这一部分是全文最核心的亮点。

- 作者明确提到：**Hermes 可以与 Pinokio 通信，从而自动控制你已经安装的任何应用。**
- 这种控制是 “自动” 的，不需要用户自己逐步打开软件、切换界面、点击执行。

###### 具体案例：自动生成视频

作者举了一个非常具体的例子：

- 用户向 Hermes 提出 “生成视频” 的需求；
- Hermes 会自动开始与**Pinokio**交互；
- 然后它会：
  - 找到相关应用**WanGP**
  - 如果该应用还没启动，就先启动它
  - 运行该应用完成任务
  - 最后把生成好的视频返回给用户

**这个案例说明了什么？**
- Hermes 不只是 “回答问题”，而是能**自主调用工具链完成任务**。
- Pinokio 在这里像一个 “应用调度与控制层”，Hermes 则像 “会思考并发出操作指令的代理”。

**通俗举例：**
就像你对一个助理说 “帮我做个视频”，它不会只告诉你 “你可以打开某某软件”，而是会自己去找软件、打开软件、执行流程，最后把结果交给你。

##### 4. 网关与集成使用情况

- 作者特别补充：**gateway（网关）运行得非常好**。
- 他还提到，自己在测试 Pinokio 7 演示中的代理集成时，实际使用的组合是：
  - **Hermes Agent**
  - **Discord 集成**

**这透露出两个信号：**
- 第一，Hermes 不只是单机运行，还能通过网关接入更完整的工作流；
- 第二，它已经被拿来做实际演示和集成测试，而不是停留在概念阶段。

##### 5. 获取方式与使用入口

作者后来补充了 “如何获取” 的信息：

- 可在**`pinokio.co`**获取
- 位置在 Pinokio 的**“explore” 页面顶部**

这说明 Hermes 的分发方式已经被纳入 Pinokio 的生态入口中，用户不需要到处找安装包。

##### 6. 移动端访问方式

文中还给出一个很实用的小功能：

- 如果手机和电脑处于**同一网络**
- 用户可以在**“Launch” 标签页**点击弹出按钮（popout button）
- 然后**扫描二维码**
- 就能在手机上打开 Hermes Agent 的终端

**这个功能的价值在于：**
- 用户不必一直守在电脑前；
- 可以直接在手机上查看或操作 Hermes 的终端界面；
- 对远程查看状态、临时发命令会更方便。
