> 一句话： **在对话里告诉 AI 你想做什么，它就会打开真实浏览器替你点、替你填、替你查** ——还能给不同账号建独立身份、把成功的操作存成「一键复用」的工作流。重复的网页活儿，从此交给 AI。

#### 它解决什么问题

很多日常事都卡在浏览器里：登录某个平台发内容、查行情、抓数据、走一套固定流程……手工做又慢又烦。NewMax 的浏览器模块让你 **用自然语言指挥 AI 操作浏览器** ，并把这些操作沉淀下来反复用。核心三件事：

1. **对话发指令** → AI 自动操作浏览器
2. **Profile** → 多账号各自独立登录态，互不串号
3. **工作流** → 把一次成功操作存成模板，下次一键复用

从侧栏 **「浏览器」** 进入即可。

浏览器模块总览

进来后左边是 **Profile（浏览器身份）** 列表，右边是 **自动化任务** 。右侧引导卡说得很直接： **「直接在对话中告诉 AI 你想做什么，AI 会自动打开浏览器帮你完成。」** 比如「帮我登录小红书发一条视频笔记」「查一下 HackerNews 今天的热帖」。

下方列着已保存的自动化任务（如 `semrush keyword search` 、 `查看 Google Trends` ），每个都带 **成功率** 徽章——AI 跑得越多越稳。

##### AI 操作时你会看到什么

在对话里发出指令后：

- AI 逐步操作浏览器（打开页面、点击、输入），对话底部有 **实时进度卡** 显示执行到第几步。
- 遇到 **需要你本人处理** 的环节（登录、验证码、人工核对），会弹出 **「需要你来处理一下」** 卡片，你在浏览器窗口里手动完成后点「继续」，AI 接着干——浏览器全程保活，从断点续行。
- 任务做完，会 **自动弹出保存提示** ，问你要不要把这次操作存成工作流。

#### 二、Profile：多账号互不串号

![新建浏览器 Profile](https://mmecoa.qpic.cn/mmecoa_png/kicknDQXfhSvzSAenX4yDvNM3fJDyLGRME9AGDQ3Kqo0m4ibpY9QVA747oUfGK63GOo1mJmsUmGg0PgEYGmVg9Gk4T7Lv2riaU3dGyZsJj71zQ/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=10005&wx_lazy=1#imgIndex=2)

新建浏览器 Profile

点 Profile 区的「+」新建一个身份。如弹窗所说： **「每个 Profile 拥有独立的 Cookie 和登录态，互不干扰。AI Agent 可以使用指定 Profile 自动操作浏览器，无需重复登录。」**

- **名称** ：如「淘宝-店铺A」
- **关联域名** （可选）：如 `taobao.com, tmall.com` ，方便 AI 自动挑对身份
- **默认打开 URL** （可选）

这样「店铺 A」和「店铺 B」用两个 Profile，登录态彼此隔离；标为「默认」的 Profile 还能与 NewMax 应用共享登录态。双击任一 Profile 可直接打开它的独立浏览器窗口。

如果一套操作你想反复用（比如每次查不同关键词、发不同内容），可以 **录一遍** 让 AI 以后照着做。在「浏览器」页选一个 Profile → 点 **「录制」** ，就会打开一个浏览器让你正常操作：

保存为 Workflow

你确认 **Workflow 名称** 、检查 **变量** （哪些输入每次执行时询问你、哪些用固定值）、看一眼 AI 总结的执行策略，保存即可。

#### 四、工作流：一次成功，反复复用

![工作流详情](https://mmecoa.qpic.cn/sz_mmecoa_png/kicknDQXfhSvRCRoSC3udKqNOBicEsFtjSTujvxByiaCnreotz1fmib9Jq4BNsz7AUYbqYJ1tnA3PmAVmribGaC4G7hHu4ZssVpGzImzS2Z4Y8o8/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=10005&wx_lazy=1#imgIndex=5)

工作流详情

AI 完成任务（或你刚录制）后存成的 **工作流** ，可在「自动化任务」列表反复执行。展开一个工作流能看到它的全貌：

- **指令** ：如「在 SEM 关键词分析里查询关键词 `{{keyword}}` 的概览数据」—— `{{ }}` 是 **参数** ，每次执行可换值。
- **执行策略** ：AI 自动总结的正确步骤（「从仪表盘进入 SEM 工具，左侧导航打开关键词概览页，在搜索框输入关键词并点击搜索…」）。
- **成功率 / 执行记录** ：成功率 100%、成功 1 次、上次成功时间。
- **执行任务 / 编辑 / 删除** ：点「执行任务」即按学到的策略自动重放，跑得越多越可靠。

点「执行任务」时，AI 会 **新开一个独立对话** 、先问你参数值（如「关键词」填什么），再按学到的策略自动回放——通常几秒、几乎不耗 token，跑得越多成功率越高。

#### 适用场景

- **重复网页活儿** ：每天查排名/行情、抓固定来源数据、走一套发布流程。
- **多账号运营** ：多个店铺/自媒体账号，用 Profile 隔离，AI 按指定身份操作。
- **半自动协作** ：AI 跑大部分，遇登录/验证码你接手一下，其余交给它。

#### 小提示

- 首次使用需要本机装有 **Chrome** ；没装时模块顶部会有提示和「下载 Chrome」入口。
- 越是「步骤固定」的任务越适合存成工作流；高度依赖临场判断的任务，AI 会在需要时暂停找你。

这段话透露出几个重要信息：

###### 1）NewMax 可能会引入 MultiAgent 架构

所谓 MultiAgent，就是不再只有一个 AI 助手，而是多个 AI Agent 分工协作。

例如：

| Agent 类型 | 可能负责的任务 |
|---|---|
| 研究 Agent | 搜集资料、读网页、整理新闻 |
| 写作 Agent | 生成文章、报告、邮件 |
| 浏览器 Agent | 打开网页、点击、填写、提交 |
| 文件 Agent | 读取本地文件、整理资料 |
| CRM Agent | 记录客户信息、总结跟进事项 |
| 项目 Agent | 维护计划、看板、进度 |

这样一来，NewMax 就不只是“一个 AI 聊天框”，而是一个可以调度多个 AI 工作者的系统。

###### 2）移动办公是优先方向

Yangyi 明确说“我现在最希望的是移动办公”。

这意味着 NewMax 未来可能不只局限于桌面端，而是会往手机端扩展。

移动端的意义很大：

- 出差时可以继续处理工作
- 随时查看 AI 总结的项目进展
- 随手发送任务给桌面端执行
- 接收浏览器自动化、日报、客户跟进提醒
- 与企业微信、飞书等 IM 工具联动

也就是说，手机端不一定承担全部复杂执行，但可能成为一个**随身任务入口和通知中心**。

###### 3）未来可能接入企业微信和客户 Memory 系统

“对外接入企业微信，直接打通客户 Memory 系统”这句话很关键。

它指向的是企业场景，尤其是销售、客服、客户成功、私域运营等场景。

例如：

- 企业微信里和客户聊天
- NewMax 自动总结客户需求
- 生成客户画像
- 记录每次跟进重点
- 提醒下一步该联系谁
- 自动生成回复建议
- 把客户历史信息作为长期 Memory 使用

这会让 NewMax 从个人效率工具进一步靠近企业级 AI 工作流。

###### 4）“缝合”式产品策略

“只要缝得足够多、足够快，大概也能足够好用”是一种非常务实的产品思路。

它的意思不是做一个从零开始的封闭系统，而是把已有的模型、浏览器、文件系统、企业微信、Memory、工作流、Skill 等能力快速拼接起来，形成可用产品。

这种方式的优势是：

- 迭代速度快
- 能快速覆盖真实工作场景
- 不必等待底层技术完全成熟
- 用户能尽早获得效率提升

缺点则是：

- 系统复杂度会上升
- 稳定性需要时间打磨
- 各模块之间的衔接体验很重要
- 权限、安全、数据一致性会变得更关键

##### 三、NewMax 浏览器自动化的核心能力

###### 1. 对话驱动浏览器操作

用户可以直接说：

- “帮我登录小红书发一条视频笔记”
- “查一下 HackerNews 今天的热帖”
- “打开 SEMrush 查这个关键词的数据”
- “帮我看看 Google Trends 上这个话题的趋势”

AI 会自动执行：

1. 打开浏览器
2. 进入指定网页
3. 点击按钮
4. 输入内容
5. 读取页面信息
6. 完成提交或查询
7. 返回结果

这比普通聊天 AI 更进一步，因为它不是“告诉你怎么做”，而是“替你做”。

---

###### 2. Profile：多账号独立身份

NewMax 浏览器模块支持 Profile，也就是浏览器身份。

每个 Profile 有独立的：

- Cookie
- 登录状态
- 账号环境
- 默认网站
- 关联域名

举个例子：

| Profile | 用途 |
|---|---|
| 小红书-账号A | 发布生活类内容 |
| 小红书-账号B | 发布商业类内容 |
| 淘宝-店铺A | 管理店铺 A |
| 淘宝-店铺B | 管理店铺 B |
| 公司账号 | 登录企业后台 |
| 个人账号 | 登录个人工具 |

这样做的好处是：

- 多账号不会串号
- 不需要每次重新登录
- AI 可以自动选择正确身份
- 适合运营、电商、自媒体、销售等场景

对于多账号运营者来说，这个功能非常实用。

---

###### 3. 人机协作：遇到登录、验证码可以人工接管

AI 操作浏览器时，难免会遇到一些它不能或不应该独立处理的环节，比如：

- 登录
- 验证码
- 二次验证
- 支付确认
- 敏感信息填写
- 人工判断页面是否正确

NewMax 的处理方式是：

> AI 暂停，并弹出“需要你来处理一下”的提示。  
> 用户手动完成后点击“继续”，AI 从断点继续执行。

这是一种比较现实的自动化方式。

它没有假装 AI 能解决所有问题，而是让 AI 负责重复操作，人类负责关键判断和敏感步骤。

###### 4. 教学录制：把你的操作录成工作流

如果某个网页流程你经常做，可以自己先操作一遍，让 NewMax 录下来。

例如：

- 每天查一次关键词排名
- 每周导出一次后台数据
- 每次发布文章到多个平台
- 每天查看竞品价格
- 定期生成报表
- 查询 Google Trends 或 SEMrush 数据

录制过程中，NewMax 会记录你的操作步骤：

- 点击了哪里
- 输入了什么
- 滚动了页面
- 提交了哪个表单
- 哪些输入内容可以设为变量

例如，你每次都查不同关键词，就可以把“关键词”设为变量。

之后执行工作流时，AI 会先问：

> 这次要查询的关键词是什么？

你输入关键词后，它就会自动跑完整流程。

---

###### 5. Workflow：一次成功，反复复用

浏览器自动化最有价值的地方在于“沉淀”。

不是每次都让 AI 从头理解网页，而是把一次成功操作保存成 Workflow。

Workflow 中包含：

- 任务指令
- 参数变量
- 执行策略
- 成功率
- 执行历史
- 上次成功时间

这意味着 NewMax 会把“临时执行”变成“可复用资产”。

例如：

```text
在 SEMrush 关键词分析中查询 {{keyword}} 的概览数据
```

这里的 `{{keyword}}` 就是变量。

下次执行时，只需要换关键词即可。

## 结构化（1）

#### NewMax 进化为 AI 操作系统

这意味着 NewMax 的定位正在从“桌面端 AI 工具”升级为能够跨设备、跨应用、跨 Agent 协同的个人或企业 AI 操作系统。

##### 2. 浏览器自动化：用对话让 AI 操作真实网页

NewMax 的浏览器模块允许用户直接用自然语言下达任务，AI 会打开本机 Chrome，自动完成：

- 打开网页、点击按钮和填写表单；
- 查询行情、搜索资料和抓取数据；
- 登录平台、发布内容；
- 跨页面执行固定业务流程。

例如，用户可以说：

> “帮我登录小红书发一条视频笔记。”  
> “查一下 Hacker News 今天的热门内容。”

执行过程中，对话界面会实时显示当前步骤。遇到登录、验证码或人工核对等无法自动完成的环节，系统会暂停并提示用户接管；处理完后点击“继续”，AI 就能从中断位置接着执行，浏览器页面不会丢失。

##### 3. Profile：隔离不同账号和登录状态

浏览器模块支持建立多个独立 **Profile（浏览器身份）**，每个 Profile 都有自己的 Cookie 和登录状态，不会相互串号。

用户可以为 Profile 设置：

- 名称，如“淘宝—店铺 A”；
- 关联域名，如 `taobao.com`、`tmall.com`；
- 默认打开的网址；
- 是否作为默认身份使用。

例如，“店铺 A”和“店铺 B”可以分别建立 Profile，AI 操作时会自动选择对应身份，无需反复登录。双击 Profile，也可以直接打开其独立浏览器窗口。

##### 4. 教学录制：把人工操作教给 AI

对于需要反复执行的网页任务，用户可以先亲自操作一次，让 NewMax 将过程录制成工作流。

录制时：

- 页面会出现绿色边框；
- 系统实时记录点击、输入、滚动等步骤；
- 对于搜索词、发布内容等每次会变化的输入，可以标记为“变量”；
- 录制完成后，AI 会自动精简步骤、识别参数并总结执行策略。

例如，用户演示一次“在 SEM 工具中查询关键词”，之后只需输入不同关键词，AI 就能重复执行完整流程。

密码、验证码和银行卡信息等敏感内容不会记录原文。

##### 5. Workflow：成功一次，后续一键复用

完成任务或教学录制后，可以将操作保存为 **Workflow（工作流）**。工作流包括：

- **执行指令**：如查询 `{{keyword}}` 的关键词数据；
- **可变参数**：每次运行时填写不同内容；
- **执行策略**：AI 总结出的正确操作路径；
- **成功率与历史记录**：用于评估任务稳定性；
- **编辑、运行和删除功能**。

官方示例中，一个工作流显示为 **成功率 100%、成功执行 1 次**。每次运行时，NewMax 会新建独立对话，询问必要参数，再自动回放操作。官方称这类固定工作流通常只需数秒、消耗很少的 Token，并且随着运行次数增加会变得更可靠。

适合保存为工作流的场景包括：

- 每日查询排名、行情或趋势；
- 从固定来源抓取数据；
- 多账号内容发布；
- 店铺后台的重复操作；
- 半自动业务流程。

首次使用浏览器自动化时，本机需要安装 Chrome。

##### 6. 本地 AI 工作区：文件、工具和任务统一管理

此外，用户可以设置按天、按周或指定时间运行的任务。AI 洞察功能还能生成每日回顾，以及按周、双周或月度输出趋势、路线图和研究主题，并推送到配置好的即时通讯渠道。

NewMax 兼容多家云端和本地模型服务，包括：

- Antigravity、OpenCode、OpenRouter；

不同对话可以独立选择模型。系统支持按照任务智能路由，并在某个模型调用失败时切换到其他模型，减少工作流中断。

这让用户可以根据任务分工：用一个模型写代码、另一个模型写文案，再用本地模型处理敏感资料。

- **教育**：根据本地研究资料生成阅读清单、讲义大纲和练习题，将数天的备课压缩到数小时。
- **销售**：连续完成通话转写、跟进邮件和 CRM 记录，减少多工具之间的复制粘贴。
- **财务**：用 Skill 处理报表核对、异常项整理和审计底稿，减少月结期间的重复劳动。
- **内容团队**：在一台电脑上完成提案、简报、素材整理和录音转写。
