## 正文

**耳朵**

Coze 支持多 Agent 协作了， 同时还支持了 Claude Code、Codex 和 OpenClaw 协作。

最近 Coze 发布了新版本，把一些好玩法都集成进来了。

我觉得这次更新最强大的特性就是 Agent 协作，Coze 的 Agent 协作有两个特点：一是多 Agent 能在同一个项目里分工协作，二是 Agent 的来源变得非常自由——云端和本地都支持，不止是 Coze Agent，主流 Agent 都可以接进来。

1️⃣ 多 Agent 协作

多 Agent 协作这个玩法，各路大神都验证过其效果了，甚至 Codex 还出了专门的官方插件，但是这个功能在很多 Agent 产品中都没产品化，Coze 算是第一个提供多 Agent 工作流的主流产品。

新版本的 Coze 中，你可以在一个会话里同时加入多个 Agent，每个 Agent 都能设置不同的角色、技能、模型。

新建项目时，选择多个 Agent，主 Agent 会自动识别项目里的其他 Agent，并按各自的技能派活。

比如让 Claude Code 做规划，接着让 Codex Review 任结果，然后再交给扣子原生 Agent 做文案润色和生成素材，整个过程在一个项目里自然流转。

团队多人加入后，也能分别提出需求、补充背景或做关键决策，人和 Agent 混合编组，@ 一下就能把任务指给对应角色。

2️⃣ 云端 Agent 和 本地 Agent 都能加

更厉害的是 Agent 的来源几乎不受限制，可以加入云端 Agent 和本地 Agent。

云端支持：除了扣子原生 Agent，现在还能创建云端 Claude Code、Codex CLI 和 OpenClaw 的云端版本，Coze 直接提供了云电脑，你选择这些 Agent 之后，Coze 会进行云端自动部署，不用你自己维护环境，持续在线，长期记忆和上下文不中断。

本地支持：如果你自己的电脑上已经有了 Claude Code 、Codex CLI 或 OpenClaw，可以一行命令接入 Coze，这样你的本地 Agent 就能访问你的本机代码和文件，同时进入同一个项目参与协作。

这些能力叠加之后，效果就非常棒：不同专长的 Agent 同时待命，多轮接力处理复杂任务，你只需要在合适的环节 @ 一下。

目前几乎所有 AI 应用场景，多 Agent 协作现在都是必不可少的，架构、编码、测试、Review，这些动作天生就不适合混杂在一个 Agent Session 中。

\---

除了多 Agent 协作，扣子编程和视频创作能力也有大升级。

扣子编程现在新增了设计引导工具、多对话支持等，且内置了很多编程skill，把从想法、设计、协作、开发到部署这一整条链路都压缩进一个项目环境里。

而在视频项目中，用户可以将灵感、脚本、分镜、素材、剪辑这些彼此割裂的环节，放在同一个项目中连续推进。

##### 一、总结

Coze 新版本核心升级：**支持多 Agent 协作**。

主要亮点：

- **多个 Agent 可在同一项目里协作**
  - 可分角色、分技能、分模型
  - 例如：Claude Code 做规划，Codex 做代码 Review，Coze Agent 做文案和素材

- **Agent 来源更开放**
  - 支持 Coze 原生 Agent
  - 支持云端 Claude Code、Codex CLI、OpenClaw
  - 也支持本地 Claude Code、Codex CLI、OpenClaw 接入

- **云端和本地都能用**
  - 云端：Coze 提供云电脑和自动部署
  - 本地：可访问本机代码和文件

- **编程和视频创作也升级**
  - 编程：从想法、设计、开发到部署都放进一个项目
  - 视频：灵感、脚本、分镜、素材、剪辑可连续推进

---

##### 二、解读

简单说，Coze 想做的是：

> 把多个 AI 助手放进同一个“项目群聊”里，让它们像团队成员一样分工合作。

以前使用 Claude Code、Codex、OpenClaw，往往是：

- 一个窗口写代码
- 一个窗口审代码
- 一个窗口做文案
- 上下文容易断
- 文件和任务难同步

现在 Coze 的思路是：

- 你建一个项目
- 拉进多个 Agent
- 每个 Agent 负责不同任务
- 需要谁干活，就 `@谁`

这更像一个 **AI 工作室**：

| 角色 | 任务 |
|---|---|
| Claude Code | 架构、规划、复杂代码 |
| Codex | 编码、Review、修 bug |
| Coze Agent | 文案、素材、流程衔接 |
| OpenClaw | 自动化操作、本地任务 |

这样复杂任务不再压给一个 AI，而是让多个 AI 接力完成。

---

##### 三、我的意见

这是一次很重要的升级。

因为未来 AI 工具的关键，不只是“单个模型有多强”，而是：

> 能不能把多个 AI、多人协作、文件、代码、流程整合到一个项目里。

Coze 这次的方向是对的，尤其适合：

- 软件开发
- 产品设计
- 内容创作
- 视频制作
- 自动化工作流

不过也要注意：

- 多 Agent 协作容易变复杂
- 任务分配不好，反而会混乱
- 云端 Agent 涉及代码和文件，隐私安全要重视
- 最终效果仍取决于提示词、权限、上下文管理

一句话评价：

> Coze 正在从“做 Bot 的平台”，升级成“AI 团队协作平台”。这比单纯堆模型更有价值。
