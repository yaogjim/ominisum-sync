## 结构化（1）

### 2026-03-15 06:44:57

这篇文章的主旨是：带你从 0 到 1 理解并搭建一个类似 Claude Code 的 AI 编程 Agent，而且采用“每次只增加一个机制”的渐进式学习方式。核心思想是先掌握最基础的 Agent 循环，再逐步叠加工具、规划、记忆、并发、协作和隔离等能力。

---

###### 1. 先理解所有 AI 编程 Agent 的共同核心
文章指出，几乎所有 AI 编程 Agent 都共享同一个最基本的工作循环：

- 调用模型
- 执行工具
- 把工具结果回传给模型
- 重复以上过程，直到模型不再请求工具

原文还给出了一个简化版循环代码逻辑：

```python
while True:
    response = client.messages.create(messages=messages, tools=tools)
    if response.stop_reason != "tool_use":
        break
    for tool_call in response.content:
        result = execute_tool(tool_call.name, tool_call.input)
        messages.append(result)
```

**关键点：**
- Agent 的本质不是“很复杂的魔法系统”，而是一个循环。
- 真正复杂的是在这个循环之上继续叠加其他机制。

---

###### 2. 生产级系统不是换核心，而是在核心循环上加层
文章强调，生产级 Agent 系统并不是推翻这个基础循环，而是在其上增加更多能力层，包括：

- **策略层**
- **权限控制层**
- **生命周期管理层**

**通俗理解：**  
基础循环像“发动机”，而生产级系统是在发动机外再加上方向盘、刹车、安全系统和调度系统，让 Agent 更可靠、更可控。

---

###### 3. Agent 执行时，消息会不断增长
文章专门提到一个很重要的观察点：**消息数组会随着循环执行不断增长**。

示例中展示了消息结构的增长过程：
- `messages[] len=3`
- 包含：
  - `user`
  - `assistant`
  - `tool_call`

**关键点：**
- Agent 不是每次都“重新开始”，而是带着之前的上下文继续工作。
- 随着消息变多，上下文管理会变成一个实际问题，这也为后面的“记忆管理”课程埋下伏笔。

---

###### 4. 学习路径采用渐进式设计，共 12 个课程
文章给出了一条完整学习路径：**共 12 个渐进式课程**，目标是从最简单的循环，一步步走到“隔离化自治执行”。

**起点：**
- 从简单 Agent Loop 开始

**终点：**
- 实现带任务隔离的自治 Agent

**关键点：**
- 不是一上来做复杂系统，而是一次只学一个机制。
- 这种设计更适合理解 Agent 系统为什么会逐渐复杂。

---

###### 5. 完整 Agent 架构由五类正交关注点组成
文章指出，一个完整的 Agent 架构可以看成由**五个相互独立但可组合的关注点**构成。并且给出了各模块对应的课程版本分布：

###### Tools & Execution（工具与执行）
- **2 个版本**
- `s01: The Agent Loop`
- `s02: Tools`

这是最基础的能力：让模型不仅能回答，还能真正调用工具做事。

###### Planning & Coordination（规划与协调）
- **4 个版本**

这部分说明 Agent 不只是“被动调用工具”，还会逐步学会任务拆解、流程安排和步骤协同。

###### Memory Management（记忆管理）
- **1 个版本**
- `s06: Compact`

重点是解决上下文越来越长的问题，让 Agent 能更高效地保留关键信息。

###### Concurrency（并发）
- **1 个版本**
- `s08: Background Tasks`

表示 Agent 可以不只做一件事，还能处理后台任务，提高执行效率。

###### Collaboration（协作）
- **4 个版本**
- `s09: Agent Teams`
- `s10: Team Protocols`
- `s11: Autonomous Agents`
- `s12: Worktree + Task Isolation`

这是更高级的阶段，重点是多个 Agent 如何分工协作，以及如何实现自治和任务隔离。

---

###### 6. 文中的重要案例：从单 Agent 到隔离化自治执行
文章列出的后期课程本身就是一个很典型的演进案例：

- `s09: Agent Teams`：多个 Agent 组成团队协作
- `s10: Team Protocols`：为团队协作设计协议
- `s11: Autonomous Agents`：让 Agent 具备更强自治能力
- `s12: Worktree + Task Isolation`：通过工作树和任务隔离，实现更安全、独立的执行环境

**通俗例子：**  
一开始像一个人单独干活；  
后面变成一个团队分工；  
再后面不仅团队能合作，还能在彼此隔离的环境里独立完成任务，避免互相干扰。

---

这篇文章的核心价值在于：它把 Claude Code-like Agent 的构建过程拆成了**12 个循序渐进的模块**，从最小可运行循环出发，逐步加入工具、规划、记忆、并发和协作机制。文章中最重要的数据和结构信息包括：**12 个课程、5 类架构关注点，以及从 `s01` 到 `s12` 的完整演进路径**。
