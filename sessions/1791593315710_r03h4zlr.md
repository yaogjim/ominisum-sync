## 通俗精炼（1）

### 2026-10-10 00:47:47

#### 扩大模型规模，能否让大语言模型学会真正复杂的推理？

Dwarkesh Patel 提出了一个尚未得到令他满意的回答的问题：当大语言模型暴露出能力局限时，研究人员常说“规模会解决”，但凭什么相信这些局限会随着模型变大而消失？回复中的分歧集中在：**把“下一个词预测得更准”，是否最终会迫使模型学会复杂推理，还是需要预训练规模之外的改进？**

需要说明：原帖的具体问题放在图片中，而提供的材料没有图片文字。因此，无法完整还原他质疑的具体能力；以下总结依据可见正文和回复，不把任何一条回复当作原问题的完整表述。

##### 1. Patel 追问的是：为什么“规模会解决”不是一句未经证明的承诺？

Patel 表示，无论在播客上还是私下交流中，他都没有听到好的回答。研究人员经常用“扩大规模”回应他的担忧，但他想知道：对于认为这些问题反映了模型根本局限的人，有什么有力反驳？

这里需要区分两种判断：

- **目前模型做不好，是因为规模还不够。**模型更大、训练更充分后，可能掌握所需能力。
- **目前模型做不好，暴露的是学习方式本身的限制。**继续扩大同一种训练方式，未必能解决问题。

讨论的关键不是规模有没有用，而是：**它为什么能够解决某一种能力缺陷，而不只是让模型更擅长原本就会做的事情？**

##### 2. 最具体的回应：简单规律先被学会，复杂能力可能随后出现

Eric J. Michaud 给出了一个可能的解释。他首先强调：忽略微调和 RLHF 等后续训练，大语言模型的预训练目标是降低人类文本上的“下一 token 预测损失”。

Token 可以理解为模型处理文本的基本单位，可能是一个字、词或词的一部分。“降低预测损失”，就是让模型给实际出现的下一个 token 更高的概率。

在这个目标下，模型学到什么，取决于两个问题：

1. **它有没有能力学会？**小网络可能容纳不了复杂的规律或算法。
2. **学会之后，对预测目标有没有足够帮助？**一种能力即使重要，也不代表它会成为模型优先学习的东西。

Michaud 的设想是，训练中存在一批更容易获取的收益。例如，模型可以先学 token 出现的频率、常见的相邻 token 组合，再学会利用上下文中重复的片段、简单语法规则和各种知识。

**这些简单规律可能比复杂推理更容易学，也更能在早期降低预测损失。**因此，小模型没有表现出高层次能力，不一定说明它永远学不会；也可能是它还在学习那些更容易、回报更直接的规律。

##### 3. “规模会解决”的关键推理：简单办法用尽后，复杂能力才值得学习

沿着 Michaud 的解释，扩大规模带来的希望是：

> 当简单规律已经被充分利用，模型若还想把预测误差再降低一点，就可能需要学会更复杂的算法，包括人们真正关心的高层次认知能力。

这连接了“预测文本”和“复杂推理”：如果正确预测某些文本必须理解其中的复杂关系，那么学习这些关系就可能成为继续改善预测表现的途径。

但 Michaud 把这称为一种**希望和粗略设想，而不是已经证明的结果**。这段推理要成立，至少需要模型能够学到那些复杂能力，而且学习它们确实能进一步改善训练目标。

所以，这个回复解释了“为什么复杂能力可能晚出现”，却没有证明：

**只要模型足够大，所有重要的复杂能力就必然出现。**

##### 4. 其他回复提出了两条不同方向：改变推理方式，或承认根本局限

###### roon：突破未必只靠扩大预训练

roon 认为，更好、更有创造性的 LLM 推理方式会解决问题，但不会仅仅通过扩大预训练规模实现。

这与“把模型训练得更大就够了”有所不同：它把希望也放在模型如何进行推理上，而不只是预训练阶段的规模。不过，提供的回复没有说明具体方法，也没有给出验证依据。

###### Jeremy Howard：组合性问题可能是根本性的

Jeremy Howard 直接表示，这确实是一个根本性局限，并提到 Yann LeCun 长期持有类似观点，以及一些研究显示这些模型存在组合性局限。

“组合性”可以理解为：**把已经掌握的元素和规则，正确组合到没见过的新情境中。**例如，分别会执行“先做 A 再做 B”和“满足条件 C 时跳过 B”，不代表模型一定能正确处理两条规则同时出现的任务。这是帮助理解概念的例子，不是原帖中的实验。

Howard 提到了对 Yejin Choi 团队论文的解读，但提供的材料没有展开论文内容。因此，我们能确认的是他提出了这一反对立场，不能据此判断研究证明了多大范围的局限，更不能直接推出“任何规模的模型都无法克服它”。

##### 5. 这场讨论真正留下的未解问题

这些回复没有形成共识，而是指出了几种不同可能：

- 当前能力不足，可能是因为模型先学习了更容易降低预测损失的规律，复杂能力尚未被学到。
- 某些问题可能需要更好的推理方式，而非仅靠扩大预训练。
- 某些缺陷也可能反映现有方法的根本限制，例如难以可靠地组合已知规则。

**Patel 要求补上的，是从“预测损失还能继续下降”到“我们关心的复杂能力会因此获得”的论证。**Michaud 给出了一个合理的可能机制，但这段讨论尚未说明：哪些能力会出现、需要什么条件，以及哪些局限不能靠规模本身解决。
