## 正文

**Frank Wang 玉伯**

刚听完橘子和 Mars 录的这期播客。比那篇爆款文章好看很多。几个很值得创业者关注的大实话：

1\. 不是 SaaS 已死、Agent 永生，而是 SaaS 已平、Agent 暴增。最好的创业机会，往往在人口增量上。人类 DAU 已饱和，agent 却有机会暴增。这是最核心的一条。认可了这一条，下面的就都是推论。

2\. Agent 是用户，因此要面向 agent 去做产品。GUI 就没啥必要了。SaaS 可以变成给 agent 提供 skills 等服务。Agent 更懂 agent，因此实现层面，也可以用 agent 去实现。这是橘子定义的 agent-native 组织（for agents + by agents）。

有意思的是，主观点之外，橘子在播客中也透露几个人味思考：

3\. 钱还在人手上。由此还是得跟 Stripe 打交道，还是得做让人类付钱的 GUI 界面。不然收不到钱。

4\. 做有 GUI 界面的 agent 依旧很值得一搏。服务人类的主要 agent 入口已经被 LLM 和大厂把握住了。然而人类总是很奇怪，会不喜欢大厂的东西。历史上总有些新公司，能成功挑战大公司。增量市场足够大，依旧很值得去博一把，去成为服务人类的 agent 入口之一。

第 1 和 2 点变成共识后，第 4 点反而是一个非共识的常识。偷偷去做，悄悄做大。疯狂去做 agent-native 的 GUI SaaS 产品，是橘子藏在文章背后的真正行动点。谁能做出 agent 时代服务好人类的 SaaS，谁有机会真正永生。

## 结构化（1）

### 2026-03-17 06:55:20

这段内容的主旨是：作者听完一档播客后认为，比起“`SaaS 已死、Agent 永生`”这种夸张说法，更关键的判断是：`SaaS 增长趋平，Agent 正在进入暴增阶段`。对创业者来说，真正值得抓住的是“agent 作为新增用户群体”带来的机会。

- 第一部分：核心判断是“增量在哪”
  - 作者认为，最重要的不是争论 SaaS 和 Agent 谁取代谁，而是看用户增量来自哪里。
  - 人类的 `DAU` 基本接近饱和，但 `agent` 的数量有机会快速增长，这才是创业机会的根源。
  - 原文强调：`“最好的创业机会，往往在人口增量上”`，这里的“人口”指的是 agent 这类新型用户。

- 第二部分：既然 Agent 是用户，产品就要面向 Agent 设计
  - 既然 agent 会成为主要用户，产品形态就不能只围绕人类界面设计。
  - 作者提出：`GUI 不再是必需品`，SaaS 可以转变为给 agent 提供 `skills` 或服务能力的平台。
  - 在实现方式上，也可以用 agent 来构建服务 agent 的产品，这被概括为 `agent-native 组织`：`for agents + by agents`。
  - 简单说，就是“用户是 agent，生产工具也越来越由 agent 参与完成”。

- 第三部分：现实约束仍然存在，钱还在人类手里
  - 虽然 agent 可能成为新用户，但付款的人暂时还是人类。
  - 因此，创业者依然要和 `Stripe` 这类支付体系打交道，也仍然需要让人类能完成支付的 `GUI` 界面。
  - 这说明：纯 agent 产品在商业化上还不能完全脱离人类操作链路。

- 第四部分：面向人类的 Agent 产品，仍然值得做
  - 作者指出，服务人类的主要 agent 入口，目前确实更容易被 `LLM` 公司和大厂掌握。
  - 但他也强调一个现实案例式判断：`人类常常不喜欢大厂产品`，历史上一直有新公司挑战大公司的机会。
  - 因为市场增量足够大，所以“做有 GUI 的 agent 产品”依然非常值得下注，仍有机会成为服务人类的重要入口之一。

- 第五部分：作者提炼出的真正行动点
  - 当前如果大家都接受了前两点，那么真正的“非共识机会”反而是第 4 点。
  - 作者认为，播客背后更实际的行动建议是：`悄悄去做 agent-native 的 GUI SaaS 产品`。
  - 也就是说，一边拥抱 agent 时代，一边继续把人类服务好，可能才是更现实也更大的机会。
  - 原文最后的判断很直接：`谁能做出 agent 时代服务好人类的 SaaS，谁就更有机会真正“永生”。`
