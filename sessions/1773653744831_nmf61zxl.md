v0.3.3

`abe067a`

#### \[0.3.3\] - 2026-03-03

##### Added

- **`ask --save-as-note`** - Save chat answers as notebook notes directly from the CLI ([#135](https://github.com/teng-lin/notebooklm-py/pull/135))
  - `notebooklm ask "question" --save-as-note` - Save response as a note
  - `notebooklm ask "question" --save-as-note --note-title "Title"` - Save with custom title
- **`history --save`** - Save full conversation history as a notebook note ([#135](https://github.com/teng-lin/notebooklm-py/pull/135))
  - `notebooklm history --save` - Save history with default title
  - `notebooklm history --save --note-title "Title"` - Save with custom title
  - `notebooklm history --show-all` - Show full Q&amp;A content instead of preview
- **`generate report --append`** - Append custom instructions to built-in report format templates ([#134](https://github.com/teng-lin/notebooklm-py/pull/134))
  - Works with `briefing-doc`, `study-guide`, and `blog-post` formats (no effect on `custom`)
  - Example: `notebooklm generate report --format study-guide --append "Target audience: beginners"`
- **`generate revise-slide`** - Revise individual slides in an existing slide deck ([#129](https://github.com/teng-lin/notebooklm-py/pull/129))
  - `notebooklm generate revise-slide "prompt" --artifact <id> --slide 0`
- **PPTX download for slide decks** - Download slide decks as editable PowerPoint files ([#129](https://github.com/teng-lin/notebooklm-py/pull/129))
  - `notebooklm download slide-deck --format pptx` (web UI only offers PDF)

##### Fixed

- **Partial artifact ID in download commands** - Download commands now support partial artifact IDs ([#130](https://github.com/teng-lin/notebooklm-py/pull/130))
- **Chat empty answer** - Fixed `ask` returning empty answer when API response marker changes ([#123](https://github.com/teng-lin/notebooklm-py/pull/123))
- **X.com/Twitter content parsing** - Fixed parsing of X.com/Twitter source content ([#119](https://github.com/teng-lin/notebooklm-py/pull/119))
- **Language sync on login** - Syncs server language setting to local config after `notebooklm login` ([#124](https://github.com/teng-lin/notebooklm-py/pull/124))
- **Python version check** - Added runtime check with clear error message for Python &lt; 3.10 ([#125](https://github.com/teng-lin/notebooklm-py/pull/125))
- **RPC error diagnostics** - Improved error reporting for GET\_NOTEBOOK and auth health check failures ([#126](https://github.com/teng-lin/notebooklm-py/pull/126), [#127](https://github.com/teng-lin/notebooklm-py/pull/127))
- **Conversation persistence** - Chat conversations now persist server-side; conversation ID shown in `history` output ([#138](https://github.com/teng-lin/notebooklm-py/pull/138))
- **History Q&amp;A previews** - Fixed populating Q&amp;A previews using conversation turns API ([#136](https://github.com/teng-lin/notebooklm-py/pull/136))
- **`generate report --language`** - Fixed missing `--language` option for report generation ([#109](https://github.com/teng-lin/notebooklm-py/pull/109))

##### Changed

- **Chat history API** - Simplified history retrieval; improved conversation grouping with parallel fetching ([#140](https://github.com/teng-lin/notebooklm-py/pull/140), [#141](https://github.com/teng-lin/notebooklm-py/pull/141))
- **Conversation ID tracking** - Server-side conversation lookup via new `hPTbtc` RPC (`GET_LAST_CONVERSATION_ID`) replaces local exchange ID tracking
- **History Q&amp;A population** - Now uses `khqZz` RPC (`GET_CONVERSATION_TURNS`) to fetch full Q&amp;A turns with accurate previews ([#136](https://github.com/teng-lin/notebooklm-py/pull/136))

##### Infrastructure

- Bumped `actions/upload-artifact` from v6 to v7 ([#131](https://github.com/teng-lin/notebooklm-py/pull/131))

v0.3.0

`7a40b30`

#### What's New

##### New Features

- **Language settings** - Configure output language for artifact generation (80+ languages)
- **Sharing API** - Programmatic notebook sharing management (`client.sharing.*`)
- **`SourceType` and `ArtifactType` enums** - Type-safe source/artifact identification
- **`.kind` property** - Unified type access across Source, Artifact, SourceFulltext
- **`--retry` flag** - Automatic retry with exponential backoff on rate limits
- **Centralized exception hierarchy** - All errors inherit from `NotebookLMError`
- **CLI `share` command group** - Notebook sharing from command line

##### Deprecated (to be removed in v0.4.0)

- `Source.source_type` → use `.kind` instead
- `Artifact.artifact_type` → use `.kind` instead
- `Artifact.variant` → use `.kind`, `.is_quiz`, or `.is_flashcards` instead
- `SourceFulltext.source_type` → use `.kind` instead
- `StudioContentType` → use `ArtifactType` instead

See [Migration Guide](https://github.com/teng-lin/notebooklm-py/blob/v0.3.0/docs/stability.md#migrating-from-v02x-to-v030) for upgrade instructions.

##### Fixed

- Silent failures in CLI now properly report errors
- Source type emoji display consistency

##### Changed

- Source type detection uses API-provided type codes
- CLI file handling simplified to use `add_file()`

##### Removed

- `detect_source_type()` - replaced by `Source.kind`
- `ARTIFACT_TYPE_DISPLAY` - replaced by `get_artifact_type_display()`

#### \[0.2.0\] - 2026-01-14

##### Added

- **Source fulltext extraction** - Retrieve the complete indexed text content of any source
  - New `client.sources.get_fulltext(notebook_id, source_id)` Python API
  - New `source fulltext <source_id>` CLI command with `--json` and `-o` output options
  - Returns `SourceFulltext` dataclass with content, title, URL, and character count
- **Chat citation references** - Get detailed source references for chat answers
  - `AskResult.references` field contains list of `ChatReference` objects
  - Each reference includes `source_id`, `cited_text`, `start_char`, `end_char`, `chunk_id`
  - Use `notebooklm ask "question" --json` to see references in CLI output
- **Source status helper** - New `source_status_to_str()` function for consistent status display
- **Quiz and flashcard downloads** - Export interactive study materials in multiple formats
  - New `download quiz` and `download flashcards` CLI commands
  - Supports JSON, Markdown, and HTML output formats via `--format` flag
  - Python API: `client.artifacts.download_quiz()` and `client.artifacts.download_flashcards()`
- **Extended artifact downloads** - Download additional artifact types
  - New `download report` command (exports as Markdown)
  - New `download mind-map` command (exports as JSON)
  - New `download data-table` command (exports as CSV)
  - All download commands support `--all`, `--latest`, `--name`, and `--artifact` selection options

##### Fixed

- **Regional Google domain authentication** - SID cookie extraction now works with regional Google domains (e.g., google.co.uk, google.de, google.cn) in addition to google.com
- **Artifact completion detection** - Media URL availability is now verified before reporting artifact as complete, preventing premature "ready" status
- **URL hostname validation** - Use proper URL parsing instead of string operations for security

##### Changed

- **Pre-commit checks** - Added mypy type checking to required pre-commit workflow

## 结构化（1）

### 2026-03-16 09:33:44

这篇发布记录主要总结了 `notebooklm-py` 从 `v0.1.4` 到 `v0.3.4` 的功能演进与问题修复。整体看，项目在这段时间里一边快速扩展 CLI / Python API 能力，一边持续提升稳定性、兼容性和下载/导出体验。

- 从早期能力扩展开始：`v0.1.4` 到 `v0.2.0`
  - `v0.1.4` 增加了更细的“按来源操作”能力：在 `ask` 或 `generate` 命令里可用 `--sources` 只选择特定资料。
  - 同时优化了研究相关显示，比如 `research status` 会把来源整理成表格，便于查看。
  - `v0.2.0` 是一次明显的大版本增强，重点补齐“内容提取”和“结果导出”：
    - 新增“源文本全文提取”，可通过 `client.sources.get_fulltext()` 或 `source fulltext &lt;source_id>` 获取完整索引文本。
    - 新增聊天引用追踪，`AskResult.references` 会给出 `source_id`、引用文本、字符位置、`chunk_id` 等细节。
    - 新增多种下载能力：`quiz`、`flashcards` 可导出为 `JSON/Markdown/HTML`，`report` 导出为 Markdown，`mind-map` 导出为 JSON，`data-table` 导出为 CSV。
  - 这一阶段也修复了关键问题，例如：
    - 支持区域性 Google 域名登录，如 `google.co.uk`、`google.de`、`google.cn`。
    - 只有在媒体 URL 真正可用时才判定 artifact 完成，避免“过早 ready”。

- 认证、诊断与可观测性增强：`v0.2.1`
  - `v0.2.1` 的重点是“更容易排查登录和接口问题”。
  - 新增 `notebooklm auth check`，可检查：
    - 认证文件位置和有效性；
    - 当前有哪些 cookies、属于哪些域名；
    - 是否使用了 `NOTEBOOKLM_AUTH_JSON`、`NOTEBOOKLM_HOME`；
    - `--test` 可做网络验证，`--json` 适合 CI/CD。
  - 新增结构化日志，支持用 `NOTEBOOKLM_LOG_LEVEL` 控制 `DEBUG/INFO/WARNING/ERROR`。
  - 还加入 RPC 健康监控，能自动发现 Google API 方法 ID 变化，并创建带 `rpc-breakage` 标签的 GitHub issue。
  - 同时修复 cookie 域名优先级问题：优先使用 `.google.com`，提升认证稳定性。

- 核心能力升级与接口整理：`v0.3.0`
  - `v0.3.0` 是另一个重要节点，新增了几项“核心基础能力”：
    - 语言设置：支持 `80+` 种语言的生成输出。
    - 分享 API：可用 `client.sharing.*` 管理 notebook 分享。
    - 引入 `SourceType`、`ArtifactType` 枚举，以及统一的 `.kind` 属性，让类型识别更规范。
    - CLI 增加 `--retry`，在限流时自动指数退避重试。
    - 统一异常体系，所有错误继承自 `NotebookLMError`。
    - 新增 CLI 的 `share` 命令组。
  - 这一版也明确了弃用项（计划 `v0.4.0` 移除），例如：
    - `Source.source_type` 改用 `.kind`
    - `Artifact.artifact_type` 改用 `.kind`
    - `Artifact.variant` 改用 `.kind`、`.is_quiz` 或 `.is_flashcards`
  - 简单说，这一阶段不仅加功能，还开始“清理 API 设计”，方便后续维护。

- 稳定性与跨平台修复：`v0.3.1` 到 `v0.3.2`
  - `v0.3.1` 主要处理稳定性问题，尤其是 Windows：
    - 修复 Windows 上 CLI 因 `asyncio ProactorEventLoop` 不兼容导致卡死。
    - 修复非英文 Windows 系统的 Unicode 编码报错。
    - 下载改为“流式下载 + 临时文件”，防止文件部分下载后损坏。
    - 所有 CLI 命令都支持 notebook、source、artifact 的“部分 ID 匹配”。
  - `v0.3.2` 继续补洞：
    - 修复切换 notebook 后 conversation ID 没有正确重置的问题。
    - 所有文件 I/O 显式使用 UTF-8 编码。
    - Windows 上恢复 Playwright 登录所需的 `ProactorEventLoop`。
  - 这两版整体是在为后续更复杂的 CLI 交互打基础。

- CLI 工作流明显增强：`v0.3.3`
  - `v0.3.3` 的重点是“让命令行操作更接近日常使用场景”。
  - 聊天与历史记录增强：
    - `ask --save-as-note`：可把问答结果直接保存成笔记。
      - 例如：`notebooklm ask "question" --save-as-note`
    - `history --save`：可把完整对话历史保存为笔记。
    - `history --show-all`：显示完整 Q&A，而不是只看预览。
  - 生成能力增强：
    - `generate report --append`：可在内置模板（如 `briefing-doc`、`study-guide`、`blog-post`）后追加自定义指令。
      - 例如：`--append "Target audience: beginners"`
    - `generate revise-slide`：可修改现有幻灯片中的单页内容。
  - 下载能力增强：
    - slide deck 支持下载为可编辑的 `pptx`，而网页 UI 只提供 PDF，这一点很实用。
  - 其他重要修复/改进：
    - 修复 `ask` 因 API 响应标记变化而返回空答案的问题。
    - 修复 X.com/Twitter 内容解析。
    - 登录后自动同步服务器语言设置到本地配置。
    - 增加对 Python `< 3.10` 的运行时检查，并给出清晰错误提示。
    - 对 `GET_NOTEBOOK` 和认证健康检查失败提供更明确的错误诊断。
    - 会话现在持久化到服务器端，`history` 输出会显示 conversation ID。

- 最新版本聚焦元数据、视频和易用性：`v0.3.4`
  - `v0.3.4` 继续扩展高层功能，重点是“元数据导出”和“新型生成内容”。
  - 元数据能力：
    - 新增 notebook 元数据 API 与 CLI 导出。
    - 新命令 `notebooklm metadata` 支持人类可读输出和 `--json`。
    - 新增公开类型：`NotebookMetadata`、`SourceSummary`。
    - 同时增加 `client.notebooks.get_metadata()` 辅助方法。
  - 新增视频与视觉样式能力：
    - 支持 “Cinematic Video Overview”，可生成并下载电影感视频。
      - 示例：`notebooklm generate video --format cinematic`
    - infographic 支持选择视觉风格。
  - 来源管理改进：
    - 增加按标题精确删除来源的命令，避免误删。
    - 改进 source delete 的歧义处理，以及“标题 vs ID”报错提示。
  - 稳定性方面也继续修复：
    - research 导入在超时时会自动重试并退避。
    - 修复 notebook summary 解析。
    - 下载空文件时不再生成 `0-byte` 文件，而是直接报错。
    - 支持用 `python -m notebooklm` 方式执行模块。
  - 文档也同步刷新，覆盖 release、CLI、README、Python API 和 `uv` 工作流。

- 整体趋势
  - 这个项目的演进可以概括为三条主线：
    - 功能不断扩展：从全文提取、引用追踪，到报告/测验/卡片下载，再到视频、信息图、元数据导出。
