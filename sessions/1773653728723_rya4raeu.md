#### ✨ 这是什么？

一个 **Claude Code Skill** ，让你用自然语言把 **任何内容** 变成 **任何格式** 。

```
你说：把这篇微信文章生成播客
AI ：✅ 8 分钟播客已生成 → podcast.mp3

你说：这本 EPUB 电子书做成思维导图
AI ：✅ 思维导图已生成 → mindmap.json

你说：这个 YouTube 视频做成 PPT
AI ：✅ 25 页 PPT 已生成 → slides.pdf
```

**原理** ：自动从多种来源获取内容 → 上传到 [Google NotebookLM](https://notebooklm.google.com/) → AI 生成你想要的格式

##### 📱 社交媒体

- **微信公众号** （绕过反爬虫）
- **YouTube 视频** （自动提取字幕）

##### 🌐 网页

- **任意网页** （新闻、博客、文档）
- **搜索关键词** （自动汇总结果）

- **Word** (.docx)
- **PowerPoint** (.pptx)
- **Excel** (.xlsx)

##### 📚 电子书与文档

- **PDF** （支持扫描件 OCR）
- **EPUB** （电子书）
- **Markdown** (.md)

##### 🖼️ 图片与音频

- **图片** （JPEG/PNG/GIF，自动 OCR）
- **音频** （WAV/MP3，自动转录）

##### 📊 结构化数据

- **CSV/JSON/XML**
- **ZIP 压缩包** （批量处理）

**技术支持**: [Microsoft markitdown](https://github.com/microsoft/markitdown)

### 2026-03-16 09:33:44

这篇文章主要介绍了一个名为 `anything-to-notebooklm` 的 Claude Code Skill：它能把微信文章、网页、YouTube、PDF、EPUB、图片、音频等多种内容，自动转换成播客、PPT、思维导图、Quiz、报告等多种输出。核心卖点是“用自然语言下指令，全流程自动完成”。

- **它是什么**
  - 这是一个“多来源内容处理器”，目标是把“任何内容”变成“任何格式”。
  - 基本流程是：先自动获取内容，再上传到 Google NotebookLM，最后生成目标格式文件。
  - 项目原名是 `weixin-to-notebooklm`，后来升级并更名为 `anything-to-notebooklm`，能力从微信文章扩展到更多来源。

- **支持哪些输入来源**
  - 社交媒体：支持微信公众号（可绕过反爬虫）、YouTube 视频（自动提取字幕）。
  - 网页与搜索：支持任意网页、搜索关键词自动汇总。
  - 文档与电子书：支持 PDF、扫描件 OCR、EPUB、Markdown，以及 Office 文件如 `.docx`、`.pptx`、`.xlsx`。
  - 图片与音频：支持 JPEG/PNG/GIF 图片 OCR，也支持 WAV/MP3 自动转录。
  - 结构化数据与批量处理：支持 CSV/JSON/XML，以及 ZIP 压缩包批量处理。
  - 技术上依赖 `Microsoft markitdown`，因此能覆盖 15+ 文件格式。

- **能生成什么输出**
  - 播客：适合通勤收听，生成时间约 `2-5 分钟`。
  - PPT：适合团队分享，生成时间约 `1-3 分钟`。
  - 思维导图、Quiz、报告、信息图、闪卡、视频等也都支持。
  - 例如：
    - “生成播客”“做成音频” → 播客
    - “做成PPT”“生成幻灯片” → PPT
    - “画个思维导图” → 脑图
  - 特点是“完全自然语言”，不需要记命令。

- **使用方式与上手门槛**
  - 前置要求很低，只需要 `Python 3.9+` 和 `Git`。
  - 安装只需 3 步：克隆仓库、运行 `./install.sh`、按提示配置 MCP 并重启 Claude Code。
  - 作者强调“其他依赖可一键自动安装”。

- **文章给出的典型案例**
  - 微信文章转播客：
    - 自动抓取文章、上传 NotebookLM、生成播客；
    - 示例结果：`/tmp/article_podcast.mp3`，`8 分钟`，`12.3 MB`。
  - EPUB 电子书转 PPT：

    - 示例结果：`25 页 PPT`，文件 `3.8 MB`。
  - YouTube 视频转 Quiz：
    - 自动提取字幕并生成题目；
    - 示例结果：`15 道题`，其中 `10 道选择题 + 5 道简答题`。
  - 多源内容整合成报告：
    - 可把网页、视频、PDF 混合输入后统一分析；
    - 示例结果：`7 个章节` 的报告，大小 `15.2 KB`。
  - 扫描图片转文档：
    - 先 OCR 识别，再输出结构化文本；
    - 示例中识别准确率达到 `95%+`。

- **核心特性**
  - 智能识别：系统会自动判断输入类型，比如链接是微信、YouTube，还是本地 EPUB 文件，用户无需手动指定。
  - 全自动处理：从“获取内容”到“生成文件”是一条龙流程，步骤包括“输入 → 获取 → 转换 → 上传 → 生成 → 下载”。
  - 多源整合：可以把“文章 + 视频 + PDF + 搜索结果”组合成一份综合报告。
  - 本地优先：像微信文章这类敏感内容，先在本地通过 MCP 抓取和转换，再交给 NotebookLM。

- **技术架构与高级能力**
  - 架构上，Claude Code Skill 负责理解自然语言、识别内容类型、调用对应工具。

    - 该 Skill 本身采用 `MIT License`

    - 原始内容仍要遵守版权规定
    - 文中建议主要用于“个人学习研究”
  - MCP 的作用主要是处理微信公众号，因为微信有反爬虫；网页、YouTube、PDF 等并不依赖 MCP。
