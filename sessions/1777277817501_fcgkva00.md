- 框架成熟后，可以切换到 Sonnet、国内模型，甚至小模型；
- 在复杂 Agent 框架加持下，中等模型在大量任务中能接近顶级模型体验；
- 甚至 3B 端侧模型也能完成一些原本看似不可能的任务。

这意味着未来竞争不只是 “谁的模型更强”，还包括：  
**谁的 Agent 框架更能释放模型潜能。**

---

##### 5. 群体智能：Agent 框架迭代速度被极大提升

春节后，罗福莉推动团队强制使用 OpenClaw。她要求团队成员大量对话、公开在群里探索任务。

她认为这样做的原因是：

> 个人想象力有限，但群体使用会互相激发想象力。

团队成员在群里共同测试、改造、讨论 OpenClaw，形成了高频反馈和快速迭代：

- 不同人探索不同场景；
- 大家互相看到新的用法；
- 框架被多人共同改进；
- 几小时就能迭代一轮。

她认为，这种群体智能是 AGI 到来前的重要信号：  
**Agent 框架不是单点产品，而会在大规模使用中自我进化。**

---

##### 6. AI 研究方式被重塑：从串行变成并行

OpenClaw 给她最大的冲击之一，是研究效率的变化。

过去一个研究想法，从提出、写代码、设计评估到验证，可能需要数天到数周。  
现在 Agent 可以在一两个小时内完成大量初步工作。

更重要的是，研究流程可以从串行变成并行：

- 同时提出 10 个 idea；
- 分配给不同 sub-agent；
- 并行实现和验证；
- Agent 之间还能交叉检查；
- 最终快速判断哪些方向值得继续投入。

因此，未来研究竞争会更依赖两个能力：

1. **研究 taste**：能否提出正确问题；
2. **Agent 使用能力**：能否高效并行验证想法。

---

##### 7. 从 Chat 到 Agent：后训练范式必须迁移

罗福莉认为，大模型训练范式正在从 Chat 向 Agent 转移。

传统 Chat 训练主要优化对话能力；但 Agent 需要处理：

- 长程任务；
- 多轮交互；
- 工具调用；
- 复杂上下文；
- 用户环境；
- 任务状态；
- 记忆管理；
- 多智能体协作。

因此，模型的后训练要适配不同 Agent 框架，而不是只适配普通聊天。

她认为未来模型要在多个 Agent 框架下稳定表现，这会成为新的竞争关键。

---

##### 8. Code 为什么重要：它是长程任务和泛化能力的训练场

罗福莉解释，Code 之所以重要，不只是因为编程有价值，而是因为它天然适合训练长上下文和长程任务能力。

原因包括：

- 代码项目通常有大量文件依赖；
- 文件之间关系紧密；
- 软件开发任务需要规划、修改、测试、回顾；
- 代码数据比书籍数据更结构化；
- 更适合训练模型理解长上下文。

她认为：

> Code 是拉高模型上限的关键，其他领域训练则用于保证模型下限。

也就是说，软件工程任务可以训练模型的通用长程能力，然后再外延到金融、办公、研究、管理等其他复杂任务。

---

##### 9. 长上下文不是简单 “塞满 1M Token”

关于 1M 上下文，她认为真正难点不只是支持长度，而是稳定完成复杂任务。

现实中，很少有单一任务真正需要完整 1M token；更多是多个复杂任务、长期状态和历史信息共同存在。

她的观点是：

- 预训练阶段需要让模型具备长上下文基础能力；
- 后训练阶段用任务激活这种能力；
- 不一定每次训练都要跑满 1M token，因为成本和效率太低；
- 真正重要的是模型在长上下文环境下的稳定性。

她认为目前 Claude Opus / Sonnet 在 1M 上下文稳定性上领先明显。

---

##### 10. 生产力变化：2026 是 AI 真正改变工作方式的一年

罗福莉判断，2026 年会成为生产力转型之年。

变化不只是 “AI 更聪明”，而是：

- 个人研究效率被放大；
- 团队协作方式变化；
- Agent 成为工作流核心；
- 产品形态从 UI 驱动转向框架驱动；
- 模型和 Agent 框架共同进化；
- 组织内部会出现新的 AI 使用文化。

她特别强调，很多能力可以在一两个月内快速习得，因此：

> 环境比经验更重要。

谁更早进入高密度 AI 使用环境，谁就更容易获得认知和效率上的跃迁。

---

##### 11. 对产品经理的启发

###### 产品形态正在变化

未来 AI 产品不只是一个聊天框，而是一个能理解任务、管理记忆、调用工具、调度模型、持续进化的 Agent 系统。

###### 框架层价值上升

产品经理需要关注的不只是用户界面，而是：

- Agent 如何规划任务；
- 如何管理上下文；
- 如何调用模型；
- 如何沉淀用户记忆；
- 如何适配不同场景；
- 如何让用户和 Agent 共同进化。

###### 组织使用方式决定 AI 效果

AI 能力不只是工具能力，也取决于团队是否形成高频使用、公开交流、快速迭代的环境。

---

#### 总结

罗福莉的核心观点是：  
**AI 的竞争正在从 “模型能力竞争” 升级为 “模型 + Agent 框架 + 群体智能 + 后训练范式” 的系统竞争。**

OpenClaw 的意义，不在于它是一个更好看的 AI 产品，而在于它证明了：

> 一个开放、可改造、可自进化的 Agent 框架，可以显著改变模型能力边界，并重塑研究、产品和组织生产力。**2026 年，AI 真正进入 Agent 驱动的生产力变革阶段。**
