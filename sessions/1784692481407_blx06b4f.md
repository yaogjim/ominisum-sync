## 结构化（1）

### 2026-07-22 03:51:54

#### BaoCut：面向 Agent 的字幕转录、翻译与辅助剪辑工具

BaoCut 是一款**仅支持 Mac** 的 Agent Skill，通过命令行工具与图形界面配合，让 Codex、Claude Code 等 Agent 完成视频转录、字幕润色与翻译，并支持人工预览和二次编辑。它的定位不是独立的视频编辑 Agent，而是**帮助现有 Agent 进行视频处理的辅助 Skill**。

##### 核心功能

BaoCut 可围绕视频字幕完成以下任务：

- **视频转录**：将视频中的语音转换为字幕。
- **说话人识别**：识别转录内容中的不同 Speaker。
- **字幕润色**：纠正错别字，并清理口癖、重复表达等。
- **字幕翻译**：由 Agent 对转录结果进行翻译，质量较好。
- **简单视频剪辑**：根据转录文本删除口癖、重复片段等内容。

##### 主要解决的问题

以往 Agent 完成字幕转录和翻译后，用户往往缺少友好的界面来检查和修改结果。BaoCut 为 Agent 提供 CLI，并通过 Skill 告知其操作方法：

1. Agent 调用 CLI 转录视频；
2. 获取转录结果后进行润色和翻译；
3. 将处理进度实时同步到 GUI；
4. 用户在 GUI 中预览结果并进行人工编辑。

这种方式兼顾了 Agent 自动处理的效率与人工校对的灵活性。

##### 使用方式

安装 BaoCut Skill 和 App 后，可在 Codex 或 Claude Code 等 Agent 中触发 Skill，例如：

```text
/baocut 转录并翻译视频：<视频 URL 或本地路径>
```

Skill 可以直接从 App 内安装，也可通过 GitHub 获取。

##### 当前限制

- **仅支持 Mac。**
- **翻译速度略慢**，但作者表示翻译质量较好。
- 存在系统兼容性问题的用户案例：有用户在 **macOS 15.7.3** 上下载 **1.7B Qwen 模型**后，新建转录并上传文件时崩溃。报错显示 `mlx.metallib` 面向 `macOS 26.0.0 / language version 4.0`，当前系统不支持。

##### 用户反馈与产品定位

- 有用户分享了类似方案：使用**火山引擎语音识别接口**快速生成字幕，再用 AI 校准，并通过 **Pi 框架**调用 AI；主要用于字幕校准、翻译和烧录。
- 作者回应称，Pi 虽然好用，但相对小众；BaoCut 的目标也并非打造完整的视频编辑 Agent，而是提供一个**辅助 Agent 编辑视频的 Skill**。
- 另有用户表示，经常使用作者此前开发的翻译 Skill。

##### 下载地址

- 官网：[https://baocut.app](https://baocut.app)
- GitHub：[https://github.com/jimliu/baocut](https://github.com/jimliu/baocut)

#### BaoCut：让 AI Agent 完成视频转录、翻译与基础剪辑

BaoCut 是一款仅支持 Mac 的视频处理工具。它通过 Agent Skill 将 Codex、Claude Code 等编程 Agent 与图形界面连接起来，让 AI 自动完成字幕转录、说话人识别、文本润色和翻译，并依据转录结果删除口癖、重复内容等，最后由用户在 GUI 中预览和二次编辑。

##### CLI 负责自动化，GUI 承接人工校对

BaoCut 试图解决一个常见问题：Agent 虽然能处理字幕，却缺少友好的结果编辑界面。其方案是向 Agent 提供 CLI 和 Skill：

- Agent 通过 CLI 执行转录、润色、翻译及简单剪辑；
- 处理进度实时同步到 BaoCut App；
- 用户在 GUI 中预览并手动修订结果。

安装 Skill 和 App 后，可用类似 `/baocut 转录并翻译视频：&lt;URL 或路径>` 的指令触发完整流程。作者特别强调，它不是独立的“视频编辑 Agent”，而是辅助现有 Agent 处理视频的 Skill。

##### 降低视频内容处理门槛，但仍有平台限制

这种“Agent 自动处理＋可视化人工确认”的模式，兼顾了自动化效率与字幕准确性，尤其适合访谈、教程和跨语言视频。目前产品仅支持 Mac；作者表示翻译速度偏慢，但质量较好。社区还有用户反馈，部分本地模型在旧版 macOS 上可能存在系统兼容问题，使用前需确认环境。App 可从 baocut.app 下载，Skill 已在 GitHub 开源。
