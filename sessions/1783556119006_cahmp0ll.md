## 结构化（1）

### 2026-07-23 10:06:09

##### 主旨概括

作者为 **pi** 开发了一个名为 **pi-cc-subagent** 的插件，目标是尽可能 **1:1 复刻 Claude Code 的 subagent（子智能体）机制**。该插件既提供内置子智能体，也支持自定义配置与独立工作环境。

##### 开发目标

- 借助 **Fable** 为 pi 编写 subagent 插件。
- 尽量还原 Claude Code 的 subagent 使用方式，让不同子智能体分工完成探索、规划和通用任务。

##### 核心功能

- 内置 3 类 subagent：
  - `explorer`：用于探索和检索信息。
  - `plan`：用于分析任务并制定计划。
  - `general-purpose`：用于处理通用任务。
- 支持通过 **Markdown（`.md`）文件**自定义 subagent。
- 支持 **Git worktree 隔离**：
  - 每个 subagent 可在独立工作环境中执行任务。
  - 不同 subagent 之间互不干扰，适合并行协作。

##### 安装与卸载

安装：

```bash
pi install git:https://github.com/linearuncle/pi-cc-subagent
```

卸载：

```bash
pi remove git:https://github.com/linearuncle/pi-cc-subagent
```
