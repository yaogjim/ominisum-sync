## 正文

Kept

##### Government vehicles

The photo and the plate are kept, and they become the public record. Public money, public roads, public vehicles.

Destroyed

##### Everybody else

The plate is destroyed on the camera itself, before anything leaves it. What reaches the server is an anonymous dot with no photo and no plate.

#### Running a camera

There is nothing to install and no account to make. It runs in a browser tab on a phone you have already stopped using, propped in a window.

The detection runs on the phone, not on a server. That matters more than it sounds: if the video were uploaded for a server to look at, there would be a video feed to intercept. There is not one.

- Works on an old phone, a laptop webcam, or a USB camera
- No account, no sign up, no app store
- Your camera's exact location is never published, only the street it watches
- You can shut it off and take your camera out of the network at any time

[Add a camera](https://map.sparrowmap.com/app) [View the live map](https://map.sparrowmap.com) [Read the code on GitHub](https://github.com/SparrowMap/sparrowmap) [Follow on Instagram](https://instagram.com/sparrowmap) Ask about running a camera

##### Already have cameras outside? (shops, workshops)

If a camera already watches the street outside your shop or house, it can feed the map without you buying anything or changing how it works. The video never leaves your network — only a crop of a vehicle, shrunk below the size a number plate can be read at.

- **Start here:**[Set up your camera](https://map.sparrowmap.com/IPCamera) — type your address, drop the pin, point the cone at the road. It gives you the camera id the app asks for.
- **Then run it:**[the IP camera app for Windows](https://map.sparrowmap.com/download) (76 MB), or [relay.py](https://map.sparrowmap.com/relay.py) on any machine with `pip install opencv-python onnxruntime numpy`
- Works with RTSP / ONVIF cameras — Hikvision, Dahua, Reolink, Axis, UniFi and most others
- No graphics card needed: the vehicle spotting is light, and deciding “patrol car or not” happens on our hardware, not yours

##### Want an always-on camera?

The other route, and the heavier one: a spare PC with a **webcam** running the full detector locally. It tells a patrol car from an ordinary one on the machine and reads plates, so nothing waits on us. One command sets it up and starts contributing to the map:

- **Windows:** run `irm https://sparrowmap.com/install-node-windows.ps1 | iex` in PowerShell, or download [SparrowMapCameraSetup.exe](https://github.com/SparrowMap/sparrowmap/releases/latest/download/SparrowMapCameraSetup.exe) ([verify the SHA-256](https://map.sparrowmap.com/checksums))
- **Linux** (help us test): `curl -fsSL https://sparrowmap.com/install-node-linux.sh | bash`
- Everything still runs on your machine — only detections leave it, never video
- **It is a big install:** about 2.5 GB of models, and it wants a PC left on, ideally with an NVIDIA card. If you already have an IP camera, the IP camera option above is far lighter.
- Full guide: [Running a desktop camera](https://github.com/SparrowMap/sparrowmap/blob/main/docs/DESKTOP_NODE.md)

## 结构化（1）

### 2026-08-17 05:17:46

#### SparrowMap 内容总结

SparrowMap 是一个由公众摄像头共同参与的政府巡逻车辆地图项目。其核心原则是：**保留政府车辆的照片和车牌作为公共记录，同时在数据离开设备前销毁普通车辆的照片与车牌信息，以降低隐私风险。**

##### 1. 政府车辆与普通车辆的处理方式

- **政府车辆**：保留车辆照片和车牌，并将其作为公共记录，理由是这些车辆由公共资金购买并行驶在公共道路上。
- **其他普通车辆**：车牌信息会直接在摄像设备上被销毁，数据离开设备前照片也不再保留。
- 服务器最终收到的只是一个**匿名位置点**，不包含可识别的照片或车牌。

##### 2. 用旧设备运行摄像头

- 无需安装软件、注册账号或通过应用商店下载 App。
- 可直接在浏览器标签页中运行，适合使用闲置手机并将其固定在窗边。
- 也支持：
  - 旧手机
  - 笔记本电脑摄像头
  - USB 摄像头
- 车辆识别在本地设备上完成，**不会把视频上传到服务器分析**，因此不存在可被截取的实时视频流。

同时，平台不会公开摄像头的精确位置，只显示其观察的街道；用户可以随时关闭设备并退出网络。

##### 3. 接入已有的店铺或住宅摄像头

如果商店、工作室或住宅已有面向街道的摄像头，可以直接接入 SparrowMap：

- 无需购买新设备，也不必改变摄像头原有工作方式。
- 视频始终留在用户自己的网络中。
- 对外仅发送车辆局部截图，而且会缩小到**无法读取车牌**的尺寸。

设置时，用户需要输入地址、在地图上放置位置标记，并调整视角范围指向道路，系统随后会生成摄像头 ID。

##### 4. IP 摄像头接入方案

平台提供两种运行方式：

- Windows IP 摄像头应用，大小约 **76 MB**。
- 在支持 Python 的设备上运行 `relay.py`，需要安装：
  - `opencv-python`
  - `onnxruntime`
  - `numpy`

该方案支持 RTSP／ONVIF 摄像头，包括 Hikvision（海康威视）、Dahua（大华）、Reolink、Axis、UniFi 等多数品牌。

本地设备只需完成较轻量的车辆发现任务，判断车辆是否为巡逻车的工作由 SparrowMap 的硬件处理，因此**不需要显卡**。

##### 5. 始终在线的完整本地识别方案

如果希望摄像头持续运行，可以使用一台闲置电脑搭配摄像头，在本地运行完整检测器：

- 在电脑上区分巡逻车与普通车辆。
- 在本地读取车牌，不依赖服务器等待处理。
- 视频不会离开本机，只有检测结果会上传。

安装方式包括：

```powershell
# Windows PowerShell
irm https://sparrowmap.com/install-node-windows.ps1 | iex
```

也可以下载 `SparrowMapCameraSetup.exe`，并核对其 SHA-256 校验值。

```bash
# Linux（测试版本）
curl -fsSL https://sparrowmap.com/install-node-linux.sh | bash
```

该方案负担较重：

- 模型安装包约 **2.5 GB**。
- 需要一台长期保持开机的电脑。
- 最好配备 NVIDIA 显卡。
- 如果已有 IP 摄像头，前述 IP 摄像头方案会更轻量、更适合日常使用。

## 通俗精炼（1）

### 2026-09-18 10:40:56

#### SparrowMap：用闲置摄像头众包记录政府车辆

SparrowMap 是一个公众协作的车辆地图：用户可用旧手机、电脑或现有监控摄像头识别街上的政府或巡逻车辆，并将记录汇入公开地图。其核心设计是尽量在设备端处理影像，只保留政府车辆信息，降低对普通人的监控风险。

##### 政府车辆留档，其他车辆即时匿名化

平台称，识别到政府车辆后，会保留照片和车牌作为公共记录，理由是“公共资金、公共道路、公共车辆”。对于其他车辆，车牌会在摄像设备上销毁；服务器只收到不含照片和车牌的匿名位置点。摄像头精确地址也不公开，只展示其监测的街道。

##### 通过边缘计算避免上传连续视频

最简单的方式是在旧手机浏览器中运行，无需账户、安装应用或经过应用商店。检测在手机本地完成，因此不存在持续上传、可能被截获的视频流，用户也能随时退出网络。

已有 RTSP/ONVIF 监控设备的商店或住宅也可接入。视频不离开本地网络，只发送缩小到无法辨认车牌的车辆截图，由 SparrowMap 服务器判断是否为巡逻车。

##### 隐私与部署成本之间存在取舍

若希望完全本地识别，可让闲置电脑运行完整模型，在设备上区分巡逻车、读取车牌，仅上传检测结果。但该方案需下载约 2.5GB 模型、保持电脑常开，最好配备 NVIDIA 显卡；相比之下，接入现有 IP 摄像头更轻量。

这一项目体现了“端侧识别、最小化上传”的隐私架构，也将公共监督能力分散给普通用户；不过相关隐私保障目前主要基于平台自身的技术说明与开源代码。
