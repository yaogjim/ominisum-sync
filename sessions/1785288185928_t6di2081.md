## 通俗精炼（1）

### 2026-07-29 01:20:25

#### Bento/Slides：把演示文稿与编辑器装进一个 HTML 文件

##### 一句话概括

Bento/Slides 是一款“文件即软件”的演示工具：一个 HTML 文件同时包含幻灯片、播放器、演讲者视图和编辑器，无需安装、注册或依赖服务器。

##### 核心特点

- **单文件交付**：内容、编辑器、图片、字体和交互能力全部嵌入一个 HTML 文件。
- **随处打开**：浏览器就是运行环境，文件可直接发送、保存和长期持有。
- **原地编辑与保存**：按 `Esc` 进入编辑器，按 `⌘S` 将修改写回当前文件。
- **数据透明**：演示内容以 JSON 形式存储，可通过查看源代码直接读取。
- **可选自动更新**：启动时可检查签名更新清单，也可以关闭该功能。

##### 演示与交互能力

- 支持柱状图、饼图、散点图等动态图表，并能在同一图表元素中平滑变形。
- 图表支持悬停提示、滚动或捏合缩放。
- 可制作路径动画，引导观众视觉注意力。
- 支持将普通幻灯片连接成多个交互场景，形成可点击的故事流程。
- 内置演讲者视图，适合现场展示。

##### 编辑体验

支持 Markdown 式输入，可快速生成：

- 加粗、斜体
- 项目符号
- 行内代码
- 删除线

##### 产品理念

Bento/Slides 的核心价值是减少软件依赖：**没有安装包、账号和服务器，一个文件即可完整承载内容、工具与交互，并真正归用户永久所有。**

## 结构化（1）

### 2026-07-30 09:21:27

#### Bento Slides 内容总结

Bento Slides 的核心理念是：**“文件本身就是软件”**。一个 HTML 文件同时包含演示文稿、播放器和编辑器，无需安装、注册或依赖服务器，使用浏览器即可随时打开、编辑和分享。

##### 1. 一个文件包含全部功能

- 整套幻灯片以**单个 HTML 文件**存在，其中包括：
  - 以 `&lt;script>` 中 JSON 形式保存的演示内容；
  - 播放器、演讲者视图、图表与变形动画；
  - 完整编辑器，按 **Esc** 即可进入；
  - 内嵌的图片和字体，无需额外资源文件。
- 按 **⌘S** 可将修改直接写回当前 HTML 文件，实现“自我保存”。
- 无需安装软件或创建账号，浏览器就是运行环境。
- 文件源代码公开透明，内容是可读的 JSON。
- 启动时可检查经过签名的更新清单，并自动更新自身；用户也可以关闭此功能。
- 常用操作包括：
  - 方向键：切换幻灯片；
  - **Esc**：进入编辑模式；
  - **S**：打开演讲者视图。

##### 2. 无依赖、永久可控

Bento Slides 强调“没有易损的活动部件”：

- **1 个文件**即可发送；
- **0 台服务器**是必需的；
- 文件内容 **100% 永久归用户所有**。

因此，它不会因服务关闭、账号失效或软件过期而无法使用。

##### 3. 支持实时交互与图表变形

同一份数据可以在一个图表元素中切换多种展示形式：

- **柱状图**：展示周一至周五的 Views 与 Edits 数据；
  - 鼠标悬停可查看实时提示；
  - 可在图表内部滚动或双指缩放数据。
- **饼图**：同一数据原地变形，比例分别为：
  - 周一 **13%**
  - 周二 **21.1%**
  - 周三 **16.7%**
  - 周四 **26.6%**
  - 周五 **22.6%**
- **散点图**：继续使用同一个图表元素展示活动数据；
  - 横轴为覆盖范围；
  - 纵轴为互动度；
  - 每个点代表一个营销活动，并区分 **Owned** 与 **Paid**。

其中，饼图等内容可以设置为“隐藏状态”：方向键会跳过，只有点击指定链接时才会进入，从而支持非线性交互演示。

##### 4. 用数据增强叙事

Bento Slides 可通过图表和动画突出趋势，例如：

- 使用 1 月至 12 月的趋势图展示增长过程；
- 重点强调 **+975%** 的增长结果；
- 让数据变化成为故事的一部分，而不只是静态数字。

##### 5. 用运动路径引导视线

- 支持在画布上编辑路径动画，例如让内容依次经过：
  **DRAFTED（起草）→ REVIEWED（审核）→ SHIPPED（发布）**。
- 用户可直接拖动路径锚点，动画轨迹会随之调整。
- 这种运动效果可以引导演讲时的视觉焦点和叙事顺序。

##### 6. 用普通幻灯片构建交互场景

同一组元素可以组织成三个不同场景：

1. 整齐网格；
2. 松散瀑布式排列；
3. 数据“天际线”布局。

每个场景本质上都是一张普通幻灯片，只需重新排列元素并给按钮添加链接，即可实现“播放下一场景”或“返回第一场景”等交互，无需额外编程。

##### 7. Markdown 输入与即时排版

编辑器支持边输入边格式化，例如：

- `**instant**`：粗体；
- `*formatting*`：斜体；
- `- bullets`：自动生成项目符号；
- `` `code` ``：代码样式；
- `~~strike~~`：删除线；
- 也可使用 **⌘B** 快速加粗。

这使用户可以像写 Markdown 一样快速完成排版。

##### 8. 直接开始编辑

当前演示文稿本身就是 Bento Slides 编辑器的副本。用户只需按 **Esc**，便可立即修改内容并将其保存为自己的单文件演示文稿。
