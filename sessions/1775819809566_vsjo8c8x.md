公众号专用抓取借口（免费）：  
（1）先拿到公众号文章链接  
比如：  
[https://mp.weixin.qq.com/s/CljajqS3x3ETOe4tPubQzw…](https://mp.weixin.qq.com/s/CljajqS3x3ETOe4tPubQzw)  
（2）把这个链接 URL 编码  
也就是把它转成这种形式：  
https%3A%2F%[http://2Fmp.weixin.qq.com](http://2Fmp.weixin.qq.com)%2Fs%2FCljajqS3x3ETOe4tPubQzw  
（3）调用一个第三方抓取接口  
curl -s "[https://down.mptext.top/api/public/v1/download?url=…](https://down.mptext.top/api/public/v1/download?url=)&amp;format=markdown"

3.小红书图文笔记

4\. 即刻文章  
1）jina，不能抓取到互动数据，免费  
2）camoufox，不能抓取到互动数据，免费  
3）xcrawl，能抓取到互动数据，免费  
4）curl + 解析，能抓取到互动数据，免费

5.抖音视频

2\. 访问抖音页面 — page.goto(url) 加载页面，此时浏览器执行 JS、生成  
msToken 和 X-Bogus 签名，所有加密参数自动搞定  
3\. 拦截 aweme/detail API 响应 — 用 page.on('response')  
监听网络响应，当抖音的详情 API 返回时，直接把 JSON 响应体拿下来  
4\. 从 JSON 中提取视频直链 — play\_addr.url\_list\[0\] 就是无水印 MP4 链接  
5\. 用 requests 下载 — 带上 Referer: [https://douyin.com](https://douyin.com)

## 结构化（1）

### 2026-04-10 11:16:49

#### 文章主旨

这篇文章主要在汇总：如何用`Claude Code`或`Openclaw`抓取多个平台的文章、图片和视频内容。核心卖点是：**大多数方案免费、且不需要自己提供 token**，尽量用 “更安全、门槛更低” 的方式完成抓取。

#### 1. 整体思路：按平台选择不同抓取方案

- 作者不是推荐一个通用工具，而是按不同平台分别给出可行方法。
- 覆盖的平台包括：`X（推文、长文、书签）`、`公众号`、`小红书`、`即刻`、`抖音`。
- 共同特点是：
  - 尽量免费；
  - 不依赖个人 token；
  - 优先使用网页解析、第三方接口或浏览器自动化。

#### 2. X 平台：推文、长文章和书签分别处理

- **推文和长文章**：作者推荐用`nitter + xcrawl`。
  - `nitter`提供静态页面；
  - `xcrawl`负责抓取数据。
- **书签内容抓取**：推荐`fieldtheory`，同样标注为免费。
- 文中还引用了一条推文，强调一个实际痛点：
  - 过去 Agent 很难抓到**X 长文章的完整正文 + 互动数据**；
  - 这对做自媒体的人很重要，因为他们经常在 X、抖音、小红书上看到爆款内容，但 “收藏后不再看” 是普遍问题。

**例子：**
- 如果只是普通推文，可以用静态页面抓正文；
- 如果是长文章或带互动信息的内容，就需要更适合结构化提取的工具链，比如`xcrawl`。

#### 3. 公众号文章：通过文章链接 + 编码 + 第三方接口获取

作者给出的公众号抓取流程比较明确，分为 3 步：

- **第一步：拿到公众号文章原始链接**
  - 示例链接：
    `https://mp.weixin.qq.com/s/CljajqS3x3ETOe4tPubQzw`
- **第二步：对链接做 URL 编码**
  - 即把原链接转成类似：
    `https%3A%2F%2Fmp.weixin.qq.com%2Fs%2FCljajqS3x3ETOe4tPubQzw`
- **第三步：调用第三方接口抓取**
  - 示例接口：
    `https://down.mptext.top/api/public/v1/download?url=&lt;URL_ENCODED_LINK>&format=markdown`

关键点是：

- 这个方案适合把公众号文章转成`markdown`；
- 对用户来说，操作门槛不高，重点在于先拿链接、再编码、再请求接口。

#### 4. 小红书图文笔记：从网页 HTML 里提取结构化数据

- 小红书方案的核心不是直接调接口，而是**解析网页本身**。
- 原文给出的处理流程是：
  - 先抓网页 HTML；
  - 先取`meta`信息；
  - 再解析`window.INITIAL_STATE`；
  - 从中拿到结构化的`note`数据；
  - 提取图片直链；
  - 必要时再对图片做视觉分析。
- 这个方案主要适合**图文笔记**，并且被标注为免费。

关键理解：

- `window.INITIAL_STATE`往往是页面初始化时写入的结构化数据；
- 比起只抓页面文字，这种方式更容易拿到完整笔记信息和图片链接。

#### 5. 即刻文章：多种方案对比，核心差别在 “能不能拿互动数据”

作者把即刻抓取方法分成了 4 类，并明确比较了是否能抓到互动数据：

- `jina`：免费，但**不能抓互动数据**
- `camoufox`：免费，但**不能抓互动数据**
- `xcrawl`：免费，**能抓互动数据**
- `curl + 解析`：免费，**能抓互动数据**

这里的重点不是 “能不能抓正文”，而是：

- 如果只看文章内容，`jina`、`camoufox`也许够用；
- 如果要看点赞、评论等互动信息，就更适合`xcrawl`或`curl + 解析`。

#### 6. 抖音视频：通过无头浏览器自动生成签名，再截取接口响应

抖音部分是全文里步骤最完整的一段，作者给出了 5 步流程：

- **1）启动无头 Chromium**
  - 模拟真实 Chrome 浏览器。
- **2）访问抖音页面**
  - 通过`page.goto (url)`加载页面；
  - 浏览器执行 JS，自动生成`msToken`和`X-Bogus`等加密参数。
- **3）拦截`aweme/detail` API 响应**
  - 用`page.on ('response')`监听网络响应；
  - 等详情 API 返回时，直接取 JSON。
- **4）从 JSON 提取视频直链**
  - `play_addr.url_list [0]`就是无水印`MP4`链接。
- **5）用 requests 下载**
  - 下载时带上`Referer: https://douyin.com`，模拟浏览器来源。

关键点：

- 难点不在 “下载视频”，而在于**页面加载时自动生成签名参数**；
- 用无头浏览器可以绕过手动计算签名的麻烦；
- 最终目标是直接拿到 JSON 里的无水印视频链接。

#### 7. 文中的用户反馈与补充信息

原文还附带了 5 条热门回复，反映出读者关注点主要集中在 “效率” 和 “批量抓取”：

- 一条热门回复提到：给`Claude Code`加 “永久记忆” 后，**每次 session Token 消耗减少 95%**，并称**48 小时达到 46k**。
- 作者本人在回复中提到：
  - 如果要**批量抓取**，可以针对 “指定的 50 篇” 使用相应方案；
  - 说明这些方法不只是单篇抓取，也可能用于批量处理。
- 其他回复则提到可尝试：
  - `opencli`
  - `bb-browser`

这些回复说明，这篇内容的使用场景很明确：**帮助用户整理和二次利用收藏内容，而不是让收藏夹继续 “吃灰”。**

#### 总结

- 文章本质上是一份 “多平台抓取方法清单”，重点突出**免费、不用自己 token、按平台选工具**。
- 其中：
  - `X`侧重推文、长文和书签分开处理；
  - `公众号`依赖 “链接编码 + 第三方接口”；
  - `小红书`依赖 HTML 和页面初始化数据解析；
  - `即刻`重点比较是否支持互动数据；
  - `抖音`则主要靠无头浏览器拦截接口响应拿视频直链。
- 文中最有价值的信息是：**不同平台的难点不同，抓取方法也要对应调整，尤其是互动数据、签名参数和结构化页面数据这三类问题。**
