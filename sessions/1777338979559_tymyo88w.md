#### Key Takeaways

- 运行未使用预定义类别的 Insights Agent 揭示了 Credit Genie 未曾预料到的情况：大量进入 AskGenie 的客户支持请求，而这是他们现有的支持聊天机器人未能覆盖的缺口。

#### 从 Insight Agent 的报告中检测功能缺口

有趣的是，Insights Agent 的无约束 V2 配置也生成了四个类别。这些自动生成的类别让我们对用户与 AskGenie 的交互有了更细致的理解。

虽然我们原本预期客户会与 AskGenie 互动以探索他们的财务状况（正如“财务洞察”板块所显示的），但结果也显示出大量的客户支持问题。这是我们未曾预料到的，特别是考虑到 Credit Genie 移动应用已经提供了一个独立的客户支持聊天机器人。

对这些集群的深入分析表明，一些客户会联系 AskGenie，修改他们从 Credit Genie 获得的现金预支的还款日期。事实上，V1 配置的结果将“Repayment Date Modifications”作为一个相关的子集群浮现出来，而 V2 配置的结果则包含了一个类似的“Repayment Date Modification Requests”子集群。

此外，我们了解到用户经常要求查看他们的现金预支状态和余额（例如由“预支状态和跟踪”及“余额和费用问题”子分类所表明）。

这些对真实用户行为的洞察凸显了 AskGenie 能力中的一些不足：该助手应 1) 向客户提供关于其现金预支的信息，以及 2) 使其能够更新还款日期。

#### Closing the gaps

基于我们从 Insights Agent 中学到的内容，我们通过添加一个用于检索用户的获批现金预支金额、现金预支的预计到账日期、计划还款日期以及用户的现金预支历史的工具，改进了 AskGenie。

我们还对 AskGenie 进行了扩展，允许客户直接从聊天界面修改还款日期或申请新的现金贷款。

最终，我们没有将用户重新引导至单独的支持机器人，而是引入了一个聊天内弹出窗口，允许客户在不离开 AskGenie 的情况下提交支持请求。

#### 将 Insights Agent 纳入 Credit Genie 的 AI 开发流程

在 Credit Genie，Insights Agent 已成为我们大规模解读客户反馈、向产品团队传达这些反馈并迭代改进我们的 AI 产品的不可或缺的一部分。

对于 AskGenie，我们现在每周定期运行 Insights Agent，以观察用户行为的变化或新兴趋势并相应地做出反应。这有助于我们加快产品构思、实验和优化的周期。

## 通俗精炼（1）

### 2026-04-28 01:16:19

#### Credit Genie 如何用 Insights Agent 改进 AI 金融助手

##### 一句话总结

Credit Genie 通过 Insights Agent 分析用户与 AI 金融助手 AskGenie 的真实对话，发现大量未被覆盖的用户需求，并据此补齐功能缺口，将 AI 助手从 “财务问答工具” 升级为更完整的金融服务入口。

##### 核心背景

Credit Genie 是一个移动优先的金融健康平台，提供现金预支、信用建设和个性化财务洞察服务。

他们在 App 中推出了 AI 金融助手 AskGenie，希望帮助用户理解财务状况、获取个性化建议。但上线后，团队需要知道：用户到底在 AskGenie 里问什么？产品是否真正满足了需求？

##### Insights Agent 做了什么

Credit Genie 使用 Insights Agent 对大量用户对话进行聚类分析。

有两种分析方式：

- **预定义分类 V1**：按团队事先设定的类别分析。
- **自动生成分类 V2**：不预设类别，让系统从真实对话中自动发现主题。

结果显示，用户并不只是询问财务建议，还大量把 AskGenie 当作客服入口使用。

##### 关键发现

Insights Agent 自动识别出几个高频需求：

- **还款管理**：用户想修改现金预支的还款日期。
- **现金预支状态查询**：用户想知道预支金额、到账时间、余额和费用。
- **产品与功能问题**：用户希望了解或申请新的现金预支。
- **支持请求**：用户直接在 AskGenie 中寻求客服帮助。

这说明，虽然 Credit Genie 已有独立客服机器人，但用户更倾向于在当前 AI 助手中完成问题解决，而不是跳转到另一个入口。

##### 产品改进动作

基于 Insights Agent 的发现，Credit Genie 对 AskGenie 做了三类升级：

###### 1. 增加现金预支查询能力

AskGenie 可以查询：

- 获批现金预支金额
- 预计到账日期
- 计划还款日期
- 历史现金预支记录

###### 2. 支持直接操作

用户可以在聊天中：

- 修改还款日期
- 申请新的现金预支

这让 AskGenie 从 “回答问题” 变成 “完成任务”。

###### 3. 引入聊天内支持请求

用户无需跳转到独立客服机器人，可以直接在 AskGenie 内提交支持请求，减少体验割裂。

##### 对产品团队的启发

###### 用户行为比产品假设更重要

团队原本以为用户主要会问财务洞察问题，但真实数据表明，大量用户把 AI 助手当作服务入口。

###### AI 对话数据是产品发现工具

Insights Agent 不只是监控工具，更像是一个持续的用户研究系统。它能从对话中发现未满足需求，并直接转化为功能路线图。

###### AI 产品需要持续反馈闭环

Credit Genie 现在每周运行 Insights Agent，用来观察用户行为变化、新兴需求和功能缺口，从而加快产品迭代节奏。

##### 最终价值

Credit Genie 通过 Insights Agent 建立了一个持续反馈机制：

> 用户对话 → 自动聚类 → 发现需求 → 补齐功能 → 持续监测

这让 AskGenie 更贴近真实用户场景，也让 AI 金融助手从单点能力进化为更完整的金融服务体验。

## 结构化（1）

#### Credit Genie 如何用 Insights Agent 改进 AI 金融助手 AskGenie

Credit Genie 在移动应用中推出 AI 金融助手 AskGenie 后，使用 LangSmith Insights Agent 大规模分析用户对话，发现了产品功能缺口。通过这些洞察，团队补齐了现金预支查询、还款日期修改、站内客服提交等能力，并把 Insights Agent 纳入每周产品迭代流程。

---

##### 1. 推出 AI 金融助手 AskGenie

- Credit Genie 的目标是帮助用户更好地理解和管理个人财务。
- 团队使用**LangGraph**构建了**AskGenie**，并将其集成到 Credit Genie 移动 App 中。
- AskGenie 上线后，新的挑战变成：  
  **如何理解用户到底在和 AI 助手聊什么，以及哪些需求没有被满足。**
- 因此，团队开始分析 AskGenie 对应的**LangSmith traces（调用轨迹）**，并借助**Insights Agent**做规模化分析。

---

##### 2. Insights Agent 发现了意料之外的用户需求

Insights Agent 的重要价值在于：不只做系统观测，还能帮助发现产品机会。

###### 两种分类方式的结果对比

文章中提到，团队使用了两种配置：

| 分类方式 | 类别 | 占比 |
|---|---:|---:|
| 预设分类 V1 | Customer Support 客服支持 | 36% |
| 预设分类 V1 | Financial Insights 财务洞察 | 30% |
| 预设分类 V1 | Product & Features 产品与功能 | 25% |
| 预设分类 V1 | Policy & Compliance 政策与合规 | 9% |
| 自动生成分类 V2 | Repayment Management 还款管理 | 33% |
| 自动生成分类 V2 | Financial Insights 财务洞察 | 30% |
| 自动生成分类 V2 | Advance Acquisition 现金预支获取 | 27% |
| 自动生成分类 V2 | Access Barriers 访问障碍 | 10% |

###### 关键发现

- 团队原本预期用户会用 AskGenie 了解财务状况，对应**Financial Insights，占比 30%**。
- 但结果显示，大量用户把 AskGenie 当成客服入口：
  - V1 中**Customer Support 占 36%**。
  - 这让团队感到意外，因为 App 内已经有单独的客服聊天机器人。
- 进一步分析后发现，用户经常提出这些需求：
  - 修改现金预支的还款日期；
  - 查询现金预支状态；
  - 查询余额和费用；
  - 跟踪现金预支到账情况。

---

##### 3. 从用户行为中定位 AskGenie 的功能缺口

Insights Agent 自动聚类出的用户问题，直接暴露了 AskGenie 的能力不足。

###### 具体缺口

- 用户希望 AskGenie 能提供现金预支相关信息，例如：
  - 已批准的现金预支金额；
  - 预计到账日期；
  - 当前还款日期；
  - 历史现金预支记录。
- 用户还希望直接在聊天中完成操作，例如：
  - 修改还款日期；
  - 申请新的现金预支；
  - 提交客服请求。

换句话说，用户并不只是想 “咨询”，还希望 AskGenie 能直接 “办事”。

---

##### 4. 根据洞察补齐产品能力

基于 Insights Agent 的分析结果，Credit Genie 对 AskGenie 做了几项改进。

###### 新增现金预支信息查询工具

AskGenie 现在可以帮助用户查询：

- 已批准的现金预支金额；
- 现金预支预计到账时间；
- 计划还款日期；
- 用户过往现金预支记录。

###### 支持在聊天中完成操作

团队还扩展了 AskGenie 的能力，让用户可以直接在聊天界面中：

- 修改还款日期；
- 申请新的现金预支。

###### 优化客服体验

- 过去可能需要把用户转到单独的客服机器人。
- 改进后，AskGenie 内新增了**站内弹窗**，用户可以不离开当前聊天界面，直接提交客服请求。

---

##### 5. 将 Insights Agent 纳入持续迭代流程

Credit Genie 没有把 Insights Agent 当成一次性审计工具，而是将其变成持续反馈机制。

###### 当前做法

- 团队每周定期运行 Insights Agent。
- 用它观察用户行为是否出现变化，识别新的趋势或需求。
- 分析结果会反馈给产品团队，用于后续产品规划和实验。

###### 带来的价值

- 更快发现用户真实需求；
- 更早捕捉行为变化；
- 缩短产品创意、实验和优化的周期；
- 让 AI 产品迭代更加贴近用户实际使用场景。

---

##### 6. 关于 Credit Genie

- Credit Genie 是一个移动优先的金融健康平台。
- 它通过 AI 提供个性化金融洞察。
- 平台还提供即时现金访问、信用建设等工具和服务。
- 其长期目标是帮助用户获得更稳定的财务未来。
