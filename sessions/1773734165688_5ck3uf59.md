- Skill 文件可审查也可复制，导致付费意愿和支付转化极低

**Leo**

### 调研了 12 个 AI Skill 平台，只有一种模式能赚钱

先说结论：卖 Skill 文件不赚钱，卖 API 服务才有壁垒。

我自己有几十个 Skill，挑了几个上架测试，也把市面上能找到的变现平台全试了一遍。下面是数据。

---

#### Skill 就是一段文本，复制粘贴就拿走了

这是整篇文章最核心的一个矛盾：

ClawHub 上的 Skill 本质是 markdown 文件。用户安装前会看源码（出于安全考虑），看完就能自己复制一份。

想收费，得先让人信任 Skill 是安全的 → 开源代码供审查 → 用户看完直接去 GitHub 拿免费版 → 没人付费。

App Store 的 app 是编译后的二进制文件，你拿不走源码。Skill 不一样 — 它就是一段文本，复制粘贴就拿走了。

---

#### 1,352 次下载，收入 $0

在 ClawHub 上架了三个免费 Skill 做测试（基于 MIT 开源协议，有自建的也有基于开源项目二创的）：

Systematic Debugging（调试框架）— 下载 1,352 次，实际安装 10 个，收入 $0

Humanizer（AI 文本去痕）— 下载 118 次，实际安装 0 个，收入 $0

Content Pipeline（内容生产线）— 下载 121 次，实际安装 0 个，收入 $0

1,352 次下载看着还行，但实际安装只有 10 个。转化率 0.74%。

作为对比，同类竞品 debug-pro 早我五周上架，下载 12,950 次，安装 112 个，转化率 0.86%。跟我的差不多 — 大部分下载可能来自爬虫和索引，真人安装不到 1%。

#### 赚到钱的，没几个是靠卖 Skill

据我观察，赚钱的是三类人，但没有一类是"Skill 创作者"：

平台方。ClawHub 生态头部应用 OpenClaw Pro、Donely 月流水都在数万美元级别。他们卖的不是单个 Skill，是整套解决方案。

服务商。帮企业装 OpenClaw、做定制 Agent 的人，根据公开分享的数据月入 $5K-12K。卖的是手艺和时间。

代币相关的早期参与者。SkillMarket 的 $SKILL、Claw Mart 的生态代币，早期参与者可能从代币增值中获益。但这不是 Skill 本身赚的钱。

没赚到钱的呢？一位创作者上架了 30+ 付费 Skill，总收入 $208。另一位做了多个产品，$0。我自己的测试也是 $0。这不是个例。

#### 用户拿到文件后还需不需要你

回到开头的结论。以下是我根据数据做的推测：

Skill-as-API。把能力包装成 API 按次收费，后端跑模型或数据处理。用户不需要装任何东西，调一次扣一次。壁垒在服务器和数据，不在代码文件本身。用户拿到你的 Skill 文件也没用，因为跑不起来 — 数据和算力在你那边。SkillMarket 的 x402 协议就是走这个方向。

垂直数据 Skill。通用 Skill（调试、格式化、写作辅助）壁垒接近零，谁都能写一个差不多的。但如果 Skill 依赖特定领域的数据 — 比如金融信号、行业报告、专有数据集 — 别人抄不走文件之外的东西。

企业定制。$3 的标准 Skill 很难形成可持续收入，$3K 的定制 Agent 解决方案可以。但这就从产品生意变成了服务生意，不可规模化。

---

#### 写在最后

AI Skill 市场像不像早期的 App Store？有点像 — 大量开发者涌入，平台方鼓励"人人都能赚钱"，但头部效应明显，大部分创作者颗粒无收。

如果你也在考虑 Skill 变现，建议先想清楚一个问题：你卖的东西，用户拿到文件后还需不需要你？如果不需要，那这个生意的天花板可能比你想象的低。

## 结构化（1）

### 2026-03-17 07:59:16

主旨很明确：作者调研并实测了 12 个 AI Skill 平台后认为，单卖 Skill 文件几乎不赚钱，因为内容可复制、缺少壁垒；真正能形成收入的，是把能力做成 API 服务，或绑定数据、定制化服务来卖。

- 第一部分：为什么“卖 Skill 文件”天然难赚钱
  - Skill 本质上就是一段文本/Markdown，用户安装前往往还能直接看到源码。
  - 这就带来一个核心矛盾：为了让用户信任安全性，创作者需要开放内容供审查；但一旦看见源码，用户就可能直接复制免费使用。
  - 这和 App Store 的二进制应用不同：App 源码拿不走，但 Skill 往往“看完就能复制”。

- 第二部分：作者自己的实测数据，验证了转化很差
  - 作者在 ClawHub 上架了 3 个免费 Skill 做测试，结果都是“有下载、没收入”：
  - `Systematic Debugging`：1,352 次下载，实际安装 10 个，收入 `$0`
  - `Humanizer`：118 次下载，实际安装 0 个，收入 `$0`
  - `Content Pipeline`：121 次下载，实际安装 0 个，收入 `$0`
  - 其中下载最多的 Skill，安装转化率只有 `0.74%`。
  - 对比竞品 `debug-pro`：上架早 5 周，12,950 次下载、112 个安装，转化率 `0.86%`，也很低。
  - 作者据此判断：大量“下载”可能来自爬虫或索引流量，真人安装不到 `1%`。

- 第三部分：真正赚到钱的，并不是普通 Skill 创作者
  - 作者观察到，赚钱的主要是 3 类人：
  - 平台方：例如 ClawHub 生态头部应用 `OpenClaw Pro`、`Donely`，月流水达到“数万美元级别”，卖的是整套方案，不是单个 Skill。
  - 服务商：帮企业部署 OpenClaw、定制 Agent，据公开分享月入约 `$5K-$12K`，本质是卖服务能力和交付时间。
  - 代币早期参与者：如 `SkillMarket` 的 `$SKILL`、`Claw Mart` 生态代币，可能靠代币升值获利，但这不等于 Skill 本身赚钱。
  - 反过来看，普通创作者收入很惨淡：有人上架 `30+` 个付费 Skill，总收入仅 `$208`；有人做了多个产品，收入仍是 `$0`；作者自己测试也是 `$0`。

- 第四部分：12 个平台的整体情况，说明这个市场仍很不稳定
  - 作者统计了 12 个平台，其中 `5 个已经打不开`，包括 `SkillPort`、`AgentPowers`、`JustSkillPay`、`Agent37`、`SkillDock`。
  - 仍在运行的平台包括：
  - `ClawHub`：官方 Skill 商店，`50%` 分成，生态月收入约 `$274K/月`
  - `skills.sh`：Vercel 官方目录，免费分发，`89,000+` 个 skill，头部 skill 有 `50万+` 安装
  - `SkillMarket`：API 按次收费，创作者分成 `70%`，有 `847` 个 skill，页面显示累计收益 `$3.4M`
  - `LarryBrain`：订阅制 `$29.99/月`，`50%` 分成，`134` 位订阅者
  - `Claw Mart`：创作者订阅 `$20/月`，5 周约 `$195K`
  - `ComposioHQ awesome-claude-skills`：GitHub `12K+ stars`，免费曝光
  - `skillsmp.com`：免费聚合器，仍属早期
  - 但作者特别提醒：`SkillMarket` 和 `Claw Mart` 的收入数据要打折看，因为平台跑在 Solana 上，流水里可能混有代币交易和投机成分，未必都是真实使用收入。

- 第五部分：作者给出的真正可行的 3 种变现方向
  - `Skill-as-API`
    - 把能力封装成 API，按次收费，后端模型、算力、数据都掌握在服务方手里。
    - 即使用户拿到 Skill 文件，也无法真正跑起来，因此壁垒在服务端，而不是文本本身。
    - 作者认为这是最有希望的一种模式，`SkillMarket` 的 `x402` 协议就在朝这个方向走。
  - `垂直数据 Skill`
    - 通用 Skill（如调试、写作辅助、格式化）几乎没有壁垒，别人很容易仿一个类似版本。
    - 但如果 Skill 依赖金融信号、行业报告、专有数据集等独家数据，那么别人复制走的只是“壳”，复制不走真正价值。
  - `企业定制`
    - 标准化 Skill 卖 `$3` 很难形成持续收入，但定制 Agent 解决方案卖 `$3K` 甚至更高是可能的。
    - 不过这已经不是标准产品逻辑，而是服务生意，收入更高，但难以规模化复制。

- 第六部分：作者的最终判断
  - AI Skill 市场有点像早期 App Store：平台会鼓励大家“人人都能赚钱”，也确实吸引了很多开发者进入。
  - 但现实是头部效应非常明显，大多数创作者几乎赚不到钱。
  - 作者给出的关键判断标准是：`用户拿到文件后，还需不需要你？`
  - 如果用户拿到文件后就不再需要你，那这个商业模式的上限通常会很低。
