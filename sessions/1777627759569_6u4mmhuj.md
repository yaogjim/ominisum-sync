## 正文

**陈成**

花了点时间把 Claude Code 的社区 Skills 生态摸了一遍，规模远超预期。整理一份信息密度拉满的盘点，建议收藏。

先说规模：最大社区市场 ClawHub 已有 52,700+ 工具、18 万用户、1200 万次下载。Anthropic 把 Skill 格式推成了开放标准 Agent Skills（[http://agentskills.io](http://agentskills.io)），GitHub Copilot、Cursor、Gemini CLI、OpenAI Codex、JetBrains Junie 等 35+ 工具已采纳。写一个 SKILL.md，到处能跑。

再说质量：有人把 ClawHub 上 13,729 个 skill 挨个过了一遍，只留下 5,211 个，淘汰率 62%——大量垃圾、重复和恶意内容。所以别盲目装，跟着社区精选清单走。

下面是我筛出来值得关注的 skills，按品类分：

Token 优化 → caveman（51K⭐）：让 Claude 像原始人说话，砍 65% 输出 token。社区最火单品，说明 token 成本是真痛点

规划与工程 → planning-with-files（20K⭐）：Manus 风格持久化 Markdown 规划流 → everything-claude-code（170K⭐）：Agent 调优全家桶——skills、instincts、memory、security → claude-code-best-practice（50K⭐）：从 vibe coding 到 agentic engineering 的方法论

研究与知识 → last30days（24K⭐）：跨 Reddit/X/YouTube/HN 等 10+ 来源的近 30 天深度研究 → graphify（39K⭐）：任意文件夹变可查询知识图谱 → codebase-to-course（4.2K⭐）：代码库变交互式 HTML 教程

浏览器 → dev-browser（6K⭐）：给 Agent 加浏览器能力 → playwright-skill（2.5K⭐）：Playwright 自动化

内容创作 → humanizer（16.6K⭐）：去除 AI 写作痕迹 → prompt-master（6.8K⭐）：为任意 AI 工具写精准 prompt → fireworks-tech-graph（5K⭐）：生产级 SVG 技术图表 → guizang-ppt（4.4K⭐）：杂志风 HTML 演示文稿 + WebGL

安全 → trailofbits/skills（4.9K⭐）：Trail of Bits 官方出品，智能合约审计 + 漏洞检测 → Claude-Red（1.1K⭐）：攻击性安全技能库 → android-reverse-engineering（5.4K⭐）：Android 逆向

插件（比 skill 更重的分发单元） → claude-mem（70K⭐）：自动捕获 session 历史，给 Claude 加持久记忆 → claude-hud（21K⭐）：实时显示 context 用量、活跃 Agent、todo 进度 → claude-octopus（3.2K⭐）：同一任务派给 8 个模型做盲点检测

大型 Skill 集合 → alirezarezvani/claude-skills（13K⭐）：235+ 生产级 skill，覆盖工程/营销/C-suite 等 9 个领域 → Jeffallan/claude-skills（8.7K⭐）：66 个全栈开发 skill → antigravity-awesome-skills（36K⭐）：1,400+ 可安装 skill + CLI

精选清单入口（从这里开始逛） → ComposioHQ/awesome-claude-skills（57K⭐） → hesreallyhim/awesome-claude-code（42K⭐） → VoltAgent/awesome-openclaw-skills（48K⭐）

一句话判断：Claude Code 的 skill 生态正在从「个人脚本」变成「跨工具标准化组件市场」。Agent Skills 开放标准是拐点——当你的 SKILL.md 能同时跑在 Claude Code、Copilot、Cursor、Codex 上时，skill 就不再是某个工具的附属品，而是独立的生产力资产。

## 通俗精炼（1）

### 2026-05-01 09:29:19

#### Claude Code Skills 生态盘点：从个人脚本到标准化组件市场

##### 核心结论

Claude Code 的社区 Skills 生态已经超出 “小众插件” 范畴，正在演化为一个跨 AI 编程工具的标准化组件市场。

关键变化是：Anthropic 推出了开放标准**Agent Skills**。未来一个`SKILL.md`不只服务 Claude Code，也可以运行在 GitHub Copilot、Cursor、Gemini CLI、OpenAI Codex、JetBrains Junie 等工具中。

这意味着 Skill 正在从 “某个工具的附属能力”，变成可复用、可分发、可交易的独立生产力资产。

---

##### 生态规模：已经形成市场雏形

目前最大的社区市场**ClawHub**已有：

- **52,700+ 工具**
- **18 万用户**
- **1200 万次下载**
- **35+ 主流 AI 工具采纳 Agent Skills 标准**

这说明 Claude Code Skills 不再只是开发者自娱自乐的脚本集合，而是具备了平台生态的雏形。

---

##### 质量问题：生态繁荣但鱼龙混杂

社区有人审查了 ClawHub 上**13,729 个 Skill**，最终只保留**5,211 个**，淘汰率高达**62%**。

主要问题包括：

- 重复内容多
- 低质量工具多
- 存在恶意或不安全内容
- 很多 Skill 只是简单包装，实用价值有限

所以作者建议：不要盲目安装，优先参考社区精选清单。

---

##### 值得关注的 Skill 类型

###### 1. Token 优化

代表工具：**caveman**

它让 Claude 用极简表达输出，最多可减少约 65% 的 token 消耗。

这类工具的火爆说明一个核心痛点：AI Agent 使用成本正在成为高频用户的关键约束。

---

###### 2. 规划与工程能力

代表工具包括：

- **planning-with-files**：用 Markdown 文件实现持久化规划流程，类似 Manus 的工作方式
- **everything-claude-code**：覆盖 skills、memory、security、agent 调优等完整工具包
- **claude-code-best-practice**：总结从 vibe coding 到 agentic engineering 的方法论

这类 Skill 的价值在于：让 AI 编程从 “临时对话” 变成 “结构化工程协作”。

---

###### 3. 研究与知识管理

代表工具包括：

- **last30days**：整合 Reddit、X、YouTube、HN 等来源，做近 30 天深度研究
- **graphify**：把任意文件夹转成可查询知识图谱
- **codebase-to-course**：把代码库转成互动式 HTML 教程

这些工具把 Agent 从 “代码生成器” 扩展为 “研究助理” 和 “知识组织者”。

---

###### 4. 浏览器与自动化

代表工具包括：

- **dev-browser**：为 Agent 增加浏览器能力
- **playwright-skill**：支持 Playwright 自动化操作

这类能力对网页测试、信息采集、自动化执行非常关键，是 Agent 从 “思考” 走向 “行动” 的基础设施。

---

###### 5. 内容创作

代表工具包括：

- **humanizer**：弱化 AI 写作痕迹
- **prompt-master**：为不同 AI 工具生成高质量 prompt
- **fireworks-tech-graph**：生成生产级 SVG 技术图表
- **guizang-ppt**：生成杂志风 HTML 演示文稿和 WebGL 内容

这类 Skill 说明 Claude Code 的使用场景已不局限于写代码，也在进入内容生产、表达设计和商业呈现领域。

---

###### 6. 安全方向

代表工具包括：

- **trailofbits/skills**：智能合约审计与漏洞检测
- **Claude-Red**：攻击性安全技能库
- **android-reverse-engineering**：Android 逆向工程

安全类 Skill 价值高，但风险也更大，尤其需要关注来源可信度和使用边界。

---

###### 7. 更重型的插件能力

除了 Skill，还有更复杂的插件形态，例如：

- **claude-mem**：自动记录 session 历史，为 Claude 增加持久记忆
- **claude-hud**：实时显示上下文用量、活跃 Agent、todo 进度
- **claude-octopus**：把同一任务分配给多个模型，进行盲点检测

这些更像是 “Agent 操作系统插件”，不仅增强某个任务，而是增强整体工作流。

---

##### 大型集合：生态入口正在形成

作者还推荐了一些大型 Skill 集合：

- **alirezarezvani/claude-skills**：235+ 生产级 Skill，覆盖工程、营销、管理等领域
- **Jeffallan/claude-skills**：66 个全栈开发 Skill
- **antigravity-awesome-skills**：1400+ 可安装 Skill 和 CLI 精选清单
- **ComposioHQ/awesome-claude-skills**
- **hesreallyhim/awesome-claude-code**
- **VoltAgent/awesome-openclaw-skills**

这些集合的作用类似早期 App Store 榜单，是普通用户进入生态的主要入口。

---

##### 产品与商业启示

###### 1. Skill 会成为 Agent 时代的 “应用形态”

过去 SaaS 是完整产品，插件是功能扩展；但在 Agent 时代，一个高质量 Skill 可能就是一个可复用的工作流产品。

###### 2. 标准化是生态爆发的前提

`SKILL.md`能跨 Claude Code、Cursor、Copilot、Codex 使用，降低了开发者分发成本，也扩大了用户市场。

标准一旦稳定，围绕 Skill 的市场、评价、分发、付费、权限、安全审核都会出现。

###### 3. 高质量精选和安全治理会成为核心基础设施

当前生态最大的问题不是数量不够，而是质量参差不齐。

未来真正有价值的平台能力可能包括：

- Skill 审核
- 安全扫描
- 权限管理
- 使用评分
- 企业白名单
- 付费分发
- 工作流模板市场

---

##### 一句话总结

Claude Code Skills 生态正在从零散的个人脚本，演变为跨工具、可复用、可分发的 Agent 组件市场；Agent Skills 开放标准可能是这一生态走向规模化的关键拐点。
