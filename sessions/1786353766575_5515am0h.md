#### Privacy &amp; Data

Nothing about your work is collected or sent anywhere. Your code and session content stay on your machine, and remote access can be protected when the workspace leaves localhost.

###### Code and sessions stay with you

Project names, paths, prompts, code, diffs, and session content are not collected by OpenChamber.

###### Remote access is protected

Browser access can be gated with a UI password, and tunnel links can be rotated or revoked when they should no longer work.

###### Private Relay, no open ports

Pair a device with a one-time QR code and connect through Private Relay without opening ports or exposing a public server. The connection is end-to-end encrypted and can be revoked at any time.

## 结构化（1）

### 2026-08-10 09:19:46

#### OpenChamber：面向 AI 编程的智能体开发环境

OpenChamber 是一款用于编排 AI 编程智能体的开发环境，能让智能体围绕目标持续工作，并支持多模型协作、代码审查、GitHub 工作流和自动化任务。它强调本地优先与隐私保护，项目代码、提示词及会话内容不会被平台收集。

##### 1. 持续执行目标

- 用户可以为会话设定明确的“终点”或目标。
- 智能体会一轮接一轮地持续推进任务，**即使应用已经关闭，也会继续朝目标工作**。
- 定时提示词可与“会话目标”结合，让智能体不只是定期执行命令，而是持续追求预设结果。

##### 2. 多模型并行协作

- 同一个任务最多可以同时交给 **5 个模型**处理。
- 用户既可以从多个结果中选择最佳方案，也可以融合各模型最优秀的部分。
- 这种方式适合比较不同实现思路，或综合多个模型在架构、编码和调试方面的优势。

##### 3. 更易理解和审查代码改动

- 面对规模较大的代码差异（diff），OpenChamber 会按执行顺序将其拆分成多个步骤。
- 每一步都会说明具体变更，以及该变更如何融入整体方案。
- 这有助于开发者快速理解修改逻辑，而不必直接阅读一整块复杂 diff。

##### 4. 从运行界面直接提供上下文

- 用户可以在正在运行的应用中直接指向某个界面元素。
- OpenChamber 会把该元素背后的相关信息一并发送给智能体。
- 例如，发现某个按钮样式或行为异常时，可直接选中它，让智能体获得对应上下文并进行修改。

##### 5. 集成 GitHub 开发流程

- 可以从 GitHub Issue 或 Pull Request 直接启动任务。
- CI 检查失败后，可将失败结果重新发送给智能体处理。
- 从问题定位、代码修改、检查修复到合并，都可以在 OpenChamber 中完成，无须频繁切换工具。

##### 6. 定时任务与移动端访问

- 支持通过 **Cron 定时计划**运行提示词，并可搭配会话目标实现持续自动化。
- 提供移动端界面，可查看：
  - 会话列表；
  - 对话内容；
  - 使用情况与额度限制。
- 适合远程查看智能体进度或管理正在执行的任务。

##### 7. 用户评价与使用体验

用户反馈主要集中在以下方面：

- 在 IDE、终端界面工具（TUI）之间反复切换后，有开发者认为 OpenChamber 找到了功能与体验之间的平衡点。
- 有用户称赞其界面完成度、流式输出效果和操作流畅度，认为项目在短时间内进步明显。
- 一些开发者将其与 **OpenCode、OhMyOpenCode** 组合使用，认为这套工具链让传统编辑器显得落后。
- 一位 DevOps 开发者表示，在尝试多种智能体编排工具后，OpenChamber 是唯一让他感觉“自然且符合逻辑”的产品。

##### 8. 隐私与数据保护

OpenChamber 强调代码和会话数据由用户掌控：

- **不收集工作内容**：项目名称、文件路径、提示词、代码、diff 和会话内容都不会被 OpenChamber 收集或上传。
- **数据保留在本机**：代码与会话内容存储于用户自己的设备。
- **远程访问可保护**：浏览器访问可设置界面密码；隧道链接可以轮换或撤销。
- **Private Relay 私密中继**：
  - 通过一次性二维码配对设备；
  - 无须开放端口或暴露公共服务器；
  - 连接采用端到端加密；
  - 用户可随时撤销连接权限。

##### 总结

OpenChamber 的核心价值是让 AI 编程智能体能够长期、自动、协同地完成开发任务，同时把多模型比较、代码审查、GitHub 流程和远程管理整合到一个环境中。其本地优先、端到端加密和不收集项目内容的设计，也使其更适合重视代码隐私的开发者与团队。
